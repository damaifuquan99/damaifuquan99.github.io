## 一、本讲定位

这一讲是"**器官发生**"的第一站，也是全课唯一一个把"**从一层细胞到一个有功能器官**"完整走完的章节。

它要回答四个层层递进的问题：

1. **外胚层怎么一分为二？** —— 一部分变皮肤，一部分变神经（神经诱导）
2. **神经板怎么卷成管？** —— 神经管形成（neurulation）
3. **管子怎么变成一个立体的脑和脊髓？** —— 沿**三个轴**分化
4. **神经元怎么找到自己的靶子并连上？** —— 轴突导向、突触形成、神经嵴迁移

> **考情提示**：2024 和 2025 连续两年简答都考了「**神经系统沿 AP、DV、内外（PD）三个轴线的分化**」。这是本讲唯一必须**默写**的框架，见 §五。

## 三、外胚层命运的决定：表皮 vs 神经

### 3.1 胚胎的三条路

原肠作用前，外胚层只有两种可能命运：**神经外胚层** neuroectoderm 与**表皮外胚层** epidermis。

### 3.2 一个关键的先决问题：外胚层的"预置命运"是什么？（p10）

这是本讲最值得想清楚的一个逻辑点。两种说法：

- **旧说**：外胚层预置命运是**神经**，需要被"诱导"成表皮
- **课件采纳的解释（p10–11）**：外胚层**预置命运是表皮**，需要被"诱导"成神经

**为什么这么定？** 因为——

> **BMP 信号是外胚层细胞向表皮细胞分化的关键信号**（p11）

三条证据：
1. 可能存在**母源 BMP** 信号
2. BMP 在囊胚后期呈现**腹部高、背部低**的浓度梯度
3. **BMP 信号维持表皮命运、抑制神经命运**；而来自组织中心的 **BMP 抑制因子（Chordin、Noggin、Follistatin）是神经系统发育所必需**

**推论（"神经诱导的默认模型"）**：

> 外胚层的**默认命运是神经**，BMP 把它"压"成表皮；组织者分泌 BMP 拮抗剂解除压制，背侧外胚层才成为神经。

⚠️ 注意两句话不矛盾：**"外胚层预置命运是表皮"说的是它需要 BMP 才能成表皮；"默认模型"说的是没有 BMP 时它会走向神经。** 考试时按课件 p11 的表述写：**BMP 维持表皮、抑制神经；组织者分泌拮抗剂解除抑制 → 神经。**

### 3.3 神经外胚层命运的决定发生在什么时候（p9）

**原肠作用期**。移植实验（p8）：把早期外胚层从背侧移到腹侧，它会跟着新位置变成表皮 → 说明此时尚未决定；到原肠作用期，命运才被"锁定"。

### 3.4 更上游：外胚层与中内胚层的分离（p5–7）

要成为神经，外胚层首先得**不被中内胚层化的信号拉走**：

- **Ectodermin / Tif1γ**：在爪蛙外胚层中表达，**抑制 TGF-β/Nodal 信号的 Smad4**，从而阻止外胚层被 Nodal 中内胚层化
- **xNorrin**：爪蛙外胚层表达，**同时拮抗 Nodal 和 BMP**，保护外胚层的"外胚层身份"

> 一句话：**外胚层要先"免疫"于 Nodal（不变中内胚层），再"局部解除" BMP（才能变神经）。** 两个信号都得管。

### 3.5 斑马鱼的神经诱导分子模型（p13）★

一张必须看懂的图，网络结构是：

```
腹部：BMP2/4/7 高 → p-Smad1/5/8 → 表皮
背部：母源 Huluwa → β-catenin → Chordin/Noggin/Follistatin（BMP 拮抗剂）
              ↑                    ↓
             Nodal ────────────→ 压制 BMP
              Fgf
              ADMP/Bmp（反向维持梯度）
```

> 注意 **Huluwa 又出现了**——从第 3 讲的"定背侧"一直贯通到本讲的"神经诱导"。这是老师课程的一条暗线。

## 四、神经外胚层的前后（A–P）分化

### 4.1 两个模型（p15）★

| 模型 | 主张 |
|---|---|
| **模型 I** | 先诱导**前端**神经外胚层，之后后部再被"后部化" |
| **模型 II** | 神经诱导与前后分化**同步**发生 |

**课件采纳的是模型 I 的变体**（p16 爪蟾）：

### 4.2 爪蟾的机制（p16）★

```
原肠早期：Chordin 等 BMP 拮抗剂 → 神经诱导
        → 神经板所有细胞先获得"前部"命运（前脑），表达前部标记
              ↓
原肠中后期/体节期：后部中胚层表达"后部化信号"
        （FGF、Wnt、RA 视黄酸）
        → 后部转化为中脑、后脑、脊髓命运，表达后部基因
              ↓
同时：前端中胚层/内胚层分泌 Dkk、Cerberus 等
        → 拮抗后部化信号 → 保证最前端保持"前部化"
```

**一句话**：**先全都当地前脑，再从后往前"退火"成前后有序的结构，同时前端被保护。**

### 4.3 斑马鱼与鸡（p17–19）

- **斑马鱼**：胚盾中母源 Hwa 激活的 β-catenin → 诱导 Chordin 等 → 背部外胚层获得**前部**命运；而胚盘侧部、后腹部的**合子 Wnt、Fgf、Bmp** → 附近外胚层获得**后部**命运
- **鸡**：Hensen's node 中 **Vg1 和 Wnt8c** 诱导 BMP 拮抗剂 → 附近外胚层获前部命运
- **鸡的后部神经由"干细胞区"产生**：Node 后退时，Node 处原条两侧的**干细胞区**随 Node 后退并扩增，部分细胞滞留 Node 前端形成脊髓。**哺乳类机制类似**

## 五、神经管的形成（neurulation）

### 5.1 两种方式（p21、p30）★

| | **初级神经管形成** primary | **次级神经管形成** secondary |
|---|---|---|
| **过程** | 神经板细胞增殖 → 侧翼抬升 → 向中线靠拢 → **闭合并离开表面** → 中空神经管 | 外胚层腹侧的**间质细胞聚集形成实心索** → 再**中空** |
| **分布** | 绝大多数脊椎动物的**前部**神经管 | 鸟类、哺乳类、两栖类的**尾部**神经管 |
| **典型** | 鸡、鼠、人前部 | 人/鸡/鼠的尾段 |

**术语**：神经管 neural tube 是中枢神经系统原基；形成过程叫 neurulation；该时期胚胎叫**神经胚 neurula**。

### 5.2 初级神经管形成的四步（p22–27）

1. **神经板** neural plate 形成（背部中间区）
2. **神经褶** neural fold：来自**脊索的 Shh** 锚定神经板中线细胞，两侧表皮细胞向中线汇聚，表皮与神经板交界处凸起
3. **抬升与靠拢**：神经板侧翼上抬、向中线移动
4. **闭合与分离**：与相邻表皮分离（**靠表达不同的细胞黏附分子 CAM**）

**神经嵴的位置**（p22，务必记）：**神经板与表皮外胚层的交界处**。

### 5.3 闭合顺序与缺陷（p27–29）★

- **鸡**：沿 A–P 轴**依次**闭合
- **人**：闭合**始于中段**（颈部），向头尾两端"拉链式"推进
- **缺陷**（人类最主要的先天畸形之一）：

| 封口失败位置 | 结果 |
|---|---|
| **第 2 区** | **无脑症** anencephaly（前脑不发育）→ 致死 |
| **第 5 区** | **脊柱裂** spina bifida |

- **必需因子**：Sonic Hedgehog、Pax3
- **预防**：孕妇补充**叶酸（维生素 B9）**与适量**胆固醇**可降低风险

> 这条是"发育生物学与医学"的最佳连接点，简答/论述都可能从这里切入。

### 5.4 斑马鱼的特殊方式（p32）

神经板向中心聚集时，**上皮细胞分裂，子细胞可穿越中线**；管腔形成方式类似**次级**神经管，但与羊膜动物的初级方式不同。→ **斑马鱼是"混合型"，答题时不要一刀切。**

## 六、神经管的三个轴分化 ★★★ 简答必背（连考两年）

课件 p33 直接给出三轴框架，这是本讲的"主答案"：

```
1. 前后轴线（A–P）→ 脑 vs 脊髓
2. 背腹轴线（D–V）→ 不同类型的神经元
3. 内外轴线（PD，顶端–基底）→ 神经干细胞、神经元、胶质细胞
```

### 6.1 前后轴（A–P）：脑的分区（p34–37）

从前往后：

| 脑泡 | English | 衍生物 |
|---|---|---|
| **端脑** | telencephalon | 大脑皮层、基底核 |
| **间脑** | diencephalon | 丘脑、下丘脑、视网膜 |
| **中脑** | mesencephalon | 视顶盖 |
| **后脑** | hindbrain（metencephalon + myelencephalon） | 小脑、脑桥、延髓 |
| **末脑** | myelencephalon | 延髓 |

**菱脑原节（rhombomeres，p36）**★：

- 后脑再分成多个**菱脑原节**，每个是一个**发育单位**
- **节内细胞可以移动，但不能跨节移动**（这是"隔间 compartment"的经典例子）
- 后脑产生控制**面颈部**的神经；其神经嵴细胞分化出**周边神经、面部骨骼与结缔组织**
- **Hox 基因表达谱决定各菱脑原节的特性**（p37）：从菱脑迁出的神经嵴进入**表达类似 Hox 的鳃弓** → Hox 代码决定"这根神经/这块骨属于第几鳃弓"

> 这里和第 4 讲的 **Hox 共线性**直接接上了：**同一套 Hox 基因，在果蝇管体节身份，在脊椎动物管菱脑和鳃弓身份。**

### 6.2 背腹轴（D–V）：神经元的类型（p43–47）★★

**两极信号**：

| 位置 | 信号 | 后果 |
|---|---|---|
| **腹侧（底板 floor plate + 脊索）** | **Shh** 浓度最高 | 运动神经元、腹侧中间神经元 |
| **背侧（顶板 roof plate + 表皮）** | **BMP / Wnt** 浓度最高 | 感觉神经元、背侧中间神经元 |

**Shh 梯度如何切分腹侧神经管**（p46–47）：

- Shh 从底板向外扩散形成**浓度梯度**
- 不同浓度阈值诱导不同的 **Class I（被高 Shh 抑制）/ Class II（被高 Shh 激活）** 转录因子组合
- 组合边界把神经管腹侧划成 **p0、p1、p2、p3、pMN** 等**祖细胞域**（progenitor domains）
- **pMN 域 → 运动神经元**（Isl1/2、Hb9、Olig2）
- 背侧由 BMP/Wnt 反向切出 **dI1–dI6** 等域

**D–V 的"对抗模型"**：**Shh（腹）↔ BMP/Wnt（背）** 两个反向梯度，靠**相互抑制**建立清晰边界。这与第 3 讲背腹中胚层的"Nodal ↔ BMP"是同一套逻辑。

### 6.3 内外轴（PD，顶端–基底）：干细胞→神经元→胶质（p48–53）★

**从管腔（apical/ventricular）到软膜（basal/pial）**，细胞层次依次是：

| 层 | English | 内容 |
|---|---|---|
| **室管膜层/脑室区** | ventricular zone, **VZ** | 最靠近管腔，**神经干细胞所在**，细胞在此增殖 |
| **脑室下区** | subventricular zone, **SVZ** | 中间增殖区（哺乳类发达） |
| **中间带/皮质板** | intermediate zone / cortical plate | 迁移中的神经元与已定位的神经元 |
| **边缘带** | marginal zone | 最外层（ Cajal-Retzius 细胞） |

**关键机制**：

- **放射状胶质细胞（radial glia）** 既是**神经干细胞**，又伸出长突起作为**神经元迁移的支架**
- **"inside-out" 迁移**：**先出生的神经元先占据深层，后出生的越过它们走到浅层** → 皮层由内向外逐层建立
- **成年人神经系统中仍存在有增殖能力的干细胞**（p53）→ 海马齿状回、脑室下区

> **内外轴是最容易被忽略的一轴**，但简答题问"三轴"时必须写出这一层内容（VZ→SVZ→皮质板→边缘带，以及放射状胶质与 inside-out）。

### 6.4 神经元命运的确定（p39–42）

- **位置信息决定命运**（p40）：同样类型的祖细胞，处在不同位置（不同 Shh/BMP 浓度）就产生不同类型神经元
- **Delta–Notch 侧向抑制**（p41–42）：一群等价的前体细胞中，一个开始表达 Delta → 激活邻居 Notch → 邻居被抑制、维持前体状态 → **只有一部分成为神经细胞**（其余成表皮/胶质）
  - 果蝇**成神经细胞（neuroblast）** 的命运决定就是范例

> 这就是第 1 讲"侧向抑制产生间距模式"的落地实例，两讲可以直接串起来答。

## 七、神经元的生长、定向与存活

### 7.1 轴突生长与髓鞘（p55–57）

- 神经元之间及与靶细胞形成连接
- **髓鞘 myelin sheath**：**中枢**由**少突胶质细胞**形成，**外周**由**施万细胞**形成（选择题爱考这个区分）

### 7.2 轴突导向（p58–66）★★

**生长锥（growth cone）** 靠四类信号导航：

| 分子 | 受体 | 作用 | 经典例子 |
|---|---|---|---|
| **Netrin** | **DCC**（吸引）/ UNC5（排斥） | **吸引** | 脊髓**连合神经元**穿越中线；**2025 年 1 月选择题原题** |
| **Slit** | **Robo** | **排斥** | 连合神经元过中线后被"推走"，防止来回穿 |
| **Ephrin** | **Eph** | 排斥/黏附 | 体节**生骨区后部**的 Ephrin 排斥运动神经元轴突 → 只从**前半部**穿过 |
| **Semaphorin** | Plexin/Neuropilin | 排斥 | 昆虫肢体中的跨膜 Semaphorin |

**三个必背案例**：

1. **连合神经元穿越中线**（p63）：Netrin（中线，吸引）+ Slit/Robo（过线后排斥）→ 精确的"过而不返"
2. **体节前半部限制**（p64）：Ephrin 在生骨区**后部**表达，排斥运动神经元 → 轴突只能走**前半部**
3. **视网膜拓扑投射**（p65）：视网膜表达 **EphA3** 呈**鼻–颞梯度**，顶盖表达 Ephrin 呈**前–后梯度** → 浓度匹配决定投射位置。**这是"化学亲和性假说"的分子证明**

> 第 3 个案例是 Sperry 的"化学亲和性假说"的现代版本，论述题很好用。

### 7.3 神经营养因子与存活（p67–68）

- **NGF、BDNF、NT3、NT4**，受体为 **Trk** 家族
- **"神经营养因子假说"**：靶组织分泌有限量的营养因子，**神经元竞争性摄取**，只有连对靶、拿到足够因子的才存活，其余的**凋亡**
- **不同类型的神经元需要不同的营养因子；同类神经元之间也竞争**

> 这条解释了"为什么发育过程中会产生过量神经元再删掉一半"——**数量由靶的大小决定**。

### 7.4 突触形成（p69–80）★

- **神经肌突触**（p72–73）：运动神经元末梢释放 **Agrin** → 肌细胞膜上 **MuSK/LRP4** 受体 → **乙酰胆碱受体（AChR）在突触后膜聚集** → 突触成熟
- **中枢突触与树突棘**（p74–78）：**树突棘 dendritic spine** 是树突上的小突起，是兴奋性突触的**主要接收位点**
  - 形成涉及**树突的伪足与轴突的互作**
  - **一个轴突可与多个树突连接；一个轴突可与同一树突形成多次连接；一个树突也可与多个轴突形成多个树突棘**（p76–78，三条都必须能说）

> **2024 年 1 月名词解释：神经突触和树突棘** —— 这题就是 p69–78 的浓缩。

## 八、神经嵴细胞（neural crest）★★

> **2025 年 1 月名词解释原题：神经嵴细胞的来源和发育方向**

### 8.1 来源（p82）

- 位于**神经板与表皮外胚层的交界处**
- 神经管闭合过程中，这些细胞经历 **EMT**（失去上皮特性、获得迁移能力）后脱离神经管
- **诱导**：需要**中等强度的 BMP**（太低→神经，太高→表皮，中间→神经嵴）+ Wnt、FGF

> **"中等 BMP 浓度"是神经嵴的关键**，这也是把它叫"第四胚层"的原因——它不属于任何一个经典胚层的产物。

### 8.2 迁移路径（p87–91）

| 类型 | 位置 | 主要去向 |
|---|---|---|
| **颅神经嵴** cranial | 头部 | 面部骨骼与软骨、颅神经、黑色素细胞 |
| **躯干神经嵴** trunk | 躯干 | **背侧路径**：经表皮 → 色素细胞；**腹侧路径**：经体节前半部 → 周边神经、肾上腺髓质 |
| **心脏神经嵴** cardiac | 咽部 | 主动脉弓、心脏间隔 |
| **肠神经嵴** vagal/sacral | 迷走/骶部 | **肠神经系统**（缺失 → 先天性巨结肠） |

### 8.3 体节的"门禁"（p91）★

**神经嵴细胞只能从体节的"前半部"迁移**——即使把体节旋转 180°，它们仍然只从前半部走。

**分子基础**：体节后半部表达 **Ephrin**（排斥）、前半部表达允许性分子 → 形成"斑马纹"式的通道。**同一个 Ephrin/Eph 机制，既管神经嵴迁移，又管运动神经元轴突路径**（§7.2 案例 2）。

### 8.4 逐级分化（p84–86）

神经嵴 → 多潜能前体 → 谱系限制性前体 → 分化细胞。**头尾轴线上不同位置的神经嵴命运不同**（Hox 代码决定）。

### 8.5 分化产物总表（背这个就够答题）

| 类别 | 产物 |
|---|---|
| **神经元** | 感觉神经元（背根神经节）、交感神经元、副交感神经元、肠神经元 |
| **胶质** | 施万细胞、卫星细胞 |
| **内分泌** | 肾上腺髓质嗜铬细胞 |
| **色素** | 黑色素细胞 |
| **骨骼/结缔组织** | 面部软骨与骨、牙本质、部分颅骨 |
| **其他** | 心血管间隔、角膜内皮 |
