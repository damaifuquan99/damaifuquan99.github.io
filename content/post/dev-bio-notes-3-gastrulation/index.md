## 一、本讲定位

一句话：**原肠作用是把"一堆细胞"变成"一个有内外有前后有背腹的身体"的那一步。**

前面（第 2 讲）胚胎只是把自己切成很多块，所有细胞都在球的表面。这一讲要解决三件事：

1. **把细胞送进去** —— 外胚层留在外面，中胚层和内胚层钻进内部（**细胞运动**）
2. **定出方向** —— 背在哪、腹在哪、头在哪、尾在哪（**图式形成 pattern formation**）
3. **让邻居不一样** —— 靠一个"信号中心"去诱导周围组织（**组织者 organizer**）

Lewis Wolpert 那句被印在课件第 3 页上的话值得记住：

> "It is not birth, marriage, or death, but gastrulation, which is truly the most important time in your life."

**这一讲是全课程分值最重的一讲**：名词解释（原肠作用、上皮与间质）、简答（跨物种组织者对比）、选择题（哪个胚层生成哪个器官）几乎每年都从这里出。

## 三、原肠作用的五种细胞运动 ★★这是本章的"字母表"

### 3.1 原肠作用的定义（2024 年 1 月名词解释原题）

> **原肠作用 gastrulation**：胚胎细胞有规律地运动，使细胞重新排列，**外胚层留在外面、中胚层与内胚层进入内部**，从而建立三胚层结构的过程。

定义里必须出现两个要素：**有规律的细胞运动** + **三胚层建立**。

### 3.2 上皮与间质（2024 年 1 月名词解释原题）

| | 上皮细胞 | 间质细胞 |
|---|---|---|
| **排列** | 紧密排列成片/层 | 单个游离 |
| **连接** | 有紧密连接、黏着连接、桥粒 | 无稳定细胞间连接 |
| **极性** | 有**顶–基极性** | 无 |
| **基膜** | 有 | 无/不完整 |
| **运动** | 集体运动（片状） | 单个细胞迁移（阿米巴样） |

### 3.3 上皮–间质转换（EMT）★

> **EMT**：上皮细胞失去极性、断开连接、获得迁移能力，转变为间质细胞的过程。

**分子变化**：E-cadherin 下调 → 连接解体；N-cadherin 上调；细胞骨架重排；MMP 分泌降解基膜。**反向过程叫 MET**（间质–上皮转换），在肾小管、体节形成时用。

> 这是本课最"跨界"的一个概念：肿瘤转移、纤维化都用它。**考名词解释时最好顺带提一句"生理与病理意义"**。

### 3.4 五种运动方式（p5–7）★必须能区分

| 方式 | English | 动作 | 典型场景 |
|---|---|---|---|
| **内陷** | invagination | 一片上皮**向内凹**成沟/管 | 果蝇腹沟、海胆原肠、神经管形成 |
| **内移** | ingression | **单个**细胞从上皮脱离、迁入内部 | 海胆初级间质细胞、小鼠原条上皮→间质 |
| **内卷** | involution | 一片上皮沿**内表面**卷进去、贴着走 | 爪蛙胚孔背唇、斑马鱼胚环 |
| **外包** | epiboly | 一层上皮**向外扩展、覆盖**整个胚胎 | 爪蛙动物极、斑马鱼胚盘下包 |
| **汇聚伸展** | convergence & extension | 细胞**相互插入**、变窄变长 | 爪蛙/斑马鱼中线、原条延伸 |

> **⚠️ 2025 年 1 月选择题**：「原肠作用**不**涉及——外胚层细胞内卷」✔
> **原因**：**外胚层做的是"外包"（epiboly），不是"内卷"（involution）**。内卷的是中胚层和内胚层。这是本章最容易犯的方向性错误。

## 四、海胆：最"教科书"的原肠作用（p11–22）

海胆的好处是简单——只有三层细胞、透明、可以活体看。

### 4.1 起始信号（p12）

植物极细胞释放**硫酸软骨素蛋白多糖** → 触发初级间质细胞的内移。

### 4.2 两类间质细胞（p13–15）★ 容易混淆，必须分清

| | 初级间质细胞 primary mesenchyme | 次级间质细胞 secondary mesenchyme |
|---|---|---|
| **来源** | 小分裂球 micromeres | 植物极其他细胞 |
| **时间** | 先 | 后 |
| **命运** | **生骨中胚层**（形成骨针） | 平滑肌、色素细胞、体腔细胞 |
| **动作** | 内移 → 靠**伪足**迁移 | 在肠管前端**引导/牵拉**原肠延伸 |

### 4.3 小分裂球的组织者作用（p17–20）★★

**三个身份**（第 2 讲已出现，这里展开）：
1. 生骨中胚层来源
2. **启动原肠作用**
3. **可诱导第二胚轴**（把它移植到动物极，能在异位诱导出完整的次级轴）

**分子基础**：小分裂球的组织者作用决定于**母源 β-catenin 在细胞核中的积累**。两个漂亮的实验（p19–20）：

- **LiCl 处理**：抑制 GSK3β → 稳定 β-catenin（不能降解）→ 动物极细胞被**重新定义为中胚层和内胚层命运**（本该是外胚层的变成中内胚层）
- **过表达 C-cadherin**：把 β-catenin 锚在膜上、**阻断入核** → 整个胚胎发育成**纤毛化外胚层细胞团**（本该有中内胚层的全变成外胚层）

> **这两个实验是"β-catenin 入核决定中内胚层命运"的充分 + 必要证据**，也是简答题"如何证明某因子定命运"的标准范式。

### 4.4 海鞘（p21–22）

Nodal 由母源 Univin（Vg1）激活、被背部 Panda 抑制 → 形成**口侧高、反口侧低**的 Nodal 梯度 → Nodal 激活口侧 Bmp2/4、Lefty、Chordin → 划分腹侧外胚层 / 背侧外胚层 / 中间的纤毛带外胚层（产生神经元）。

**拮抗因子如何让梯度更陡**（p22）：拮抗因子的**扩散距离大于**信号分子本身 → 形成"信号 + 其拮抗物"的对峙 → 有效活性梯度比单纯扩散更陡峭。这是形态素理论的经典补充。

## 五、果蝇（p23–25）

- 原肠作用**开始于腹部预置中胚层的内陷** → 形成**腹沟** ventral furrow
- 顺序（p24）：腹沟内陷 → 中胚层成管状 → 两侧腹部外胚层向中线合拢 → 中胚层细胞**间质化迁移**铺展 → 前部中肠内陷、后部中肠内陷（带极细胞）→ 羊浆膜收缩带动胚带后部向背侧头端迁移 → **胚带 germ band 加长**
- 胚带后退 → 前后中肠汇合 → 头部内卷 → 神经祖细胞迁出外胚层
- **2025 年 1 月选择题**：「果蝇囊胚期内胚层细胞分布于——头尾」（内胚层分前后两处，靠胚带运动汇合）

> 果蝇的"体轴"不靠原肠作用定，而是**母源基因预先定好**的——这正是第 4 讲的主题。

## 六、爪蛙：Spemann 组织者 ★★★本章核心

### 6.1 起始：瓶状细胞与胚孔（p27）

原肠作用开始于**瓶状细胞** bottle cells 的形成与**内突**。它们的顶端收缩、基部变细窄，使囊胚表面形成一个小沟，即**胚孔 blastopore**。

### 6.2 运动过程（p28–31）

四种方式同时进行：**瓶状细胞的内陷 → 中胚层内卷（沿胚孔背唇）→ 动物极外包 → 中线汇聚伸展**。内胚层在整个过程中重新排列（p31）。

### 6.3 组织者是什么（p33）★★ 2025 年 1 月简答原题

> **Spemann 组织者（Spemann organizer）**：原肠作用开始时，位于**胚孔背唇**、能**诱导胚轴形成**的一个信号中心。

**两条功能**（答题分两段写）：

**(1) 自身形成中轴组织**：
- 头部/前端内胚层（anterior endoderm）
- 前脊索中胚层（prechordal mesoderm）
- **脊索**（notochord）
- **神经基板/底板**（floor plate）—— 来自瓶状细胞

**(2) 组织和协调周围细胞**：
- 沿**背腹轴**和**前后轴**指导周围细胞分化为体节、神经组织、肝、胰等

### 6.4 组织者的关键诱导信号是什么 ★简答必答

组织者的本质是**分泌一组拮抗因子**，把腹侧的 BMP 和 Wnt 信号"压掉"：

| 分泌因子 | 拮抗对象 | 后果 |
|---|---|---|
| **Chordin、Noggin、Follistatin** | **BMP** | 解除 BMP 的"表皮化"作用 → 背侧成为**神经组织**与**背侧中胚层** |
| **Dkk、Frzb** | **Wnt** | 使前部结构（头）形成，抑制后部化 |
| **Cerberus** | Nodal、BMP、Wnt | 诱导头部 |
| **ADMP** | 反向调节 BMP | 维持梯度 |

> **一句话**：**组织者 = BMP 拮抗剂工厂**。"神经诱导的默认模型"（default model）就是说：外胚层**本来**要变成神经，BMP 让它变表皮，组织者分泌 Chordin 等挡住 BMP，神经才出得来。

### 6.5 组织者怎么形成：Huluwa（p34–36）★★ 本讲最新的部分

链式因果：

```
母源背部决定因子 Huluwa（Hwa）
   ↓
促进 Axin 的 poly-ADP-核糖基化（TNKS/tankyrase 催化）
   ↓
Axin 被泛素化 → 蛋白酶体降解
   ↓
β-catenin 降解复合体（Axin/APC/GSK3/CK1）瓦解
   ↓
β-catenin 在背侧细胞核内积累
   ↓
启动 siamois 等 → 形成 Nieuwkoop 中心 → 组织者
```

**实验证据**（p46–48）：斑马鱼**母源 hwa 突变体不能形成组织者和体轴**。表型机制很清楚——缺少组织者 → 侧部和腹部中内胚层细胞内卷后**不能向背部中线汇聚**，这些细胞停滞聚集在某处，把卵黄**绞缢**住 → 形态异常。

> **注意这是 2018 年 *Science* 的工作，是这个领域近年最重要的中国学者贡献之一，也是老师的本行。**
> 后续仍有新进展：2024 年[磷酸化开关](https://pubmed.ncbi.nlm.nih.gov/39562571/)、2026 年[微管阵列与背侧决定子运输](https://pubmed.ncbi.nlm.nih.gov/42773144/)。
> **这可能出论述题**：Huluwa 如何在上游把"背在哪"这件事定下来。

### 6.6 中胚层从哪来：Nieuwkoop 中心（p37–38）★

**经典实验**（Pieter Nieuwkoop）：把晚囊胚**动物极帽**（本该成外胚层）与**植物极半球**接触共培养 → 动物极帽分化出**中胚层**。

**结论**：**中胚层是被其下方的植物极内胚层诱导出来的。**

**Nieuwkoop 中心**：能诱导背部中胚层命运的**背部内胚层**。它是组织者的"上游"，位置在植物极背侧。

**DV 轴上的分化**（p38）：

| 内侧位置 | 诱导出的中胚层 |
|---|---|
| 背侧 | 背部中胚层：**脊索、体节** |
| 中间 | 中间中胚层：**肾** |
| 腹侧 | 腹部中胚层：**血细胞** |

### 6.7 Nodal 浓度梯度控制背腹分化（p39–40）

- **Nodal** 在植物极/背侧高表达，形成浓度梯度 → 高浓度区成背部中胚层（脊索），低浓度区成腹部中胚层（血）
- **BMP** 是**腹部化**信号；组织者分泌的 Chordin 等压制它

> 于是背腹轴 = **Nodal 梯度（背高腹低）** 与 **BMP 活性（腹高背低）** 的对抗结果。

## 七、斑马鱼（p41–53）

### 7.1 形态学名词（p41）★ 一组名词解释常客

- **下包** epiboly：晚囊胚时胚盘细胞向营养极方向下包，由 **YSL 驱动**，胚盘变薄
- **胚环** germ ring：50% 下包时，与卵黄交界处的深层细胞内卷，形成厚实的一圈
- **上胚层 / 下胚层**：内卷的细胞 + 上层内移的细胞形成**下胚层**；滞留上层的深层细胞为**上胚层**
- **胚盾** embryonic shield：深层细胞内卷 + 汇聚伸展，在**背部**胚环形成的加厚区 = **斑马鱼的组织者**
  - 来源分化：下胚层 → 脊索中胚层、轴旁中胚层、内胚层；上胚层 → 外胚层

### 7.2 胚盾的四个作用（p44）★简答可用

① 调控细胞运动 ② 诱导体轴形成 ③ 诱导神经系统 ④ 诱导中内胚层

### 7.3 分子机制

- **β-catenin2 入核**是斑马鱼组织者与体轴形成的关键（p45）：*ichabod* 突变体核内无 β-catenin2 → 无组织者
- **母源 Hwa** 促进背部组织者中 Axin 降解 → 稳定 β-catenin2（p48）
- **Nodal 是关键的中内胚层诱导信号**（p49）：*sqt*（ndr1）+ *cyc*（ndr2）双突变 → **缺失中内胚层，但中枢神经系统仍存在**
  - **这个"神经系统还在"的现象很重要**，它说明神经诱导不是简单依赖 Nodal
- **nodal 表达的三重调控**（p51）：母源 **Eomesa** + 母源 **Hwa** + **Nodal 自反馈正调控**
- **腹部化信号是 BMP**（p52）：Bmp2b 在腹侧，Chordin 在背侧，p-Smad1/5/8 读 BMP 活性
- **为什么缺 Nodal 仍有神经？**（p53）因为背部还有 β-catenin、Fgf、以及 BMP 拮抗剂（Chordin/Noggin/Follistatin）与 ADMP 形成的网络，神经系统并不单靠 Nodal

## 八、鸡胚（p54–60）★

### 8.1 原条（primitive streak，p55）★★

- **形成**：胚盘**后部边缘区**的上胚层细胞聚集加厚而成
- **意义**：原条的出现**确定了胚胎的 A–P 轴线**（这是鸡胚定前后轴的方式，与蛙的完全不同）
- **原沟** primitive groove：原条内的凹陷，是上胚层细胞进入囊胚腔的**门户**
- **Hensen's node（原结）**：原条**头部末端的加厚层**，是**鸟类的背部组织者**

### 8.2 细胞命运（p55–56）★选择/判断题高发

| 进入方式 | 命运 |
|---|---|
| **最早**穿过原条、向头移动 | **前肠内胚层**；把这些细胞挤到明区前部 → **生殖新月区**（原生殖细胞所在地） |
| 其后通过 Node 进入、在上胚层与内胚层之间向头移动 | 头部中胚层、脊索中胚层 |
| 从原条**侧面**进入 | ① 与下胚层接触后把下胚层赶向两侧，自身成为**内胚层**（内胚层器官 + 大部分胚外膜）② 夹在中间的形成**中胚层** + 少量胚外膜 |
| 留在上胚层的预定外胚层细胞 | 在上胚层中增殖、**外包** → 外胚层 |

### 8.3 原条后退（p55）

Node 移到明区中央后，**Node 与原条一起后退**，过程中长出**脊索**；Node 退到最末端形成**肛门区**。

**不同时间点穿过原条的中胚层细胞命运不同**（p59）—— 早的成头颈部，晚的成尾部和侧板。这就是"**时序决定命运**"。

### 8.4 中胚层命运的诱导（p58）

**Hensen's node 移植**能在异位诱导次级轴，与 Spemann 组织者等价。

## 九、小鼠（p61–71）

### 9.1 原肠作用前的准备

- 内细胞团分化（p62）：上胚层 epiblast + 原始内胚层 primitive endoderm
- 着床后早期发育（p63）：卵柱 cylinder 形成

### 9.2 前部内脏内胚层（AVE，p65）★

**AVE**（anterior visceral endoderm）向**头端**运动，分泌 **Dkk1、Cerberus、Lefty1** 等拮抗因子 → **抑制近端 Wnt/Nodal** → 定出**前极**。

> 这是哺乳类特有的"前部信号中心"，作用类似爪蛙组织者的"头部诱导"部分。

### 9.3 原条与 node

- 原条诱导依赖 **Wnt3a** 和 **Nodal**（p66）
- **小鼠原结（node）具有组织者活性**（p67）—— 移植可诱导次级轴
- 原条在**上胚层后端**（近端）形成 → 2024 年判断题「小鼠的原条在上胚层前端形成」→ **错（是后端）**

### 9.4 反转（p69）

小鼠胚胎在着床后发生**反转**（"轴向反转"），使胚体方向与胚外组织关系改变 —— 这是哺乳类特有的形态学事件。

### 9.5 脊椎动物命运图比较（p71）

同一套三胚层，不同物种的**细胞运动路线**不同，但**最终命运图高度保守**。

## 十、人胚（p72–81）

- 上胚层与下胚层形成（p73）→ 与原肠作用前的双层胚盘
- 三胚层建立与命运（p74）：与原条机制一致
- 胚外结构（p79）：羊膜、绒毛膜、卵黄囊、尿囊
- 母胎物质交流（p80）：胎盘屏障

## 十一、猴胚（p82）

2019 年后才有非人灵长类的体外培养与单细胞数据，是"老资料必缺"的部分。**要点**：猴胚原肠作用在**形态上更接近人**（盘状胚盘、原条、卵黄囊），因此是研究人胚原肠的**最佳模型**之一。

## 十二、跨物种组织者对照表 ★★ 简答必考（2024、2025 连考两年）

| 物种 | 组织者名称 | English | 位置 | 定前后轴的方式 |
|---|---|---|---|---|
| **海胆** | 小分裂球 | micromeres | 植物极 | 口—离口轴与第一次卵裂面相关 |
| **爪蛙** | **Spemann 组织者** | Spemann organizer | **胚孔背唇** | 精子入口 → 皮质旋转 → 灰色新月 |
| **斑马鱼** | **胚盾** | embryonic shield | 背部胚环加厚区 | 母源 Hwa → β-catenin2 入核 |
| **鸡** | **原条 + Hensen's node** | primitive streak / Hensen's node | 胚盘后部边缘区 → 原条头端 | **原条的出现即定 A–P 轴** |
| **小鼠** | **原结** | node | 原条前端 | AVE 定前极 + Wnt3a/Nodal 诱导原条 |
| **人** | 原条 + 原结（同小鼠） | primitive streak / node | 同上 | 同上 |

**共同点**：都是**分泌 BMP/Wnt 拮抗因子**的信号中心，都能在异位移植时诱导**次级胚轴**（这是"组织者"的操作性定义）。

9. 鸡胚中最早穿过原条的细胞变成什么？从原条侧面进入的细胞变成什么？
10. 把六个物种的组织者名称、位置、定轴方式默写出来。

<details>
<summary>参考答案要点</summary>

1. 见 §3.1。要素：有规律的细胞运动 + 三胚层建立。
2. 排列／连接／极性／基膜／运动方式。EMT：E-cadherin 降、N-cadherin 升、骨架重排、MMP 降解基膜。
3. 内陷（果蝇腹沟）／内移（初级间质）／内卷（胚孔背唇）／外包（爪蛙动物极）／汇聚伸展（中线）。**外胚层做外包。**
4. 生骨中胚层／启动原肠／诱导第二胚轴。LiCl 稳定 β-catenin → 动物极变中内胚层；C-cadherin 阻断入核 → 全成外胚层。说明 β-catenin 入核是决定中内胚层命运的必要条件。
5. 见 §6.3–6.4。Chordin/Noggin/Follistatin 拮抗 BMP；Dkk/Frzb 拮抗 Wnt；Cerberus 拮抗 Nodal/BMP/Wnt。
6. Hwa → TNKS 介导 Axin 多聚 ADP 核糖基化 → Axin 泛素化降解 → 降解复合体瓦解 → β-catenin 入核 → siamois → Nieuwkoop 中心 → 组织者。突变体缺组织者 → 侧腹中内胚层不能向背中线汇聚 → 停滞聚集绞缢卵黄。
7. 动物极帽 + 植物极半球共培养 → 动物极帽分化出中胚层。结论：中胚层由植物极内胚层诱导。
8. 胚盘后部边缘区上胚层细胞聚集加厚。确定 A–P 轴。Node 在原条头端，是鸟类组织者。
9. 最早穿过的 → 前肠内胚层（并把下胚层挤成生殖新月区）。侧面进入的 → 内胚层（含大部分胚外膜）与中胚层。
10. 见 §十二。
