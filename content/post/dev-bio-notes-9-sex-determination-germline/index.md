## 一、本讲定位

这一讲有两个主题，看起来独立，其实是同一条线的两端：

- **性别决定**：个体层面，**体细胞**怎么决定"做雄还是做雌"
- **生殖细胞**：细胞层面，**生殖系**怎么被"单独拎出来"、迁移到生殖嵴、最后做成配子

共同点是：**这两件事都是"命运决定"的极端案例**——一个决定整个身体，一个决定"不朽的细胞系"（只有生殖细胞能把基因传给下一代）。

## 三、哺乳动物的性别决定

### 3.1 主要性别决定（primary sex determination，p3–12）

**定义**：决定**性腺**（睾丸 or 卵巢）走向的过程。**注意：是先定性腺，再由性腺的激素决定身体其他部分**——这是理解整节的关键。

**（1）生殖嵴（genital ridge）** ★ 2025 年名词解释原题

> **生殖嵴**：胚胎期**中肾**内侧体腔上皮增厚形成的**性腺原基**，由**体细胞（支持细胞前体、类固醇生成细胞前体）+ 迁入的原始生殖细胞（PGC）**组成；是睾丸或卵巢发育的起点。

- 位置：中肾内侧（中间中胚层区域）
- 组成：**体细胞 + PGC**
- 命运：**双向潜能**（bipotential gonad）—— 既可以成睾丸，也可以成卵巢

**（2）SRY 决定睾丸（p6–7）★**

```
Y 染色体上的 SRY
   ↓（在未分化的生殖嵴体细胞中瞬时表达）
Sox9  ↑
   ↓
支持细胞（Sertoli cell）分化
   ↓
睾丸形成
```

- **SRY 位于 Y 染色体**，在未分化性腺的**支持细胞前体**中表达
- **Sox9 是 SRY 的直接下游**，是睾丸决定的"主开关"
- 小鼠 Sry 同样在 Y 上，表达窗口很短（约 E10.5–E12.5）

**（3）协同因子（p8–9）**

| 基因 | 作用 |
|---|---|
| **Sox9** | 睾丸决定的核心 |
| **Sf1（Nr5a1）** | 性腺发育与类固醇生成 |
| **Wt1** | 生殖嵴发育 |
| **Gata4** | 协同 Sox9 |
| **Dax1（Nr0b1，X 染色体）** | **促进卵巢**、拮抗 Sox9 |
| **Wnt4（常染色体）** | **促进卵巢**（Wnt4 缺失 → XX 性腺男性化） |
| **RSPO1、FoxL2** | 卵巢维持 |

> **经典对抗模型**：**Sox9/FGF9（睾丸）↔ Wnt4/RSPO1/β-catenin（卵巢）** 两套程序**互相抑制**，谁占上风就走向哪边。这也解释了为什么**Dax1 剂量加倍（XY 个体 X 重复）会导致性反转**。

### 3.2 次级性别决定（secondary sex determination，p13–17）

**定义**：性腺分泌的激素决定**性腺以外**的性别特征（内生殖道、外生殖器、第二性征）。

| 激素 | 来源 | 作用 |
|---|---|---|
| **抗中肾旁管激素 AMH**（Müllerian inhibiting substance） | **支持细胞（Sertoli）** | **使中肾旁管（Müllerian duct）退化** → 不形成子宫、输卵管、阴道上段 |
| **睾酮 testosterone** | **间质细胞（Leydig）** | **维持中肾管（Wolffian duct）** → 附睾、输精管、精囊 |
| **双氢睾酮 DHT**（由睾酮经 **5α-还原酶** 转化） | 外周组织 | **外生殖器男性化**（阴茎、阴囊、前列腺） |

**雌性胚胎**（p17）：卵巢合成**少量**睾酮（无 AMH）→ 中肾旁管保留 → 子宫、输卵管；中肾管退化。

> **经典临床推理题**（2024 年简答题就是这个）：
> **XY 个体、雄激素受体（AR）缺失** → 有睾丸（SRY 正常）→ **AMH 正常分泌 → 中肾旁管退化**（无子宫）；但**睾酮不能起作用 → 中肾管退化、外生殖器不男性化** → 表现为**女性外生殖器、无子宫、睾丸未下降（隐睾）**。这就是**雄激素不敏感综合征（AIS）**。

## 四、其他动物的性别决定

### 4.1 鸟类（p18–21）★

- **ZZ = 雄，ZW = 雌**（与哺乳类相反：**雌性是异配性别**）
- **细胞自主性**（p19）：鸟类的性别决定是**每个细胞自己决定**的，不靠全身激素
- **证据**（p20）：**雌雄嵌合体（gynandromorph）**——一侧卵巢、一侧睾丸的鸡；把 ZW 细胞和 ZZ 细胞混合，各自按自己的基因型发育
- **分子机制**（p21）：**DMRT1**（Z 染色体）剂量决定——ZZ 有双份 DMRT1 → 睾丸；ZW 单份 → 卵巢

> **对比记忆**：**哺乳类 = 激素主导（全身性）；鸟类 = 细胞自主（局部性）。** 这是最容易被出对比题的地方。

### 4.2 果蝇（p22–25）★★

- **性别由 X 染色体数目与常染色体套数之比（X:A）决定**：
  - **X:A = 1.0 → 雌**
  - **X:A = 0.5 → 雄**
- **级联**（p25）：

```
X:A 比值
   ↓
Sxl（Sex-lethal）—— 只在 X:A=1 时开启
   ↓
tra（transformer）→ tra2
   ↓
dsx（doublesex）→ 剪接出 Dsx-F（雌）或 Dsx-M（雄）
   ↓
体细胞性别分化
```

**关键**：**Sxl 是一个"开关"**，通过**选择性剪接**自我维持；下游 **tra → dsx** 全靠**剪接调控**，不是转录调控。这是"**一个基因决定整个性别**"的经典范式。

**雌雄嵌合体**（p24）：果蝇的 gynandromorph 是**细胞自主**的——XX 细胞变成雌性结构，XO 细胞变成雄性结构，同一只果蝇身上并存。

### 4.3 线虫（p26–28）

- 性别也由 **X:A 比**决定：**XX（X:A=1）= 雌雄同体**；**XO（X:A=0.5）= 雄性**
- 关键因子：**xol-1**（X:A 低时高表达 → 雄性）、**sdc-1/2/3**（X:A 高时抑制 xol-1）

## 五、X 染色体剂量补偿（dosage compensation）★★ 2025 年简答原题

**问题**：雌性有两条 X、雄性只有一条，X 连锁基因的剂量差一倍，怎么平衡？

**三种动物，三种解法**（这张表必须默写）：

| 物种 | 策略 | 关键分子 | 结果 |
|---|---|---|---|
| **哺乳动物** | **失活一条 X**（X-inactivation） | **Xist**（长链非编码 RNA）**顺式**包裹该 X → 招募 PRC2 → H3K27me3 → 沉默 | 雌性只有一条 X 有活性（**巴氏小体**） |
| **果蝇** | **雄性 X 转录加倍**（up-regulation） | **MSL 复合体**（MSL1/2/3 + MOF）结合雄性 X → **H4K16 乙酰化** → 转录升高 2 倍 | 雄性 X 表达量 = 雌性两条 X 之和 |
| **线虫** | **雌雄同体两条 X 都减半**（down-regulation） | **DCC 复合体**（SDC-1/2/3 + DPY-21/26/27/28）结合两条 X → 抑制转录约 50% | 两条 X 各半量 = 雄性一条 X |

**哺乳动物 X 失活的细节**（p30–31）：
- **大多数哺乳动物 XX 胚泡中，滋养层和原始内胚层的细胞中父源 X 优先失活**（**印记性失活**）；而**胚体**细胞是**随机失活**
- **Xist RNA 由失活的 X 表达，顺式覆盖该染色体**，招募沉默复合体
- **X 失活中心（XIC）** 决定"哪条被失活"；X 失活一旦建立，在后续分裂中**稳定遗传**

> **答题模板**：先一句话说"剂量补偿是为了平衡 X 连锁基因剂量"，然后三段（哺乳/果蝇/线虫），每段写"策略 + 关键分子 + 结果"，最后补一句"三者机制完全不同 → 趋同演化"。

## 六、环境对性别的影响（p35–37）

| 例子 | 机制 |
|---|---|
| **斑马鱼的性别** | 决定于**幼年卵巢是否能够存活**（不是固定遗传） |
| **后螠（Bonellia）** | 幼虫**落在雌性吻部 → 雄性**；**自由生活 → 雌性**（位置决定性别） |
| **爬行动物** | 孵化**温度**决定性别（温度依赖型性别决定 TSD） |

> 判断题常考："性别完全由遗传决定" → **错**。

## 七、原始生殖细胞（PGC）的起源与迁移 ★★

### 7.1 两种模式（这是本节的核心对比）

| 模式 | 物种 | 机制 |
|---|---|---|
| **预置型（preformation）** | 果蝇、线虫、斑马鱼、爪蛙、鸟 | 卵内**生殖质（germ plasm）**预先定位，含决定生殖系的 RNA/蛋白 |
| **诱导型（induction）** | **小鼠、人（哺乳类）** | 无预置生殖质，由**胚胎信号（BMP4 等）诱导**上胚层细胞成为 PGC |

### 7.2 各物种细节

**（1）果蝇：极质（pole plasm，p39–43）★**

- **PGC 命运决定于后部极质**
- **移植极质可异位诱导生殖细胞**（p40）→ 这是"极质足以决定生殖细胞命运"的判决性实验
- 关键基因（p41–42）：**oskar**（由滋养细胞合成 oskar mRNA 运到卵后端，在胚胎中决定极质组装）、**vasa**、**nanos**、**gcl（germ cell-less）**
- **PGC 迁移**（p43）：极细胞随胚带运动进入中肠 → 穿过中肠壁 → 经血淋巴/主动迁移 → 到达生殖嵴

**（2）线虫：P 颗粒与 Pie-1（p44）**
- PGC 命运决定于 **Pie-1**（P 颗粒组分，抑制体细胞转录程序）

**（3）斑马鱼（p45–46）**：生殖质（germ plasm）定位在卵的**植物极**；PGC 沿胚胎迁移至生殖嵴

**（4）爪蛙（p47–48）**：**生殖质（germ plasm）**位于植物极；PGC 迁移路线清楚

**（5）鸟类（p49–51）**：**PGC 通过卵黄膜血管迁移**到生殖嵴——**走血管**，这是很特殊的一条路

**（6）哺乳动物（p52–56）★**

- **小鼠 PGC 的起源**（p53）：**上胚层细胞**在 **BMP4**（来自胚外外胚层）+ BMP8b 诱导下成为 PGC → 表达 **Blimp1/Prdm1、Stella/Dppa3**
- **迁移**（p54）：后肠 → 背侧肠系膜 → 生殖嵴
- **灵长类/人**（p55–56）：**也是诱导型**，机制与小鼠类似（BMP4、SOX17、BLIMP1）

> **这是"预置 vs 诱导"的最好对比材料**：果蝇/线虫/鱼/蛙/鸟 = 卵里先放好东西；小鼠/人 = 到时要靠信号现场指定。**进化上，哺乳类是"后来改的"。**

## 八、生殖细胞类型的选择与减数分裂

### 8.1 类型选择（p57–62）

- **雌鱼生殖细胞移植到雄鱼睾丸 → 发育为精子**（p58）→ 说明**生殖细胞的性别不由自身基因型决定，而由性腺环境决定**
- **XY 型生殖细胞只能发育为精子，不受生殖细胞自身影响**（p59）
- **线虫 XX 雌雄同体生殖细胞经历两次选择**（p60–62）：幼虫期先产生**精子**，成虫期产生**卵**——时序决定类型

### 8.2 减数分裂的启动：RA（p63–66）★★ 2025 年选择题

> **视黄酸（RA）是启动哺乳动物生殖细胞减数分裂的信号。**

| 性别 | 机制 |
|---|---|
| **雌性** | 中肾产生 **RA** → 生殖细胞表达 **Stra8** → 进入减数分裂 → 卵母细胞停在**减数第一次分裂前期的双线期** |
| **雄性** | 生殖细胞表达 **CYP26B1**（降解 RA）→ RA 被清除 → 不进入减数分裂 → 停在**有丝分裂**（精原细胞） |

> **一句话**：**同一个 RA，雌性用来"启动减数分裂"，雄性用来"把它拆掉"。** 这个差异是雌雄配子发生分道扬镳的起点。

### 8.3 精子发生（p67–71）★

**曲精管中的细胞排列**（p67，从基膜到管腔）：**精原细胞 → 初级精母细胞 → 次级精母细胞 → 精细胞（spermatid）→ 精子**

**精原细胞的分裂与分化**（p68–69）★ 2024 年简答原题「对比 A1 型、A2 型和 B 型精原细胞的分裂和分化特点」：

| 类型 | 分裂方式 | 特点 |
|---|---|---|
| **A-single / A-paired（As/Apr）** | 有丝分裂，**自我更新** | **干细胞**，维持精子发生池 |
| **A1 → A2 → A3 → A4** | 有丝分裂（**定向分化**） | 逐步进入分化程序，**不再自我更新** |
| **中间型（In）** | 有丝分裂 | 过渡态 |
| **B 型** | 有丝分裂（最后一次） | **产生初级精母细胞**，进入减数分裂 |

> 答题要点：**As/Apr 是干细胞（自我更新）；A1–A4 是有丝分裂定向分化；B 型是最后一次有丝分裂、直接产生进入减数分裂的初级精母细胞。**

### 8.4 卵子发生（p72–83）

- **初级卵母细胞**完成减数第一次分裂 → **一个继承绝大部分细胞质的卵母细胞 + 一个极体**（p74）
- **卵母细胞具有丰富的内含物**（p80）：卵黄、母源 mRNA、蛋白、细胞器
- **成年人卵巢中原始卵泡周期性进入生长期**（每天约 30–50 个）（p76）
- **排卵**（p79–81）：LH 峰 → 卵泡破裂 → 排出次级卵母细胞（停在 MII）
- **常见女性生殖疾病**（p82）；**外观异常的人类卵子**（p83）

## 九、基因组印记（genomic imprinting，p84–90）★★

### 9.1 定义

> **基因组印记**：某个基因是否表达，取决于它来自**父源还是母源**（而不取决于序列本身）。

**机制**：**印记控制区（ICR）的 DNA 甲基化**——配子发生时就已"打好标记"，受精后保持不变。

### 9.2 为什么需要印记：核移植实验（p86）

- **雄核 + 雌核都是胚胎正常发育所必需的**，但作用不完全相同
- **只有父源基因组** → 胚外组织过度发育、胚体发育不良
- **只有母源基因组** → 胚体发育较好、胚外组织缺陷
- 结论：**父源和母源基因组贡献不同的基因（印记基因），必须各有一套**

### 9.3 IGF2/H19 模型（p87–90）★★ 这是必背的标准案例

```
父源染色体：ICR 甲基化 → 绝缘子失效 → IGF2 表达（父源表达）
母源染色体：ICR 不甲基化 → CTCF 结合 → 绝缘子生效 → IGF2 沉默；H19 表达
```

**结果**：**IGF2 只由父源等位基因表达；H19 只由母源等位基因表达。**

**证据**（p87）：含 **Igf2 突变**的精子 + 正常卵子 → 子代**瘦小**（因为唯一能表达的父源 Igf2 坏了）。

### 9.4 临床：Beckwith-Wiedemann 综合征（BWS，p89）

- **2025 年 1 月判断题**：「Beckwith-Wiedemann 综合征患者**父源 H19 低甲基化**」→ **错**
- **正确机制**：BWS 最常见的是 **父源 ICR 甲基化异常**，导致 **IGF2 双等位表达（过量）**、**H19 沉默**。也就是说，出问题的是 **IGF2/H19 的 ICR 甲基化状态**，不是"H19 低甲基化"这个描述本身（H19 在父源本来就该沉默）。**关键点是"父源等位基因被错误激活/去抑制"。**

> 这类题的陷阱：把"父源/母源"和"甲基化高/低"对调。**记住：ICR 甲基化 → IGF2 开、H19 关；ICR 不甲基化 → IGF2 关、H19 开。**

## 十、受精（p91–105）

### 10.1 多精入卵的阻断 ★

| 机制 | 速度 | 内容 |
|---|---|---|
| **快速阻断（膜电位）** | 秒级 | 第一个精子与卵质膜结合后 → **膜电位去极化** → 其他精子不能融合 |
| **慢速阻断（皮质反应）** | 20–60 秒 | 皮质颗粒外排 → **受精膜（fertilization envelope）** 形成 → 物理屏障 |

- **海胆**：两种机制都有（p96–98）
- **哺乳动物**：主要靠**皮质反应** + **透明带反应（ZP2 切割）**

### 10.2 生理性多精入卵（physiological polyspermy，p100–101）★ 2025 年选择题

> **生理性多精入卵**：某些动物**正常就有多个精子进入卵**，但只有**一个精核与卵核融合**，其余退化。

- **代表动物**：**鸟类（鹌鹑、鸡）、蝾螈、部分爬行类**
- **2025 年 1 月选择题**：「生理性多精入卵发生在——**鹌鹑**」✔
- **蝾螈**的机制（p101）：多精进入后，只有**最靠近雌原核的那个雄原核**能融合，其余被排斥/退化

### 10.3 受精激活与钙波（p102–105）

- **受精激活钙离子释放** → 激活**第二次减数分裂**（完成减数分裂、排出第二极体）
- **钙波（calcium wave）**：从精子入卵点向对侧传播，是激活卵的"通用信号"
- **雌原核与雄原核融合**（p104–105）：形成合子基因组

<details>
<summary>参考答案要点</summary>

1. 主要=决定性腺（睾丸/卵巢）；次级=性腺激素决定其余。因为身体其他部分依赖性腺激素。
2. 体腔上皮增厚的体细胞 + 迁入的 PGC。SRY 上调 Sox9。
3. AMH：Sertoli，使中肾旁管退化；睾酮：Leydig，维持中肾管；DHT：外周 5α-还原酶转化，外生殖器男性化。
4. 有睾丸、AMH 正常 → 无子宫输卵管；睾酮无效 → 中肾管退化、外生殖器不男性化、隐睾 → AIS 女性表型。
5. 鸟：ZZ/ZW，DMRT1 剂量，细胞自主；果蝇：X:A，Sxl→tra→dsx；线虫：X:A，xol-1/sdc。
6. 见 §五 表。
7. 预置：果蝇、线虫、斑马鱼、爪蛙、鸟；诱导：小鼠、人。BMP4（+BMP8b）。
8. 雌性 RA→Stra8→减数分裂；雄性 CYP26B1 降解 RA→不进减数分裂。
9. 见 §8.3 表。
10. 父源 ICR 甲基化→IGF2 表达、H19 沉默；母源不甲基化→IGF2 沉默、H19 表达。BWS：父源 ICR 异常→IGF2 双等位表达。
11. 快速=膜去极化（秒）；慢速=皮质反应形成受精膜（20–60 s）。鹌鹑、蝾螈、鸟类。

</details>
