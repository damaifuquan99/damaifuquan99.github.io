## 一、本讲定位

这门课的主线到第 9 讲其实已经讲完了"**怎么造出一个个体**"。这一讲回答最后一个问题：**造好之后，它怎么长大、怎么变形、怎么老去。**

三个主题：

1. **生长**：细胞变大 + 细胞变多 + 器官按比例长大——**但"长大"不是简单的等比例放大**
2. **蜕皮与变态**：同一套基因组，怎么在个体一生中"再建一次身体"
3. **衰老**：为什么会有寿命上限，以及能不能干预

> 这一讲的考试特点是：**选择题固定出 1–2 道（都是胰岛素/IGF-1 与衰老），名词解释固定出 1 道（蜕皮和变态）**。属于"投入少、得分稳"的一讲。

## 三、生长的一般规律

### 3.1 三条基本规律（p2–3、p12–14）★

1. **胚胎早期生长不明显或缓慢**（先"分化"后"长大"）
2. **人体的生长速率因发育阶段而异**（p12）：婴儿期快 → 儿童期平稳 → **青春期突增** → 之后停止
3. **人躯体的不同部分有不同的生长速率**（p13）：**头→躯干→四肢**的顺序（"头尾梯度"：脑和头先长，四肢后长）

> 这是**异速生长（allometry）**：不同器官的**生长曲线斜率不同**。所以成年人的比例和婴儿完全不同（婴儿头大、腿短）。

### 3.2 不同器官有不同内在生长程序（p14）

每个器官有自己的"**内在生长程序**"（intrinsic growth program）——把肝脏移植到别处，它仍然长到"该有的大小"就停。这说明**器官大小是被"程序"设定的，不是被空间限制的**。

### 3.3 器官大小受遗传控制（p15）

- 同物种个体间器官大小差异小 → 遗传决定
- **Hippo/YAP 通路**是器官大小的核心"刹车"：Hippo 开启 → YAP 被磷酸化降解 → 停止生长；Hippo 关闭 → YAP 入核 → 增殖

### 3.4 激素与营养（p16–17）★

| 因子 | 作用 |
|---|---|
| **生长激素 GH**（垂体前叶） | 促生长，主要经 **IGF-1** 介导 |
| **IGF-1**（肝产生） | 促进软骨细胞与多种细胞**增殖** |
| **甲状腺激素** | 促进**变态**与神经系统发育（缺乏 → 呆小症） |
| **性激素** | 青春期突增 + **骨骺闭合** |
| **胰岛素** | 促进合成代谢 |
| **营养** | 是生长的"许可条件"；营养不良 → 生长迟缓 |

> 注意 GH/IGF-1 的双面性：**发育期促进生长，成年后促进衰老**（见 §七）。这是本讲最漂亮的"一个通路两个角色"。

## 四、细胞大小与细胞周期

### 4.1 细胞大小受控制（p4–7）

- 细胞体积大小有**物种/组织特异性**，且被精确调控
- **细胞生长与细胞周期可独立调控**（p6）★：**抑制分裂但不禁生长 → 细胞变大**；**促进分裂但限制生长 → 细胞变小**
- **细胞大小感应的可能机制**（p7）：**mTOR**（营养/能量充足 → 促生长）、**Hippo**（接触抑制）、渗透压/膜张力

> 这条很重要：**"长大"有两个完全不同的维度——细胞变多（增殖）和细胞变大（生长）**，二者由不同通路控制。

### 4.2 果蝇的极端例子（p11）

**果蝇胚胎前 13 次核分裂同时、快速、无细胞质分裂** → 形成多核胚。这说明**核分裂可以完全脱离细胞生长**（核质比不断升高，直到触发细胞化）——正好呼应第 2 讲的 MZT。

## 五、组织与个体生长的策略（p8–10、p18–23）

| 策略 | 例子 |
|---|---|
| **靠细胞数量增加** | 长骨（生长板软骨细胞增殖）、肝 |
| **靠细胞体积增加** | 植物组织（p27）；部分肌纤维（肥大而非增生） |
| **两者兼有** | 大多数器官 |

**具体例子**：

- **长骨的生长**依赖**生长板中细胞数量的增加**（p19）→ 链接第 6 讲
- **肌肉组织的生长**：出生后主要靠**肌纤维肥大** + **肌卫星细胞融合**增加核数（p20）
- **条纹肌肌原节数目的增加依赖于骨的压迫力**（p21）——力学信号调控生长
- **成年哺乳动物皮肤表皮不断更新**（p22）；**毛发生长依赖干细胞**（p23，毛囊隆突部干细胞）
- **遗传物质改变导致生长失控 → 肿瘤**（p24）
- **极少数肿瘤不涉及遗传物质改变**（p25）——表观遗传异常/微环境驱动

**植物对照**（p26–27）：**顶端产生的生长素 Auxin 抑制侧芽生长**（顶端优势）；植物组织生长主要靠**细胞体积增加**。

## 六、蜕皮与变态（molting & metamorphosis）★★ 2024 年名词解释原题

### 6.1 定义

> **蜕皮（molting）**：昆虫等节肢动物**周期性脱去旧外骨骼**、换上新外骨骼的过程，以便身体继续生长。
> **变态（metamorphosis）**：个体在胚后发育中**形态与生活习性发生剧烈改变**的过程（如幼虫 → 成虫）。

**关系**：**蜕皮是"换壳"，变态是"换形"**；变态必须通过蜕皮实现，但蜕皮不等于变态（很多昆虫只蜕皮不变态）。

### 6.2 昆虫蜕皮的激素调控（p28–32）★★

```
脑神经分泌细胞 → PTTH（促前胸腺激素）
        ↓
前胸腺（prothoracic gland）→ 蜕皮激素（20-羟基蜕皮酮，20E）
        ↓
表皮细胞 → 蜕皮（apolysis → 新表皮沉积 → 旧皮脱落）
        ↓
咽侧体（corpus allatum）→ 保幼激素（JH）
        ↓
JH 高 → 蜕皮后仍是幼虫；JH 低 → 蜕皮后化蛹/成虫
```

**核心逻辑（必须会讲）**：
- **蜕皮激素决定"要不要蜕皮"**
- **保幼激素决定"蜕成什么"**
- **JH 滴度下降是变态的开关**

> **2025 年 1 月判断题**：「自然光照不足可以诱导昆虫的前胸腺产生蜕皮激素」→ **错**
> 原因：**前胸腺产生蜕皮激素的指令来自脑的 PTTH**，而**光照（光周期）**影响的是**滞育（diapause）**的决定，不是直接"诱导前胸腺产生蜕皮激素"。这条把"光周期"和"激素分泌"直接连起来，是典型的因果偷换。

### 6.3 变态的类型

| 类型 | 过程 | 例子 |
|---|---|---|
| **完全变态** | 卵 → 幼虫 → **蛹** → 成虫 | 蝴蝶、甲虫、蝇 |
| **不完全变态** | 卵 → **若虫** → 成虫（无蛹） | 蝗虫、蟋蟀 |
| **半变态** | 卵 → 稚虫（水生）→ 成虫 | 蜻蜓、蜉蝣 |

课件 p29 的"预若虫"指不完全变态中的若虫阶段。

### 6.4 两栖类的变态（p33）★

- **甲状腺激素（TH）** 是核心驱动：蝌蚪 → 蛙
- **TH 的作用**：尾退化（凋亡）、四肢长出、鳃退化肺形成、肠道缩短、血红蛋白类型转换
- **催乳素（prolactin）** 拮抗 TH，维持蝌蚪状态
- **这是"同一套基因组重新编程"的最佳例子**——变态前后的细胞基因型完全相同

> **对比记忆**：**昆虫靠 20E + JH，两栖类靠 TH。** 两者都是"激素在胚后重新启动一套发育程序"。

## 七、个体衰老（ageing）★★

### 7.1 定义与规律（p35–38）

> **衰老（ageing）**：随年龄增长，机体**功能进行性衰退**、**对应激与损伤的抵抗力下降**、**死亡风险上升**的过程。

**三条相关性**：

| 规律 | 说明 |
|---|---|
| 寿命与**性成熟年龄**相关（p36） | 成熟晚的物种寿命长 |
| 寿命与**体重**正相关（p37） | 大动物寿命长（同纲内） |
| 个体寿命与**细胞寿命**正相关（p38） | 成纤维细胞的体外分裂次数与物种寿命相关（"Hayflick 极限"） |

### 7.2 胰岛素/IGF-1 通路：衰老的第一个分子通路（p39–41）★★★ 连年考

**发现**：在线虫中，**daf-2**（胰岛素/IGF-1 受体）功能缺失突变 → **寿命延长 2 倍**。

**通路**：

```
胰岛素/IGF-1
   ↓
DAF-2（受体，人 INS/IGF1R）
   ↓
AGE-1（PI3K）→ PIP3
   ↓
PDK-1 / AKT-1/2
   ↓ 磷酸化并抑制
DAF-16（FoxO 转录因子）
   ↓
应激抵抗基因、抗氧化基因、自噬基因
```

**核心逻辑（必须能反向说）**：

> **胰岛素/IGF-1 信号强 → FoxO 被磷酸化、留在胞质、失活 → 抗逆基因不表达 → 寿命短**
> **胰岛素/IGF-1 信号弱 → FoxO 入核、激活 → 抗逆基因表达 → 寿命长**

**两个选择题的直接答案**：
- **2025 年选择**：「IGF1 可以——**抑制 FoxO**」✔
- **2024 年选择**：「延缓衰老的方法——**抑制胰岛素-IGF1 通路**」✔

> 这两个题其实是同一个知识点的正反两面。**记住一句话：IGF-1 抑制 FoxO，所以抑制 IGF-1 通路能延寿。**

### 7.3 能量代谢与 DNA 损伤（p42–43）

- **能量代谢产生的 ROS → DNA/蛋白/脂质损伤 → 衰老**（"自由基理论"）
- **热量限制（caloric restriction）** 是唯一在多种动物中反复验证的延寿干预
- **衰老在组织、细胞、分子三个水平的改变**（p43）：

| 水平 | 改变 |
|---|---|
| **组织** | 干细胞耗竭、组织萎缩、纤维化、炎症（"炎性衰老" inflammaging） |
| **细胞** | 细胞衰老（senescence）、端粒缩短、线粒体功能下降、自噬减弱 |
| **分子** | DNA 损伤累积、表观遗传漂移、蛋白稳态失衡、**NAD⁺ 下降** |

### 7.4 几个具体的干预（p45–51）★

| 干预 | 机制 | 证据/现状 |
|---|---|---|
| **NAD⁺ 前体（NMN/NR）** | 补充 NAD⁺ → 激活 **sirtuins**、改善线粒体功能 | 小鼠有效；**人体证据有限**（p46 标题带问号） |
| **端粒酶过表达** | 延长端粒 | 小鼠**改善健康状况**（p47），但**增加肿瘤风险** |
| **热量限制** | 降低 IGF-1/mTOR、激活 FoxO/sirtuin | **猴的实验结果不一致**（p48–49，标题带问号）→ 要谨慎表述 |
| **雷帕霉素（rapamycin，mTOR 抑制剂）** | 抑制 mTORC1 | **雌鼠寿命更长**（p50） |

> ⚠️ 课件在这些地方都用了**问号**（"可延缓衰老?""能延缓猴的衰老吗?"），说明老师的态度是**"证据不足"**。答题时**不要断言"NMN 能延缓人类衰老"**，要写"在小鼠中有证据，人体尚缺乏确证"。

### 7.5 早老症（HGPS，p52–53）

- **Hutchinson-Gilford 早老症**：**LMNA 基因**点突变 → 产生**早老素（progerin）** → 核膜异常 → 加速衰老
- 是"**单基因即可导致衰老表型**"的证据，说明衰老有明确的分子基础

### 7.6 长寿的途径（p54–56）

- 中国人口预期寿命的变化（p54）
- **延缓衰老的可能途径**（p55）：热量限制、运动、药物（二甲双胍、雷帕霉素）、清除衰老细胞（senolytics）
- **长寿老人的共同点**（p56）：遗传变异（FOXO3 等）、生活方式、代谢特征

7. 甲状腺激素；尾退化、四肢长出、鳃退化肺形成、肠道缩短、血红蛋白转换（任三）。

9. 动物证据较强、人体证据有限；用"在小鼠中""尚缺乏人体确证"表述，不要断言。
10. LMNA 突变 → progerin → 核膜异常；说明单基因即可驱动衰老表型。
