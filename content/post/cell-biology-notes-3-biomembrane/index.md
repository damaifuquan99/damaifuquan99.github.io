# **细胞生物学学习笔记 3 | 生物膜：结构模型、化学组成与膜特性**

---

> **对应课件：** Lecture 3 - Memb-Junc 2026，Page 1–54（Chapter 3 部分）  
> **本章核心内容：** 生物膜结构模型、膜的化学组成（膜脂、膜蛋白、膜糖）、生物膜的三大特征（流动性、不对称性、不均一性）、膜功能概述  
> **复习目标：** 掌握流动镶嵌模型与脂筏模型的核心观点；能区分三类膜蛋白与去垢剂的作用；理解膜不对称性与脂筏的生理意义；熟悉膜的主要功能。

## 一、生物膜结构模型的历史演变

### 1. 三大经典模型

| 模型 | 提出者/时间 | 核心观点 | 局限性 |
| :--- | :--- | :--- | :--- |
| **单位膜模型（Unit membrane model）** | J.D. Robertson（1959） | 电镜下质膜呈“暗-亮-暗”三层（trilaminar），所有膜结构相似 | 无法解释膜的动态变化和蛋白分布差异 |
| **流动镶嵌模型（Fluid-mosaic model）** | S.J. Singer & G. Nicolson（1972） | 脂双层是流动的，膜蛋白像“马赛克”一样镶嵌其中 | 将膜视为均匀“流体”，忽略了微区结构 |
| **脂筏模型（Lipid rafts model）** | K. Simons et al.（1997） | 质膜上存在富含胆固醇、鞘磷脂和 GPI 锚定蛋白的微结构域 | 脂筏尺寸小（~70 nm）、动态变化，难以直接观察 |

> **考试重点：** 流动镶嵌模型是膜生物学的“中心法则（central dogma）”，其核心是**脂双层具有流动性**，**膜蛋白以不同深度嵌入或穿透脂双层**。

### 2. 脂筏（Lipid Rafts）与胞膜窖（Caveolae）

- **脂筏**：质膜和高尔基体反面膜囊（TGN）上富含**胆固醇（cholesterol）**、**鞘磷脂（sphingolipids）**和 **GPI 锚定蛋白**的微结构域（microdomains），直径约 70 nm。
- **功能**：作为信号转导的平台（signaling centers），富集特定受体和信号分子。
- **胞膜窖（Caveola）**：一种特殊的脂筏，含有**小窝蛋白（caveolin）**，呈烧瓶状内陷，参与内吞和信号转导。

## 二、生物膜的化学组成

生物膜主要由**脂类（Lipids）**、**蛋白质（Proteins）**和**糖类（Carbohydrates）**组成。

### 1. 膜脂（Membrane Lipids）

膜脂是**两亲性（amphipathic）**分子，具有亲水头部（hydrophilic head）和疏水尾部（hydrophobic tail）。主要分为三类：

| 类型 | 代表分子 | 特点与功能 |
| :--- | :--- | :--- |
| **磷脂（Phospholipids）** | 磷脂酰胆碱（PC）、磷脂酰乙醇胺（PE）、磷脂酰丝氨酸（PS）、磷脂酰肌醇（PI）、鞘磷脂（SM） | 构成脂双层骨架；PI 可被磷酸化参与信号转导 |
| **糖脂（Glycolipids）** | 神经节苷脂（GM1 ganglioside，含唾液酸 NANA）、半乳糖脑苷脂 | 位于质膜外侧，参与细胞识别 |
| **固醇（Sterols）** | 胆固醇（cholesterol，仅存在于动物细胞） | 调节膜的流动性（低温防冻结，高温防过流动）；降低膜的亲水性 |

#### 脂质体（Liposome）

- 磷脂在水溶液中自发形成封闭的囊泡（liposome），内部包裹水相。
- **应用**：药物递送、膜蛋白重构（如纳米磷脂盘 nanodisc）。

#### 磷脂酰肌醇（PI）与信号转导

- PI 可被 **PI3K** 磷酸化为 PIP3，招募下游蛋白（如 AKT）；
- PI 可被 **磷脂酶 C（PLC）** 水解为 DAG 和 IP3，产生第二信使。

> **磷脂酶分类（易考）：**
> - **磷脂酶 A1**：切 sn-1 酰基链；
> - **磷脂酶 A2**：切 sn-2 酰基链，释放花生四烯酸；
> - **磷脂酶 B**：同时具有 A1 和 A2 活性；
> - **磷脂酶 C**：切磷酸基团之前，释放 DAG 和磷酸化头部；
> - **磷脂酶 D**：切磷酸基团之后，释放磷脂酸和醇。

### 2. 膜蛋白（Membrane Proteins）

膜蛋白约占生物膜总质量的 20–30%。根据与脂双层的结合方式，分为三类：

| 类型 | 结合方式 | 举例 | 分离方法 |
| :--- | :--- | :--- | :--- |
| **内在膜蛋白（Integral / Intrinsic）** | 跨膜区（疏水 α 螺旋或 β 桶）嵌入脂双层 | 通道蛋白、受体、GPI 锚定蛋白 | 必须用**去垢剂（detergent）**破坏脂双层 |
| **外周膜蛋白（Peripheral / Extrinsic）** | 通过离子键等弱键结合在膜表面或内在蛋白上 | 多种磷脂酶、细胞骨架蛋白 | 改变离子强度（如高盐）即可分离 |
| **脂锚定蛋白（Lipid-anchored）** | 通过共价连接的脂质锚定在膜上 | Src 激酶（豆蔻酰化）、Ras（法尼基化）、GPI 锚定蛋白 | 可用去垢剂或磷脂酶 C 处理 |

#### 膜蛋白与脂双层结合的几种方式（课件 Page 21）

1. 单次跨膜 α 螺旋；
2. 多次跨膜 α 螺旋；
3. 跨膜 β 桶（β barrel）；
4. 通过两亲性 α 螺旋结合；
5. 通过共价脂质锚定（脂肪酸：豆蔻酰化、棕榈酰化；异戊二烯：法尼基化）；
6. 通过 GPI 锚定（糖脂锚定蛋白）；
7. 与非共价结合的其他膜蛋白结合。

#### 去垢剂（Detergents）

- **作用**：破坏脂双层，溶解膜蛋白，形成蛋白-去垢剂胶束（micelle）。
- **常用类型**：
  - **SDS**：离子型，强变性，常用于 SDS-PAGE；
  - **Triton X-100**：非离子型，温和，常用于膜蛋白提取；
  - **β-辛基葡萄糖苷（β-octylglucoside）**：非离子型，温和，适合重构膜蛋白。
- **CMC（临界胶束浓度）**：去垢剂形成胶束的最低浓度。
- **纳米磷脂盘（nanodisc）**：用膜支架蛋白将磷脂双分子层包裹成盘状，用于重构膜蛋白。

#### 膜蛋白的糖基化

- 膜蛋白多在**非胞质侧（non-cytosolic side）**被糖基化；
- 类型：**N-连接糖基化**（Asn 残基）和 **O-连接糖基化**（Ser/Thr 残基）；
- 功能：帮助折叠、增强稳定性、参与细胞识别。

### 3. 膜糖类与糖被（Glycocalyx）

- 质膜外侧的糖类通过共价键连接在膜脂（糖脂）和膜蛋白（糖蛋白）上，形成**糖被（glycocalyx）**。
- **功能**：细胞识别、免疫应答、细胞黏附、保护细胞表面。
- 糖脂例子：**GM1 神经节苷脂**，含唾液酸（NANA），位于质膜外侧。

## 三、生物膜的三大特征

### 1. 流动性（Fluidity）

#### 膜脂的运动方式

| 运动方式 | 说明 |
| :--- | :--- |
| **侧向扩散（lateral diffusion）** | 在同一层内移动，最常见 |
| **旋转（rotation）** | 绕自身轴旋转 |
| **摆动（flexion）** | 碳氢链的摆动 |
| **翻转（flip-flop）** | 从一层翻到另一层，**很少发生**（能量上不利），由 flippase/scramblase 催化 |

#### 影响流动性的因素

- **脂肪酸链长度**：链越短，流动性越高；
- **不饱和度**：双键越多，流动性越高（顺式双键产生“折角”）；
- **胆固醇**：双向调节（低温增加流动性，高温降低流动性）；
- **温度**：温度升高，流动性增加。

#### 检测流动性的技术

- **FRAP（荧光漂白恢复，Fluorescence Recovery After Photobleaching）**：用激光漂白特定区域，观察荧光恢复速度，判断膜蛋白或膜脂的扩散速率。
- **FLIP（荧光丢失，Fluorescence Loss In Photobleaching）**：反复漂白同一区域，观察整体荧光减弱。
- **细胞融合实验**：小鼠细胞与人细胞融合，荧光标记的膜蛋白在杂交细胞表面重新分布，证明膜蛋白可以侧向扩散。

### 2. 不对称性（Asymmetry）

#### 膜脂的不对称分布

| 小叶（leaflet） | 主要脂质 |
| :--- | :--- |
| **外层（exoplasmic / outer）** | 磷脂酰胆碱（PC）、鞘磷脂（SM）、糖脂 |
| **内层（cytosolic / inner）** | 磷脂酰乙醇胺（PE）、磷脂酰丝氨酸（PS）、磷脂酰肌醇（PI）、胆固醇（部分） |

- **PS 外翻**是细胞凋亡（apoptosis）的早期标志，可被巨噬细胞识别。
- **功能意义**：
  - 胞质侧蛋白可特异性结合内层脂质头部（如 PKC 结合 PS）；
  - PI 可被 PI3K 修饰，招募信号蛋白；
  - 磷脂可被磷脂酶切割产生第二信使。

#### 膜蛋白与糖的不对称性

- 内在膜蛋白**定向插入**膜中，具有明确的方向性（如 N 端在胞外或胞内）；
- 膜糖类**只分布在质膜外侧**（E 面）；
- 冷冻蚀刻（freeze-fracture）可显示 P 面（protoplasmic face，胞质侧）和 E 面（ectoplasmic face，外质侧）的蛋白颗粒分布差异。

### 3. 不均一性（Heterogeneity）与脂筏

- 膜脂在平面上的分布不均匀，形成**脂筏（lipid rafts）**等微结构域。
- **脂筏**富含胆固醇、鞘磷脂和 GPI 锚定蛋白，参与信号转导。
- **形成因素**：鞘磷脂与胆固醇的相互作用、膜骨架限制、紧密连接限制、胞内外蛋白结合。
- **人工脂双层实验**：PC + SM 均匀混合；加入胆固醇后出现**侧向相分离（lateral phase separation）**，形成“筏”样结构。
- **膜蛋白与脂质的区域化**：如豚鼠精子质膜分为前头、后头、尾部三个结构域；上皮细胞顶端膜与基底膜蛋白分布不同，紧密连接阻止膜蛋白侧向扩散。

## 四、膜功能概述

课件 Page 52–53 概括了生物膜的主要功能：

| 功能 | 说明 |
| :--- | :--- |
| **界定边界** | 质膜界定细胞边界，膜性细胞器界定细胞内区室 |
| **区室化（compartmentalization）** | 膜形成连续片层，包围细胞内不同区室 |
| **物质运输** | 膜蛋白协助物质在区室间移动 |
| **信号转导** | 膜受体感知外界信号并传递到细胞内 |
| **细胞间相互作用** | 膜介导细胞识别、通讯和连接 |
| **生化反应场所** | 膜提供支架，组织酶促反应 |
| **能量转导** | 膜参与光合作用、氧化磷酸化、离子梯度储能 |

## 五、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **膜结构模型** | 单位膜模型 → 流动镶嵌模型（脂双层流动、蛋白镶嵌）→ 脂筏模型（胆固醇+鞘磷脂微区） |
| **膜脂** | 磷脂、糖脂、胆固醇；两亲性；脂质体；PI 与信号转导；磷脂酶分类 |
| **膜蛋白** | 内在（跨膜，需去垢剂）、外周（弱键，可高盐分离）、脂锚定（GPI、脂肪酸、异戊二烯） |
| **去垢剂** | SDS（强变性）、Triton X-100（温和）、β-辛基葡萄糖苷（温和）；CMC；纳米磷脂盘 |
| **膜糖** | 糖蛋白、糖脂、糖被；N-连接/O-连接糖基化；糖类只在外侧 |
| **膜特性** | 流动性（FRAP、FLIP、细胞融合）、不对称性（PS 外翻、糖基外侧）、不均一性（脂筏） |
| **膜功能** | 界定边界、区室化、运输、信号、细胞间作用、生化反应场所、能量转导 |
