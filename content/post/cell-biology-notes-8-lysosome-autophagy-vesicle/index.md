# **细胞生物学学习笔记 8 | 溶酶体、自噬与囊泡运输的分子机制**

---

> **对应课件：** Lecture 6 - Vesicle 2026  
> **本章核心内容：** 溶酶体的结构动态与 M6P 分选途径、溶酶体相关疾病、自噬的分类与分子机制（宏自噬、线粒体自噬）、囊泡运输的基本步骤（包被蛋白、Rab、SNARE、马达蛋白）、非经典分泌途径  
> **复习目标：** 掌握溶酶体酶的 M6P 靶向机制及 I-细胞病原理；理解自噬的核心步骤及 LC3 脂化过程；掌握囊泡定向运输与融合的分子机制；了解非经典分泌的主要类型。

## 一、溶酶体 (Lysosomes)

溶酶体是细胞内负责降解大分子物质的单层膜细胞器，含有大量**酸性水解酶**，标志酶为**酸性磷酸酶 (acid phosphatase)**。其形态和内容物具有高度的**异质性 (Heterogeneous)** 和**动态变化**。

### 1. 溶酶体的膜结构特征
*   **V 型质子泵 (V-type H⁺-ATPase)**：消耗 ATP 将 H⁺ 泵入溶酶体，维持腔内酸性环境 (pH ~ 5.0)，以激活酸性水解酶。
*   **高度糖基化的膜蛋白**：如 LAMP1/2，保护溶酶体膜免受自身水解酶的消化。
*   **转运蛋白**：将降解产物（如氨基酸、单糖）转运至细胞质供细胞再利用。

### 2. 溶酶体酶的分选与生物发生：M6P 途径
溶酶体蛋白在粗面内质网合成后，必须被精准靶向到溶酶体：
1.  **M6P 标记生成**：在**顺面高尔基体 (cis-Golgi)** 中，溶酶体水解酶上的甘露糖残基被 **GlcNAc 磷酸转移酶 (GlcNAc phosphotransferase)** 识别，加上磷酸基团，随后切去 GlcNAc，暴露出**甘露糖-6-磷酸 (M6P)**。
2.  **受体结合**：在**反面高尔基体网络 (TGN)**，M6P 标签被 **M6P 受体**识别。
3.  **网格蛋白包被**：受体-货物复合物聚集在网格蛋白包被小窝中，出芽形成运输囊泡。
4.  **解离与回收**：囊泡与晚期内体融合，**低 pH 环境**使 M6P 与受体分离，受体通过 COPI 囊泡回收至 TGN。

### 3. 溶酶体的功能
*   **消化中心**：降解大分子、吞噬体 (Phagosome) 和自噬体 (Autophagosome)。
*   **分泌功能（胞吐）**：如**破骨细胞 (Osteoclasts)** 分泌水解酶和 H⁺ 进行骨吸收；中性粒细胞在炎症时释放水解酶。
*   **质膜修复**：溶酶体与受损质膜融合，提供膜脂补丁。
*   **信号枢纽**：表面偶联 **mTOR**（感应营养充足）和 **AMPK**（感应能量匮乏）信号。

### 4. 溶酶体相关疾病
*   **自溶作用 (Autolysis) / 硅肺 (Silicosis)**：吸入的二氧化硅颗粒被巨噬细胞吞噬后破坏溶酶体膜，导致水解酶泄漏引起细胞死亡，并释放致纤维化因子。
*   **I-细胞病 (I-cell disease / 粘脂贮积症 II 型)**：**GNPTA 基因突变**导致 GlcNAc 磷酸转移酶缺失，溶酶体酶无法加上 M6P 标签，被默认分泌到血液中。导致溶酶体内缺乏水解酶，大量底物堆积形成包涵体。
*   **Tay-Sachs 病 (家族黑蒙性痴呆)**：己糖胺酶 A 缺乏，神经节苷脂 (Gangliosides) 在神经元中大量积累，导致精神呆滞和幼年夭折。

## 二、自噬 (Autophagy)

**自噬**是真核细胞通过双层膜结构包裹自身细胞质成分（如受损细胞器、蛋白聚集体），送至溶酶体降解的过程。大隅良典因发现自噬机制获 2016 诺贝尔奖（通过酵母 ATG 突变体筛选）。

### 1. 自噬的分类
*   **巨自噬 (Macroautophagy)**：形成双膜的自噬体，是最主要的形式。
*   **微自噬 (Microautophagy)**：溶酶体膜直接内陷吞噬货物。
*   **分子伴侣介导的自噬 (CMA)**：底物（含 KFERQ 序列）通过 HSC70 结合，直接通过 LAMP2A 转运入溶酶体。

### 2. 巨自噬的步骤与分子机制
1.  **诱导 (Induction)**：饥饿或应激导致 **mTOR** 被抑制，**AMPK** 激活，进而激活 **ULK1 复合体**，启动吞噬泡形成。
2.  **成核与延伸 (Nucleation & Elongation)**：在 ER 等膜结构上形成隔离膜 (Phagophore)，依赖 PI3K 复合体（产生 PI3P）和 ATG 家族蛋白。
3.  **LC3 脂化**：延伸过程中，胞质中的 LC3-I 在 Atg7 (E1)、Atg3 (E2) 和 Atg5-Atg12-Atg16L (类似 E3) 的作用下，共价结合到磷脂酰乙醇胺 (PE) 上，形成 **LC3-II**，锚定在自噬体膜上。
4.  **闭合与融合**：自噬体闭合，与溶酶体融合形成自噬溶酶体，由水解酶降解。

### 3. 选择性自噬 (Selective Autophagy)
底物通过受体蛋白（如 **p62**）识别泛素化标签，受体再通过 **LIR 结构域**与 LC3 结合，将底物特异性地包裹进自噬体。
*   **线粒体自噬 (Mitophagy)**：
    *   **泛素依赖途径**：去极化的线粒体累积 PINK1，招募 **Parkin (E3 酶)**，使线粒体外膜蛋白泛素化，被 p62 等受体识别。
    *   **泛素非依赖途径**：线粒体表面的 Nix、BNIP3、FUNDC1 等受体直接与 LC3 结合。
*   **蛋白聚集体自噬**：液态凝聚体（经 p62 识别）、胶态（SEPA-1）和固态（CCT2 介导）均可通过自噬降解，异常会导致阿尔茨海默病、帕金森病等神经退行性疾病。

### 4. 自噬的功能
提供能量（细胞存活）、质量控制（清除受损细胞器）、清除胞内病原体、参与细胞分化与抗原递呈。过度自噬也可诱导细胞死亡（自噬性细胞死亡）。

## 三、囊泡运输 (Vesicular Transport)

囊泡运输是内膜系统物质交流的基础。基本步骤包括：**出芽 (Budding) → 脱被 (Uncoating) → 运输 (Transport) → 锚定 (Docking) → 融合 (Fusion)**。

### 1. 囊泡的包被蛋白 (Coat Proteins)
| 囊泡类型 | 包被蛋白 | 小 GTP 酶 | 运输方向 |
| :--- | :--- | :--- | :--- |
| **COP II** | Sec23/24, Sec13/31 | **Sar1** | ER → 高尔基体（顺向） |
| **COP I** | COPI 亚基复合体 | **ARF** | 高尔基体内部及高尔基体 → ER（逆向） |
| **Clathrin** | 网格蛋白 + 接头蛋白 (AP2, AP1) | **ARF** | TGN → 内体/溶酶体；质膜 → 内体（内吞） |

*   **COP I 识别信号**：负责回收逃逸的 ER 蛋白，如可溶蛋白的 **KDEL** 序列和膜蛋白的 **KKXX** 序列。
*   **Dynamin（发动蛋白）**：一种 GTP 酶，负责在网格蛋白囊泡颈部收缩，使其从质膜上切断。

### 2. 囊泡的定向运输：马达蛋白 (Motor Proteins)
囊泡沿微管 (Microtubules) 运输：
*   **Kinesin（驱动蛋白）**：向微管的 **(+) 极** 移动（通常朝向细胞外周），介导顺向运输。
*   **Dynein（动力蛋白）**：向微管的 **(-) 极** 移动（通常朝向细胞中心），介导逆向运输。

### 3. 囊泡的锚定与融合：Rab 与 SNARE
*   **Rab 蛋白**：小 GTP 酶家族（分子开关）。结合 GTP 时，其脂质基团暴露并插入膜中，负责将囊泡精确引导至靶膜并进行锚定 (Tethering)。受 GEF（激活）和 GAP（失活）调控。
*   **SNARE 复合体**：
    *   **v-SNARE**（囊泡膜上）与 **t-SNARE**（靶膜上）通过拉链式缠绕形成紧密的**四螺旋束**，克服水合排斥力，驱动两层膜融合。
    *   融合后，**NSF**（一种 ATP 酶）利用 ATP 水解的能量解开 SNARE 复合体，实现循环利用。

## 四、非经典分泌 (Unconventional Secretion)

无信号肽的蛋白质（如炎症因子、生长因子）不经过 ER-高尔基体途径的分泌方式。主要有四种类型：
*   **I 型**：直接跨质膜转运。如 FGF2 通过 ATP1A1 和 Tec 激酶介导；**THU 途径**（HSP90A 协助货物去折叠，通过 **TMED10** 通道转运）。
*   **II 型**：利用 ABC 转运蛋白跨膜。
*   **III 型**：利用跨膜载体或膜翻转。
*   **IV 型**：依赖自噬/溶酶体途径。如无前导序列的 **IL-1β** 通过 **GSDMD 孔**直接释放；或进入多泡体 (MVB) 释放。
*   **CMA (分子伴侣介导的自噬)**：含 KFERQ 序列的蛋白通过 HSC70 进入溶酶体。
*   **MAPS (错误折叠蛋白分泌)**：错误折叠蛋白通过 USP19、DNAJC5 等转运至细胞膜分泌。

## 五、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **溶酶体** | 酸性水解酶；V 型泵维持 pH 5.0；膜蛋白高度糖基化防自溶。 |
| **M6P 途径** | 溶酶体酶在高尔基体被 GlcNAc 磷酸转移酶修饰为 M6P，由 M6P 受体分选至溶酶体。 |
| **相关疾病** | I-细胞病（GNPTA 突变，M6P 标记失败）；Tay-Sachs（酶缺乏导致脂质堆积）；硅肺（溶酶体破裂）。 |
| **自噬** | 巨自噬、微自噬、CMA。巨自噬受 mTOR/AMPK 调节，依赖 ATG 基因。LC3-II 是自噬体标志。 |
| **选择性自噬** | 泛素化货物由 p62 等受体（LIR 结构域）识别；线粒体自噬由 PINK1/Parkin 或 Nix 介导。 |
| **囊泡出芽** | COPII (ER→Golgi), COPI (Golgi 内部/回收), Clathrin (内吞/TGN)。Dynamin 负责切断。 |
| **靶向与融合** | 马达蛋白 (Kinesin 顺向，Dynein 逆向)；Rab 负责锚定；SNARE (v/t) 负责融合，NSF 负责解离。 |
| **非经典分泌** | I 型 (TMED10, GSDMD)，IV 型 (自噬途径)，CMA (LAMP2A)。 |
