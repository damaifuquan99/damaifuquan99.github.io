# **细胞生物学学习笔记 6 | 细胞内膜系统、蛋白质分选与膜泡运输**

---

> **对应课件：** Lecture 4 - Transport-sorting 2026（Page 48–101，Chapter 6 前半：区室化与蛋白质分选）+ Lecture 5 - membrane trafficking 2026（Page 1–79，内膜系统与膜泡运输）
> **本章核心内容：** 真核细胞的三类区室与内膜系统；无膜区室与相分离；蛋白质分选的三种机制（门控、跨膜、囊泡）；信号假说与共翻译转运（SRP、SRP 受体、SEC61）；非经典分泌（THU）；线粒体 TOM/TIM、叶绿体类囊体与核孔运输；内质网（rER 的合成/糖基化/质量控制/UPR、sER 的六项功能、脂质合成）；高尔基体的极性、糖基化加工、分选与两种运输模型；胞吞的四种类型（液相、受体介导、吞噬、caveolae）与胞内体途径（LDL、转铁蛋白、MVB、外泌体）。
> **复习目标：** 能说清"三种分选机制"各对应哪些细胞器；能复述 Milstein 实验与信号假说的推理链；能默写 SRP 的三个活性位点与 SEC61 的作用；能比较共翻译与翻译后转运；能解释 KDEL 受体为什么靠 pH 工作；能列出 rER 与 sER 的功能清单；能说清高尔基体 cis→trans 的化学标志与"顺面成熟 vs 囊泡运输"两种模型；能画出 LDL 受体介导胞吞的完整路径与其四种遗传缺陷。

## 一、区室化：真核细胞的空间组织

### 1. 三类区室（p50）

课件把真核细胞的膜性区室分为**三类**：

1. **胞质溶胶（cytosol）**；
2. **内膜系统（endomembrane system）**：**ER、高尔基体、内体、溶酶体、运输囊泡、过氧化物酶体（peroxisomes）**；
3. **线粒体、叶绿体、细胞核**。

课件同时提醒两条：**所有真核细胞都有膜围成的细胞器**；**无膜区室（membraneless compartments）也可以作为独立的反应中心（independent reaction hubs）**。

> **补充：** 教材通常把过氧化物酶体单列（它不由 ER 出芽、蛋白靠 PTS 信号 + PEX 蛋白导入），不归入内膜系统。课件把 peroxisome 列入内膜系统，这里按课件原样记录（课件未讲分类争议）。

### 2. 胞质溶胶 vs 细胞质（p51）

| 概念 | 定义 |
| :--- | :--- |
| **细胞质（cytoplasm）** | 细胞核以外的**全部**内容（含细胞器） |
| **胞质溶胶（cytosol）** | 细胞质中**膜性细胞器之外**的液体部分 |

**胞质溶胶的功能（课件原文）：** 蛋白质**合成、修饰、降解**的场所；执行细胞**大部分中间代谢（intermediary metabolism）**。

**为什么这个区分重要：** "蛋白质在胞质溶胶中合成"只对**核基因编码的蛋白**成立，且只是"起点"——之后要么留在胞质，要么被分选进细胞器。这是本章所有分选路径的出发点。

### 3. 肝细胞各区室体积占比（p53）

课件给出定量表（**占细胞总体积的百分比**）：

| 区室 | 占比 |
| :--- | :--- |
| **胞质溶胶** | **54%** |
| **线粒体** | **22%** |
| **粗面 ER 池（rER cisternae）** | **9%** |
| **光面 ER + 高尔基体池** | **6%** |
| **细胞核** | **6%** |
| **过氧化物酶体** | **1%** |
| **溶酶体** | **1%** |
| **内体** | **1%** |

**读表要点：** ① 胞质溶胶占一半以上，说明"分选"必须在一半以上的空间里精准进行；② 线粒体占 22%，是肝细胞（高耗能）的特征；③ 溶酶体/内体只占 1%，但通量极大——**体积小 ≠ 功能弱**，它们是"物流枢纽"而非"仓库"。

### 4. 内膜系统与它的动态性（p55–56）

**定义（p55）：** 内膜系统是**结构与功能相关**的细胞器集合，包括 **ER、高尔基复合体、内体、溶酶体、运输囊泡**。

**动态性（p56）：** "**大多数细胞器是动态系统的一部分，囊泡在区室之间移动**。" 课件列出四条：

| 途径 | 方向 | 内容 |
| :--- | :--- | :--- |
| **生物合成途径（biosynthetic pathways）** | ER → 高尔基体 → …… | 运输**蛋白质、糖类、脂类** |
| **分泌途径（secretory pathways）** | 向内 → 质膜/胞外 | 把蛋白质**排出细胞** |
| **胞吞途径（endocytic pathways）** | 质膜 → 向内 | 把物质**运入细胞** |
| **分选信号（sorting signals）** | —— | 被**受体识别**，把蛋白导向特定位点 |

**为什么"动态"是内膜系统的第一属性：** 内膜系统不是一堆静态的"房间"，而是一条**有方向的流水线**：ER 是"车间"，高尔基体是"加工与分拣中心"，囊泡是"运输车"，溶酶体/质膜是"目的地"。理解这条流水线的**方向性**，是理解后面所有机制的前提。

### 5. 无膜区室与相分离（p57–62）

课件用了 6 页讲"没有膜的区室"，这是近年细胞生物学的重要转向。

#### （1）现象

- **碳固定（carbon fixation）** 中的无膜区室（p57）——如蓝细菌的**羧酶体（carboxysome）**，把 Rubisco 浓缩在蛋白外壳内提高固碳效率；
- 细胞内多种**无膜区室**（p58）——核仁、应激颗粒、P 颗粒、突触囊泡簇等。

#### （2）机制：液-液相分离（LLPS）

课件 p59 给出三条：

1. **不同性质的凝聚体（condensates with different properties）可以共存**，作为更大结构的一部分；
2. **支架蛋白（scaffold proteins）组织凝聚体**；
3. 形成机制是**液-液相分离（liquid–liquid phase separation）**。

**怎么工作：** 多价（multivalent）蛋白/RNA 之间通过**弱而多的相互作用**（如低复杂度结构域、RNA-蛋白、电荷-电荷）交联成网络；当浓度超过**饱和浓度（saturation concentration）** 时，从均匀溶液中"分"出一相——形成富集的液滴，液滴与周围溶液**不混溶**但分子可自由进出。**关键判据：** 液滴会**融合（fusion）**、**圆形化（rounding）**、**荧光漂白后快速恢复（FRAP 快）**——即"液体"性质。

**学术背景（p5–6）：** 课件引 **Hyman et al., Annu Rev Cell Dev Biol, 2014**；**2023 年生命科学突破奖（Breakthrough Prize）授予 Clifford P. Brangwynne 与 Anthony A. Hyman**——表彰他们发现相分离/凝聚体。

#### （3）三个具体例子（p60–62）

| 例子 | 内容 | 出处 |
| :--- | :--- | :--- |
| **突触前终末的 SV（突触囊泡）组织** | 相分离参与突触前 bouton 中囊泡簇的组织 | **张明杰教授**（南方科技大学），Wu et al., *JMB*, 2023；Wu et al., *Mol Cell*, 2021 |
| **相分离调控凝聚体的自噬降解** | 凝聚体**相转变（phase transition）：liquid → gel → solid**；PGL 颗粒（EPG-2/SEPA-1/PGL-1/-3，1 μM，1 min → 12 h） | **张宏研究员**（中科院生物物理所），Zhang et al., *Cell*, 2018 |
| **CCT2 把固体凝聚体送进自噬降解** | 生理 vs 病理（如 **AD、PD**）；CCT2 靶向**固体凝聚体**至自噬降解 | **马欣宇研究员**，Ma X et al., *Cell*, 2022 |

**为什么"相分离"对本章重要：** 它给出了**除膜之外的第二种"区室化"方式**——不靠脂双层，而靠"相"的边界。这样一来，"细胞如何组织生化反应"就有两套答案：**膜围成的区室**（本章主线）与**相分离形成的凝聚体**（近年新增）。二者并非互斥：许多膜性细胞器内部也有凝聚体（如核仁、ER 腔内的蛋白聚集体）。

**为什么"液→凝胶→固体"的转变重要（p61）：** 液态凝聚体是可逆、动态的；一旦"固化"，就难以被降解——**神经退行性疾病（AD、PD、ALS）中的蛋白聚集体正是"过度固化"的凝聚体**。细胞因此需要专门的"清障机制"：p62 的 **CCT2**（伴侣蛋白 TRiC 的亚基）能识别固体凝聚体并把它们交给**自噬**降解，这就是"**凝聚体质量控制（condensate quality control）**"。

## 二、蛋白质分选总览

### 1. 三种进入细胞器的机制（p64）

> **Proteins are imported into organelles by three mechanisms:**
> - **Gated Transport**：through **nuclear pores**（核孔）
> - **Transmembrane Transport**：**ER、mitochondria、chloroplast、peroxisome**（跨膜转运）
> - **Vesicular Transport**：**ER–Golgi–PM–endosome–lysosome**（囊泡运输）

| 机制 | 通道 | 蛋白状态 | 是否需展开 | 举例 |
| :--- | :--- | :--- | :--- | :--- |
| **门控转运** | 核孔复合体 | **折叠并装配好**的蛋白 | 否（折叠态通过） | 核蛋白（NLS） |
| **跨膜转运** | 膜上的**转位子（translocon）** | **单条、未折叠**的肽链 | 是（需伴侣蛋白辅助） | ER（信号肽）、线粒体/叶绿体/过氧化物酶体（引导序列） |
| **囊泡运输** | 囊泡出芽/融合 | 已折叠、已完成修饰的蛋白 | 否 | ER→高尔基体→质膜/内体/溶酶体 |

**这张表是本章的"地图"：** 后文所有内容都可以归到这三行中的某一行——信号假说属"跨膜转运"，KDEL 回收属"囊泡运输"，核孔属"门控转运"。

### 2. 分选信号的特征（p68）

课件原文："**蛋白质分子在分选信号的引导下，从胞质溶胶移动到靶细胞器或细胞表面。**"

**两条规律：**
1. **大多数分选信号位于 N 端或 C 端**；
2. **核运输的信号例外——可以位于肽链的任何位置**。

**为什么核信号可以"任意位置"：** 因为核孔运输的是**折叠好的蛋白**，信号只需暴露在表面即可被 importin 识别；而跨膜转运要求信号在**未折叠链**上被 SRP/转位子识别，通常必须在末端才能保证"先被识别、再被拉进去"的顺序。

### 3. Road map（p65–66）

课件用两页"蛋白质分选路线图"把全部路径画在一起。**主线（记住这一条即可）：**

**核基因编码的蛋白在胞质溶胶的游离核糖体上开始翻译** →
- 若带 **ER 信号序列** → 核糖体附着到 ER → **共翻译转运**入 ER 腔/膜 → 经高尔基体分选 → 溶酶体、质膜、分泌到胞外；
- 若带**线粒体/叶绿体/过氧化物酶体引导序列** → 翻译完成后（**翻译后转运**）由相应转位子导入；
- 若带 **NLS** → 经核孔进入细胞核（**门控转运**）；
- 若不带任何信号 → 留在胞质溶胶。

## 三、信号假说与共翻译转运

### 1. Milstein 实验：一个"多出 20 个氨基酸"的线索（p69）

课件 p69 给出关键实验：

> **Milstein et al：在无细胞体系中研究 IgG 轻链的合成**——产物比**真实轻链 N 端长 20 个氨基酸**；
> **向该体系加入 ER 膜**后，产物变成**正确大小**的 IgG 轻链。

**推理链（这是"信号假说"的实验根基）：**
1. 无细胞体系（只有核糖体 + mRNA + 氨基酸）中，产物**多了一段**——说明 mRNA 编码的是一条"前体"，多出的部分是**信号序列**；
2. 加入 ER 膜后，产物**变短**——说明这段序列在 ER 膜存在时被**切除**了；
3. 结论：**信号序列的功能是"把正在合成的肽链导向 ER"，并在进入 ER 腔后被信号肽酶切掉**。

**为什么这个实验漂亮：** 它用"**分子量差异**"（20 aa ≈ 2 kDa）作为唯一读数，把"分选"这种看不见的过程变成了**可测量的电泳条带位移**。

### 2. Blobel 与 Sabatini 的模型（p70）

> **G. Blobel and D. Sabatini（1971）提出了共翻译导入（cotranslational import）信号机制的模型。**

**模型内容：** 信号序列在**新生肽链**上出现 → 被胞质中的**信号识别颗粒（SRP）** 识别并结合 → 翻译**暂停** → SRP-核糖体复合物结合到 **ER 膜上的 SRP 受体** → 核糖体附着到 ER → 翻译恢复，肽链**边合成边穿过** ER 膜 → 信号肽被切除。

**为什么这是"共翻译（co-translational）"：** 转运与翻译**同时进行**——肽链还没合成完，就已经在穿过 ER 膜了。这与线粒体/叶绿体的"**翻译后转运**"（先合成完整前体，再导入）形成对比。

**学术地位（p21）：** Blobel 因"蛋白质在细胞内运输与定位的信号"获 **1999 年诺贝尔生理学或医学奖**；Palade 因细胞超微结构与功能获 **1974 年诺贝尔奖**（他最早描述 ER 与核糖体）。

### 3. ER 信号序列的结构（p71）

> **ER signal sequence：通常 15–30 个氨基酸，由三个结构域组成：**
> - **带正电的 N 端区（positively charged N-terminal region）**；
> - **中央疏水区（central hydrophobic region）**；
> - **极性的 C 端区（polar region）**，紧邻成熟蛋白的切割位点。

**为什么是"三段式"：** ① N 端正电荷帮助肽链以正确方向插入转位子（"正电荷在内"规则）；② 中央疏水段是**真正插入脂双层/转位子孔道**的部分，也是 SRP 识别的核心；③ C 端极性区提供**信号肽酶的切割位点**，保证切下的位置精确。

**切除后：** 成熟蛋白的 N 端就是原本信号肽之后的那一段。

### 4. SRP 与 SRP 受体（p71）

**SRP 的组成：** **6 种不同多肽 + 1 个约 300 个核苷酸的 RNA**（即 **7S RNA**）——是一个**核糖核蛋白（RNP）**。

**SRP 的三个主要活性位点（课件原文，务必记住三个"一个……一个……一个……"）：**

| 位点 | 作用 |
| :--- | :--- |
| ① | **识别并结合 ER 信号序列** |
| ② | **与核糖体相互作用，阻断进一步翻译**（暂停翻译，防止肽链在胞质中折叠/聚集） |
| ③ | **结合 ER 膜上的 SRP 受体（docking protein）** |

**SRP 受体：** 是一种 **GTP 结合蛋白（GTP-binding protein）**。SRP 与受体结合后，**GTP 水解**驱动 SRP 从复合物上释放，核糖体与转位子对接，翻译恢复。

**为什么"暂停翻译"是关键设计：** 如果肽链继续在胞质中延伸，疏水的信号序列会**在胞质中聚集/被蛋白酶降解**，且肽链会提前折叠，无法穿过狭窄的转位子孔道。**暂停 = 给转运争取时间窗口。**

### 5. SEC61 转位子与穿膜过程（p72–73）

课件 p72 给"**可溶性蛋白跨 ER 膜转位**"，p73 给"**SEC61 转位子结构与信号肽的作用**"。

**SEC61 复合物：** 由 **α、β、γ 三个亚基**组成，α 亚基形成**漏斗状的孔道（aqueous pore）**，孔道在侧面有一个**"侧门（lateral gate）"**，可以让疏水的跨膜段**侧向离开孔道、进入脂双层**——这就是"可溶性蛋白留在腔内、跨膜蛋白留在膜内"的分岔点。

**可溶性蛋白的完整路径：**
1. SRP-核糖体复合物结合 SRP 受体 → 核糖体对接 SEC61；
2. 信号肽插入 SEC61 孔道，**侧门**打开，信号肽的疏水段留在脂双层中；
3. 后续肽链**边翻译边穿过**孔道进入 ER 腔；
4. **信号肽酶（signal peptidase）** 在腔侧切下信号肽，信号肽随后被降解；
5. 肽链完全进入腔后，SEC61 孔道关闭。

**为什么 SEC61 的"侧门"决定蛋白拓扑：** 同一个转位子既处理可溶性蛋白（全穿过去），又处理跨膜蛋白（疏水段从侧门"漏"进膜里）——**拓扑由肽链上疏水段的位置与数量决定**，而不是由转位子决定（p76–78 展开）。

### 6. 共翻译 vs 翻译后转运（p74）

| | **共翻译转运** | **翻译后转运** |
| :--- | :--- | :--- |
| 时机 | 翻译**进行中**就穿膜 | 翻译**完成后**再导入 |
| 主要对象 | **ER**（分泌蛋白、膜蛋白、溶酶体酶） | **线粒体、叶绿体、过氧化物酶体**；部分小蛋白也可翻译后进 ER |
| 依赖 | **SRP + SRP 受体 + SEC61** | 需**伴侣蛋白（Hsp70 等）**维持未折叠态 + 膜上转位子（TOM/TIM 等） |
| 能量 | 翻译的延伸力 + BiP 等 | **ATP**（线粒体）/+ **膜电位** |

**为什么线粒体只能"翻译后"：** 线粒体的蛋白由**胞质核糖体**合成，而线粒体膜外没有"边合成边导入"的机制——必须先合成完整前体，再由 **TOM/TIM** 导入（后文 p86–89）。

### 7. 三种经 SEC 转位子的穿膜方式（p75）

课件 p75 标题："**Three ways to translocate by SEC-translocons**"。三种方式对应三类蛋白：

| 方式 | 蛋白类型 | 拓扑结果 |
| :--- | :--- | :--- |
| ① **N 端信号肽 + 可溶性蛋白** | 分泌蛋白、腔酶 | 全链进入 **ER 腔**，信号肽切除 |
| ② **N 端信号肽 + 内部停止转移序列（stop-transfer）** | **单次跨膜蛋白** | N 端在腔、C 端在胞质（I 型膜蛋白） |
| ③ **内部信号肽（可切除或不可切除）+ 后续疏水段** | **多次跨膜蛋白** | 疏水段交替从侧门进入膜，形成多次跨膜 |

#### （1）单次跨膜蛋白（p76）

> **A single-pass transmembrane protein with signal peptide.**

**过程：** N 端信号肽引导核糖体到 ER → 肽链穿入腔 → 遇到**停止转移序列（stop-transfer sequence，一段疏水段）** → 该段从侧门"卡"在膜中，**孔道关闭、翻译继续在胞质侧进行** → 结果：**N 端在腔、C 端在胞质**。

#### （2）多次跨膜蛋白（p77）

> **A multiple-pass transmembrane protein.**

**过程：** 第一个疏水段作为**内部信号肽**插入 → 后续疏水段依次作为"**信号锚（signal-anchor）**"与"**停止转移**"交替作用 → 每遇到一个疏水段，肽链的走向就翻转一次 → **n 个疏水段 = n 次跨膜**。

**为什么"疏水段数量 = 跨膜次数"：** 因为只有疏水段能在能量上"待在"脂双层里，亲水段必须待在腔或胞质。**用疏水段预测跨膜拓扑**（如 TMHMM 等算法）正是基于这条原理。

#### （3）跨膜段本身可以当信号肽（p78）

> **A transmembrane domain can serve as a signal peptide. Recognized by SRP.**
> **What happens if the TM is in the C-terminus?**

**要点：** 跨膜段（TM）本身就能被 SRP 识别，起"内部信号肽"的作用——**不需要单独的 N 端信号肽**。

**"若 TM 在 C 端会怎样"（p78–79）：** 这就是**尾部锚定蛋白（tail-anchored proteins）** ——TM 段位于 C 端，整条肽链几乎都在胞质侧，只有 C 端一小段（含 TM）插入膜。这种蛋白**不能被共翻译机制处理**（因为 TM 段在翻译后期才出现，此时核糖体已离开 ER），因此需要**翻译后**的专门途径。

### 8. 尾部锚定膜系统（p79）

**是什么：** 一类 C 端含单一跨膜段、N 端朝向胞质的膜蛋白（如 **SNARE 的某些成员、Bcl-2 家族、细胞色素 b5**）。

**怎么工作（TA 途径）：** 翻译完成后，胞质中的**伴侣蛋白（如 Get3/TRC40）** 抓住疏水的 TM 段，把它送到 ER 膜上的**受体（Get1/Get2）**，再由 **GET 复合物**把 TM 段插入膜中——**全程不经过 SEC61**。

**为什么重要：** 尾部锚定蛋白多为**膜融合（SNARE）与凋亡调控（Bcl-2）** 的关键蛋白；这条途径的存在说明"进 ER"并非只有 SEC61 一条路（p83 的非经典分泌会再扩展这一点）。

### 9. ER 中的逆向转位（p80）

> **Retro-translocation in the ER — Hrd1**

**是什么：** 错误折叠的 ER 腔内蛋白被**逆向**运回胞质，交由**蛋白酶体（proteasome）** 降解——即 **ERAD（ER-associated degradation）**。

**怎么工作：** 腔内的错误折叠蛋白被识别 → 通过 **Hrd1**（一种 E3 泛素连接酶，同时形成逆向转位通道）**逆向穿出 ER 膜** → 在胞质侧被**泛素化** → 被 **p97/VCP** 从膜上"拉出" → 交给**蛋白酶体**降解。

**为什么重要：** 质量控制是"双向"的：**正向**（只有折叠正确的才放行，p15–16）+ **逆向**（折叠错误的被拉出去销毁，p80）。两条路都断了，错误蛋白就会在 ER 中堆积 → **ER 应激 → UPR**（内质网一节展开）。

## 四、非经典分泌：没有信号肽也能出去（p81–85）

### 1. 教条（p81）

> **It has been a dogma that secretory proteins require a signal peptide.**

### 2. 问题（p82）

> **Can a cytosolic protein lacking a signal peptide enter into the secretion system?**

### 3. 答案：THU 途径（p83）

课件给出 **TMED10-Channeled Unconventional secretion（THU）**——"**一条用于非经典分泌的转位途径（a translocation pathway for unconventional secretion）**"；对照"**SEC61-channeled conventional secretion**"。

- **文献：** **M Zhang et al., 2020, *Cell***；**J Zheng et al., 2022, *NSO***（*Nature Structural & Molecular Biology* 相关）；
- **研究者：** **张敏教授（清华）**、**刘磊博士**、**Tom Rapoport（哈佛）**。

**怎么工作（THU 模型）：** 无信号肽的胞质蛋白（如 **IL-1β、IL-18、FGF2、HMGB1**）在胞质中与 **TMED10**（一种单次跨膜蛋白）结合 → TMED10 寡聚形成**通道** → 底物经该通道进入 **ERGIC/高尔基体腔** → 再经经典分泌途径释放。

**为什么重要：** 它打破了"分泌必须走 ER 信号肽"的教条，解释了**炎症因子（IL-1β）如何在没有信号肽的情况下被释放**——这是天然免疫的关键一步（也是"非经典分泌"成为热点的起点）。

### 4. 直接穿质膜（p84）

课件另列"**非经典分泌中直接穿过质膜（direct crossing of the plasma membrane）**"，并列出 **Walter Nickel（海德堡）** 与 **邵峰院士（NIBS）**。

**邵峰团队的关键发现：** **GSDMD（gasdermin D）** 被炎症 caspase 切割后，N 端片段在质膜上**寡聚成孔**，既介导 **IL-1β 的直接释放**，又导致**细胞焦亡（pyroptosis）**——这是"直接穿膜"非经典分泌的代表机制。

**p85 的路线图：** 课件在"蛋白质分选路线图"上标出两处"**非经典分泌**"，说明它是与经典 ER-Golgi 途径**并行**的一条独立路线。

## 五、线粒体、叶绿体与细胞核的蛋白导入（p86–95）

### 1. 线粒体：TOM 与 TIM（p87）

> **TOM：translocase of the outer mitochondrial membrane（外膜转位子）**
> **TIM：translocase of the inner mitochondrial membrane（内膜转位子）**

**过程：** 胞质中合成的**前体蛋白**（带 N 端**引导序列/前序列 presequence**）→ 由 **Hsp70** 维持未折叠 → **TOM40** 通道进入膜间隙 → 由 **TIM23**（或 TIM22）导入基质或插入内膜 → 基质中的 **mtHsp70** 用 ATP 把肽链"拉"进去 → **MPP（基质加工肽酶）** 切去前序列。

**能量（p89）：** "**跨线粒体内膜转位的能量驱动**"——① **ATP**（mtHsp70 的拉力和伴侣循环）；② **内膜电位 ΔΨ**（带正电的前序列在电场中向基质移动）。**两者缺一不可**，这也是"线粒体导入需要能量"的定量含义。

### 2. TIM23 的真实通道是谁（p88）

> **A hybrid working model：Tim17 与 Mgr2 可形成蛋白传导"通道"**
> **Tim17 单独就足以作为转位酶/插入酶发挥功能**
> **Tim17 in the TIM23 complex acts as the true translocase**
> ——**Zhou X. et al., *Nat. Struct. Mol. Biol.* (2023)**，**李龙教授（北京大学）**

**为什么这是一个"改写教科书"的发现：** 长期以来 TIM23 被认为由 **Tim23** 蛋白构成通道；结构生物学工作表明**真正的通道是 Tim17**（Tim23 更像"受体/支架"）。这提醒我们：**"复合物名字"不等于"通道亚基名字"**。

### 3. 叶绿体类囊体（p90）

> **Protein import to the thylakoid membrane in chloroplasts.**

**路径：** 胞质前体（带**转运肽 transit peptide**）→ **TOC**（外膜）→ **TIC**（内膜）→ 基质 → 分为四条途径进入类囊体：① **cpSec**（SEC 同源，需 ATP）；② **cpTat**（双精氨酸易位，靠 **ΔpH**）；③ **cpSRP**（信号识别颗粒同源，插入膜蛋白）；④ 自发插入（spontaneous）。

**为什么强调"四条"：** 说明同一个细胞器内也有"多种转运机制并存"——这是内膜系统"机制多样性"的又一例证。

### 4. 核孔运输（p91–95）

课件 p92 给出两个关键数字：

> **Molecules (< 40 kDa) diffuse freely（自由扩散）**
> **Molecules (> 60 kDa) are actively transported（主动转运）**

**核孔复合体（NPC）：** 约 **30 种核孔蛋白（nucleoporin, Nup）**，每个 NPC 有多个拷贝，形成**8 重对称**的圆柱；中央通道由 **FG-Nup**（含 Phe-Gly 重复）构成**水凝胶样选择性屏障**。

**主动转运机制：**
1. **货物**带 **NLS（核定位信号）** → 被 **importin α/β** 识别；
2. importin-货物复合物穿过 FG 网；
3. 核内 **RanGTP** 结合 importin β → 货物释放；
4. importin 回到胞质，**RanGAP** 水解 RanGTP → RanGDP，循环继续。

**为什么"小分子自由扩散、大分子主动运输"：** FG 网形成"**选择性相**"——小分子可溶入并扩散通过，大分子需要 **importin/exportin** 这类"通行证"携带才能穿过。**核运输的方向性由 RanGTP 梯度决定**（核内高、胞质低）。

> **补充：** 课件未展开 Ran 梯度、exportin 与 mRNA 出核。以上属教材内容（课件未讲）。

## 六、脂质的区室间运输（p96–98）

### 1. 脂质在双层上的定位（p96）

课件 p96："**Lipid positioning on the double layer membrane**"——脂质在脂双层上的**不对称分布**（Chapter 3 已讲外层胆碱头/内层伯氨基），这里强调它**在每个区室的膜上都不同**。

### 2. 膜接触位点介导脂质转移（p97）

> **Membrane contacts mediate lipid transfer between compartments.**

**是什么：** 两个细胞器的膜靠得很近（**10–30 nm**）形成"**膜接触位点（membrane contact sites, MCS）**"，如 ER-线粒体、ER-质膜、ER-内体。

**怎么工作：** **脂质转移蛋白（LTP）** 在两个膜之间"摆渡"单个脂分子——**不经过囊泡**，因此速度快、可逆、可精细调节。

### 3. 囊泡 vs 非囊泡脂质运输（p98）

| 方式 | 机制 | 特点 |
| :--- | :--- | :--- |
| **囊泡运输（vesicular）** | 膜本身随囊泡移动 | 大量、批量；**同时带走膜蛋白** |
| **非囊泡（non-vesicular）** | LTP / MCS "摆渡" | 选择性、快速、可逆；**不移动膜蛋白** |

**为什么需要非囊泡途径：** 有些细胞器（线粒体、叶绿体）不参与囊泡流，但仍需从 ER 获取脂质——只能靠 MCS + LTP。**这是"脂质不能只靠囊泡运"的结构性原因。**

## 七、内质网（ER）

> **（本节起页码切换：第七至九节对应 Lecture 5 - membrane trafficking 2026 的第 1–79 页；第一至六节对应 Lecture 4 的第 48–101 页。）**

### 1. 结构：rER 与 sER（p9）

> **rER has ribosomes on the cytosolic side of continuous, flattened sacs (cisternae)；sER is an interconnecting network of tubular membrane elements.**

| | **粗面 ER（rER）** | **光面 ER（sER）** |
| :--- | :--- | :--- |
| 形态 | **扁平的池（cisternae）**，胞质侧有**核糖体** | **相互连通的管状网络** |
| 主要功能 | 蛋白质合成、修饰、质量控制 | 脂质合成、Ca²⁺ 储存、解毒 |

**两者是连续的：** 同一个 ER 网络的不同区域，**rER 与 sER 的边界可以随功能变化**（如未折叠蛋白增多时，rER 扩张）。

### 2. 微粒体（microsome，p10）

> **Microsomes are heterogeneous mixtures of similar-sized vesicles, formed from membranes of the ER and Golgi complex. Microsomes retain activity during purification, allowing studies of function and composition.**

**是什么：** 细胞匀浆后，ER 与高尔基体膜**破碎并重新封闭**成 **100–200 nm** 的小囊泡。

**为什么重要：** 它是**体外研究 ER 功能的经典材料**——微粒体保留了**信号肽酶、糖基转移酶、PDI、Ca²⁺ 泵**等活性，可以做"共翻译转运"的体外重建（Milstein 实验正是用了 ER 膜/微粒体）。**"破碎后还能工作"说明膜蛋白的拓扑与酶活性不依赖细胞完整性。**

### 3. rER 的三项功能（p11）

1. **蛋白质合成（protein synthesis）**；
2. **新合成蛋白的修饰与加工（modification and processing）**：**rER 中的糖基化（glycosylation）**；
3. **新合成蛋白的质量控制（quality control）**：**N-连接糖基化在 ER 蛋白折叠中的作用**。

#### （1）哪些蛋白在 rER 上合成（p12）

> ① **分泌蛋白（secretory proteins）**；② **整合膜蛋白（integral membrane proteins）**；③ **细胞器的可溶性蛋白（soluble proteins of organelles）**。

**为什么是这三类：** 它们都要**穿过或进入 ER 膜**，因而必须走"共翻译转运"；而留在胞质溶胶的蛋白、以及去线粒体/叶绿体/核的蛋白，则在**游离核糖体**上合成。

### 4. N-连接与 O-连接糖基化（p13）

| | **N-连接（N-linked）** | **O-连接（O-linked）** |
| :--- | :--- | :--- |
| 连接位点 | **天冬酰胺（Asn）的酰胺氮** | **丝氨酸/苏氨酸的羟基**，经 **GalNAc（N-乙酰半乳糖胺）** |
| 序列要求 | **Asn-X-Ser/Thr**（X 为任意氨基酸，Pro 除外） | 无严格序列要求 |
| 起始位置 | **ER** | **高尔基体** |

**为什么 N-连接需要"序列基序"：** 因为糖基转移酶（寡糖转移酶）识别的不是单个 Asn，而是"**Asn-X-Ser/Thr**"这个三肽构象——这保证了只有**正确折叠到膜上、且序列合适**的位点才被糖基化。

### 5. 多萜醇（dolichol）与 N-糖基化的起始（p14）

**是什么：** 一种**长链多萜醇（polyisoprenoid）**，嵌在 ER 膜中，作为**寡糖链的载体（lipid-linked oligosaccharide, LLO）**。

**怎么工作：** 胞质侧逐步在 dolichol 上装配 **Glc₃Man₉GlcNAc₂** 的 14 糖前体 → 翻转（flip）到 **腔侧** → 寡糖转移酶把整个 14 糖**一次性**转移到新生肽链的 Asn 上 → 随后由**葡萄糖苷酶 I/II** 与**甘露糖苷酶**修剪。

**为什么用"脂载体"：** 糖链是**亲水**的，无法直接穿过疏水的 ER 膜；dolichol 把糖链"挂"在膜内，再整体翻转——这是"**用脂质解决跨膜运输亲水分子**"的漂亮设计。

### 6. 质量控制：让错误折叠的蛋白出不去（p15–16）

> **Quality control：ensuring that misfolded proteins do not leave ER.**

**rER 腔内的四个关键角色（课件原文）：**

| 分子 | 作用 |
| :--- | :--- |
| **BiP** | 伴侣蛋白：识别并结合**未折叠/错误折叠**蛋白，引导其正确构象 |
| **calnexin（钙联蛋白）** | 伴侣蛋白：识别**单葡萄糖基化**的糖蛋白，循环"折叠-检查" |
| **PDI（蛋白二硫键异构酶）** | 催化**二硫键的形成与重排** |
| **glucosyl-transferase（葡萄糖基转移酶）** | **监测酶**：识别未折叠/错误折叠蛋白，在寡糖末端**加一个葡萄糖**，使其重新进入 calnexin 循环 |

**"calnexin 循环"怎么工作：**
1. 新生糖蛋白带 **Glc₃Man₉GlcNAc₂** → 葡萄糖苷酶 I/II 切去两个葡萄糖 → 剩 **单葡萄糖**；
2. 单葡萄糖糖蛋白结合 **calnexin/calreticulin** → 被"扣留"在 ER 中折叠；
3. 葡萄糖苷酶 II 切去最后一个葡萄糖 → 若已正确折叠，**释放并出 ER**；
4. 若仍未折叠，**UGGT（即 glucosyl-transferase）重新加一个葡萄糖** → 再次结合 calnexin → **循环**；
5. 循环多次仍失败 → 被**逆向转位**（p80）到胞质降解。

**为什么"加糖-切糖"要循环：** 它提供了一个**可反复检查的"时间窗口"**，而不是"一次判死刑"。这是"质量控制"与"质量检查"的区别。

### 7. 二硫键与 PDI（p18）

> **Disulfide bonds are formed and rearranged in the ER lumen.**
> **Only in the ER lumen is there a redox environment for oxidation of –SH groups.**
> **PDI: found in abundance in the ER lumen.**

**为什么只有 ER 腔能形成二硫键：** 胞质是**还原性**环境（高 GSH/GSSG 比），二硫键会被还原；ER 腔是**氧化性**环境（Ero1 等氧化酶维持），–SH 才能被氧化成 –S–S–。

**PDI 的双重功能：** ① **氧化**（形成二硫键）；② **异构化**（把"错配"的二硫键重排成正确配对）。**它既是"催化剂"又是"纠错器"。**

**为什么重要：** 二硫键是分泌蛋白与膜蛋白胞外域的"骨架"；抗体（IgG）的四链结构完全依赖链内与链间二硫键。

### 8. 未折叠蛋白反应（UPR，p19–20）

> **Misfolded Proteins in the ER Activate a UPR.**
> **The Kinase: IRE1 → XBP1**

**是什么：** 当 ER 中未折叠蛋白超过折叠能力时，细胞启动**转录与翻译层面的补偿程序**：① 增加 ER 伴侣蛋白与折叠酶的表达；② 扩大 ER 体积；③ 减少入 ER 的蛋白量；④ 若仍不能恢复，则**诱导凋亡**。

**三条感受器（课件提到 IRE1，教材补全为三条）：**

| 感受器 | 类型 | 下游 |
| :--- | :--- | :--- |
| **IRE1** | 跨膜**激酶/核酸内切酶** | 剪接 **XBP1 mRNA** → 产生有活性的 **XBP1s** 转录因子 |
| **PERK** | 跨膜激酶 | 磷酸化 **eIF2α** → **全局翻译抑制**（减少新蛋白入 ER） |
| **ATF6** | 跨膜转录因子 | 转运到高尔基体被切割 → 入核激活伴侣基因 |

**IRE1–XBP1 的机制细节：** 未折叠蛋白结合 BiP 使 BiP 从 IRE1 上解离 → IRE1 寡聚、自磷酸化 → 其**核酸内切酶**活性剪接 XBP1 mRNA 的 26 nt 内含子 → 移码产生**XBP1s** → 激活 UPR 靶基因。

**为什么重要：** UPR 是**分泌细胞（浆细胞、肝细胞、胰腺 β 细胞）** 的生存核心；慢性 UPR 失败与**糖尿病、神经退行性疾病、炎症性肠病**相关。

> **补充：** 课件只给 IRE1/XBP1 与"UPR"的名字，未讲 PERK/ATF6 三条分支，也未讲 BiP 的"滴定"机制。以上属教材内容（课件未讲）。

### 10. KDEL 受体与 ER 驻留蛋白的回收（p22）

> **Role of the KDEL receptor in the retrieval of ER-resident proteins.**
> **pH-sensitive protein–protein interactions form the basis for many of the sorting steps in the cell.**
> **ERGIC**

**问题：** ER 驻留蛋白（BiP、PDI、calreticulin）如果随囊泡流"漏"到高尔基体，ER 就会被"掏空"——必须有**回收机制**。

**怎么工作：**
1. ER 驻留蛋白的 **C 端有 KDEL 序列**（Lys-Asp-Glu-Leu）；
2. 漏到 **ERGIC/高尔基体**后，**KDEL 受体**（一个 **7 次跨膜**的膜蛋白）在**高尔基体的低 pH** 下**高亲和**结合 KDEL；
3. 受体-货物复合物被**COPI 囊泡**包装，**逆向**运回 ER；
4. 回到 **ER 的中性 pH** 后，受体对 KDEL 的**亲和力下降**，货物释放。

**"pH 敏感"为什么是关键：** 同一个受体在**两个区室**要有**两种亲和力**——高尔基体（低 pH）抓货、ER（中性）放货。**pH 梯度本身就是"分选开关"**，这是课件那句"pH-sensitive protein–protein interactions form the basis for many sorting steps"的含义。KKXX 序列（C 端双赖氨酸）则用于**膜蛋白**的 COPI 回收。

### 11. sER 的六项功能（p23）

| # | 功能 | 要点 |
| :--- | :--- | :--- |
| 1 | **Ca²⁺ 的储存（sequestration）** | **Ca²⁺-ATPase** 把 Ca²⁺ **泵入**；**Ca²⁺ 通道**（IP₃ 受体/Ryanodine 受体）把 Ca²⁺ **释放出** |
| 2 | **磷脂合成（synthesis of phospholipids）** | 膜脂的主要合成场所 |
| 3 | **类固醇合成（synthesis of steroids）** | 内分泌细胞（肾上腺皮质、性腺） |
| 4 | **加氧酶（oxygenases）——细胞色素 P450 家族** | 疏水化合物的**羟化**；**药物代谢** |
| 5 | **解毒（detoxification）** | 肝细胞中有机化合物的解毒 |
| 6 | **向血液释放葡萄糖** | 肝细胞 ER 膜上的 **G-6-Pase（葡萄糖-6-磷酸酶）** 去掉磷酸，使葡萄糖能出细胞 |

**为什么第 1 条最重要：** sER 是胞内 **Ca²⁺ 库**——胞质 Ca²⁺ 静息约 10⁻⁷ M，sER 腔内可达 10⁻³ M 量级。IP₃ 或 Ryanodine 受体一开，Ca²⁺ 涌入胞质，触发肌肉收缩、分泌、受精等（Chapter 9 展开）。**"泵入-释放"的双向装置使 sER 成为可快速开关的信号源。**

**为什么第 6 条是"代谢整合"的例子：** 糖原分解产生的 **G-6-P** 带磷酸基、无法穿膜；只有 ER 腔侧的 **G-6-Pase** 去掉磷酸生成**葡萄糖**，才能经 **GLUT2** 出细胞进入血液——**ER 直接参与血糖调节**。

### 12. 膜脂的合成与转运（p24–25）

> **Most membrane lipids are synthesized entirely within the ER.**

**两个例外：**
1. **鞘磷脂与糖脂（sphingomyelin and glycolipids）**：**起始于 ER，完成于高尔基体**；
2. **线粒体与叶绿体膜的某些特有脂质**（如心磷脂 cardiolipin）。

**不同细胞器膜的脂质组成显著不同**——这是"膜的身份（membrane identity）"的化学基础。

**转运方式（p24）：**
- **出芽运输（transport by budding）**：**ER → 高尔基体 → 溶酶体 → 质膜**（随囊泡流"捎带"）；
- **磷脂交换蛋白（phospholipid exchange proteins, PEP）**：在 ER 或其他细胞器（**线粒体、叶绿体、TGN**）之间**单体摆渡**脂分子。

**合成中的"翻转"（p25）：** **磷脂转位酶（phospholipid translocator）**——包括 **scramblase（ABC 转运体家族）** 与 **flippase**——把新合成的磷脂从**胞质侧**翻到**腔侧**，使双层两侧的脂质组成不同。

**为什么需要 flippase/scramblase：** 磷脂在 ER 的**胞质侧**合成，但膜要**两侧都长**；若不翻转，膜会"单侧膨胀"而弯曲。flippase（P4-ATPase）**定向**把 PS/PE 翻到胞质侧，scramblase 则**无方向**地快速交换——二者共同维持"生长中的双层"与"成熟膜的不对称"。

> **补充：** 课件未讲 P4-ATPase（flippase）与 ABCA1（胆固醇外排）的具体家族归属与疾病（如 Tangier 病）。以上属教材内容（课件未讲）。

## 八、高尔基体

### 1. 结构（p26）

> **Stacks of flattened membrane cisternae (sac) that are closely associated with vesicles.**
> **From cis-Golgi（convex outer face closest to rER, forming face）to trans-Golgi（concave inner face closest to the plasma membrane, maturing face）, consisting of cis Golgi, medial Golgi, trans Golgi and trans-Golgi network (TGN).**

| 区域 | 位置 | 别名 |
| :--- | :--- | :--- |
| **cis 高尔基体** | 靠近 rER 的**凸面** | **形成面（forming face）** |
| **medial 高尔基体** | 中间 | —— |
| **trans 高尔基体** | 靠近质膜的**凹面** | **成熟面（maturing face）** |
| **TGN** | trans 面的**管网** | **分选中心** |

**为什么"极性"是高尔基体的核心概念：** 从 cis 到 trans，**膜的脂质组成、酶的种类、腔的 pH 都在渐变**——这不是一个"袋子"，而是一条**有方向的生产线**（p28 "The polarity of the Golgi complex"）。

### 2. 区域差异的化学标志（p29）

课件给出三种**细胞化学染色**，分别标记不同层次的膜囊：

| 标志 | 定位 |
| :--- | :--- |
| **还原四氧化锇（reduced osmium tetroxide）** | **cis 膜囊** |
| **甘露糖苷酶 II（mannosidase II）** | **medial 膜囊** |
| **核苷二磷酸酶（nucleoside diphosphatase, NDPase）** | **trans 膜囊** |

**这三条是"高尔基体分层"的经典实验证据：** 酶活性的**梯度分布**证明各层膜囊在**生化上不同**，而不是同一张膜的随机皱褶。

（p79 补充了中文教材常用的四种反应：**嗜锇反应**——cis 面膜囊；**NADP 酶**——中间扁平囊；**TPP 酶**——trans 面 1–2 层；**CMP 酶**——靠近 trans 面的膜囊状与管状结构。）

### 3. 高尔基体的功能（p30）

| 功能 | 内容 |
| :--- | :--- |
| **蛋白质的翻译后修饰** | **糖基化（N-连接与 O-连接）**、**脂修饰（棕榈酰化 palmitation）**、**酪氨酸硫酸化（sulphation of tyrosines）**、**蛋白酶解（激素加工）** |
| **蛋白质分选** | 分选到**内体/溶酶体**或**分泌**——**分选发生在 TGN** |
| **膜再循环（membrane recycling）** | 把膜"送回"ER 或质膜，维持各区室膜面积平衡 |

**为什么"分选在 TGN"：** TGN 是高尔基体的"出货码头（sorting station）"，p37 称其为"**加工与分选站（processing and sorting stations）**"：蛋白在此被修饰、**分类（segregated）**，然后装上不同的囊泡发往不同目的地（p38）。

### 4. N-糖链的加工（p31–32）

> **The core carbohydrate of N-linked oligosaccharides is assembled in the rER.**
> **Modifications to N-linked oligosaccharides are completed in the Golgi complex.**

**加工顺序（"修剪-再加"）：**
1. ER 中先装上 **Glc₃Man₉GlcNAc₂**（14 糖）；
2. ER 与高尔基体中由**葡萄糖苷酶、甘露糖苷酶**切去葡萄糖与部分甘露糖 → 得到 **Man₅GlcNAc₂** 核心；
3. 高尔基体中依次**加上**：**GlcNAc（N-乙酰葡糖胺）→ 半乳糖（galactose）→ 唾液酸（sialic acid，即 N-乙酰神经氨酸）**，并可加**岩藻糖**。

**O-连接（p32）：** 在**高尔基体**中，**GalNAc（乙酰半乳糖胺）** 先加到 Ser/Thr 的羟基上，再逐步延伸；胶原的**羟赖氨酸（hydroxylysine）** 上也有 O-连接糖。

**为什么"先修剪再加"：** 修剪产生一个**统一的"核心"**，再加不同的"外周末端"——这样**同一核心可以长出无数种糖链**，实现巨大的结构多样性（这是"糖密码"的基础）。

### 5. 糖基化的功能（p33）

| 功能 | 说明 |
| :--- | :--- |
| ① **辅助折叠与运输** | 糖链作为 ER 折叠的**标记**；**凝集素（lectin）** 识别糖链引导 **ER→高尔基体**运输 |
| ② **限制其他大分子接近蛋白表面** | 使蛋白**更抗蛋白酶消化** |
| ③ **信号调控** | 通过细胞表面受体（如 **Notch**）参与信号，使细胞**选择性**响应刺激 |

**两个"独特性质"（课件原文）：**
1. **N-连接糖基化在所有真核生物中普遍存在，但原核生物中没有（absent from prokaryotes）**；
2. **不需要模板（doesn't require a template）**——与 DNA、RNA、蛋白质的合成有本质区别。

**为什么"无模板"重要：** 糖链的合成由**一套酶的次序**决定，而不是由模板"抄写"；因此同一蛋白在不同细胞、不同条件下可以有**不同的糖型（glycoform）**——这解释了为什么重组蛋白药物（如抗体）必须在特定细胞系中生产。

### 6. 蛋白酶解加工：组成型 vs 调节型分泌（p34–35）

| | **组成型分泌（constitutive）** | **调节型分泌（regulated）** |
| :--- | :--- | :--- |
| 释放方式 | **持续、不受调控**（continual, unregulated discharge） | 产物**储存在分泌颗粒**中，**响应刺激**才释放 |
| 例子 | 胶原、血清白蛋白、膜蛋白 | 胰岛素、消化酶、神经肽 |
| 加工 | 常在 TGN 或分泌囊泡中完成 | 常在**未成熟分泌颗粒**中完成 |

**胰岛素的经典例子（p35）：**
1. 胰岛 β 细胞中，**前胰岛素（proinsulin）** 在 ER 中折叠、形成**三个二硫键**；
2. 转运到 TGN，**聚集（aggregation）** 并包装进**未成熟分泌颗粒（immature secretory vesicle）**；
3. 在颗粒中，**蛋白酶（PC1/3、PC2、羧肽酶 E）** 切去 **C 肽（C-peptide）**，产生**胰岛素（insulin）** 与 C 肽；
4. **成熟分泌颗粒（mature secretory granule）** 储存，血糖升高时释放。

**课件 p35 的实验设计很妙：** 用 **anti-proinsulin（只认前胰岛素）** 与 **anti-insulin（只认成熟胰岛素）** 两种抗体分别染色——**同一批颗粒在成熟过程中"换了身份"**，直接证明"切割发生在颗粒内"。

**为什么"聚集"先于"切割"：** 高浓度的前体先聚集成**致密核心**，既便于储存，也使蛋白酶能在"浓缩环境"中高效切割；颗粒的**酸性 pH** 也有利于切割酶活性（并抑制胰岛素结晶过早形成）。

### 7. 分泌颗粒（p41–43）

**三条特征（p41）：**
1. **只存在于某些细胞**——**外分泌（exocrine）、内分泌（endocrine）、神经元（neuronal）细胞**；
2. **由 TGN 形成**；
3. **储存浓缩的蛋白与其他物质**，**响应胞外刺激**释放（调节型分泌）。

**p42** 给出**人胰腺腺泡细胞的酶原颗粒（zymogen granules）**——消化酶以**无活性的酶原**形式储存，分泌到小肠后被**肠激酶**激活，防止"自己消化自己"。

**浓缩储存的机制（p43 四条）：**
- **强电荷相互作用（strong charge interactions）**；
- **分子间二硫键（intermolecular disulfide bonds）**；
- **强离子相互作用（strong ionic interaction）**；
- 其他。

**为什么"浓缩"是必要的：** 调节型分泌要求"一次刺激释放大量"——若颗粒内浓度低，就需要更多颗粒、更大体积；**浓缩使小颗粒装下大剂量**。而"浓缩"的代价是**必须防止 premature 激活/聚集失控**，这正是"酶原 + 酸性 pH + 稳定剂"共同作用的原因。

### 8. 高尔基体内的运输：两种模型（p36）

> **Two possible models explain the organization of the Golgi complex and the transport from one cisterna to the next.**

| | **顺面成熟模型（cisternal maturation）** | **囊泡运输模型（vesicular transport）** |
| :--- | :--- | :--- |
| 核心主张 | **整个膜囊在成熟**：cis 囊"变成"medial，再"变成"trans；**货物不动，膜囊在动** | **膜囊固定**，货物由**囊泡**一站一站向前运 |
| 证据 | 大型货物（如**前胶原**）能在高尔基体中"通过"而不被囊泡装下——只有"囊在成熟"才解释得通；活细胞成像显示 cis 酶逐渐被 trans 酶替换 | 大量 COPI 囊泡存在于囊间；体外可重建囊泡出芽 |
| 问题 | 需要**逆向**把酶"送回"前面的囊（COPI 逆行运输） | 难以解释大型货物如何通过 |

**目前的主流观点：** **两者并存**——**顺面成熟**是主线（尤其对大型货物），**囊泡运输**负责**酶的逆向回收**与部分小货物前向运输。课件把它列为"两种可能模型"，正是为了让你理解"**证据如何约束模型**"。

## 九、胞吞（Endocytosis）

### 1. 膜流（membrane flow，p44–45）

> **Endocytosis/Exocytosis：Transport into/out of the cell from the plasma membrane.**

**"膜流"的概念：** 胞吞时质膜**内陷成囊泡**（膜"减少"），胞吐时囊泡**与质膜融合**（膜"增加"）。二者必须**动态平衡**，否则细胞表面积会不断缩小或膨胀。**膜流 = 膜在区室之间的循环。**

**Schekman 的贡献（p46）：** 用**酵母遗传学**筛选分泌缺陷突变体（**sec 突变体**），发现分泌是**由一系列基因（SEC 基因）分步催化**的——这为"囊泡运输有分子机器"提供了遗传学证据（Schekman 与 Rothman、Südhof 共享 **2013 年诺贝尔生理学或医学奖**）。

### 2. 胞吞的类型（p50–60）

#### （1）"吃"与"喝"（p50–52）

> **A. 胞吞把溶解或悬浮在液体中的胞外分子通过质膜形成囊泡而导入细胞。**
> **Bulk-phase endocytosis（液相胞吞/胞饮）不需要表面膜识别**——是**非特异**的胞外液体摄取。
> **Receptor-mediated endocytosis（受体介导胞吞）** 则始于**物质与膜受体结合**。

| | **液相胞吞（bulk-phase / pinocytosis）** | **受体介导胞吞** |
| :--- | :--- | :--- |
| 特异性 | **无**（ nonspecific） | **有**（受体识别配体） |
| 效率 | 低（摄取液体中溶解物） | 高（可浓缩特定配体成百上千倍） |
| 例子 | 细胞饮液 | LDL、转铁蛋白、EGF |

#### （2）吞噬（phagocytosis，p53–54）

> **B. Phagocytosis：大颗粒的摄取。**
> - 包括**大分子、细胞碎片、甚至微生物与其他细胞**；
> - 通常**局限于特化的吞噬细胞（phagocytes）**；
> - 由**细胞与合适靶标的接触**启动；
> - 可被**调理素（opsonins）** 刺激；
> - 由**肌动蛋白聚合的收缩活动**驱动。

**课件图片：** **中性粒细胞吞噬细菌**、**巨噬细胞吞噬红细胞**。

**调理素（opsonin）是什么：** 包被在病原体表面、能被吞噬细胞受体识别的分子（**IgG 的 Fc 段、补体 C3b**）。"调理"= 给病原体"涂上调料"，使吞噬效率提高数十倍。

**为什么吞噬必须靠 actin：** 吞噬需要**膜伸出伪足（pseudopod）** 把颗粒"包"起来，这是**主动的形态变形**——只有肌动蛋白聚合能提供这种局部推力。**肌动蛋白抑制剂（如 cytochalasin）可完全阻断吞噬**，这是最直接的证据。

#### （3）网格蛋白（clathrin）包被的胞吞（p56–58）

> **Model for the formation of a clathrin-coated pit and the selective incorporation of integral membrane proteins into clathrin-coated vesicles.**

**四步：**
1. **货物受体**（如 LDL 受体）结合配体，在质膜上**聚集**；
2. **AP2 接头蛋白**识别受体的**胞内分选信号（如 YxxΦ、NPXY）**，招募 **clathrin 三聚体（triskelion）**；
3. clathrin 在膜内侧**自组装成笼状（hexagon + pentagon 构成的"足球"）**，膜被"拉"成**包被小窝（coated pit）**；
4. **dynamin（发动蛋白，一种 GTP 酶）** 在"窝颈"处聚合并水解 **GTP**，把囊泡**"掐"下来（fission）** → **包被囊泡（coated vesicle）** → 随后 clathrin 与 AP2 脱落（**uncoating**）。

**为什么"选择性"是重点：** 包被小窝不是"随机吞一口膜"，而是通过**AP2-受体信号**把特定膜蛋白**富集**进去——这就是"受体介导"的分子含义。

#### （4）caveolae（小窝）介导的胞吞（p59–60）

> **Caveolae-mediated endocytosis：参与内皮细胞的转胞吞（transcytosis）；病毒进入动物细胞；其他信号分子的胞吞。**
> **Caveola enter the cell as caveosomes, used by SV40 and some receptors.**

**是什么：** 质膜上富含**胆固醇与鞘脂**的**烧瓶状内陷（50–80 nm）**，由 **caveolin-1/2/3** 与 **cavin** 蛋白构成。

**功能：** ① **转胞吞**——内皮细胞把大分子从血液一侧"运到"组织一侧（不降解）；② **病毒入口**——**SV40** 等经 caveolae 进入，形成 **caveosome**；③ 信号分子（如某些受体）的内化与信号调控。

**与 clathrin 的区别：** caveolae **不依赖 dynamin 的经典途径**（部分依赖）、**不形成典型的 clathrin 笼**、尺寸更小、与**脂筏**高度重叠。

### 3. 胞内体途径（p61–74）

#### （1）早期内体与晚期内体的分选（p63）

> **Materials in the early endosomes are sorted:**
> - **整合膜蛋白被运回膜（shipped back to the membrane）**；
> - **其他溶解物质与结合的配体被运到多囊体/晚期内体（MVB/late endosomes），再到溶酶体**。
> **到达晚期内体的分子被运到溶酶体降解，或被回收回细胞表面。**

**这条"分选"的核心原则：** **受体回家，配体被降解**——受体的胞内段带"回收信号"，配体没有。

#### （2）转铁蛋白循环（p64）

> **Example of early endosome：the transferrin cycle — ion uptake by cells.**

**怎么工作：**
1. **转铁蛋白（transferrin, Tf）** 在血液中结合 **Fe³⁺**；
2. 结合质膜上的**转铁蛋白受体（TfR）** → clathrin 包被胞吞；
3. **早期内体的低 pH（约 6.0）** 使 Fe³⁺ 从 Tf 上**释放**；
4. **TfR-Tf（无铁）** 复合物**回收**到质膜；
5. 质膜的中性 pH 使 Tf 释放，TfR 重新可用。

**为什么这是"循环"的经典模型：** 受体**不被降解**、可反复使用上百次；铁的释放靠**pH 下降**，不靠酶切。**"pH 依赖的解离"是内膜系统分选的最常见策略之一**（与 KDEL 受体同理）。

#### （3）受体分选与配体解离（p65–66）

课件 p65 给"**胞吞途径中膜蛋白的分选**"，例举**转铁蛋白受体**与**阿片受体（opioid receptors）**——说明不同受体有不同命运（回收 vs 降解）。

p66："**内化的配体-受体复合物在晚期内体中解离**"，例举**唾液酸糖蛋白（asialoglycoprotein）配体及其受体在肝细胞中**、**Kupffer 细胞**对糖蛋白的**快速清除**。

**唾液酸糖蛋白受体（ASGPR）的机制：** 血液中失去唾液酸的糖蛋白（"老化"标志）被肝细胞 ASGPR 识别 → 胞吞 → **晚期内体低 pH 使配体解离** → 受体回收，配体送溶酶体降解。**这是"血浆蛋白清除"的经典途径**，ASGPR 因此被称为"清道夫受体"。

#### （4）多囊体（MVB）与外泌体（p67–69）

> **Multivesicular Bodies (MVB)** ——**Scott Emr（康奈尔大学）**
> **Exosomes generated from multivesicular bodies (MVB)** ——**Lakkaraju and Rodriguez-Boulan, *Trends Cell Biol*, 2008**

**MVB 是什么：** 晚期内体的膜**向内出芽**，把胞质中的蛋白、RNA 等**包进腔内小囊泡（intraluminal vesicles, ILVs）**——于是"一个囊泡里套着许多小囊泡"。

**两条命运：**
1. **与溶酶体融合** → ILVs 被降解（**这是"降解"路线**）；
2. **与质膜融合** → ILVs 被**释放到胞外**，成为**外泌体（exosome）**（**这是"分泌/通讯"路线**）。

**为什么 MVB 重要：** 它是**"膜蛋白下调（downregulation）"** 的主要机制（如 EGF 受体被泛素化后进入 ILV 降解）；外泌体则携带 **miRNA、蛋白、脂质**在细胞间传递信号，是**液体活检**与药物递送的热点。

**ESCRT 机制：** 泛素化的货物被 **ESCRT-0/I/II/III** 依次识别，**ESCRT-III** 在腔内形成螺旋并**"掐断"** ILV 的颈部——**与胞吞的 dynamin 掐断在拓扑上相同，方向相反**。

#### （5）LDL 与家族性高胆固醇血症（p70–73）

**LDL 是什么（p70）：** **低密度脂蛋白（low-density lipoprotein）** 颗粒，核心含**胆固醇酯**，表面有**apo-B 蛋白**（被 LDL 受体识别的配体）。

**课件数据：** "**每 500 人中就有 1 人携带一个缺陷的 LDL 受体基因**，因而**动脉粥样硬化（atherosclerosis）导致心脏病发作的风险增加**。"

**受体介导胞吞的完整路径（p71–73）：**
1. **LDL 结合 LDL 受体**（质膜上的 **clathrin 包被小窝**）；
2. 胞吞形成**包被囊泡** → **早期内体（加入 LDL 后 6 分钟即可见）**；
3. **早期内体低 pH** 使 LDL 与受体**解离**；
4. **受体回收**到质膜；**LDL 被送到溶酶体**；
5. 溶酶体的**酸性脂肪酶**水解胆固醇酯 → **游离胆固醇**释放；
6. 游离胆固醇**抑制 HMG-CoA 还原酶**（胆固醇合成限速酶）并**抑制 LDL 受体基因转录**（反馈调节）。

**家族性高胆固醇血症（p72，Brown & Goldstein，1985 年诺贝尔生理学或医学奖）的四种缺陷：**
1. **不产生 LDL 受体**（no receptor produced）；
2. **受体不能结合 LDL**（no binding to LDL）；
3. **受体部分缺失，无法锚定在质膜上**（failure of anchoring to the PM）；
4. **受体不能结合包被小窝，因而无法内化**（unable to bind to coated pit → failure to be internalized）。

**为什么这个病是"受体介导胞吞"的最佳教材：** 四种缺陷分别对应通路的**四个步骤**（合成、结合、定位、内化）——**一个疾病把整条通路"拆解"成了四个可验证的环节**。这也直接证明了"胞吞是受体特异、clathrin 依赖、需要胞内信号"的。

**治疗逻辑：** 他汀类抑制 HMG-CoA 还原酶 → 胞内胆固醇下降 → SREBP 上调 LDL 受体 → 血浆 LDL 被更多清除。**"抑制合成"反而"增加摄取"**，这是反馈调节的临床妙用。

#### （6）受体的四种命运（p74）

| 命运 | 说明 | 例子 |
| :--- | :--- | :--- |
| **回收（recycling）** | 回到质膜重复使用 | 转铁蛋白受体、LDL 受体 |
| **降解（degradation）** | 进入溶酶体被消化 | EGF 受体（泛素化后入 ILV） |
| **转胞吞（transcytosis）** | 从一侧膜运到另一侧 | 新生儿肠上皮的母源 IgG |
| **滞留（retention）** | 留在特定区室 | 部分信号受体 |

#### （7）转胞吞：新生儿 IgG（p75）

> **Example of Transcytosis：maternal IgG across the intestinal epithelial cells of newborns.**

**怎么工作：** 新生儿肠道摄入母乳中的 **IgG** → 结合肠上皮**顶面**的 **FcRn 受体** → 胞吞进入**内体** → **FcRn 在酸性 pH 下结合 IgG、在中性 pH 下释放** → 复合物**穿越细胞**到达**基底面** → 释放入血。

**为什么重要：** 新生儿免疫系统未成熟，**母源 IgG 的转胞吞**提供被动免疫；FcRn 也是**抗体药物半衰期长**的原因（它把 IgG 从溶酶体"救回"并回收）。

#### （8）GLUT4 与回收内体（p76）

> **Storage of plasma membrane proteins in recycling endosomes：Glut4.**

**怎么工作：** 胰岛素未刺激时，**GLUT4** 储存在**胞内回收内体/特化囊泡**中；胰岛素信号（PI3K–Akt）触发囊泡**转位（translocation）** 到质膜 → 葡萄糖摄取增加；信号终止后 GLUT4 被**胞吞**回储存池。

**为什么重要：** 这是**"膜蛋白数量动态调节"**的典范——不是改变活性，而是改变**在膜上的数量**；**2 型糖尿病**中这条转位通路受损。

#### （9）上皮细胞的极性维持（p77）

> **Maintenance of the polarity of epithelial cells.**

**怎么工作：** 上皮细胞**顶面**与**基底面**的膜蛋白组成不同，靠**分选信号 + 囊泡靶向**维持：新合成的蛋白在 TGN 被分装到不同囊泡，分别送到顶面或基底面；错送的蛋白被**胞吞后重定向**。

**为什么重要：** 极性是**跨上皮运输（如葡萄糖、离子吸收）** 的前提；极性丧失是**上皮癌变（EMT）** 的标志之一。

### 4. ERGIC（p78）

> **ERGIC：recycling between ER and Golgi（ER 与高尔基体之间的循环）**

**是什么：** **ER-Golgi 中间区室（ER–Golgi intermediate compartment）**，位于 ER 与高尔基体之间，是 **COPI 囊泡**的枢纽。

**功能：** ① 接收 ER 出芽的 **COPII 囊泡**；② **KDEL 受体**在此/高尔基体回收 ER 驻留蛋白（p22）；③ 部分**非经典分泌**（THU）的入口（p83）。

**为什么它是"中间站"而不是"过道"：** ERGIC 有自己的**加工酶与 pH**，部分蛋白在此**停顿、修饰、甚至被"分流"**——它是**分选网络的一个节点**，不是单纯的中转。

## 十、本章要点速记

1. **三类区室**：胞质溶胶、内膜系统（ER/Golgi/内体/溶酶体/囊泡/过氧化物酶体）、线粒体+叶绿体+核；**无膜区室**靠**相分离**。
2. **相分离**：多价弱相互作用 → 凝聚体；液→凝胶→固体；CCT2 把固体凝聚体送自噬；2023 突破奖（Brangwynne、Hyman）。
3. **三种分选机制**：门控（核孔，折叠态）、跨膜（ER/线粒体/叶绿体/过氧化物酶体，未折叠 + 转位子）、囊泡（ER-Golgi-PM-内体-溶酶体）。
4. **信号位置**：多数在 N/C 端；**NLS 可在任意位置**。
5. **Milstein 实验**：无细胞体系产物多 20 aa；加 ER 膜后变短 → 信号肽被切除。
6. **信号假说**（Blobel & Sabatini 1971）：SRP 识别 → 暂停翻译 → 结合 SRP 受体（GTP 结合蛋白）→ 对接 SEC61 → 共翻译穿膜 → 信号肽酶切除。
7. **SRP**：6 种多肽 + ~300 nt RNA；三个活性位点（识别信号、结合核糖体暂停翻译、结合 SRP 受体）。
8. **SEC61**：α/β/γ，α 形成孔道 + **侧门**；三种穿膜方式（可溶、单次跨膜、多次跨膜）；TM 段可当信号肽；C 端 TM = **尾部锚定（TA/GET 途径）**。
9. **ERAD**：Hrd1 逆向转位 + 泛素化 + p97 + 蛋白酶体。
10. **非经典分泌**：THU（TMED10 通道，张敏/Rapoport，*Cell* 2020）；GSDMD 直接穿质膜（邵峰）。
11. **线粒体**：TOM/TIM；Tim17 才是真正通道（李龙，*NSMB* 2023）；ATP + ΔΨ 驱动。**叶绿体**：TOC/TIC + cpSec/cpTat/cpSRP/自发。**核孔**：<40 kDa 自由扩散，>60 kDa 主动转运（NLS + importin + RanGTP）。
12. **rER**：蛋白合成、N-糖基化（Asn-X-Ser/Thr）、质量控制（BiP、calnexin、PDI、UGGT）、ERAD、UPR（IRE1–XBP1）。
13. **sER 六功能**：Ca²⁺ 储存、磷脂合成、类固醇合成、P450 加氧/药物代谢、解毒、G-6-Pase 释放葡萄糖。
14. **KDEL 受体**：高尔基体低 pH 抓货、ER 中性 pH 放货；COPI 逆向回收。
15. **高尔基体**：cis（形成面）/medial/trans（成熟面）/TGN；标志酶（嗜锇-cis、甘露糖苷酶 II-medial、NDPase-trans）；功能（糖基化、脂修饰、硫酸化、蛋白酶解、TGN 分选、膜再循环）。
16. **糖基化功能**：辅助折叠与运输、抗蛋白酶、信号调控；N-连接真核普遍、原核没有；**无模板**。
17. **两种高尔基运输模型**：顺面成熟（主线）+ 囊泡运输（酶回收）。
18. **胞吞**：液相 vs 受体介导；吞噬（phagocytes、opsonin、actin）；clathrin（AP2、dynamin）；caveolae（caveolin、caveosome、SV40）。
19. **胞内体**：早期内体分选（受体回家、配体降解）；转铁蛋白循环（pH 释放铁）；ASGPR；MVB（ESCRT、ILV）→ 溶酶体或**外泌体**。
20. **LDL 通路**：clathrin 胞吞 → 早期内体（6 min）解离 → 受体回收 → 溶酶体水解 → 游离胆固醇反馈抑制 HMG-CoA 还原酶与受体转录；家族性高胆固醇血症四种缺陷（Brown & Goldstein，1985 诺奖）。

## 复习自测提示

**1. 真核细胞的三类区室是什么？"无膜区室"靠什么形成？**
胞质溶胶；内膜系统（ER、高尔基体、内体、溶酶体、运输囊泡、过氧化物酶体）；线粒体、叶绿体与细胞核。无膜区室由**液-液相分离**形成：多价弱相互作用交联成网络，超过饱和浓度后分出富集液滴，可作为独立反应中心。

**2. 蛋白质进入细胞器的三种机制分别对应哪些细胞器？蛋白处于什么状态？**
① 门控转运——核孔，**折叠并装配好**的蛋白；② 跨膜转运——ER、线粒体、叶绿体、过氧化物酶体，**未折叠单链**经转位子；③ 囊泡运输——ER→高尔基体→质膜/内体/溶酶体，已折叠修饰的蛋白随囊泡移动。

**3. Milstein 实验说明了什么？**
在无细胞体系中合成的 IgG 轻链比真实轻链 N 端多约 20 个氨基酸；加入 ER 膜后产物变为正确大小。说明 mRNA 编码的是带信号序列的前体，信号序列把肽链导向 ER 并在进入腔后被信号肽酶切除。

**4. SRP 由什么组成？三个活性位点各做什么？**
6 种多肽 + 约 300 个核苷酸的 RNA。三个位点：① 识别并结合 ER 信号序列；② 与核糖体结合、阻断翻译延伸（暂停翻译）；③ 结合 ER 膜上的 SRP 受体（GTP 结合蛋白）。

**5. ER 信号序列的三个结构域是什么？为什么是这种三段式？**
带正电的 N 端区、中央疏水区、极性的 C 端区（含切割位点）。N 端正电荷保证插入方向；中央疏水段是插入与 SRP 识别的核心；C 端极性区提供信号肽酶的精确切割位点。

**6. 可溶性蛋白、单次跨膜蛋白、多次跨膜蛋白如何经 SEC61 穿膜？**
可溶性蛋白：信号肽插入孔道，肽链全链穿入腔，信号肽被切除。单次跨膜：N 端信号肽引导入腔，遇到 stop-transfer 疏水段时该段从侧门进入膜、孔道关闭，形成 N 端在腔、C 端在胞质的拓扑。多次跨膜：疏水段交替作为内部信号肽与停止转移序列，每段翻转一次走向，n 个疏水段即 n 次跨膜。

**7. 共翻译与翻译后转运的关键差别？**
共翻译在翻译进行中穿膜，依赖 SRP/SRP 受体/SEC61，主要进 ER；翻译后转运在蛋白完全合成后导入，需伴侣蛋白维持未折叠态，主要进线粒体、叶绿体、过氧化物酶体，能量来自 ATP（及线粒体内膜电位）。

**8. KDEL 受体如何保证 ER 驻留蛋白不流失？为什么 pH 是关键？**
ER 驻留蛋白 C 端有 KDEL；漏到 ERGIC/高尔基体后，KDEL 受体在**低 pH** 下高亲和结合，经 COPI 囊泡逆向运回 ER；ER 的**中性 pH** 使亲和力下降、货物释放。同一受体在两个区室有两种亲和力，pH 梯度即分选开关。

**9. 列出 rER 与 sER 的主要功能。**
rER：蛋白质合成；N-连接糖基化等修饰加工；质量控制（BiP、calnexin、PDI、UGGT 的折叠检查循环）与 ERAD。sER：Ca²⁺ 储存（Ca²⁺-ATPase 泵入、通道释放）；磷脂合成；类固醇合成；细胞色素 P450 加氧与药物代谢；解毒；G-6-Pase 释放葡萄糖入血。

**10. 高尔基体 cis→trans 的三个经典酶标志是什么？**
cis：还原四氧化锇染色（嗜锇反应）；medial：甘露糖苷酶 II；trans：核苷二磷酸酶（NDPase）。它们说明各层膜囊在生化上不同，是"极性"的证据。

**11. "顺面成熟"与"囊泡运输"两种模型的核心分歧是什么？目前怎么看？**
顺面成熟认为膜囊本身在成熟（cis→medial→trans），货物不动，需 COPI 逆向把酶送回；囊泡运输认为膜囊固定、货物由囊泡逐站前送。目前认为两者并存：顺面成熟为主线（解释大型货物通过），囊泡运输负责酶回收与部分小货物。

**12. 糖基化有哪三项功能？为什么说它"无模板"？**
① 辅助折叠与运输（糖链作折叠标记、凝集素引导 ER→高尔基体）；② 限制大分子接近、抗蛋白酶消化；③ 通过表面受体（如 Notch）参与信号调控。糖链由一套酶的次序合成，不需要 DNA/RNA 模板，因此同一蛋白可有不同糖型；N-连接糖基化在真核普遍、原核没有。

**13. 胰岛素是如何从 proinsulin 变成成熟胰岛素的？**
在 ER 中折叠并形成三个二硫键 → TGN 中聚集并包装成未成熟分泌颗粒 → 颗粒内蛋白酶（PC1/3、PC2、羧肽酶 E）切去 C 肽 → 成熟分泌颗粒储存，血糖升高时释放。用 anti-proinsulin 与 anti-insulin 分别染色可看到颗粒"换身份"。

**14. 胞吞有哪几种类型？clathrin 包被囊泡如何形成？**
液相胞吞（非特异）、受体介导胞吞、吞噬（大颗粒，phagocytes，opsonin，actin 驱动）、caveolae 介导。Clathrin 途径：受体结合配体聚集 → AP2 识别胞内信号并招募 clathrin → clathrin 自组装成笼使膜内陷成包被小窝 → dynamin 水解 GTP 掐断 → 包被囊泡，随后脱被。

**15. LDL 受体介导胞吞的完整路径？家族性高胆固醇血症有哪四种缺陷？**
LDL 结合受体 → clathrin 包被小窝胞吞 → 早期内体（6 min）低 pH 使配体-受体解离 → 受体回收、LDL 送溶酶体 → 酸性脂肪酶水解胆固醇酯 → 游离胆固醇反馈抑制 HMG-CoA 还原酶与 LDL 受体转录。四种缺陷：不产生受体；受体不能结合 LDL；受体不能锚定质膜；受体不能结合包被小窝而无法内化。

**16. MVB 的两条命运是什么？外泌体从何而来？**
MVB 可与溶酶体融合使腔内小囊泡（ILV）被降解（膜蛋白下调），也可与质膜融合把 ILV 释放为外泌体（细胞间通讯，携带 miRNA/蛋白）。ILV 由 ESCRT-0/I/II/III 在内体膜上向内出芽并掐断形成。
