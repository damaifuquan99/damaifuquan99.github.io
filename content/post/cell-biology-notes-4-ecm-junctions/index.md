# **细胞生物学学习笔记 4 | 细胞外基质与细胞连接：从 ECM 到细胞间通讯**

---

> **对应课件：** Lecture 3 - Memb-Junc 2026，Page 55–92（Chapter 4 主体）；Lecture 4 - Transport-sorting 2026，Page 1–2（衔接复习内容）  
> **本章核心内容：** 细胞外基质（ECM）的成分与功能、细胞连接的类型与作用、细胞-基质黏附（整合素）、植物细胞壁  
> **复习目标：** 熟悉 ECM 的主要成分及其结构功能关系；能比较四种动物细胞连接的结构与功能；理解整合素在细胞-基质黏附中的作用；了解植物细胞壁的组成与层次。

## 一、细胞外基质（Extracellular Matrix, ECM）

### 1. ECM 总览

ECM 是由细胞分泌到胞外的蛋白质和多糖组装而成的有序网络，与产生它的细胞表面紧密关联。ECM 不仅提供物理支撑，还参与细胞信号转导、迁移、增殖和分化。

| 成分类型 | 代表分子 | 主要功能 |
| :--- | :--- | :--- |
| **糖胺聚糖（GAGs）** | 透明质酸（hyaluronan） | 吸水形成凝胶，抗压缩 |
| **蛋白聚糖（Proteoglycans）** | aggrecan、perlecan、decorin | 核心蛋白 + GAG 链，形成“鸡毛掸子”状，赋予组织抗压性 |
| **纤维状蛋白** | 胶原蛋白（collagen）、弹性蛋白（elastin）、纤连蛋白（fibronectin） | 抗张强度、弹性、细胞黏附 |
| **基膜蛋白** | 层粘连蛋白（laminin）、IV 型胶原、nidogen | 基膜的主要成分，支撑上皮 |

### 2. 糖胺聚糖（GAGs）与透明质酸

- **结构**：重复二糖单位（A-B-A-B），通常带负电（硫酸化或羧基化）。
- **透明质酸（hyaluronan）**：最简单的 GAG，由多达 25,000 个非硫酸化二糖单位重复构成，不共价连接核心蛋白。
- **功能**：带负电的 GAGs 吸引阳离子和水，形成多孔水合凝胶（porous hydrated gel），抵抗压缩力（如关节滑液、眼玻璃体）。

### 3. 蛋白聚糖（Proteoglycans）

- **结构**：核心蛋白（core protein）共价连接多条 GAG 链（如硫酸软骨素、硫酸角质素）。
- **聚集形式**：多个蛋白聚糖通过**连接蛋白（link protein）**非共价连接到透明质酸长链上，形成巨大的**聚集蛋白聚糖（aggrecan aggregate）**，呈“鸡毛掸子”状。
- **分布**：角膜、骨、软骨。
- **功能**：赋予组织凝胶样特性和抗压能力。

### 4. 胶原蛋白（Collagen）

- **分布**：动物体内最丰富的蛋白质，仅存在于 ECM。
- **结构**：三条多肽链（α 链）形成左手螺旋，再缠绕成右手**三股超螺旋（triple helix）**；重复序列为 **Gly-X-Y**（X 常为脯氨酸，Y 常为羟脯氨酸）。
- **纤维状胶原**：多数胶原为纤维状（fibrillar），提供高抗张强度。
- **合成过程**：
  1. 在 ER 中合成前 α 链（prepro-α chain）；
  2. 脯氨酸和赖氨酸羟化（需要维生素 C）；
  3. 糖基化；
  4. 三条前 α 链自组装成三股螺旋（procollagen）；
  5. 分泌到胞外，切去前肽（propeptide）；
  6. 自组装成原纤维（fibril），并通过赖氨酰氧化酶（lysyl oxidase）催化交联，增强强度。
- **疾病**：胶原蛋白异常可导致成骨不全（osteogenesis imperfecta）、埃勒斯-当洛斯综合征（Ehlers-Danlos syndrome）；维生素 C 缺乏导致坏血病（scurvy），因羟化不足影响胶原稳定性。

### 5. 弹性蛋白（Elastin）

- 形成可拉伸的网络，赋予组织弹性（如皮肤、肺、血管壁）。
- 拉伸时伸展，放松时恢复卷曲；通过交联（cross-link）形成网络。

### 6. 纤连蛋白（Fibronectin）

- **结构**：二聚体糖蛋白，呈 V 形，含多个结构域：胶原结合域、肝素结合域、细胞结合域、自 association 域。
- **关键序列**：**RGD（Arg-Gly-Asp）**，是整合素（integrin）识别的细胞结合序列。
- **功能**：介导细胞与 ECM 的黏附；细胞迁移、伤口愈合、胚胎发育。
- **应用**：含 RGD 的化学物可竞争性抑制整合素功能。

### 7. 基膜（Basal Lamina）

- **位置**：上皮细胞下方，厚约 50 nm，分隔上皮与结缔组织。
- **主要成分**：
  - **IV 型胶原蛋白**（type IV collagen）；
  - **层粘连蛋白（laminin）**：十字形糖蛋白，含 α、β、γ 三条链；
  - **硫酸乙酰肝素蛋白聚糖（perlecan）**；
  - **nidogen**（连接层粘连蛋白和 IV 型胶原）。
- **细胞受体**：主要是**整合素（integrins）**，也可与 dystroglycan 结合。
- **功能**：支撑上皮、过滤、组织分隔、指导细胞分化。

## 二、细胞连接（Cell Junctions）

动物细胞间主要有四种连接类型，植物细胞有胞间连丝。

| 类型 | 功能 | 跨膜蛋白 | 胞内连接 | 细胞骨架 |
| :--- | :--- | :--- | :--- | :--- |
| **紧密连接（Tight junction）** | 封闭细胞间隙，形成不透性屏障；阻止膜蛋白侧向扩散 | Claudin、Occludin | ZO 蛋白 | 肌动蛋白（actin） |
| **桥粒（Desmosome）** | 机械连接，抗张强度 | 非经典钙粘蛋白（desmoglein、desmocollin） | 桥粒斑蛋白（desmoplakin）、斑菲素（plakophilin） | **中间丝（intermediate filaments）** |
| **黏着带（Adherens junction）** | 机械连接，响应力并重塑肌动蛋白 | 经典钙粘蛋白（E-cadherin） | α-、β-、γ-catenin | **肌动蛋白（actin）** |
| **间隙连接（Gap junction）** | 直接电化学通讯，交换小分子 | 连接子（connexon，由 6 个 connexin 组成） | 无 | 无 |

### 1. 紧密连接（Tight Junctions）

- **位置**：上皮细胞顶端（apical）侧面，形成“封闭带”。
- **结构**：跨膜蛋白 **claudin** 和 **occludin** 形成封闭链（sealing strands）；胞内与 ZO 蛋白结合，连接肌动蛋白。
- **功能**：
  - 封闭细胞间隙，阻止大分子通过（如血脑屏障、肠上皮屏障）；
  - 阻止膜蛋白在顶端和基底面之间侧向扩散，维持细胞极性。
- **实验证据**：示踪分子（tracer molecule）无法通过紧密连接；冷冻蚀刻显示封闭链网络。

### 2. 桥粒（Desmosomes）与半桥粒（Hemidesmosomes）

#### 桥粒

- **结构**：相邻细胞间的盘状连接（disc-shaped）；跨膜蛋白为**非经典钙粘蛋白**（desmoglein、desmocollin）；胞内通过**桥粒斑蛋白（desmoplakin）**、**斑菲素（plakophilin）**连接**中间丝（IFs）**。
- **功能**：提供机械强度，抗压力和张力（如皮肤、心肌）。
- **自身免疫病**：天疱疮（pemphigus）由抗 desmoglein 抗体引起，导致表皮细胞间连接破坏。

#### 半桥粒

- **位置**：细胞与基膜的连接（如上皮细胞基底面）。
- **跨膜蛋白**：**整合素（integrin α6β4）**。
- **胞内连接**：中间丝（角蛋白）。
- **胞外配体**：层粘连蛋白（laminin）。
- **疾病**：大疱性表皮松解症（epidermolysis bullosa）可由整合素或层粘连蛋白突变引起。

### 3. 黏着带（Adherens Junctions）与黏着斑（Focal Contacts）

#### 黏着带

- **位置**：上皮细胞中环绕细胞的黏合带（zonula adherens），位于紧密连接下方。
- **跨膜蛋白**：**经典钙粘蛋白（E-cadherin）**。
- **胞内连接**：**catenin**（α、β、γ）连接**肌动蛋白（actin）**。
- **钙粘蛋白特性**：同种亚型之间相互结合（homophilic），依赖 Ca²⁺；调控发育中的细胞分选（如神经管形成、神经嵴迁移）。

#### 黏着斑

- **位置**：细胞与 ECM 的局部接触（in vitro 培养细胞中常见）。
- **跨膜蛋白**：**整合素（integrin）**。
- **胞内连接**：talin、vinculin、α-actinin 等连接**肌动蛋白**。
- **功能**：细胞迁移、力感知、信号转导。

### 4. 选择素（Selectins）

- **功能**：介导白细胞与血管内皮细胞的**瞬时黏附**（滚动，rolling）。
- **特点**：钙依赖；亲和力较低，结合和解离快。
- **类型**：P-selectin、E-selectin、L-selectin。
- **生理意义**：炎症反应中白细胞从血管滚动、黏附并进入组织。

### 5. 间隙连接（Gap Junctions）

- **结构**：两个细胞各提供一个**连接子（connexon）**，每个连接子由 **6 个连接蛋白（connexin）** 亚基构成；两个连接子对接形成通道。
- **孔径**：约 1.4 nm；允许小于 **1000 Da** 的分子通过（离子、小分子代谢物、第二信使）。
- **功能**：
  - 电突触（electrical synapse），使动作电位快速传播；
  - 心肌、平滑肌、肝细胞的代谢偶联；
  - 胚胎发育中的细胞间通讯；
  - 肿瘤细胞中 GJIC（gap junction intercellular communication）常减弱或缺失。
- **连接子类型**：同型（homotypic）、异型（heterotypic）、同聚（homomeric）、异聚（heteromeric）。

### 6. 胞间连丝（Plasmodesmata）

- **位置**：植物细胞特有的连接，穿过细胞壁，连接相邻细胞的细胞质。
- **结构**：内质网形成**链样管（desmotubule）**穿过；周围有胞质环（annulus）。
- **功能**：允许小分子和部分大分子通过，参与物质运输和信号传递。

## 三、细胞-基质黏附（Cell-Matrix Adhesion）

### 1. 整合素（Integrins）

- **结构**：跨膜异二聚体（α 亚基 + β 亚基）。
- **配体**：胞外域结合 ECM 配体（如纤连蛋白的 **RGD 序列**、层粘连蛋白、胶原）；胞内域结合细胞骨架（talin、vinculin、α-actinin、actin）。
- **激活**：整合素可处于低亲和力或高亲和力构象；胞内信号（inside-out signaling）可激活整合素。
- **功能**：
  - 黏附细胞到基质；
  - 感知和传递环境信号到细胞内（outside-in signaling）；
  - 调控细胞迁移、增殖、存活。
- **RGD 序列**：Arg-Gly-Asp，是纤连蛋白等 ECM 蛋白中与整合素结合的关键序列。含 RGD 的化学物可抑制整合素功能。

### 2. 黏着斑与半桥粒

- **黏着斑（focal contacts）**：体外培养细胞与基质的局部接触，连接肌动蛋白。
- **半桥粒（hemidesmosomes）**：体内上皮细胞与基膜的紧密连接，连接中间丝。

## 四、细胞壁（Plant Cell Walls）

### 1. 组成

| 成分 | 特点与功能 |
| :--- | :--- |
| **纤维素（cellulose）** | 微纤丝（microfibrils）提供抗张强度；由质膜上的**玫瑰花结（rosettes）**复合体合成 |
| **半纤维素（hemicellulose）** | 连接纤维素微纤丝，形成网络 |
| **果胶（pectins）** | 形成凝胶，黏合细胞；中层（middle lamella）富含果胶 |
| **结构蛋白** | 富含羟脯氨酸、脯氨酸、甘氨酸的蛋白 |

### 2. 层次

- **初生壁（primary cell wall）**：柔性，允许细胞生长；纤维素微纤丝排列较松散。
- **次生壁（secondary cell wall）**：厚而坚硬，多层结构；纤维素微纤丝排列致密平行。
- **中层（middle lamella）**：富果胶，黏合相邻细胞。

### 3. 功能

- 提供保护，抵抗机械磨损（abrasion）、渗透胁迫（osmotic stress）和病原体（pathogens）；
- 维持细胞形状，抵抗膨压。
