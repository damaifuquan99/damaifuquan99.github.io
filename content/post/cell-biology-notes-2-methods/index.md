# **细胞生物学学习笔记 2 | 细胞生物学研究方法：从显微成像到基因编辑**

---

## 一、本章总览：研究细胞的方法体系

主线：

| 研究目的 | 主要方法 |
| :--- | :--- |
| **观察细胞** | 光学显微镜（明场、相差、DIC、暗场、荧光、共聚焦）、电子显微镜（TEM、SEM、冷冻蚀刻、cryo-EM） |
| **标记与追踪** | 荧光探针（GFP、fura-2、DAPI）、同位素（\(^{32}\text{P}\)、\(^{35}\text{S}\)、\(^{3}\text{H}\)）、脉冲-追踪（pulse-chase） |
| **分离细胞器** | 细胞组分分离（差速离心、密度梯度离心） |
| **纯化与检测蛋白质** | 柱层析、SDS-PAGE、等电聚焦、2D 电泳、免疫印迹、质谱 |
| **研究蛋白质互作** | GST pull-down、FRET、酵母双杂交、噬菌体展示、SPR（Biacore） |
| **研究基因功能** | 定点突变、RNAi、基因敲除/敲入、LoxP-Cre、CRISPR/Cas9、RNA-seq |

> **考试提示：** 每种方法的**原理**和**主要应用**是重点，而不是具体操作细节。

## 二、光学显微镜（Light Microscopy）

### 1. 分辨率基础

光学显微镜的最大分辨率约为 **0.2 μm**（200 nm），受可见光波长限制。这决定了它能看到细胞整体、细胞核、染色体等较大结构，但看不到核糖体、膜结构细节。

### 2. 四种观察活细胞的光学显微技术

| 技术 | 原理 | 特点与适用场景 |
| :--- | :--- | :--- |
| **明场（bright-field）** | 光直接透射过样品 | 最简单，对比度低，适合染色后的固定样品 |
| **相差（phase-contrast）** | 将光通过透明样品产生的相位差转换为亮度差 | 可观察未染色活细胞，能看清细胞内部结构 |
| **微分干涉（DIC / Nomarski）** | 偏振光分成两束相干光，经样品后重新组合产生干涉 | 细胞有浮雕感，适合观察活细胞动态 |
| **暗场（dark-field）** | 只检测样品侧面散射的光 | 背景暗、样品亮，适合观察未染色透明样品 |

> **记忆点：** 相差看“密度差”，DIC 看“厚度差”（浮雕感），暗场看“散射光”。

### 3. 荧光显微镜（Fluorescence Microscopy）

#### 基本原理

荧光分子吸收特定波长（激发光，excitation）后，发射更长波长（发射光，emission）的光。荧光显微镜通过滤光片系统分离激发光和发射光。

#### 光路关键部件

| 部件 | 功能 |
| :--- | :--- |
| **第一滤光片（excitation filter）** | 只让特定波长的激发光通过（如 450–490 nm 蓝光） |
| **二向色镜（beam-splitting mirror / dichroic mirror）** | 反射短波长激发光到样品，透射长波长发射光 |
| **第二滤光片（emission filter / barrier filter）** | 只让特定发射光通过，阻挡残余激发光 |

#### 常用荧光染料与蛋白

| 荧光基团 | 激发/发射（约） | 用途 |
| :--- | :--- | :--- |
| **DAPI** | 358 / 461 nm | 染 DNA（细胞核） |
| **GFP** | 488 / 507 nm | 蛋白定位（基因融合标签） |
| **FITC** | 495 / 519 nm | 抗体标记 |
| **Cy3** | 550 / 570 nm | 抗体标记 |
| **Cy5** | 650 / 670 nm | 抗体标记 |
| **Alexa 568** | 578 / 603 nm | 抗体标记 |

### 4. 共聚焦激光扫描显微镜（Confocal Laser Scanning Microscopy, CLSM）

#### 与常规荧光显微镜的关键区别

普通荧光显微镜会收集来自焦平面以外（上下层）的荧光，导致图像模糊。共聚焦显微镜通过**针孔（pinhole）**只收集焦平面上的光，从而排除焦外光，获得清晰的光学切片（optical section）。

#### 主要应用

- **Z 轴序列扫描（Z-stack）**：逐层扫描，重建细胞或组织的三维结构；
- **最大强度投影（Maximum Intensity Projection, MIP）**：将 Z-stack 中各层最亮点投影到一张图上；
- **多色成像**：同时观察多种蛋白定位；
- **活细胞成像**：观察动态过程。

> **课件中的例子：** 海胆受精卵有丝分裂纺锤体（anti-tubulin 抗体染色），普通荧光下模糊，共聚焦下可清晰看到纺锤体微管纤维。

### 5. 超分辨率成像技术

| 技术 | 原理简述 |
| :--- | :--- |
| **SIM（structured illumination microscopy）** | 用结构化照明图案提高分辨率 |
| **STORM（stochastic optical reconstruction microscopy）** | 单分子定位，逐点重建 |
| **Deconvolution（去卷积）** | 通过算法去除光学系统的模糊效应 |

课件中展示了 ERGIC 与 COPII、LC3 与 IL1B 等蛋白的超分辨率共定位图像，以及中国科学家李栋发展的 GI-SIM（grazing-incidence SIM）用于活细胞中溶酶体、ER、微管的动态成像。

### 6. 无标记三维光学衍射断层扫描（ODT）

课件中提到陈良怡教授发展的 **label-free 3D optical diffraction tomography (ODT)**，无需荧光标记即可获得细胞的三维折射率分布图像。

### 7. 间接免疫细胞化学（Indirect Immunocytochemistry）

#### 原理

1. **一抗（primary antibody）**：识别目标抗原（antigen A）；
2. **二抗（secondary antibody）**：带有荧光染料、辣根过氧化物酶（HRP）、碱性磷酸酶（AP）或胶体金等标记，识别一抗。

#### 优点

- 信号放大：多个二抗可结合一个一抗；
- 通用性：同一二抗可用于多种一抗；
- 标记灵活：可换不同标记的二抗实现不同检测目的。

### 8. 时间延迟显微技术（Time-lapse Microscopy）

在活细胞培养条件下，按固定时间间隔连续拍照，观察细胞运动、分裂、囊泡运输等动态过程。课件中展示了培养成纤维细胞在 0–34 min 内的运动过程。

## 三、电子显微镜（Electron Microscopy, EM）

### 1. 为什么需要电子显微镜？

电子束的波长远小于可见光（约 0.004 nm），因此电子显微镜的分辨率远高于光学显微镜，可达 **0.1–0.2 nm**（原子级）。但电子束在空气中会被散射，因此电镜需要**高真空**，样品必须固定、脱水、包埋，不能观察活细胞。

### 2. 透射电镜（Transmission Electron Microscopy, TEM）

#### 原理

电子束穿过超薄切片（通常 50–100 nm），经电磁透镜聚焦成像。样品中电子密度高的区域（如被锇酸染色的膜）散射电子，在图像上显示为暗区。

#### 样品制备流程

1. **固定（fixation）**：常用戊二醛（glutaraldehyde）和四氧化锇（OsO₄）；
2. **脱水**：乙醇或丙酮梯度脱水；
3. **包埋（embedding）**：环氧树脂（如 Epon、Araldite）；
4. **超薄切片（ultrathin sectioning）**：用超薄切片机切 50–100 nm 薄片；
5. **染色**：醋酸铀、柠檬酸铅等重金属染色。

#### 应用

- 观察细胞内部超微结构（细胞器、膜、核糖体、细胞骨架）；
- 免疫电镜（immuno-EM）：用胶体金标记抗体，定位特定蛋白。

### 3. 扫描电镜（Scanning Electron Microscopy, SEM）

#### 原理

电子束扫描样品表面，收集二次电子（secondary electrons）或背散射电子成像。样品表面需喷镀金属（如金、铂）以增加导电性并防止电子积累。

#### 应用

- 观察细胞表面形貌（微绒毛、纤毛、伪足、细胞间连接）；
- 立体感强，适合表面结构研究。

### 4. 冷冻蚀刻（Freeze-Etching / Freeze-Fracture）

#### 原理

1. 样品快速冷冻；
2. 用刀片断裂，断裂面常沿脂双层中间走；
3. 升华表面冰（etching）暴露更多结构；
4. 喷镀铂-碳形成 replica（复型）；
5. 用 TEM 观察复型。

#### 应用

- 观察膜内蛋白颗粒分布（如质膜 P 面与 E 面）；
- 观察核孔、紧密连接、间隙连接等膜结构。

### 5. 冷冻电镜（Cryo-Electron Microscopy, Cryo-EM）

#### 原理

样品在玻璃态冰（vitreous ice）中快速冷冻，不经过固定和染色，保持近生理状态。通过单颗粒重建（single-particle reconstruction）或电子断层扫描（electron tomography）解析结构。

#### 应用

- 解析蛋白质、病毒、核糖体等大分子复合物的高分辨率结构；
- 2017 年诺贝尔化学奖授予 Jacques Dubochet、Joachim Frank、Richard Henderson。

### 6. 其他电子显微技术

| 技术 | 原理与应用 |
| :--- | :--- |
| **负染（negative staining）** | 用重金属盐（如磷钨酸）包裹样品，样品呈亮区，适合观察病毒、蛋白纤维、微丝 |
| **免疫胶体金（immunogold）** | 金颗粒标记抗体，用于定位特定蛋白（如过氧化物酶体中的过氧化氢酶） |
| **原子力显微镜（AFM）** | 通过探针与样品表面原子间作用力成像，可获得纳米级表面形貌 |
| **扫描隧道显微镜（STM）** | 利用隧道电流，可达单原子分辨率，可在低温下操纵原子 |

## 四、荧光探针与流式细胞术

### 1. 检测细胞内 Ca²⁺

| 探针 | 原理 |
| :--- | :--- |
| **水母素（aequorin）** | 来自水母的发光蛋白，与 Ca²⁺ 结合后发光，可检测细胞内 Ca²⁺ 变化 |
| **Fura-2** | 荧光染料，与 Ca²⁺ 结合后激发光谱发生偏移，可定量细胞内 Ca²⁺ 浓度 |

课件中展示了 Fura-2 在小脑浦肯野细胞（Purkinje cell）中显示 Ca²⁺ 浓度梯度的图像，颜色从蓝到红表示 Ca²⁺ 浓度由低到高。

### 2. GFP：活细胞蛋白定位的利器

- 来自水母（jellyfish）的绿色荧光蛋白；
- 发色团（chromophore）由三个氨基酸残基翻译后形成；
- 通过基因融合（GFP tag）可追踪目标蛋白的定位和动态；
- 变体：CFP（青色）、YFP（黄色）、RFP（红色）等，用于多色成像和 FRET。

### 3. 荧光激活细胞分选（Fluorescence-Activated Cell Sorter, FACS）

#### 原理

1. 细胞悬液经喷嘴形成液滴；
2. 激光照射液滴中的细胞，检测荧光信号和散射光；
3. 带电荷的液滴在电场中偏转，分选到不同收集管中。

#### 应用

- 根据表面标志物分选特定细胞类型；
- 定量检测细胞内蛋白质和核酸含量；
- 单细胞分选用于单细胞测序。

## 五、同位素示踪（Isotope Probes）

### 1. 常用放射性同位素

| 同位素 | 半衰期 | 用途 |
| :--- | :--- | :--- |
| **\(^{32}\text{P}\)** | 14 天 | 标记 ATP、核酸 |
| **\(^{131}\text{I}\)** | 8.1 天 | 标记蛋白质（也发 γ 射线） |
| **\(^{35}\text{S}\)** | 87 天 | 标记蛋白质（甲硫氨酸/半胱氨酸） |
| **\(^{14}\text{C}\)** | 5570 年 | 标记有机物 |
| **\(^{45}\text{Ca}\)** | 164 天 | 标记钙 |
| **\(^{3}\text{H}\)** | 12.3 年 | 标记小分子、核苷酸 |

### 2. 脉冲-追踪实验（Pulse-Chase）

#### 原理

1. **脉冲（pulse）**：短时间内加入放射性标记物（如 \(^{35}\text{S}\)-Met），新合成的蛋白质被标记；
2. **追踪（chase）**：洗去放射性标记，换成非放射性培养基，随时间取样；
3. 观察放射性在不同细胞组分或不同蛋白形式中的分布变化。

#### 经典应用

- **胰岛素生物合成追踪**：Palade 等用脉冲-追踪结合 EM 放射自显影，证明分泌蛋白从 ER → Golgi → 分泌颗粒的运输路径；
- **激素分泌与受体周转**：如 SRIF 分泌、TGF-β 受体（TβRII）成熟与降解。

## 六、细胞组分分离（Cell Fractionation）

### 1. 基本原理

细胞匀浆（homogenate）后，不同细胞器因**大小、形状、密度**不同，在离心力场中沉降速度不同，从而被分离。

### 2. 差速离心（Differential Centrifugation）

按离心力从小到大逐级离心，依次沉淀不同组分：

| 离心条件（示例） | 沉淀组分 |
| :--- | :--- |
| 600 × g，10 min | 细胞核（nuclei） |
| 15,000 × g，5 min | 线粒体、叶绿体、溶酶体、过氧化物酶体 |
| 100,000 × g，60 min | 质膜、微粒体（ER 碎片）、大得多核糖体 |
| 300,000 × g，2 h | 核糖体亚基、小多核糖体 |
| 上清 | 细胞质基质（cytosol） |

### 3. 速度沉降 vs 平衡沉降

| 类型 | 原理 | 应用 |
| :--- | :--- | :--- |
| **速度沉降（velocity sedimentation）** | 在蔗糖梯度（5–20%）中按**大小和形状**不同沉降速度分离 | 分离不同大小的细胞器或复合物 |
| **平衡沉降（equilibrium sedimentation）** | 在陡蔗糖梯度（如 20–70%）或 CsCl 梯度中，颗粒移动到**密度相等**的位置 | 分离不同密度的细胞器（如溶酶体 1.12、线粒体 1.18、过氧化物酶体 1.23 g/cm³） |

### 4. 免疫纯化（Immuno-purification）

用针对特定蛋白的抗体（如 anti-clathrin）结合到固相支持物上，从细胞匀浆中特异性捕获带该蛋白的囊泡或复合物（如网格蛋白包被囊泡）。

### 5. 无细胞体系（Cell-Free Systems）

在体外用分离的组分重建细胞过程，是研究机制的重要手段。

#### 经典例子

- **Golgi 囊泡运输**：Rothman 等将来自突变细胞（缺乏 GlcNAc 转移酶 I）的“供体”Golgi 与野生型“受体”Golgi 混合，加入 ATP 和细胞质，检测病毒糖蛋白是否被 \(^{3}\text{H}\)-GlcNAc 修饰，证明囊泡在 Golgi 堆叠间运输。
- **LC3 脂化实验**：用 Atg5 敲除细胞的膜与野生型细胞质混合，加入 GTP 和 ATP，检测 LC3-I 向 LC3-II 的转化（自噬体形成的关键步骤）。

> **意义：** 无细胞体系使复杂的细胞过程可以在受控条件下拆解分析，是细胞生物学研究的核心策略之一。

## 七、蛋白质纯化与检测

### 1. 柱层析（Column Chromatography）

| 类型 | 原理 | 特点 |
| :--- | :--- | :--- |
| **凝胶过滤（gel-filtration / size-exclusion）** | 多孔珠，小分子进入孔内被滞留，大分子先流出 | 按**大小**分离，大分子先出 |
| **离子交换（ion-exchange）** | 带电荷的珠与带相反电荷的蛋白结合，用盐梯度洗脱 | 按**电荷**分离 |
| **亲和层析（affinity）** | 固相上偶联特定配体（如抗体、底物、谷胱甘肽），特异结合目标蛋白 | 纯度最高，常作为最后一步 |

### 2. SDS-PAGE（SDS-聚丙烯酰胺凝胶电泳）

#### 原理

- SDS（十二烷基硫酸钠）使蛋白质变性并带上均匀负电荷；
- 巯基乙醇（mercaptoethanol）还原二硫键；
- 蛋白质在电场中按**分子量**分离，小分子跑得快。

#### 应用

- 检测蛋白质纯度；
- 估计分子量；
- 配合免疫印迹（Western blot）检测特定蛋白。

### 3. 等电聚焦（Isoelectric Focusing, IEF）

#### 原理

在 pH 梯度中，蛋白质移动到其**等电点（pI）**位置时净电荷为零，不再迁移。

### 4. 双向凝胶电泳（2D Gel）

#### 原理

1. 第一维：IEF，按 **pI** 分离；
2. 第二维：SDS-PAGE，按**分子量**分离。

#### 应用

- 分离复杂蛋白质混合物（如全细胞裂解液）；
- 比较不同处理条件下蛋白质表达差异；
- 配合质谱鉴定蛋白质。

### 5. 免疫印迹（Immunoblotting / Western Blot）

#### 流程

1. SDS-PAGE 分离蛋白质；
2. 电转移（electrotransfer）到膜上（如硝酸纤维素膜、PVDF 膜）；
3. 一抗孵育，识别目标蛋白；
4. 酶标二抗孵育；
5. 加底物显色或化学发光检测。

#### 应用

- 检测特定蛋白的表达与分子量；
- 半定量比较不同样品中蛋白表达水平。

### 6. 质谱（Mass Spectrometry, MS）

#### 原理

1. 蛋白质酶切（如胰蛋白酶）成肽段；
2. 肽段电离（如 MALDI 或 ESI）；
3. 测量肽段的质荷比（m/z）；
4. 与数据库比对，鉴定蛋白质。

#### 应用

- 从 2D 胶中切取单个蛋白点进行鉴定；
- 大规模蛋白质组学分析；
- 串联质谱（MS/MS）可推断部分氨基酸序列。

## 八、蛋白质-蛋白质相互作用（Protein-Protein Interactions, PPI）

### 1. GST Pull-Down

#### 原理

- 将目标蛋白 X 与 GST（谷胱甘肽 S-转移酶）融合表达；
- 融合蛋白结合到谷胱甘肽包被的珠上；
- 加入细胞裂解液，与 X 互作的蛋白被捕获；
- 用谷胱甘肽洗脱，SDS-PAGE 检测。

#### 应用

- 体外验证已知或推测的蛋白互作；
- 筛选互作蛋白。

### 2. FRET（荧光共振能量转移）

#### 原理

- 两个荧光蛋白（如 CFP 和 YFP）分别融合到蛋白 X 和 Y；
- 当 X 和 Y 距离足够近（<10 nm）时，激发 CFP 可导致 YFP 发射荧光（能量转移）；
- 检测 YFP 荧光即可判断互作。

#### 应用

- 活细胞中实时监测蛋白互作；
- 检测构象变化。

### 3. 酵母双杂交（Yeast Two-Hybrid）

#### 原理

- 将诱饵蛋白（bait）与 DNA 结合域（BD）融合；
- 将猎物蛋白（prey）与转录激活域（AD）融合；
- 若 bait 与 prey 互作，BD 与 AD 靠近，激活报告基因表达。

#### 应用

- 筛选 cDNA 文库中的互作蛋白；
- 验证已知互作。

### 4. 噬菌体展示（Phage Display）

#### 原理

- 将外源肽段或蛋白与噬菌体外壳蛋白融合，展示在噬菌体表面；
- 用靶分子（如抗体、受体）筛选结合的噬菌体；
- 回收并测序，获得编码序列。

#### 应用

- 筛选特异性结合肽或抗体；
- 课件例子：将噬菌体文库注射到脑肿瘤小鼠体内，筛选能特异性结合肿瘤血管的肽段。

### 5. 表面等离子体共振（Surface Plasmon Resonance, SPR / Biacore）

#### 原理

- 将诱饵分子固定在金膜表面；
- 流入猎物分子溶液；
- 分子结合改变金膜表面折射率，导致共振角变化；
- 实时监测结合（association）和解离（dissociation）曲线，计算 \(K_d\)。

#### 应用

- 定量测定蛋白-蛋白、蛋白-小分子、抗原-抗体的结合亲和力；
- 无需标记，实时检测。

## 九、分子生物学与遗传学方法

### 1. 定点突变（Site-Directed Mutagenesis）

#### 原理

- 设计含突变碱基的寡核苷酸引物；
- 以质粒模板进行 PCR 扩增；
- DNA 聚合酶延伸、连接酶封闭；
- 转化细胞，筛选含突变基因的克隆。

#### 应用

- 研究特定氨基酸对蛋白功能的影响；
- 构建点突变疾病模型。

### 2. 将物质导入细胞

| 方法 | 原理 |
| :--- | :--- |
| **显微注射（microinjection）** | 玻璃微针直接注射到细胞质或细胞核 |
| **电穿孔（electroporation）** | 短暂电脉冲在膜上形成瞬时可逆孔道 |
| **脂质体介导（lipid-mediated）** | 脂质体与质膜融合，将内容物释放到细胞质 |
| **金颗粒介导（gold particle-mediated / gene gun）** | DNA 包被金颗粒，高压射入细胞 |

### 3. 异位过表达（Ectopic Misexpression）

在非正常位置或时间表达某基因，观察表型变化。

#### 课件例子

- **Wnt 异位表达**：在胚胎中异位表达 Wnt，导致形成第二体轴；
- **Dapper2 过表达**：在斑马鱼中过表达 Dapper2，导致眼睛融合（eye fusion），证明其在发育中的作用（Zhang et al., 2004, Science）。

### 4. RNA 干扰（RNA Interference, RNAi）

#### 原理

- 双链 RNA（dsRNA）被 Dicer 切割成小干扰 RNA（siRNA）；
- siRNA 与 RISC 复合物结合，降解同源 mRNA；
- 导致基因表达**敲低（knockdown）**，而非完全敲除。

#### 形式

- **siRNA**：体外合成，直接导入细胞，瞬时敲低；
- **shRNA**：通过载体在细胞内表达短发夹 RNA，可稳定敲低。

#### 应用

- 研究基因功能；
- 课件例子：线虫（*C. elegans*）中通过喂食表达 dsRNA 的 *E. coli* 实现基因敲低。

### 5. 基因敲除、敲入与替换

| 类型 | 结果 |
| :--- | :--- |
| **基因替换（gene replacement）** | 用突变基因替换正常基因，只有突变基因有活性 |
| **基因敲除（gene knockout）** | 破坏目标基因，使其无活性 |
| **基因添加（gene addition）** | 在基因组中额外插入一个基因，正常基因和额外基因都有活性 |

### 6. 基因敲除小鼠的制备

#### 流程

1. 构建含同源臂的替换载体（含 neo\(^r\) 正筛选标记和 tk\(^{HSV}\) 负筛选标记）；
2. 电穿孔导入 ES 细胞；
3. **同源重组（homologous recombination）**：目标基因被破坏；
4. **随机插入（nonhomologous recombination）**：tk 基因插入，细胞对 ganciclovir 敏感；
5. 用 neomycin（正筛选）和 ganciclovir（负筛选）筛选；
6. 将正确重组的 ES 细胞注射到囊胚腔；
7. 产生嵌合体小鼠（chimeric mice）；
8. 与野生型小鼠交配，获得杂合子；
9. 杂合子互交，获得纯合敲除小鼠。

### 7. 条件性敲除：LoxP-Cre 系统

#### 原理

- **LoxP**：34 bp 的 DNA 识别位点；
- **Cre 重组酶**：来自 P1 噬菌体，识别 LoxP 位点并介导重组；
- 将 LoxP 位点置于目标基因两侧（floxed 基因）；
- 在表达 Cre 的细胞中，LoxP 位点间的序列被切除，实现**组织特异性或时间特异性敲除**。

#### 应用

- 研究特定组织或发育阶段中基因的功能；
- 避免全身敲除导致的胚胎致死。

### 8. CRISPR/Cas9 基因编辑

#### 原理

- **Cas9**：核酸内切酶，在 guide RNA（gRNA）引导下切割目标 DNA；
- **gRNA**：与目标 DNA 互补配对（约 20 nt）；
- 切割后通过非同源末端连接（NHEJ）或同源定向修复（HDR）实现基因敲除或敲入。

#### 优点

- 操作简单、效率高、可同时编辑多个基因；
- 2020 年诺贝尔化学奖授予 Emmanuelle Charpentier 和 Jennifer Doudna。

### 9. RNA-seq

#### 原理

1. 提取 mRNA；
2. 片段化；
3. 反转录为 cDNA；
4. 加接头、PCR 扩增；
5. 高通量测序（如 Illumina）；
6. 比对到参考基因组，定量基因表达。

#### 应用

- 同时监测数千个基因的表达；
- 比较不同处理、不同发育阶段或不同疾病状态的转录组差异；
- 聚类分析（clustering）可发现共表达基因模块（如胆固醇合成、细胞周期、伤口愈合相关基因）。

## 十、模式生物（Model Organisms）

| 模式生物 | 研究优势 | 主要应用 |
| :--- | :--- | :--- |
| **病毒（viruses）** | 结构简单、基因组小 | DNA/RNA/蛋白质合成、基因调控、癌症、基因治疗 |
| **细菌（bacteria）** | 繁殖快、遗传操作方便 | DNA/RNA/蛋白质合成、代谢、抗生素靶点、细胞周期、信号转导 |
| **酵母（*S. cerevisiae*）** | 真核生物、遗传操作成熟 | 细胞周期、蛋白质分泌、膜生物发生、细胞骨架、衰老、基因调控 |
| **线虫（*C. elegans*）** | 细胞数目恒定、谱系清楚 | 体轴发育、细胞谱系、神经系统、程序性细胞死亡、衰老、行为 |
| **果蝇（*D. melanogaster*）** | 遗传学经典、发育机制保守 | 体轴发育、细胞分化、神经系统、心脏、肌肉、程序性细胞死亡、癌症基因、行为 |
| **斑马鱼（*D. rerio*）** | 脊椎动物、胚胎透明、体外发育 | 脊椎动物组织发育、脑和神经系统、出生缺陷、癌症 |
| **小鼠（*M. musculus*）** | 哺乳动物、与人类亲缘近 | 组织发育、免疫系统、脑和神经系统、人类疾病模型、基因调控、传染病 |
| **拟南芥（*A. thaliana*）** | 植物模式生物、基因组小 | 植物组织发育、细胞生物学遗传学、农业应用、生理、免疫 |

### 保守基因的例子

- **Hox 基因**：在果蝇和哺乳动物中均控制体轴发育；
- **Pax6 / eyeless**：果蝇的 eyeless 基因与哺乳动物的 Pax6 同源，均控制眼睛发育；人类 PAX6 突变导致无虹膜症（aniridia）。

> **意义：** 模式生物研究表明，许多控制发育和细胞过程的基因在进化中高度保守，因此可以从简单生物的研究推及人类。

## 十一、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **光学显微镜** | 明场、相差、DIC、暗场；荧光显微镜；共聚焦排除焦外光；超分辨率（SIM、STORM） |
| **电子显微镜** | TEM 看内部超微结构；SEM 看表面形貌；冷冻蚀刻看膜内结构；cryo-EM 解析大分子结构 |
| **荧光探针** | GFP 标记蛋白；fura-2 检测 Ca²⁺；FACS 分选细胞 |
| **同位素** | \(^{32}\text{P}\) 标记核酸/ATP；\(^{35}\text{S}\) 标记蛋白；脉冲-追踪研究动态过程 |
| **细胞组分分离** | 差速离心按大小分离；密度梯度离心按密度分离；无细胞体系重建细胞过程 |
| **蛋白质纯化** | 凝胶过滤按大小；离子交换按电荷；亲和层析按特异结合；SDS-PAGE 按分子量 |
| **蛋白质检测** | Western blot 检测特定蛋白；质谱鉴定蛋白质 |
| **蛋白质互作** | GST pull-down（体外）、FRET（活细胞）、酵母双杂交（筛选）、噬菌体展示（筛选）、SPR（定量亲和力） |
| **基因功能研究** | 定点突变、RNAi 敲低、基因敲除/敲入、LoxP-Cre 条件敲除、CRISPR/Cas9 编辑、RNA-seq 转录组分析 |
| **模式生物** | 病毒、细菌、酵母、线虫、果蝇、斑马鱼、小鼠、拟南芥；基因功能高度保守 |
