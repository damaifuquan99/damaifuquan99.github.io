## 二、光学显微：从"看见"到"看清"

### 1. 荧光显微镜（Page 1–4）

**是什么：** 用特定波长的激发光照射样品，样品中的荧光分子吸收能量后发射更长波长的光，经滤光片只让发射光进入检测器，从而在暗背景上得到高对比度的信号。

**怎么工作（课件给出的三个例子）：**
1. **Actin fibers in a fibroblast**（p3）：用荧光标记显示成纤维细胞内的 actin 纤维——说明荧光显微可以把"某一种分子"从细胞里单独提出来看。
2. **Microtubules / Chromosome / Centromeres**（p4）：同一细胞的多色标记——微管、染色体、着丝粒分别用不同荧光，说明**多通道成像**可以同时定位多种结构。
3. **可见光波段（Visible lightwave，p1）**：荧光显微的分辨极限由光的衍射决定，这一限制直接引出共聚焦与超分辨。

**为什么重要：** 荧光显微第一次让"分子身份"与"空间位置"绑定——这是细胞生物学从形态学走向分子细胞学的关键一步。

### 2. 共聚焦显微镜与三维重建（Page 5–8）

**是什么：** 在普通荧光显微镜的光路中加一个**针孔（pinhole）**，只让焦平面上的光通过，焦平面以外的杂散光被挡掉，从而逐点扫描、逐层成像。

**怎么工作：**
1. 激光逐点扫描样品；
2. 针孔挡掉非焦平面（out-of-focus）的荧光；
3. 每个像素记录强度，扫描完成得到一幅"光学切片"；
4. 改变焦平面重复，得到 z 序列，可做**三维重建（3-D reconstruction）**。

**课件给出的证据：**
- p6 "Comparison of conventional and confocal fluorescence microscopy"：同一对象——**海胆受精卵的有丝分裂纺锤体，用抗微管蛋白抗体染色（anti-tubulin antibodies）**——常规荧光 vs 共聚焦的对比，共聚焦明显更清晰。
- p7–8 三维重建：**盘基网柄菌（*Dictyostelium*）的丝状伪足（filopodia）**，双标记 **GFP-dDia2**（绿色荧光蛋白标记的 dDia2）与 **TRITC-phalloidin**（鬼笔环肽标记 F-actin）。

**为什么重要：** 针孔把"厚度"从图像里去掉，使细胞从"投影图"变成"可切片的三维体"——这是研究细胞器空间关系的必备前提。

### 3. 活细胞成像与超分辨（Page 9–12）

课件在这一段集中展示了"突破衍射极限"的几条路线：

| 技术 | 课件页 | 原理要点 |
| :--- | :--- | :--- |
| **SIM**（structured illumination microscopy，结构光照明） | p9 | 用 patterned illumination 产生摩尔纹，把高频信息"搬到"可分辨的低频区，再计算还原；可做**活细胞**成像 |
| **STORM**（stochastic optical reconstruction microscopy） | p10 | 让荧光分子随机、稀疏地发光，逐个定位其中心再叠加重建；分辨率可达 ~20 nm 量级 |
| **Deconvolution**（去卷积） | p10 | 已知点扩散函数（PSF）后，用算法把模糊"反算"回去；不需要特殊硬件 |
| **GI-SIM**（李栋，p11） | p11 | 掠入射结构光照明，用于快速、长时程地同时观察 **Lysosome、ER、MT**（溶酶体、内质网、微管）三者互动 |
| **ODT**（optical diffraction tomography，p12） | p12 | **无标记（label-free）三维**折射率成像（Kebin Shi、Liangyi Chen，2020；陈良怡） |

**课件给出的生物学问题：**
- p9 "Membrane contact of ERGIC and ERES"——用 SIM 观察 **ERGIC（内质网-高尔基体中间区室）与 ERES（内质网出口位点）** 的膜接触；
- p10 "3-D reconstruction using super resolution imaging"——用 STORM 与去卷积重建 **ERGIC 与 COPII**、**LC3 与 IL1B** 的空间关系。

**为什么重要：** 细胞器之间的"膜接触位点（membrane contact site）"尺度在几十纳米，常规显微镜看不到；超分辨把这类结构从"推测"变成"可见"。同时，**活细胞 + 长时程**的要求又限制了可用的标记方式（光毒性、亮度），这就是 GI-SIM、ODT 这类方法的动机。

> **补充：** 课件只给技术名与图像，没有给各技术的分辨率数字与光毒性的定量比较。上述原理性描述属教材与综述内容（课件未讲具体参数）。

### 4. 免疫细胞化学（Page 13）

**是什么：** 用抗体特异识别细胞内的目标分子，再用可检测的"标记物"把抗体位置显影出来——"间接免疫细胞化学（indirect immunocytochemistry）"指先用一抗结合目标，再用带标记的二抗放大信号。

**课件列出的四类标记物：**

| 标记物 | 读出方式 |
| :--- | :--- |
| **荧光染料（fluorescence dyes）** | 荧光显微镜 |
| **辣根过氧化物酶（horseradish peroxidase, HRP）** | 酶促显色/化学发光 |
| **碱性磷酸酶（alkaline phosphatase）** | 酶促显色 |
| **胶体金（colloidal gold）** | 电镜下呈电子致密颗粒（免疫金） |

**为什么重要：** 同一套"抗体—标记"逻辑可以适配光镜、电镜、甚至分子检测（Western blot），这是"免疫学方法"贯穿全章的原因。

## 三、电子显微：用电子代替光子

### 1. 为什么需要电镜

光的分辨极限约半个波长（可见光 ~200 nm 量级），而细胞器内部结构（膜厚度 ~5 nm、核糖体 ~25 nm）远低于此。电子的德布罗意波长极短，用**磁透镜（magnetic lens）**聚焦电子束即可获得纳米级分辨。

### 2. 透射电镜（TEM，Page 14–22）

**怎么工作（课件页面的顺序即流程）：**
1. **固定（fixation）：** 课件 p18 明确给出 **戊二醛（glutaraldehyde）+ 四氧化锇（osmium tetroxide）**——戊二醛交联蛋白，四氧化锇固定并**提供电子密度**（膜因此呈深色）；
2. **包埋、超薄切片（section）；**
3. 电子束穿透切片，经**磁透镜**成像，荧光屏/CCD 记录。

**课件给出的例子：**
- p18 "A plasma cell"（浆细胞）——典型分泌细胞，可见大量粗面内质网；
- p19 "A root-tip cell"（根尖细胞）；
- p20–21 **免疫电镜（immuno-electron microscopy）**：用**免疫金（immunogold）**定位特定蛋白——金颗粒在电镜下是明确的黑点，实现"分子身份 + 超微结构"的双重定位；
- p22 **高尔基体的区室化（compartmentation of the Golgi apparatus）**：用不同细胞化学标记区分高尔基体各层——
  - **无染色（No stain）**：对照；
  - **锇（osmium）**：标记 **cis Golgi**（顺面）；
  - **核苷二磷酸酶（nucleoside diphosphatase）**：标记 **trans Golgi**（反面）；
  - **酸性磷酸酶（acid phosphatase）**：标记 **TGN**（反面高尔基网络）。

**为什么重要：** p22 是"用酶细胞化学给细胞器分区"的经典示范——同一个高尔基体，靠不同酶的分布被切成 cis / trans / TGN 三段，这直接支持了"高尔基体是有极性的加工流水线"这一模型（Chapter 6 会展开）。

### 3. 扫描电镜（SEM，Page 23–28）

**是什么：** 电子束在样品表面扫描，收集**二次电子**，得到表面的立体形貌。

**课件例子：** 巨噬细胞与淋巴细胞的**表面微绒毛（surface microvilli）**（p24–25）；牛蛙内耳毛细胞的**静纤毛（stereocilia）**（p26），同页并列 **DIC / TEM / SEM** 三种视角——同一结构，三种方法给出"活细胞光学外观 / 内部超微结构 / 表面形貌"三类信息；p27–28 **核孔（nuclear pores）**的表面观察。

**为什么重要：** SEM 回答"表面长什么样"，这是 TEM 切片无法回答的问题（切片只给截面）。

### 4. 冷冻蚀刻/冷冻断裂与复型（Page 29–31）

**怎么工作：**
1. 样品快速冷冻；
2. 在真空中**断裂（fracture）**，断裂面沿脂双层疏水核心走，把膜劈成两半；
3. **蚀刻（etching）**：升华掉表面冰，暴露结构；
4. 蒸镀铂碳**复型（replica）**，把复型捞到铜网上观察。

**课件给出的两个面（p31）：**

| 面 | 英文 | 定义 |
| :--- | :--- | :--- |
| **P 面** | P-face (protoplasmic face) | 朝向细胞质的内侧半膜（"outwardly directed inner half"） |
| **E 面** | E-face (ectoplasmic face) | 朝向外侧的外侧半膜（"inwardly directed outer half"） |

**为什么重要：** 冷冻断裂把"膜内蛋白颗粒"暴露出来——膜蛋白在 P 面/E 面的分布不对称，是**膜不对称性**最直观的电镜证据（Chapter 3 会用到）。

### 5. 负染与其他电镜技术（Page 29、32）

- **负染（negative staining）**（p29）：用重金属盐（如磷钨酸）衬在样品周围，样品本身"透亮"、背景深，用于观察**单个蛋白/纤维**——课件用来看 **actin filaments**（肌动蛋白丝）。
- **冷冻电镜（cryo-electron microscopy）**（p32）：快速冷冻保存近天然构象，无需染色与包埋，可做单颗粒三维重构与**冷冻电子断层扫描（cryo-ET）**。
- **原子力显微镜（AFM）**（p32）：检测针尖与样品表面之间极微弱的**原子间相互作用力**，以纳米级分辨率获得表面形貌与粗糙度信息。
- **扫描隧道显微镜（STM）**（p32）：利用隧道电流，分辨率高于 AFM，可在低温（4 K）下用针尖**精确操纵单个原子**。

## 四、荧光探针：把小分子和蛋白变成"报告器"

### 1. 钙探针：从 aequorin 到 fura-2（Page 34–36）

- **aequorin（水母素）**：来自水母的**发光蛋白**，在**游离 Ca²⁺** 存在时发光（p34）——它把"钙浓度"翻译成"光"，是最早的钙指示剂之一。
- **fura-2**：**荧光指示剂**，用于可视化胞内 Ca²⁺ 变化（p35）；课件 p36 给出在**浦肯野细胞（Purkinje cell）**中观察 Ca²⁺ 浓度的例子。

**怎么工作（fura-2 的要点）：** fura-2 结合 Ca²⁺ 后**激发光谱发生位移**，因此可以用两个激发波长测量**比值（ratiometric）**，比值抵消了染料浓度与光漂白的影响——这是它比单波长染料可靠的原因。

> **补充：** 课件只写"visualizing intracellular Ca²⁺ change by fura-2"，没有解释比值法原理。比值法属教材内容（课件未讲）。

### 2. GFP：把蛋白变成"自带光源"的标签（Page 37–39）

**是什么：** 绿色荧光蛋白（green fluorescent protein, GFP）来自**水母（jellyfish）**，是最重要的活细胞蛋白定位工具。

**怎么工作（课件的关键句）：** 发色团（chromophore）是**翻译后**由**三个氨基酸残基伸出的侧链**形成的（"formed post-translationally from the protruding side chains of three amino acid residues"）。这一点决定了 GFP 的两个特性：
1. **不需要外加底物或辅因子**——只要蛋白折叠正确就发光，因此可以做成**融合蛋白**（fusion protein）在任何细胞里表达；
2. **必须正确折叠**——融合后若破坏折叠就不发光，这也是"GFP 融合是否保留功能"必须验证的原因。

**课件例子：**
- p38 "Dynamics of GFP tagging"：用 GFP 标记**剪接体（spliceosome）**，在**活细胞**中追踪其在核内的运动——这是"活细胞动态定位"的典型用例；
- p39 "Optimized dye labeling of mitochondria"：用优化的小分子染料标记**线粒体**——说明除遗传编码标签外，化学染料仍是快速标记细胞器的选择。

**为什么重要：** GFP 让"蛋白在哪、什么时候到、移动多快"三个问题可以在**不杀死细胞**的前提下回答，这是活细胞成像的基础。

### 3. FACS：把细胞按荧光分选（Page 40）

**是什么：** 荧光激活细胞分选（fluorescence-activated cell sorter, FACS）——让单细胞悬液逐个通过激光，检测其荧光与散射光，再靠**静电偏转**把目标细胞分到不同收集管。

**课件的用途表述：** "Determining the contents of proteins and nucleic acids in a cell"——通过荧光强度（如 DNA 染料、抗体标记）定量细胞内蛋白/核酸含量，并据此分选。

**为什么重要：** 显微镜给"群体中的形态"，FACS 给"群体中的分布"——两者互补；分选出的细胞还可继续培养或做测序。

## 五、同位素示踪：给分子打上"记号"再追踪（Page 41–46）

### 1. 原理

把放射性同位素（如 ³H、¹⁴C、³²P、³⁵S、¹²⁵I）掺入前体分子，细胞合成时把它装进目标分子；再用放射自显影或闪烁计数定位/定量。

**课件 p43** 给出 **三种市售的放射性 ATP 形式**（³²P 标记在不同磷酸位点）——同一个分子、不同位置标记，可用于追踪不同磷酸基团的去向。

### 2. Pulse-chase（脉冲-追踪）：本章最重要的实验设计

课件的定义值得逐句读：

> Radioactive material (the pulse) is added for a very brief period and then washed away and replaced by nonradioactive molecules (the chase). Samples are taken at regular intervals, and the chemical form or location of the radioactivity is identified for each sample.

拆成四步：
1. **pulse**：短时间加入放射性前体，让一批新合成的分子被标记；
2. **chase**：洗掉放射性，换成非放射性前体，此后新合成的分子都不带标记；
3. **定时取样**：在若干时间点固定/取材；
4. **定位或定性**：看放射性出现在哪种分子、哪个细胞器里。

**为什么这个设计成立：** 它把"合成时间"变成了"标签"，于是**同一批分子**在时间轴上的位置变化可以被看到——这是研究"分泌途径顺序"的唯一直接手段。

### 3. 三个经典应用

| 课件页 | 应用 | 结论 |
| :--- | :--- | :--- |
| p45 | **胰岛素生物合成**：pulse-chase + EM 放射自显影，追踪从 **ER 到分泌颗粒（secretory granules）** | 分泌蛋白沿"ER → 高尔基体 → 分泌颗粒 → 胞外"定向流动（Palade 的经典工作） |
| p46 | **激素（SRIF，生长抑素）分泌**（Chen et al., 1995, *JBC*） | 用 pulse-chase 定量激素的合成与分泌动力学 |
| p46 | **受体 TβRII 的成熟与周转**（Wells et al., 1997, *JBC*） | 用 pulse-chase 追踪膜受体的糖基化成熟与降解速率 |

**为什么重要：** p45 的结果是"内膜系统定向运输"模型的实验基石；p46 则说明同一方法可以用于**分泌**与**膜蛋白周转**两类完全不同的动力学问题。

## 六、细胞组分分离：把细胞拆成零件（Page 47–56）

### 1. 无细胞体系（cell-free system）

课件反复出现一句标题："The cellular events can be studied in cell-free system"（p48、p54、p55）。含义是：把细胞打碎、分离出组分后，在试管里重组反应，从而把"复杂细胞"化为"可控的分子反应"。

**课件例子：**
- p55 提到 **James Rothman**——用无细胞体系研究囊泡运输（Chapter 6/8 会展开）；
- p56 **cell-free LC3 lipidation assay**（Ge L et al., 2013, *eLife*）：在体外用 T7-LC3 与膜、ATG 蛋白重组，检测 LC3-I → LC3-II 的脂化（横轴 0/30/60/90 min 的孵育时间）——这是"自噬核心反应可在试管里重建"的直接证据（Chapter 8 会讲 LC3 脂化）。

### 2. 离心分离的两条路线

| 方式 | 原理（课件 p51 原文之意） | 分离依据 |
| :--- | :--- | :--- |
| **速度沉降（velocity sedimentation）** | 亚细胞组分按**大小与形状**以不同速度沉降；用**5–20% 蔗糖梯度** | 沉降系数（size/shape） |
| **平衡沉降（equilibrium sedimentation）** | 组分在梯度中上浮或下沉，直到所在位置的**密度与自身浮力密度相等** | 浮力密度（buoyant density），与大小形状无关 |

**怎么选：** 要按"大小"分开（如不同膜泡）用速度沉降；要按"密度"分开（如把膜与蛋白复合体分开）用平衡沉降（常配蔗糖或 Percoll 梯度）。

**课件证据（p52）：** 纯化的大鼠肝细胞器电镜图——**细胞核（nuclei）、粗面内质网微粒体（rER-microsome）、过氧化物酶体（peroxisome）**，说明离心可以得到形态完整的细胞器。

**免疫纯化（p53）：** "Immuno-purification of clathrin-coated vesicles"——用抗体偶联磁珠/树脂，从混合物中"钓"出**网格蛋白包被小泡（clathrin-coated vesicles）**。这是"密度分不开就用亲和力分"的补充手段。

**为什么重要：** 组分分离是"从形态学到生物化学"的桥：只有拿到纯的细胞器，才能测它的酶活、脂组成、蛋白组。

## 七、蛋白质科学：纯化、分离、检测、鉴定（Page 57–68）

### 1. 柱层析纯化（Page 58–62）

| 类型 | 分离依据 | 课件示例 |
| :--- | :--- | :--- |
| **凝胶过滤（gel-filtration）** | 分子**大小**：大分子进不了珠孔、先流出；小分子进孔、后流出 | p59 |
| **离子交换（ion-exchange）** | **电荷**：与树脂相反电荷的蛋白结合，用盐梯度洗脱 | p60 |
| **亲和（affinity）** | **特异性结合**：如 GST 与谷胱甘肽、His 与镍、抗体与抗原 | p61 |

**p62 的三条泳道是本章最好的"纯化逻辑"示意：** 1 = 总细胞裂解液（total cell extract）；2 = 亲和纯化后（affinity purified）；3 = 再经凝胶过滤（gel-filtration purified）。条带从"满屏"到"单一条带"，就是纯化步骤的直观证据。

### 2. 蛋白质分离：SDS-PAGE、等电聚焦与 2D 胶（Page 63–65）

- **SDS-PAGE**（p63）：SDS 使蛋白变性并带上均匀负电荷，电泳迁移率只取决于**分子量**——因此可读"表观分子量"。
- **等电聚焦（isoelectric focusing, IEF）**（p64）：在 pH 梯度中电泳，蛋白停在**净电荷为零**的 pH（等电点 pI）处——按**电荷**分离。
- **二维电泳（2D gel）**（p65）：**第一维按电荷（IEF），第二维按大小（SDS-PAGE）**。课件页面把顺序写成 "1st D: protein separation (based on size) / 2nd D: separation based on charge"，与常见教材顺序相反；**以课件顺序记忆即可，关键点是两维分别对应"大小"与"电荷"两个独立物理量**。

**为什么用二维：** 一维只能分辨一个参数；细胞里有上万种蛋白，只有把两个正交参数叠加才能把多数蛋白分开。

### 3. 检测与鉴定：Western blot 与质谱（Page 66–68）

- **免疫印迹（immunoblotting，即 Western blot）**（p66）：SDS-PAGE 分离 → 转膜 → 抗体杂交 → 显色/发光。它回答"**某蛋白是否存在、量多少、分子量是否变化**"。
- **质谱（mass spectrometry）**（p67–68，课件标注邓海腾教授）：把蛋白/肽段离子化，按**质荷比（m/z）**分离并测定，再用数据库比对鉴定蛋白、检测修饰。它回答"**这是什么蛋白、有哪些修饰**"。

**互补关系：** Western blot 是"用已知抗体找已知蛋白"（假设驱动）；质谱是"不预设、把样品里的蛋白都列出来"（发现驱动）。

## 八、蛋白质-蛋白质相互作用：一个问题、十种答案（Page 69–76）

### 1. 课件给出的方法清单（p70）

| 方法 | 回答的核心问题 |
| :--- | :--- |
| GST 融合蛋白（GST pull-down） | 两个蛋白**能否直接结合**（体外） |
| 免疫共沉淀（co-immunoprecipitation, co-IP） | 在**细胞裂解液/细胞内**是否存在于同一复合物 |
| 化学交联（chemical cross-linking） | 两个蛋白在空间上**是否足够近**（可形成共价键） |
| 酵母/细菌双杂交（two-hybrid） | 在**活细胞核内**能否重建转录因子活性 → 是否互作 |
| 噬菌体展示（phage display） | 从文库中**筛选**能结合靶标的肽/抗体 |
| 遗传学 suppressor 策略 | 通过**突变抑制**推断物理互作 |
| FRET 显微 | 活细胞中两蛋白**距离 < ~10 nm** |
| 质谱 | 复合物的**组成清单** |
| 原子力显微镜（AFM） | 配体-受体**结合力**（单分子力学） |
| 表面等离子共振（SPR, Biacore） | **实时动力学**：结合速率、解离速率、亲和力 |
| 生物信息学预测 | 从序列/结构**推测**可能的互作 |

### 2. 四个重点方法的机制

**（1）GST pull-down（p71）**

- **是什么：** 把"诱饵"蛋白与**谷胱甘肽 S-转移酶（GST）**融合，固定在谷胱甘肽琼脂糖珠上；加入细胞裂解液，能结合的蛋白被"拉下来"。
- **怎么工作：** GST 与谷胱甘肽的强亲和是"固定"手段；融合蛋白保持诱饵的天然构象是"捕获"手段；洗脱后用 SDS-PAGE/质谱鉴定"猎物"。
- **边界：** 体外结合不等于细胞内结合；裂解液可能把本来分开的蛋白混在一起。

**（2）FRET（p72）**

- **是什么：** 荧光共振能量转移（fluorescence resonance energy transfer）——两个荧光基团（供体、受体）距离足够近（约 1–10 nm）且光谱重叠时，供体激发能转移给受体。
- **怎么工作：** 把供体与受体分别融合到两个蛋白上；若两蛋白靠近，受体发出敏化发射（或供体荧光被淬灭）；用受体/供体荧光比值读出"距离变化"。
- **为什么重要：** 它是**活细胞、实时**的"分子尺"，能区分"同一复合物"与"只是同一区域"。

**（3）酵母双杂交（p73）**

- **是什么：** 把转录因子拆成 **DNA 结合域（BD）** 与 **激活域（AD）** 两部分，分别融合到两个待测蛋白上。
- **怎么工作：** 若两蛋白互作，BD 与 AD 在空间上靠近，重建有功能的转录因子，启动**报告基因**（如 HIS3、lacZ）表达——用"能否在选择性培养基上生长"读出互作。
- **边界：** 互作发生在**核内**，膜蛋白与需要翻译后修饰的蛋白常不适用；融合也可能造成假阳性/假阴性。

**（4）SPR / Biacore（p75–76）**

- **是什么：** 表面等离子共振（surface plasmon resonance）——配体固定在芯片表面，分析物流过；结合改变表面折射率，实时记录"响应值（RU）"曲线。
- **怎么工作：** 从传感图读出 **ka（结合速率常数）**、**kd（解离速率常数）**、**KD（解离平衡常数）**，无需标记。
- **为什么重要：** 它给出"结合强弱"之外还给出"结合快慢"——同一 KD 可以是"快结合快解离"或"慢结合慢解离"，生理意义完全不同。

**（5）噬菌体展示（p74）**

- **是什么：** 把肽/抗体片段展示在噬菌体表面，用"靶标包被 + 洗脱"的**亲和筛选（biopanning）**富集结合克隆，再测序。
- **为什么重要：** 它是"从海量序列中找结合者"的方法，也是抗体工程的基础。

## 九、分子生物学与遗传学方法：改基因、看表型（Page 77–91）

### 1. 定点突变（Page 78）

**是什么：** 在克隆的基因上改变特定碱基，使蛋白的某个氨基酸被替换/删除。

**怎么工作：** 设计含突变碱基的引物，PCR 扩增整个质粒 → 用 DpnI 消化模板 → 转化，得到突变体。

**为什么重要：** 这是"结构-功能关系"的因果检验：如果突变某个位点后功能丧失，该位点就是必需的。它把"相关性"变成"必要性"。

### 2. 把不能过膜的物质送进细胞（Page 79）

课件并列四种导入方式：**显微注射（microinjection）、电穿孔（electroporation）、脂质体介导（lipid-mediated）、金颗粒轰击（gold particle-mediated）**。

| 方式 | 特点 |
| :--- | :--- |
| 显微注射 | 单细胞、精确、通量低（常用于受精卵/卵母细胞） |
| 电穿孔 | 高压脉冲瞬时打孔，通量大，细胞损伤较大 |
| 脂质体介导 | 脂质体包裹核酸与膜融合，温和、常用 |
| 金颗粒轰击 | 基因枪，把 DNA 包被在金颗粒上高速打入细胞/组织（植物常用） |

### 3. 异位表达（ectopic misexpression）：用"放错地方"证明功能（Page 80–81）

- **Wnt 异位表达导致第二个体轴（second body axis）**（p80）：在胚胎中把 Wnt 放到不该出现的位置，结果长出额外的体轴——证明 **Wnt 是体轴决定信号**。
- **Dapper2 过表达导致斑马鱼眼睛融合（eye fusion）**（p81，Zhang et al., 2004, *Science*）：过表达改变发育表型，说明该基因参与眼部发育。

**为什么这类实验有说服力：** 它不是"敲掉看少了什么"，而是"加到别处看多出什么"——**获得功能（gain-of-function）**往往比**失去功能（loss-of-function）**更能定位信号的作用范围。

### 4. RNA 干扰：敲低（knockdown）（Page 82、94）

**是什么：** 双链 RNA 被 Dicer 切成 **siRNA**，装载进 **RISC**，引导其切割/抑制**互补的 mRNA**，从而降低蛋白水平。

**课件的两种形式：** **siRNA**（直接导入合成的双链小 RNA，瞬时）与 **shRNA**（用载体在细胞内转录出短发夹 RNA，稳定、可诱导）。

**边界：** 敲低是"减少"而不是"消除"，且可能有**脱靶（off-target）**效应；因此需要多条 siRNA 与 rescue 实验互证。

### 5. 基因替换、敲除与敲入（Page 83–87）

**（1）同源重组制备敲除小鼠（gene replacement → knockout mice，p84–86）**

- **怎么工作：** 构建**打靶载体**（targeting vector）：两端是与目的基因同源的臂，中间是**正选择标记**（如 neo）与**负选择标记**（如 HSV-tk）；ES 细胞中发生**同源重组**后，用药物筛选出正确整合的克隆；注入囊胚 → 嵌合体 → 生殖系传递 → 纯合敲除小鼠。
- **为什么需要负选择：** 随机整合的克隆会带上 tk，被 gangcyclovir 杀死；只有同源重组的克隆丢掉 tk 而存活。

**（2）Cre-LoxP 组织特异性敲除（p87）**

- **是什么：** **Cre 重组酶**来自 **P1 噬菌体**，识别 **loxP** 位点并在其间切割/重组。
- **怎么工作：** 在目的基因两侧放两个 loxP（"floxed" 等位基因）；与**组织特异启动子驱动的 Cre** 小鼠杂交，Cre 只在特定组织表达，该组织的两个 loxP 之间被切除 → **只在特定组织敲除**。
- **为什么重要：** 全身敲除常因胚胎致死或代偿而看不到表型；时空可控的敲除解决了这两个问题。

**（3）CRISPR/Cas9 基因编辑（p88）**

- **是什么：** **Emmanuelle Charpentier 与 Jennifer A. Doudna** 开发的基因编辑技术（2020 年诺贝尔化学奖）。
- **怎么工作：** **sgRNA** 通过碱基互补引导 **Cas9** 到目标 DNA，Cas9 的两个核酸酶结构域切断双链，产生双链断裂（DSB）；细胞通过 **NHEJ**（易错，产生 indel → 敲除）或 **HDR**（有模板时精确替换 → 敲入）修复。
- **为什么重要：** 相比同源重组打靶，它把"编辑"从"百万分之一的重组事件"变成"一次切割 + 修复"，效率与可及性都大幅提高；且可同时打多个位点（multiplex）。

**（4）两个应用例子（p89–90）：** **FGF5 敲除**（FGF5 是毛发生长抑制因子，敲除后毛长增加——这是"基因编辑改变性状"的直观例子）；**转基因植物**（p90）。

### 6. RNA-seq：一次测上万个基因（Page 91）

**是什么：** 把 mRNA 逆转录成 cDNA 并测序，用 reads 数反映各转录本的丰度。

**怎么工作：** 提取 RNA → 富集 mRNA/去 rRNA → 片段化 → 逆转录 → 建库 → 测序 → 比对 → 计数 → **聚类（clustering）**分析（课件 p91 用 11 个样本展示不同处理下的表达聚类）。

**为什么重要：** 它把"表型"与"全转录组"连接起来，是寻找差异表达基因与推断调控网络的标准起点。**注意它是"相关"而非"因果"**，需要 qPCR/蛋白水平/功能实验验证。

## 复习自测提示

**1. 共聚焦为什么比常规荧光"清楚"？**
常规荧光收集整个视野内所有焦平面的荧光，离焦光形成背景模糊；共聚焦在检测光路加**针孔**，只允许焦平面（及其附近）的光通过，逐点扫描成像，因此 z 向分辨率显著提高，可做光学切片与三维重建。

**2. 速度沉降与平衡沉降的区别是什么？**
速度沉降按**大小与形状**（沉降系数）分离，常用 5–20% 蔗糖梯度，离心时间较短；平衡沉降按**浮力密度**分离，组分在梯度中移动到密度与自身相等的位置，与大小形状无关，需要较长时间达到平衡。

**3. pulse-chase 的四步是什么？为什么能追踪分泌途径？**
① 短时间加放射性前体（pulse）；② 洗掉并换成非放射性前体（chase）；③ 定时取样；④ 定位/定性放射性。这样只有 pulse 期间合成的一批分子带标记，此后它们在细胞内的移动可被逐步观察到——Palade 用此法确立了"ER → 高尔基体 → 分泌颗粒 → 胞外"的顺序。

**4. GFP 为什么适合做活细胞标签？**
发色团由三个氨基酸残基的侧链**翻译后**形成，不需要外加底物或辅因子；只要融合蛋白正确折叠即可发光，因此可在活细胞中表达并实时追踪蛋白定位与运动。

**5. GST pull-down、FRET、酵母双杂交、SPR 各回答什么问题？**
pull-down：体外能否直接结合（并"钓出"未知伙伴）；FRET：活细胞中两蛋白是否在 ~10 nm 内；双杂交：活细胞核内能否重建转录因子活性（互作）；SPR：实时结合/解离动力学与亲和力（无需标记）。

**6. 为什么做条件性（Cre-LoxP）敲除？**
全身敲除可能胚胎致死或引起代偿；Cre-LoxP 把敲除限定在特定组织或特定时间（如诱导型 Cre），可绕过致死并区分细胞自主与非自主效应。Cre 来自 P1 噬菌体，识别 loxP 位点。

**7. RNAi 与 CRISPR 的区别？**
RNAi 作用于 **mRNA**，是**敲低**（部分降低、可逆、瞬时或可诱导），不改变基因组；CRISPR/Cas9 作用于 **DNA**，造成双链断裂后经 NHEJ 产生 indel（敲除）或经 HDR 精确替换（敲入），改变基因组，效果稳定可遗传。

**8. 为什么 Western blot 与质谱互补？**
Western blot 用已知抗体检测特定蛋白（假设驱动、定量、看分子量与修饰变化）；质谱不依赖抗体、可一次性鉴定样品中的大量蛋白与修饰（发现驱动）。前者验证，后者发现。
