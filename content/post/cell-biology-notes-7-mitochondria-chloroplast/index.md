# **细胞生物学学习笔记 7 | 线粒体与叶绿体：能量转换与内共生**

---

> **对应课件：** Mitochondria & Chloroplast-2026  
> **本章核心内容：** 线粒体与叶绿体的结构、动力学、内共生假说、线粒体能量代谢（TCA循环、电子传递链、化学渗透、ATP合酶）、代谢调控、线粒体基因与炎症、细胞凋亡与信号、光合作用（光反应与暗反应）  
> **复习目标：** 掌握线粒体与叶绿体在结构上的异同（膜层数）；理解内共生学说的主要证据；掌握电子传递链和化学渗透学说的核心原理；理解 ATP 合酶的工作机制；了解线粒体 mtDNA 的遗传特征及 cGAS-STING 炎症通路；对比线粒体与叶绿体的能量转换机制。

## 一、线粒体与叶绿体的结构与动力学

### 1. 结构的异同（核心考点）
| 特征 | 细菌 (Bacterium) | 线粒体 (Mitochondrion) | 叶绿体 (Chloroplast) |
| :--- | :--- | :--- | :--- |
| **膜的层数** | 2层 | 2层 | **3层**（外膜、内膜、类囊体膜） |
| **产能部位** | 内膜 | **嵴 (Cristae)** | **类囊体 (Thylakoid)** |
| **能量转换** | 代谢物分解 | 产能（代谢物分解）、产生 CO₂ | 产能（光能驱动）、合成糖、释放 O₂ |

**线粒体结构**：
- 外膜 (Outer membrane)、膜间隙 (Intermembrane space)、内膜 (Inner membrane)、基质 (Matrix)。
- **嵴 (Cristae)**：内膜内卷形成，目的是**增加工作面积**，是电子传递和 ATP 合成的场所。

### 2. 线粒体动力学 (Dynamics) 与分布
- 线粒体形态丰富，根据细胞能量需求不断进行**融合 (Fusion)** 和 **分裂 (Fission)**。
- **调控机制**：由 **GTP**（而非 ATP）调控。
- **融合与分裂的意义**：
  - *融合*：给不含 mtDNA 的线粒体补充 mtDNA 及其产物（混匀效应）。
  - *分裂*：辅助线粒体质量控制（如自噬）、运输、凋亡、细胞分裂时的线粒体分配。
- 毒素影响：CCCP（线粒体毒素）诱导分裂。
- 分布：通常散布于细胞质，但在肌肉、精子等特殊细胞中有特定的空间分布 pattern。

## 二、内共生假说 (Endosymbiosis)

线粒体和叶绿体都起源于细菌祖先。
**为什么说线粒体先于叶绿体完成内共生？**
1. 大多数真核生物（包括植物、动物、真菌）都有线粒体，而只有植物和藻类有叶绿体。
2. 线粒体来源于 α-变形菌，叶绿体来源于蓝细菌。

### 内共生学说的主要证据
1.  **基因转移**：>99% 的线粒体蛋白通过基因转移，由**核基因编码**。线粒体基因组仅编码 13 个蛋白（高度疏水、多重跨膜，如 ETC 复合物亚基）。
2.  **原核特征保留**：
    *   部分核编码的线粒体蛋白（如 RNA 聚合酶、核糖体）携带原核特征。
    *   线粒体基因编码的蛋白携带 **N-formyl-methionine**（N-甲酰甲硫氨酸）原核特征。
3.  **心磷脂 (Cardiolipin)**：线粒体内膜与细菌内膜共有，参与调节蛋白复合物活性及内膜曲率。
4.  **抗生素敏感性**：线粒体拥有原核特征，部分抗生素（如喹诺酮、氨基糖苷、β-内酰胺类、氯霉素）具有线粒体毒性。

## 三、线粒体能量代谢（核心重点）

### 1. 氧化磷酸化 (Oxidative Phosphorylation)
**定义**：代谢物氧化释放的能量，通过电子传递链驱动质子泵送，建立跨膜质子梯度，进而驱动 ATP 合成的过程。
*   **化学渗透学说 (Chemiosmotic theory)**：由 Peter Mitchell 提出（1978 诺贝尔化学奖）。

### 2. 电子传递链 (ETC) 与质子泵
*   **电子传递路径**：NADH → 复合物 I (Complex I) → CoQ → 复合物 III → Cyt c → 复合物 IV → O₂。
*   或 Succinate → 复合物 II (Complex II) → CoQ...
*   **质子泵送**：
    *   **复合物 I, III, IV** 具有质子泵功能，将 H⁺ 从基质 (Matrix) 泵入膜间隙。
    *   **复合物 II 不能泵出 H⁺**。
*   **能量计算**：
    *   氧化 1 分子 NADH 驱动 10 个 H⁺ 转运 (I:4 + III:4 + IV:2) → 生成 **2.5 ATP**。
    *   氧化 1 分子 FADH₂ 驱动 6 个 H⁺ 转运 (III:4 + IV:2) → 生成 **1.5 ATP**。
*   **胞质 NADH 的穿梭机制**：
    *   **苹果酸-天冬氨酸穿梭**：将胞质 NADH 完整转入线粒体基质，氧化可泵 10 个 H⁺。
    *   **甘油-3-磷酸穿梭**：电子跳过复合物 I，直接给 CoQ，氧化只泵 6 个 H⁺。

### 3. ATP 合酶 (ATP Synthase)
*   **结构**：F₀（转子 ring，嵌入膜内，含 c 亚基）和 F₁（催化头部，含 α、β、γ 亚基）。
*   **工作机制**：**旋转催化**。
    *   H⁺ 顺浓度梯度穿过 F₀，推动 C-ring 旋转。
    *   转子 stalk (γ 亚基) 随之旋转，搅动 F₁ 头部，引起构象改变。
    *   构象变化驱动 ADP + Pi 合成 ATP（Open → Loose → Tight 状态循环）。
*   **双向性**：既可在 H⁺ 梯度驱动下合成 ATP，也可水解 ATP 制造 H⁺ 梯度（如溶酶体 V 型质子泵）。
*   **消耗比**：合成 1 个 ATP 理论消耗约 3.7 个 H⁺，实验实测约 4 个（人类转子有 8 个亚基）。
*   **晶体学证明**：Paul Boyer 和 John Walker 通过实验（附着荧光肌动蛋白纤维）直接观察到旋转现象，获 1997 诺贝尔化学奖。

### 4. 结构优化与解偶联
*   **嵴的作用**：ATP 合酶二聚体弯曲膜形成嵴，将质子泵集中，提高 ATP 合成效率。
*   **解偶联 (Uncoupling)**：
    *   **生理性**：棕色脂肪细胞 (BAT) 中的 **UCP1**（解偶联蛋白 1），受冷刺激和去甲肾上腺素调控，H⁺ 通过 UCP1 漏回基质，不经过 ATP 合酶，能量直接以**热能**释放。
    *   **化学性**：**DNP (2,4-二硝基苯酚)**，曾用于减肥，但会导致体温过高甚至死亡。

## 四、代谢调控与 TCA 循环

### 1. 三羧酸循环 (TCA / Krebs cycle)
*   **功能**：不仅氧化乙酰辅酶 A 产生 NADH 和 FADH₂，还是**代谢中转站**。
*   **调控**：受底物（NAD⁺, ADP）激活，受产物（NADH, ATP）抑制。
*   **Ca²⁺ 兴奋-代谢偶联**：神经传递、肌肉收缩时释放 Ca²⁺，Ca²⁺ 进入线粒体，激活 TCA 循环，同步增加 ATP 产量以满足能量需求。
*   **转脂原理**：碳水（葡萄糖）代谢产生柠檬酸，出线粒体后由 ACLY 酶转为乙酰辅酶 A；瘦肉（氨基酸）代谢也会产生乙酰辅酶 A，两者均可作为脂肪酸合成的前体。

## 五、线粒体基因组与炎症

### 1. 线粒体基因组 (mtDNA)
*   人类 mtDNA 编码 **13 个 OXPHOS 亚基** + 22 个 tRNA + 2 个 rRNA。
*   **半自主性**：约 1200 个核基因编码蛋白服务于线粒体。
*   **母系遗传**：每个细胞有 500-100,000 个 mtDNA 拷贝。存在**异质性 (Heteroplasmy)**，突变比例不同会导致不同程度的后代症状（阈值效应）。
*   **三亲婴儿**：通过线粒体置换技术（将母亲卵子的细胞核转移到健康供体卵子中），避免母系遗传的线粒体疾病。

### 2. 线粒体与炎症 (2024 Lasker 奖)
*   **cGAS-STING 通路**：细胞质中通常没有 DNA。当线粒体损伤、mtDNA 突变或感染时，mtDNA 释放到细胞质。**mtDNA 是强烈的免疫激动剂**，被 **cGAS** 识别，生成 cGAMP，激活 STING，最终诱导 I 型干扰素 (IFN) 产生炎症反应。（James Chen 杰出贡献）

## 六、线粒体信号与细胞凋亡

### 1. 细胞凋亡 (Apoptosis) 途径
*   线粒体不仅是细胞工厂，还决定细胞命运。
*   **内在通路**：细胞应激导致 Bcl-2 家族蛋白（Bax/Bak）激活 → 线粒体外膜透化 (MOMP) → **细胞色素 c (Cytochrome c)** 释放入胞质 → 与 Apaf-1、Caspase-9 结合形成**凋亡体 (Apoptosome)** → 激活 Caspase-3/7 执行凋亡。（王晓东院士的经典发现，1996）

### 2. 线粒体信号网络
释放 Cyt c（死亡）、H₂O₂（氧化还原）、AMPK（代谢）、mtDNA（免疫）、TCA 代谢物（表观遗传修饰）等。

## 七、叶绿体与光合作用

### 1. 结构
外膜、内膜、类囊体膜（**3层膜**）。类囊体膜上发生光反应，基质 (Stroma) 发生暗反应（固碳）。

### 2. 光反应 (Light Reactions)
*   **光系统**：光捕获复合物 + 反应中心。有 PSII（吸收 680 nm）和 PSI（吸收 700 nm）。
*   **电子传递**：光系统 II 光解水（产生 O₂ 和 H⁺）启动电子传递 → 质体醌 → 细胞色素 b6f 复合体（泵 H⁺）→ 质体蓝素 → 光系统 I（二次充能）→ 铁氧还蛋白 → **产生 NADPH**。
*   **相似性**：光系统 II 和细胞色素 b6f 泵送 H⁺，建立跨膜质子梯度，驱动 ATP 合酶合成 ATP（类似线粒体）。

### 3. 暗反应 (Dark Reactions / 卡尔文循环)
*   虽然叫暗反应，但**不需要光**，而非只在黑暗中发生。
*   **三个阶段**：
    1.  **固碳 (Fixation)**：Rubisco 催化 CO₂ 与二磷酸核酮糖 (RuBP) 结合。
    2.  **还原 (Reduction)**：消耗光反应产生的 ATP 和 NADPH，将 3-磷酸甘油酸还原为甘油醛-3-磷酸 (G3P)。
    3.  **RuBP 再生 (Regeneration)**。
*   总反应：3 CO₂ + 6 NADPH + 9 ATP → G3P 等。

### 4. 原核光合作用与光遗传学
*   **无氧光合作用**：紫菌、绿菌。
*   **视紫红质光合作用**：古菌 (Archaea)。
*   **光遗传学 (Optogenetics)**：将光敏离子通道（如 Channelrhodopsin-2, NpHR）转入神经元，用光精确控制神经元电活动。（Karl Deisseroth 等发展）

## 八、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **结构对比** | 线粒体 2 层膜（内膜内折形成嵴）；叶绿体 3 层膜（类囊体膜）。 |
| **动力学** | 由 **GTP** 调控融合与分裂。融合互补 mtDNA，分裂辅助自噬分配。 |
| **内共生证据** | 基因转移（依赖核基因）、原核特征（N-甲酰甲硫氨酸）、心磷脂、抗生素敏感。 |
| **能量代谢** | ETC 将 H⁺ 泵出内膜；ATP 合酶利用 H⁺ 梯度旋转催化合成 ATP。 |
| **TCA 循环** | 受 Ca²⁺ 促进（兴奋-代谢偶联）；作为代谢中转站。 |
| **mtDNA** | 母系遗传，半自主性（编码 13 个蛋白），多拷贝异质性。 |
| **免疫与凋亡** | 释放胞质激活 cGAS-STING 炎症通路；释放细胞色素 c 激活 Caspase 引发凋亡。 |
| **光合作用** | 光反应（PSII 与 PSI 电子传递，产 O₂、ATP、NADPH）；暗反应（卡尔文循环固碳）。 |
