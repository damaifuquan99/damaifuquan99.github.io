# **物理化学学习笔记 3 | 第三章 溶液热力学：从偏摩尔量到依数性**

---

> **对应课件：** 第 5 讲（第三章 上，§3.0～§3.5）、第 6 讲（第三章 下，§3.5～§3.8）
> **本章核心内容：** 多组分系统的加和性问题、偏摩尔量与集合公式、化学势的定义与判据、化学势与 T/p 的关系、理想气体与实际气体的化学势、组成表示与换算、拉乌尔定律与理想液体混合物、亨利定律与理想稀薄溶液、实际溶液与活度、依数性（蒸气压降低、凝固点降低、沸点升高、渗透压）
> **复习目标：** 理解偏摩尔量与化学势的区别与联系；会用化学势判断传质方向与平衡；能正确选择标准态并写出各类系统的化学势表达式；熟练推导理想混合物的混合性质；掌握四个依数性公式及其适用条件

## 一、本章绪论：多组分系统为什么需要新工具

### 1. 几个基本概念

- **多组分系统**：由两种或两种以上组分（物质）组成的系统。
- **溶液**：由两种或两种以上物质以**分子分散程度**相互混合而成的**均相系统**。通常指液态或固态溶液。
- **均相系统**：以分子分散程度混合且性质均匀的系统。

溶液分溶质与溶剂，热力学上对两者**按不同方法处理**：稀溶液中溶剂服从 Raoult 定律，溶质服从 Henry 定律。这正是本章的主线。

### 2. 核心矛盾：容量性质的加和性失效

对**单组分**（定组成）系统，组成是常数，任意广延性质都有加和性：

```
1 mol 水：V = Vm
2 mol 水：V = 2Vm
n mol 水：V = nVm
```

对**多组分**系统，这个结论**不成立**。以 50 wt% 乙醇水溶液（298 K，pθ）为例：

```
V(水+乙醇) ≠ n水 Vm,水* + n乙醇 Vm,乙醇*
```

混合后体积**收缩**（教材 P64 表 3-1）。结论：

> **一个多组分系统的广延性质，一般不等于各组分在纯态时该性质之和。**

原因：不同分子间的相互作用与同种分子间不同，混合后每个分子所处的环境变了，其"贡献"也就变了。

### 3. 解决思路（本章逻辑主线）

```
容量性质加和性失效
      ↓
引入偏摩尔量（描述"这一组分在这个组成下"的贡献）
      ↓
定义化学势 μB = GB（偏摩尔 Gibbs 函数）
      ↓
化学势判据 → 判断传质方向与平衡
      ↓
绝对值不可知 → 人为规定标准态 → 各类系统的 μB 表达式
      ↓
应用：混合性质、依数性
```

## 二、偏摩尔量

### 1. 定义

对多组分均相系统，任一容量性质 X（V、U、H、S、A、G）可写成：

```
X = X(T, p, n1, n2, …, nk)
```

其全微分为：

```
dX = (∂X/∂T)p,n dT + (∂X/∂p)T,n dp + ΣB (∂X/∂nB)T,p,nC dnB
```

**偏摩尔量的定义：**

```
XB ≡ (∂X/∂nB)T, p, nC(C≠B)
```

即：在**等温、等压**下，保持除 B 以外其余组分的物质的量不变，系统的容量性质 X 随组分 B 的物质的量的变化率。

### 2. 物理意义（两种等价说法）

1. 上述偏导数——**变化率**；
2. 在等温等压、其余组分不变的前提下，往**一个巨大的均相系统**中单独加入 1 mol 物质 B 时，系统容量性质 X 的变化量。

> "巨大"是关键：只有这样加入 1 mol B 才不会明显改变系统的组成（浓度），XB 才是该组成下的确定值。

### 3. 四点说明（判断、选择高频）

1. **只有均相系统的容量性质才有偏摩尔量**，强度性质没有偏摩尔量；
2. 只有某组分在**多相系统中某一相态**里的偏摩尔量，不存在"整个多相系统"的偏摩尔量；
3. 偏摩尔量是**强度性质**，与 T、p 和**组成**有关，而与系统内物质的总量无关；
4. 对**纯物质 B**：XB = Xm,B*（偏摩尔量退化为摩尔量）。下标必须同时是 T、p、nC(C≠B)。

### 4. 具体形式

| 偏摩尔量 | 定义式 |
| :--- | :--- |
| 偏摩尔体积 VB | (∂V/∂nB)T,p,nC |
| 偏摩尔内能 UB | (∂U/∂nB)T,p,nC |
| 偏摩尔焓 HB | (∂H/∂nB)T,p,nC |
| 偏摩尔熵 SB | (∂S/∂nB)T,p,nC |
| 偏摩尔 Helmholtz 函数 AB | (∂A/∂nB)T,p,nC |
| 偏摩尔 Gibbs 函数 GB | (∂G/∂nB)T,p,nC |

### 5. 集合公式（加和定理）

**结论：** 多组分均相系统的广延性质等于各组分的物质的量与其偏摩尔量乘积之和。

```
X = ΣB nB XB
```

**推导（等温等压，按比例配制）：** 在等温等压下，令各组分按同一比例由 0 增至 nB（即 nB = λ nB,0，λ 从 0 到 1），此时组成不变，所有 XB 为常数，且 dX = Σ XB dnB，故

```
X = ∫(0→n) ΣB XB dnB = ΣB XB ∫dnB = ΣB nB XB
```

以二元溶液体积为例：

```
V = nA VA + nB VB
```

同理可写出 U、H、S、A、G 的集合公式。

> **由此可推出 Gibbs–Duhem 关系：** 对集合公式取全微分得 dX = Σ XB dnB + Σ nB dXB；与 dX = Σ XB dnB（等温等压）比较，得
> ```
> ΣB nB dXB = 0   （等温等压）
> ```
> 即各组分偏摩尔量的变化不能彼此独立，一个增大另一个必然减小。

## 三、化学势

### 1. 定义

**化学势就是偏摩尔 Gibbs 函数：**

```
μB ≡ GB = (∂G/∂nB)T, p, nC(C≠B)
```

### 2. 三点注意

1. 化学势**等于**偏摩尔 Gibbs 函数；
2. 在等温等压下，**其他**广延性质对 nB 的偏导（VB、HB、SB…）**不是**化学势；
3. 化学势有明确的物理化学意义（见下），这也是它比其它偏摩尔量更受重视的原因。

### 3. 化学势的物理意义

- 在等温等压下，向系统中加入 dnB 的物质 B 所引起的系统 Gibbs 函数的改变为 μB dnB；
- 换个角度：μB 是物质 B 的**逃逸趋势**（化学"逸出本领"）的度量，μB 越高，该组分越"想"离开所在相或参与反应。

### 4. 开放系统的热力学基本关系式

对组成可变的系统，G = G(T, p, n1, n2, …)，全微分为：

```
dG = −SdT + Vdp + ΣB μB dnB
```

其中由对应系数关系可得 (∂G/∂T)p,n = −S，(∂G/∂p)T,n = V。这是**开放系统（组分可变）的 Gibbs 函数基本关系式**。

相应地，其它三个基本式也推广为：

```
dU = TdS − pdV + Σ μB dnB
dH = TdS + Vdp + Σ μB dnB
dA = −SdT − pdV + Σ μB dnB
```

### 5. 化学势判据

在**等温、等压、W' = 0** 的多组分封闭系统中，组成变化时：

```
dG = ΣB μB dnB
```

由 Gibbs 函数减少原理：

```
ΣB μB dnB < 0   自发过程
ΣB μB dnB = 0   可逆过程，平衡状态
ΣB μB dnB > 0   不可能进行
```

### 6. 应用一：相变过程

设系统由 α、β 两相组成，有 dnB 的物质 B 由 α 相转移到 β 相（则 dnB(α) = −dnB，dnB(β) = +dnB）：

```
dG = μB(α) dnB(α) + μB(β) dnB(β) = [μB(β) − μB(α)] dnB
```

| 条件 | dG | 结论 |
| :--- | :--- | :--- |
| μB(α) > μB(β) | < 0 | 由 α 相流向 β 相，**自发** |
| μB(α) = μB(β) | = 0 | **两相平衡** |
| μB(α) < μB(β) | > 0 | 上述方向不可能发生 |

**两条结论：**

1. 在等 T、p、W' = 0 下，物质总是自动地从**化学势高**的相流向**化学势低**的相；
2. **多组分多相系统的平衡条件**：每种组分在它所存在的各相中化学势相等，即
```
μB(α) = μB(β) = μB(γ) = …
```

### 7. 应用二：化学反应

在等 T、p、W' = 0 下发生微量反应 dξ 时，dnB = νB dξ，故

```
dG = ΣB μB dnB = (ΣB νB μB) dξ
```

判据为：

```
ΣB νB μB < 0   自发（正向进行）
ΣB νB μB = 0   可逆，化学平衡
ΣB νB μB > 0   不可能（正向）
```

**结论：** 在等 T、p、W' = 0 下，化学反应向着**化学势降低**的方向进行，化学平衡时（ΣνB μB = 0）。

### 8. 化学势判据的三点总结

1. 在等 T、p、W' = 0 下，物质总是由高化学势流向低化学势，平衡时化学势相等；
2. 在 W' = 0 下，化学势是**所有传质过程的统一判据**（化学势判据）；
3. 化学势相等是**平衡的条件**，是处理平衡问题的依据。

## 四、化学势与温度、压力的关系

### 1. 与压力的关系（恒 T、恒组成）

由 μB = (∂G/∂nB)T,p,nC 与 (∂G/∂p)T,n = V，交换微分次序：

```
(∂μB/∂p)T, nC = (∂V/∂nB)T,p,nC = VB
```

**结论：** 一般 p↑，μB↑（因为 VB > 0）。VB 是物质 B 的偏摩尔体积。

### 2. 与温度的关系（恒 p、恒组成）

同理：

```
(∂μB/∂T)p, nC = −SB
```

**结论：** 一般 T↑，μB↓（因为 SB > 0）。SB 是物质 B 的偏摩尔熵。

> 思考：同温度下比较液相与气相的 μB 对 T 的敏感程度——气相 SB 远大于液相 SB，所以**升温时气相化学势下降得更快**。这正是升温使液体挥发趋势增大、沸点存在的热力学根源。

### 3. Gibbs–Helmholtz 型关系

由 G = H − TS 对 nB 求偏导，得 μB = HB − TSB，两边除以 T 再对 T 求偏导：

```
[∂(μB/T)/∂T]p, nC = −HB/T²
```

### 4. 与纯物质公式的对应关系（重要记忆法）

**只要把定组成系统中关于 G 的公式里的容量性质（摩尔量）换成相应的偏摩尔量，就得到 μB 的公式。**

| 纯物质 B | 多组分系统中的组分 B |
| :--- | :--- |
| Gm = Hm − TSm | μB = HB − TSB |
| (∂Gm/∂T)p = −Sm | (∂μB/∂T)p = −SB |
| (∂Gm/∂p)T = Vm | (∂μB/∂p)T = VB |
| [∂(Gm/T)/∂T]p = −Hm/T² | [∂(μB/T)/∂T]p = −HB/T² |

## 五、气体的化学势

化学势绝对值不可知，只能比较相对大小或求变化值——因此必须**人为规定标准态**，用相对值表示 μB。

### 1. 纯理想气体

对纯理想气体 B(T, p)，由 (∂μ*/∂p)T = V* = RT/p，从标准态积分到 p：

```
∫(pθ→p) dμ* = ∫(pθ→p) (RT/p) dp
```

得到：

```
μ*(T, p) = μθ(pg, T) + RT ln(p/pθ)
```

- **标准态：** 温度 T、标准压力 pθ 下的**纯理想气体**（这是假想态，因为理想气体本身是模型）；
- μθ(pg, T) 称为**标准化学势**，**只是温度的函数**；
- μ*(T, p) 是 T、p 的函数。

### 2. 理想气体混合物中各组分

理想气体混合物中，各组分独立行动（无分子间力、分子是几何点），组分 B 的化学势只取决于它的**分压** pB：

```
μB(T, p, xB) = μBθ(pg, T) + RT ln(pB/pθ)
```

由分压定律 pB = p·xB：

```
μB = μBθ(pg, T) + RT ln(p/pθ) + RT ln xB = μB*(T, p) + RT ln xB
```

- μBθ(pg, T)：纯理想气体 B 在温度 T、标准压力 pθ 下的化学势；
- μB*(T, p)：纯理想气体 B 在 T、p 下的化学势；
- **μB 是 T、p、组成的函数**；当 xB = 1 时退化为纯理想气体的表达式。

### 3. 理想气体混合的混合性质（由化学势推出）

等温等压混合：

```
ΔmixG = G(混合后) − G(混合前) = ΣB nB(μB* + RT ln xB) − ΣB nB μB* = RT ΣB nB ln xB
```

由于 0 < xB < 1，ln xB < 0，故：

| 量 | 结果 | 说明 |
| :--- | :--- | :--- |
| ΔmixG | RT Σ nB ln xB < 0 | Gibbs 函数减小，混合自发 |
| ΔmixS | −R Σ nB ln xB > 0 | 熵增加 |
| ΔmixH | 0 | 无热效应（等温、无分子间作用力） |
| ΔmixV | 0 | 无体积效应（理气不可压缩） |

（ΔmixS 由 ΔmixS = −(∂ΔmixG/∂T)p,n 求得。）

### 4. 实际气体：逸度与逸度系数

对实际气体，V ≠ RT/p，所以 μ* = μθ + RT ln(p/pθ) **不适用**；而实际气体状态方程不统一、普适性差。

**Lewis 的解决办法：用逸度 f 代替压力 p。**

```
μB*(T, p) = μBθ(pg, T) + RT ln(f/pθ)
```

- f 称为**逸度**（校正压力），单位与压力相同（Pa）；
- 意义：把各种实际气体的化学势表达式**统一**成与理想气体相同的形式；
- 标准态仍是：T、pθ 下纯理想气体 B 的**假想态**；
- RT ln(f/pθ) 表示实际气体 B(T, p) 与理想气体 B(T, pθ) 的化学势之差。

**逸度系数：**

```
γ = f/p        即   f = γp
```

| 情形 | γ 与 f |
| :--- | :--- |
| 理想气体 | γ = 1，f = p（不需校正） |
| 实际气体 | γ ≠ 1，反映对理想气体的偏离程度 |
| p → 0 | γ → 1，f → p（lim(p→0) f/p = 1） |
| 标准态 | γ = 1，f = pθ = 101325 Pa |

- γ = γ(T, p, 气体本性)：对指定气体 γ = γ(T, p)，**不是物性参数**，而与状态有关；
- 实际气体混合物中组分 B：

```
μB(T, p, xB) = μBθ(pg, T) + RT ln(fB/pθ)
fB = γB pB
lim(p→0) fB/pB = 1
```

其中 fB、γB、pB 分别为 B 在混合气中的逸度、逸度系数、分压，p 为混合气总压。

## 六、液体混合物与溶液的组成表示

组成是溶液的**强度性质**，与 T、p 并列。四种表示方法：

| 名称 | 定义 | 单位 |
| :--- | :--- | :--- |
| 物质的量分数（摩尔分数） | xB = nB/ΣnB | 无量纲 |
| 质量摩尔浓度（溶质 B） | bB = nB/mA（mA 为溶剂质量） | mol·kg⁻¹ |
| 物质的量浓度（体积摩尔浓度） | cB = nB/V | mol·m⁻³（常用 mol·dm⁻³） |
| 质量分数 | wB = mB/ΣmB | 无量纲 |

### 换算关系

因组成是强度性质，与总量无关，换算时可**任选适量的溶液**（如取 100 g）。

记 ρ 为溶液密度，MA、MB 为溶剂和溶质的摩尔质量，则：

```
xB = cB MA / [ρ + cB(MA − MB)]
bB = cB / (ρ − cB MB)
```

**稀溶液（非常有用的近似）：**

```
xB ≈ bB MA / 1000 = cB MA / ρA
```

其中 ρA 为**溶剂**密度，MA 用 g·mol⁻¹。以水溶液为例 ρA ≈ 1000 kg·m⁻³，故 xB ≈ bB/55.5 ≈ cB/55.5。

> **换算注意：** 单位要统一（cB 用 mol·m⁻³ 还是 mol·dm⁻³、MA 用 g/mol 还是 kg/mol），ρ 用 kg·m⁻³，否则差 10³ 倍。

## 七、拉乌尔定律与理想液体混合物

### 1. 饱和蒸气压

- **表述一：** 一定温度下，与液体处于相平衡的蒸气所具有的压力。
- **表述二：** 液体分子蒸发为气态、气态分子又凝结回液体的动态平衡时，气态分子对液体产生的压强。
- 蒸气压是液体的**本质属性**，同一物质不同温度下蒸气压不同（随 T 升高而迅速增大）。
- 区分四个概念：**外压**（环境施加的压力）、**系统的压力**、**饱和蒸气压**（液体自身的性质）、**沸点**（饱和蒸气压等于外压时的温度）。

### 2. 拉乌尔定律（Raoult，1886）

**内容：** 在稀薄溶液上方的平衡气相中，**溶剂的蒸气压**等于该温度下纯溶剂的蒸气压与它在溶液中摩尔分数的乘积。

```
pA = pA* xA
```

其中 pA* 为溶液所处温度、压力下**纯溶剂**的蒸气压，xA 为溶剂的摩尔分数。

**蒸气压降低：**

```
Δp = pA* − pA = pA*(1 − xA) = pA* xB
```

**适用条件与注意：**

1. 适用于含**非电解质**溶质（挥发或不挥发均可）的稀溶液；对任何溶液，当 xA → 1 时表达式**严格正确**；
2. 计算溶剂的物质的量时，摩尔质量应取**气态分子的摩尔质量**（若溶液中有缔合或二聚，其摩尔质量与气态不同）。

### 3. 理想液体混合物（理想溶液）

**定义：** 任一组分在**全部浓度范围**内都遵守拉乌尔定律的液体混合物。

```
pA = pA* xA
pB = pB* xB
p = pA + pB = pA* xA + pB* xB
```

**微观模型：**

```
f(A−A) = f(B−B) = f(A−B)
```

即同种分子之间与异种分子之间的作用力完全相同——这是"全浓度服从 Raoult"的物理原因。

**典型例子**（结构、性质相近的液体）：

| 类型 | 举例 |
| :--- | :--- |
| 同位素化合物 | 水 ～ 重水 |
| 光学异构体 | d-樟脑 ～ l-樟脑 |
| 结构异构体 | 邻、对、间二甲苯 |
| 紧邻同系物 | 苯 ～ 甲苯，甲醇 ～ 乙醇 |

### 4. 分压、气相组成与液相组成的关系

液相用 x 表示组成（Raoult），气相用 y 表示组成（分压定律）：

```
pB = pB* xB        （液相 → 分压）
pB = p yB          （分压 → 气相组成）
```

联立得**最有用的换算关系**：

```
yB = pB* xB / p        yA = pA* xA / p
```

**结论：理想溶液中易挥发组分在气相中的含量大于它在液相中的含量。**

证明：若 pB* > pA*（B 为易挥发组分），则 p = pA* xA + pB* xB < pB*(xA + xB) = pB*，于是

```
yB = pB* xB / p > xB
```

这一结论是后续相平衡（第四章）中气液平衡相图的基础。

### 5. 理想液体混合物中组分的化学势

**推导思路（气液平衡）：** 达到平衡时液相中 B 的化学势等于气相中 B 的化学势。

气相（理想气体）：

```
μB(sln) = μB(g) = μBθ(g, T) + RT ln(pB/pθ)
```

代入 Raoult 定律 pB = pB* xB：

```
μB(sln) = μBθ(g, T) + RT ln(pB*/pθ) + RT ln xB
```

括号内前两项只与 T、p 有关（纯液体 B 的蒸气压 pB* 是 T 的函数），可合并记为 μB*(l, T, p)，即纯液体 B 的化学势，于是：

```
μB(sln) = μB*(l, T, p) + RT ln xB
```

**更严格的推导**（把压力从 pθ 修正到 p）：标准态取 T、pθ 下的纯 B 液体，化学势为 μBθ(l, T)，则

```
μB(sln) = μBθ(l, T) + RT ln xB + ∫(pθ→p) VB* dp
```

其中 VB* 为纯液体 B 的摩尔体积。

**近似式（压力不太大时）：**

```
μB(sln) = μBθ(l, T) + RT ln xB
```

因为 ∫VB* dp 的值与 RT ln xB 相比通常很小，可以忽略。

> **三条要点：**
> 1. 条件：理想液体混合物中的**任意组分**；
> 2. 标准态：温度 T、标准压力 pθ 下的**纯 B 液体**（这是**实际存在**的状态，与气体的假想态不同）；
> 3. 压力影响通过 ∫VB* dp 体现，压力不大时可忽略。

### 6. 理想液体混合物的混合性质（四个结论及推导）

在等 T、p 下由纯液体混合配制理想液体混合物。

**(1) 混合 Gibbs 函数减小**

由于混合前后每组分的化学势分别为 μB*（纯）与 μB* + RT ln xB（溶液中）：

```
ΔmixG = G后 − G前 = ΣB nB(μB* + RT ln xB) − ΣB nB μB* = RT ΣB nB ln xB < 0
```

**(2) 混合体积为零**

由 (∂μB/∂p)T = VB，对 μB = μB*(l,T,p) + RT ln xB 求偏导（T、组成不变）：

```
VB = (∂μB/∂p)T = (∂μB*/∂p)T + 0 = VB*
```

即溶液中 B 的偏摩尔体积等于纯 B 的摩尔体积，故

```
ΔmixV = ΣB nB(VB − VB*) = 0
```

**(3) 混合焓为零**

由 Gibbs–Helmholtz 型关系 [∂(μB/T)/∂T]p = −HB/T²，注意到 RT ln xB 项除以 T 后与组成有关但与 T 无关的 ln xB 项对 T 求偏导为零，故

```
HB = HB*      于是   ΔmixH = ΣB nB(HB − HB*) = 0
```

**(4) 混合熵增加**

由 ΔmixG = ΔmixH − TΔmixS 与 ΔmixH = 0：

```
ΔmixS = −ΔmixG/T = −R ΣB nB ln xB > 0
```

（也可由 ΔmixS = −(∂ΔmixG/∂T)p,n 直接求得。）

> **一句话总结：** 等温等压下配制理想液体混合物时——**无体积效应、无热效应、熵增加、Gibbs 函数减小**。

### 7. 理想气体与理想液体混合性质的比较

| 量 | 理想气体混合 | 理想液体混合 |
| :--- | :--- | :--- |
| ΔmixG | RT Σ nB ln xB < 0 | RT Σ nB ln xB < 0 |
| ΔmixS | −R Σ nB ln xB > 0 | −R Σ nB ln xB > 0 |
| ΔmixH | 0 | 0 |
| ΔmixV | 0 | 0 |

**形式完全相同**，但物理根源不同：理想气体是"分子间无作用力"，理想液体是"同种与异种分子间作用力相等"。两者混合都是**熵驱动的自发过程**。

## 八、亨利定律与理想稀薄溶液

### 1. 亨利定律（Henry）

**内容：** 一定温度下，稀薄溶液中**挥发性溶质**的蒸气压与溶液中该溶质的摩尔分数成正比。

```
pB = kx · xB
```

- **使用条件：** 稀薄溶液中的挥发性溶质；
- **kx：** Henry 常数，与 xB 对应，单位 Pa；
- **kx 的物理意义：** xB = 1 且仍服从亨利定律时的蒸气压——即图中 **H 点**，是一个**假想态**；
- **kx ≠ pB***：kx 与纯溶质蒸气压一般不等，这正是 Henry 定律与 Raoult 定律的本质差别。

**kx 大小的物理含义：**

- kx 可以大于 pB*，也可以小于 pB*；
- kx 取决于**溶剂分子对溶质分子作用力**的大小：若溶剂对溶质的作用力大于溶质分子自身间的作用力，则溶质分子"逃逸能力"下降，kx < pB*；反之 kx > pB*；
- kx 与 T、p 以及 **A（溶剂）和 B（溶质）的本性**都有关。

### 2. 亨利定律的三种表示形式

| 形式 | 表达式 | Henry 常数 | 标准浓度 |
| :--- | :--- | :--- | :--- |
| 摩尔分数 | pB = kx xB | kx（Pa） | xB = 1 |
| 质量摩尔浓度 | pB = kb (bB/bθ) | kb | bθ = 1 mol·kg⁻¹ |
| 体积摩尔浓度 | pB = kc (cB/cθ) | kc | cθ = 1 mol·dm⁻³ |

- **kx ≠ kb ≠ kc**，但可以相互换算（稀溶液中 x ∝ b ∝ c）。

### 3. 使用亨利定律的三点注意

1. **溶质 B 在气、液相中的分子形态应相同。** 若溶质在液相中有少量缔合或离解，则浓度只算**未缔合或未离解**的那部分（如 SO2 溶于水）。
2. 压力不大时，若含多种溶质，可**分别**使用（每种溶质的 Henry 常数不同）。
3. 三种表示形式的 Henry 常数不同，不能混用。

### 4. 理想稀薄溶液

**定义：** 在一定浓度范围内，**溶剂服从 Raoult 定律、溶质服从 Henry 定律**的溶液。

> **重要提醒：** 热力学上的"理想稀薄溶液"**并不指浓度很小的溶液**，而是指"服从上述两个定律"的溶液。浓度小只是它常见的实现方式。

### 5. 溶剂的化学势

标准态取 T、pθ 下的**纯液体 A**（实际状态）：

```
μA(sln) = μAθ(l, T) + RT ln xA + ∫(pθ→p) VA* dp
```

压力不大时：

```
μA(sln) = μAθ(l, T) + RT ln xA
```

形式与理想液体混合物中任一组分的表达式**完全一致**——因为溶剂本来就服从 Raoult 定律。

### 6. 溶质的化学势

**推导：** 根据气液两相中溶质 B 的化学势相等：

```
μB(sln) = μB(g, T, p) = μBθ(g, T) + RT ln(pB/pθ)
```

代入 Henry 定律 pB = kx,B xB：

```
μB(sln) = μBθ(g, T) + RT ln(kx,B/pθ) + RT ln xB
```

方括号内只与 T、p 有关，定义为 μB△(l, T, p)：

```
μB(sln) = μB△(l, T, p) + RT ln xB
```

**μB△ 代表的状态：** T、p 下 xB = 1 且**仍遵守亨利定律**的"纯溶质 B"状态——即 **H 点的假想态**。

**该假想态的性质：** 它具有**无限稀薄溶液（xB → 0）中溶质 B 的性质**。例如偏摩尔体积相等：

```
VB△ = lim(xB→0) VB = VB∞
```

VB∞ 称为**无限稀偏摩尔体积**。

**严格式（含压力修正）：** 标准态取 T、pθ 下 xB = 1 且服从亨利定律的假想态，化学势为 μBθ(l, T)，则

```
μB(sln) = μBθ(l, T) + RT ln xB + ∫(pθ→p) VB∞ dp
```

### 7. 溶质化学势的三种形式与对应标准态

| Henry 定律形式 | 化学势表达式 | 标准态 |
| :--- | :--- | :--- |
| pB = kx xB | μB = μBθ(l,T) + RT ln xB + ∫VB∞dp | T、pθ 下 xB = 1 仍服从 Henry 的假想态 |
| pB = kb bB | μB = μBθ(l,T) + RT ln(bB/bθ) + ∫VB∞dp | T、pθ 下 bB = bθ 仍服从 Henry 的假想态 |
| pB = kc cB | μB = μBθ(l,T) + RT ln(cB/cθ) + ∫VB∞dp | T、pθ 下 cB = cθ 仍服从 Henry 的假想态 |

### 8. 溶剂与溶质表达式的三点区别（重要结论）

| 比较项 | 溶剂 A | 溶质 B |
| :--- | :--- | :--- |
| 服从的定律 | Raoult | Henry |
| 标准态 | T、pθ 下纯 A 液体（**实际存在**） | T、pθ 下 xB = 1 仍服从 Henry 的**假想态**（三种形式） |
| 被积函数（压力修正项） | VA*（纯溶剂摩尔体积） | VB∞（无限稀偏摩尔体积） |

> **第三点也是最重要的：** 对于确定状态的溶液，溶质 B 可以有多种表达形式，**标准化学势和组成变量的形式不同，但化学势 μB 的值是唯一确定的**（因为状态确定，μB 就确定）。

## 九、实际溶液的化学势：活度与活度系数

### 1. 实际溶液对理想溶液的偏差

| 偏差类型 | 判据 |
| :--- | :--- |
| 正偏差 | pA > pA* xA，pB > pB* xB |
| 负偏差 | pA < pA* xA，pB < pB* xB |

- 正偏差：异种分子间作用力**弱于**同种分子间作用力，分子更易逃逸；
- 负偏差：异种分子间作用力**强于**同种分子间作用力（如形成氢键），分子不易逃逸。
- **至今尚未研究出非理想溶液的统一规律**，因此只能"校正"而非"重建"。

### 2. Lewis 的活度与活度系数

**思路：** 保留理想溶液化学势表达式的形式，只把浓度 xB 换成校正后的"有效浓度"aB。

**校正方法 a：按 Raoult 定律校正（适用于溶剂、或全部浓度范围）**

```
aB = pB/pB* = γB xB
lim(xB→1) γB = 1
```

- 标准态：温度 T、标准压力 pθ 下的**纯 B 液体**；
- aB 为**活度**（无量纲），物理意义是"校正浓度"；
- γB 为**活度系数**，代表组分 B 对 Raoult 定律的偏差程度：

| γB | 含义 |
| :--- | :--- |
| γB > 1 | 正偏差 |
| γB = 1 | 服从 Raoult 定律 |
| γB < 1 | 负偏差 |

**校正方法 b：按 Henry 定律校正（适用于溶质）**

Henry 定律有三种表示式，校正后的表达式也有三种：

```
pB = kx,B aB = kx,B γB xB,      lim(xB→0) γB = 1
pB = kb aB = kb γB (bB/bθ),    lim(bB→0) γB = 1
pB = kc aB = kc γB (cB/cθ),    lim(cB→0) γB = 1
```

对应三套标准态（均为假想态）：

| 形式 | 标准态 |
| :--- | :--- |
| x 形式 | T、pθ 下 xB = 1 纯物质 B 仍遵守 Henry 的假想态 |
| b 形式 | T、pθ 下 bB = bθ（1 mol/kg）时仍遵守 Henry 的假想态 |
| c 形式 | T、pθ 下 cB = cθ（1 mol/dm³）时仍遵守 Henry 的假想态 |

此时 γB 代表组分 B 对 **Henry** 定律的偏差。

### 3. 实际溶液化学势的表达式

**通常做法：** 参照理想稀薄溶液校正实际溶液——**溶剂按 Raoult 校正，溶质按 Henry 校正**，把理想稀薄溶液化学势表达式中的 xB、bB、cB 换为 aB 即可，**标准态同理想稀薄溶液**。

溶剂 A：

```
μA(sln) = μAθ(l, T) + RT ln aA + ∫(pθ→p) VA* dp,     aA = γA xA
```

溶质 B：

```
μB(sln) = μBθ(l, T) + RT ln aB + ∫(pθ→p) VB∞ dp
```

（aB、γB 的具体形式与所选的 Henry 定律表示对应。）

### 4. 化学势通式

所有系统的化学势可统一写成：

```
μB = μBθ(T) + RT ln aB + ∫(pθ→p) VB∞ dp
```

| 系统 | aB 的取法 |
| :--- | :--- |
| 理想气体 | aB = pB/pθ |
| 实际气体 | aB = fB/pθ（即 fB/pθ，逸度代替压力） |
| 理想液体混合物 | aB = xB |
| 理想稀薄溶液（溶剂） | aA = xA |
| 理想稀薄溶液（溶质） | aB = xB（或 bB/bθ、cB/cθ） |
| 实际溶液 | aB = γB xB（或 γB bB/bθ、γB cB/cθ） |

其中压力项（积分项）通常很小可忽略，于是通式简写为：

```
μB = μBθ(T) + RT ln aB
```

### 5. 三条重要结论（判断、填空常考）

1. **化学势是状态量**：状态确定，μB 就确定；
2. **标准态选取不同，意味着 μBθ 不同、aB 不同、γB 不同**；
3. 对给定状态的溶液：其**化学势和蒸气压唯一确定**，但溶质的**活度和活度系数随标准态的选择而变化**。

一句话对照：**同一状态，μ 相同，a 不同，γ 不同，μθ 不同。**

## 十、依数性

### 1. 定义

在一定温度和压力下，溶液的某些热力学性质**只决定于溶液中溶质的浓度（数量），而与溶质的物理、化学性质无关**，这类性质称为**依数性**。

四种依数性：

```
蒸气压降低    凝固点降低    沸点升高    渗透压
```

### 2. 蒸气压降低

对非挥发性溶质的理想液体混合物或理想稀薄溶液，由 Raoult 定律：

```
pA = pA* xA
Δp = pA* − pA = pA*(1 − xA) = pA* xB
```

- Δp 是依数性：只取决于溶剂的本性（pA*）与溶质的浓度（xB），与溶质的本性无关；
- **为什么限定非挥发性溶质？** 若溶质挥发，它本身也贡献蒸气压，总压不一定下降，Raoult 定律的简单形式不再适用。

### 3. 凝固点降低

**凝固点：** 固体和液体的蒸气压相等时的温度。Tf* 为纯溶剂凝固点，Tf 为溶液凝固点（溶液与**纯溶剂固相**平衡的温度）。

**假设溶液在 Tf 时只析出纯溶剂 A(s)**，则 Tf < Tf*。

**公式：**

```
ΔTf = Tf* − Tf = Kf bB
Kf = R (Tf*)² MA / ΔfusHm,A
```

- **Kf：** 凝固点降低常数，**仅与溶剂性质有关**，可查手册（水约 1.86 K·kg·mol⁻¹）；
- 条件：**稀薄溶液**；
- 两个思考：① 是否限定非挥发性溶质？（不需要，凝固点降低只涉及固液平衡，与溶质挥发性无关）；② 为什么有"纯溶剂固相"的条件？（若析出固溶体，则固相组成也随溶液改变，公式不再成立）。

**推导思路：** 在 Tf 时纯溶剂固相 A(s) 与溶液中 A 达到平衡，μA(s) = μA(sln)。由 μA(sln) = μA*(l,T,p) + RT ln xA 与 dμ = −SdT + Vdp，沿固液平衡线积分并作稀溶液近似（−ln xA ≈ xB ≈ MA bB/1000，ΔHfus 视为常数），即得上述 Kf 表达式。

### 4. 沸点升高

**沸点：** 液体的饱和蒸气压等于外压时的温度。

```
ΔTb = Tb − Tb* = Kb bB
Kb = R (Tb*)² MA / ΔvapHm,A
```

- **Kb：** 沸点升高常数，只与溶剂本身性质有关，可查手册；
- **只适用于不挥发性溶质的稀溶液**；
- 两个思考：① 为什么限于不挥发性溶质？② 若是挥发性溶质，沸点将如何变化？（溶质也贡献蒸气压，使总压升高，沸点可能降低，取决于溶质的挥发性与浓度。）

### 5. 渗透压

**渗透现象：** 溶剂通过半透膜渗透到溶液一侧，使溶液侧液面升高的现象。

**热力学原因：** 同温同压下

```
μA*(T, p) > μA(sln, T, p)
```

纯溶剂的化学势高于溶液中溶剂的化学势，故溶剂自发向溶液侧转移。

**渗透压 Π：** 维持两侧平衡时双方的压差——即需要在溶液侧额外施加的压力。

**平衡条件：**

```
μA*(l, T, p) = μA(sln, T, p + Π)
```

**推导：**

左侧（纯溶剂，压力 p）：

```
μ左 = μA*(l, T, p) = μAθ + ∫(pθ→p) VA* dp
```

右侧（溶液，压力 p + Π）：

```
μ右 = μA(sln, T, p + Π) = μAθ + RT ln xA + ∫(pθ→p+Π) VA* dp
```

两式相减（VA* 视为常数）：

```
0 = RT ln xA + VA* Π      →      Π = −(RT/VA*) ln xA
```

稀溶液近似（xB ≪ 1，−ln xA = −ln(1 − xB) ≈ xB，且 xB ≈ nB/nA，nA VA* ≈ V）：

```
Π = (RT/VA*) xB ≈ (nB/V) RT = cB RT
```

**van't Hoff 公式（1886）：**

```
Π = cB RT
```

- cB 单位取 mol·m⁻³ 时，Π 的单位为 Pa；
- 条件：理想稀薄溶液；
- 是否限定非挥发性溶质？（不需要，渗透压只涉及溶剂在两相间的化学势相等）。

> **四个依数性中，渗透压最显著。** 这正是渗透压法能用于测定高分子摩尔质量的原因。

### 6. 四个依数性公式汇总

| 依数性 | 公式 | 常数/条件 |
| :--- | :--- | :--- |
| 蒸气压降低 | Δp = pA* xB | 非挥发性溶质；理想溶液/理想稀溶液 |
| 凝固点降低 | ΔTf = Kf bB | Kf = R(Tf*)²MA/ΔfusHm,A；稀溶液；析出纯溶剂固相 |
| 沸点升高 | ΔTb = Kb bB | Kb = R(Tb*)²MA/ΔvapHm,A；不挥发性溶质；稀溶液 |
| 渗透压 | Π = cB RT | 稀溶液 |

**共同点：** 都只与溶质的**数量（浓度）**有关；都必须用稀溶液近似；浓度单位必须与常数匹配（bB 用 mol·kg⁻¹，cB 用 mol·m⁻³）。

### 7. 依数性的应用

1. **生命科学中的渗透压：** 渗透压是调节细胞内外水分及可渗透物质的主要因素；人体血液渗透压约 770 kPa（710–860 kPa 为正常范围），过高过低都是病理状态；肾脏通过调节尿液浓度维持血液渗透压；血液透析（人造肾脏）利用半透膜原理。
2. **测定摩尔质量或纯度：** 由 ΔTf = Kf(WB/MB)/WA、ΔTb = Kb(WB/MB)/WA、Π = (WB/MB)RT/V 反解 MB。渗透压法最适合测定**高分子**的摩尔质量（因为高分子溶液的 bB 很小，ΔTf、ΔTb 太小测不准，而 Π 很显著）。
3. **反渗透：** 施加超过 Π 的外压，可使溶剂从溶液侧反向透过半透膜——用于海水淡化、溶液浓缩。

> 思考题（课件）：深海潜水员为何必须缓慢上浮？——上浮过快时外压骤降，血液中溶解的气体析出形成气泡（减压病），这与气体溶解度随压力变化（Henry 定律）直接相关。

## 十一、易错点清单

1. **偏摩尔量 ≠ 摩尔量**：只有纯物质时两者才相等；偏摩尔量与**组成**有关。
2. 只有**容量性质**才有偏摩尔量；强度性质（T、p）没有偏摩尔量。
3. 只有"某组分在某**一相**中的偏摩尔量"，没有"整个多相系统的偏摩尔量"。
4. **只有 G 的偏摩尔量叫化学势**，VB、HB、SB 都不是化学势。
5. 集合公式 X = ΣnB XB 的条件是**等温等压**（此时组成固定，XB 为常数）。
6. 化学势判据 ΣμB dnB ≤ 0 的条件是**等温、等压、W' = 0**；缺一不可。
7. 平衡条件是**各相中同一组分**的化学势相等，不是不同组分的化学势相等。
8. 纯理想气体标准态是**假想态**（理想气体本身是模型）；纯液体标准态是**实际状态**；溶质标准态是**假想态**。
9. 理想稀薄溶液的"理想"指的是**服从两个定律**，不是"浓度很小"。
10. **kx ≠ pB***：Henry 常数不是纯溶质的蒸气压，它对应假想态（H 点）。
11. 使用 Henry 定律时，若溶质在液相缔合或离解，**只算未缔合（未离解）部分**。
12. 理想液体混合物的 ΔmixH = 0、ΔmixV = 0，但 **ΔmixS > 0、ΔmixG < 0**——混合是熵驱动的。
13. 依数性只依赖**溶质数量**；电解质溶液需考虑解离（i 因子），课件范围内按非电解质处理。
14. 沸点升高要求**不挥发性**溶质；凝固点降低与渗透压**不要求**。
15. 同一状态溶液，**μ 唯一，但 a、γ、μθ 随标准态改变**——这是填空题的经典陷阱。
16. 浓度换算时单位必须统一，cB、ρ、M 的量纲不匹配会造成 10³ 倍误差。

## 十二、公式速查

| 名称 | 表达式 | 条件 |
| :--- | :--- | :--- |
| 偏摩尔量 | XB = (∂X/∂nB)T,p,nC | 均相、容量性质 |
| 集合公式 | X = ΣB nB XB | 等温等压 |
| Gibbs–Duhem | ΣB nB dXB = 0 | 等温等压 |
| 化学势 | μB = GB = (∂G/∂nB)T,p,nC | — |
| 开放系统基本式 | dG = −SdT + Vdp + ΣμB dnB | 组分可变 |
| 化学势判据 | ΣμB dnB ≤ 0 | 等 T、p、W' = 0 |
| 相平衡条件 | μB(α) = μB(β) = … | 等 T、p、W' = 0 |
| 化学平衡条件 | ΣB νB μB = 0 | 等 T、p、W' = 0 |
| μ 与 p | (∂μB/∂p)T,n = VB | — |
| μ 与 T | (∂μB/∂T)p,n = −SB | — |
| μ 与 T（G-H 型） | [∂(μB/T)/∂T]p,n = −HB/T² | — |
| 纯理想气体 | μ* = μθ(pg,T) + RT ln(p/pθ) | — |
| 理气混合物 | μB = μBθ(pg,T) + RT ln(pB/pθ) = μB* + RT ln xB | — |
| 实际气体 | μ* = μθ(pg,T) + RT ln(f/pθ)，f = γp | lim(p→0) f/p = 1 |
| 理气混合 | ΔmixG = RTΣnB ln xB；ΔmixS = −RΣnB ln xB；ΔmixH = ΔmixV = 0 | 等 T、p |
| 质量摩尔浓度 | bB = nB/mA | mol·kg⁻¹ |
| 稀溶液换算 | xB ≈ bB MA/1000 = cB MA/ρA | 稀溶液 |
| 拉乌尔定律 | pA = pA* xA | 非电解质、稀溶液 |
| 蒸气压降低 | Δp = pA* xB | 非挥发性溶质 |
| 气相组成 | yB = pB* xB/p | 理想溶液 |
| 理想溶液化学势 | μB = μB*(l,T,p) + RT ln xB | 全浓度 |
| 理想溶液混合 | ΔmixG = RTΣnB ln xB；ΔmixS = −RΣnB ln xB；ΔmixH = ΔmixV = 0 | 等 T、p |
| 亨利定律 | pB = kx xB = kb(bB/bθ) = kc(cB/cθ) | 稀溶液、挥发性溶质 |
| 溶剂化学势 | μA = μAθ(l,T) + RT ln xA + ∫VA*dp | 理想稀溶液 |
| 溶质化学势 | μB = μBθ(l,T) + RT ln xB + ∫VB∞dp | 标准态为假想态 |
| 活度（Raoult 校正） | aB = pB/pB* = γB xB，lim(xB→1)γB = 1 | 溶剂 |
| 活度（Henry 校正） | aB = pB/kx = γB xB，lim(xB→0)γB = 1 | 溶质 |
| 化学势通式 | μB = μBθ(T) + RT ln aB + ∫VB∞dp | 各类系统 |
| 凝固点降低 | ΔTf = Kf bB，Kf = R(Tf*)²MA/ΔfusHm,A | 稀溶液、析出纯溶剂 |
| 沸点升高 | ΔTb = Kb bB，Kb = R(Tb*)²MA/ΔvapHm,A | 不挥发溶质、稀溶液 |
| 渗透压 | Π = cB RT | 理想稀溶液 |

## 十三、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **多组分系统的困难** | 容量性质失去加和性，V(混合) ≠ ΣnB Vm,B* |
| **偏摩尔量** | XB = (∂X/∂nB)T,p,nC；强度性质；与 T、p、组成有关；集合公式 X = ΣnB XB |
| **化学势** | μB = GB；开放系统 dG = −SdT + Vdp + ΣμBdnB |
| **化学势判据** | 等 T、p、W'=0：ΣμB dnB ≤ 0；物质由高 μ 流向低 μ；平衡时各相 μ 相等 |
| **μ 与 T、p** | (∂μB/∂p)T = VB > 0；(∂μB/∂T)p = −SB < 0；摩尔量→偏摩尔量即可套用 G 的公式 |
| **气体化学势** | 理气 μ = μθ + RT ln(p/pθ)；实际气体用逸度 f = γp，lim(p→0)γ = 1 |
| **组成表示** | xB、bB、cB、wB；稀溶液 xB ≈ bB MA/1000 ≈ cB MA/ρA |
| **拉乌尔定律** | pA = pA* xA；Δp = pA* xB；理想溶液全浓度服从 |
| **理想液体混合物** | 微观 f(A−A)=f(B−B)=f(A−B)；μB = μB* + RT ln xB；ΔmixV=ΔmixH=0，ΔmixS>0，ΔmixG<0 |
| **亨利定律** | pB = kx xB；标准态为假想态（H 点）；kx ≠ pB*；注意缔合离解 |
| **理想稀薄溶液** | 溶剂 Raoult、溶质 Henry；溶质标准态为假想态；不指"浓度很小" |
| **实际溶液** | 正/负偏差；活度 aB、活度系数 γB；μB = μBθ + RT ln aB |
| **标准态与活度** | 同一状态 μ 唯一，但 a、γ、μθ 随标准态而变 |
| **依数性** | Δp = pA* xB；ΔTf = Kf bB；ΔTb = Kb bB；Π = cB RT；只依赖溶质数量 |
