# **细胞生物学学习笔记 9 | 细胞信号转导：从受体到级联放大**

---

> **对应课件：** Cell signaling-2026  
> **本章核心内容：** 信号转导的 5 大特征、信号的多样性、四大类受体（离子通道、GPCR、酶偶联受体、核受体）、第二信使系统、整合素信号及发育相关通路（Wnt、Hedgehog）。  
> **复习目标：** 掌握信号转导的 5 个核心特征；熟记 GPCR 激活的 6 个步骤及两大第二信使通路（cAMP 与 IP3/DAG）；掌握 RTK 的激活机制（不对称激活、自磷酸化）及下游 PI3K 和 MAPK 通路；了解 JAK-STAT、整合素及 Wnt 通路的核心逻辑。

## 一、信号转导的 5 大特征 (Features of Signaling)
（*这 5 个词是简答题常客*）
1.  **特异性 (Specificity)**：信号分子与受体结合位点精准互补（锁与钥匙）。
2.  **放大效应 (Amplification)**：通过酶促级联反应（如激酶磷酸化激酶），1 个信号分子可引发成千上万个底物改变。
3.  **模块化 (Modularity)**：带有多个结合结构域（如 SH2、PTB、PH 结构域）的接头蛋白，像积木一样组合出不同的信号复合体（Tony Pawson 发现）。
4.  **脱敏/适应 (Desensitization/Adaptation)**：受体激活后触发负反馈，关闭受体或使其内吞，防止过度反应。
5.  **整合 (Integration)**：细胞同时接收多个信号，最终表现为一个综合的生理反应（存活、生长、分化或死亡）。

### 信号的多样性 (Signaling Diversity)
*   **组合效应**：细胞的命运由接收到的信号**组合**决定。
*   **同信号不同效应**：同一信号分子（如乙酰胆碱 ACh）作用于不同细胞，受体不同或胞内解读不同，效应完全不同（心肌减速、唾液腺分泌、骨骼肌收缩）。

## 二、四大类信号受体 (Signal Transducers)

### 1. 离子通道偶联受体 (Ion-channel-coupled receptors)
*   **类型**：配体门控（如神经递质受体）或电压门控。
*   **核心机制**：受体本身是通道，配体结合直接导致通道打开，离子流入/流出，引起膜电位变化。
*   **内质网上的钙通道**：**IP3R**（响应 GPCR 信号）和 **RyR**（介导钙诱导的钙释放 CICR，对心肌收缩至关重要）。

### 2. G 蛋白偶联受体 (GPCR) —— 核心重点！
GPCR 是人类基因组中最大的受体家族（~800 个），是目前最成功的药物靶点（约 36% 的上市药物靶向 GPCR）。
*   **结构**：单体，7 次跨膜 α 螺旋（7TM）。配体结合导致 TM6 胞质端向外旋转，招募 G 蛋白。

#### GPCR 激活与信号传递的 6 个核心步骤（必背！）
1.  **激动剂结合**，受体构象激活。
2.  **G 蛋白招募与核苷酸交换**：受体作为 **GEF**（鸟苷酸交换因子），促使 Gα 亚基释放 GDP，结合 GTP。
3.  **G 蛋白解离**：Gα-GTP 与 Gβγ 二聚体分离。
4.  **双分支信号启动**：Gα-GTP 和 Gβγ 各自结合并激活不同的下游效应器（如腺苷酸环化酶 AC、磷脂酶 C PLC）。
5.  **第二信使放大**：效应器产生第二信使（cAMP、IP3、DAG、Ca²⁺）。
6.  **信号终止**：Gα 具有 **GTP 酶活性**，将 GTP 水解为 GDP，Gα-GDP 重新与 Gβγ 结合，回到静息态。（注：人体内有 RGS 蛋白可作为 GAP 加速此过程）。

#### 两大核心第二信使通路：
*   **cAMP 通路 (Gαs/Gαi)**：
    *   **Gαs** 激活腺苷酸环化酶 (AC) → 产生 cAMP → 激活 **PKA**（释放催化亚基）。
    *   **Gαi** 抑制 AC。
    *   PDE（磷酸二酯酶）可将 cAMP 水解为 5'-AMP 从而终止信号。
*   **IP3 / DAG 通路 (Gq 与 Gβγ)**：
    *   Gβγ 结合并激活 **PLCβ**（磷脂酶 C）。
    *   PLCβ 切割质膜上的 PIP2，产生 **IP3** 和 **DAG**。
    *   **IP3** 扩散到内质网，打开 IP3R 通道，**释放 Ca²⁺**。
    *   **DAG** 留在质膜上，与 Ca²⁺ 协同激活 **PKC**。

#### 钙信号与振荡 (Calcium Oscillation)
*   细胞内 Ca²⁺ 浓度（~100-200 nM）远低于内质网（~100-500 μM）。
*   钙振荡的产生：**低 Ca²⁺ 促进 IP3R 释放**（正反馈），**高 Ca²⁺ 抑制 IP3R**（负反馈）。这种正负反馈循环导致周期性的钙峰。
*   Ca²⁺ 的效应器包括：Calmodulin (CaM，激活 CaM-kinase)、PKC、Calcineurin (激活 NFAT 转录因子) 等。

#### NO/cGMP 通路（心血管舒张，1998 诺奖）
*   乙酰胆碱 → 内皮细胞 GPCR → 胞内 Ca²⁺ 升高 → 激活 **NOS** (一氧化氮合酶) → 产生 **NO** 气体。
*   NO 快速跨膜扩散至平滑肌细胞 → 激活鸟苷酸环化酶 (sGC) → 产生 **cGMP** → 舒张血管。
*   *医学联系*：**伟哥 (PDE5 抑制剂)** 通过抑制 cGMP 的降解，维持血管舒张。

#### GPCR 的脱敏与终止
*   **GRK (GPCR kinase)** 磷酸化激活的受体。
*   **Arrestin (抑制蛋白)** 结合磷酸化的受体，阻断其与 G 蛋白结合，并启动受体内吞（Endocytosis）。

### 3. 酶偶联受体 (Enzyme-coupled Receptors)
跨膜受体，胞内域本身具有酶活性或直接与酶结合。主要有三类：

#### A. 受体酪氨酸激酶 (RTK)
人类有 58 个 RTK（如 EGFR、胰岛素受体、VEGF 受体）。发现者 Tony Hunter。
*   **激活机制**：
    1.  配体结合导致受体**二聚化 (Dimerization)**。
    2.  **交叉自磷酸化 (Trans-autophosphorylation)**：胞内激酶结构域互相磷酸化激活环 (Activation loop) 上的酪氨酸。激活环磷酸化后从底物结合口袋移开，这是激酶活化的通用机制。
    3.  *EGFR 的特例（不对称激活）*：EGFR 二聚化后，一个激酶（Activator）推挤另一个激酶（Receiver），只有 Receiver 具有催化活性，随后磷酸化 C 端尾巴上的多个酪氨酸。
    4.  磷酸化的酪氨酸 (p-Tyr) 成为对接位点，招募含有 **SH2** 或 **PTB** 结构域的蛋白。
*   **负调控**：E3 泛素连接酶 **C-Cbl** 结合 p-Tyr，给受体挂上泛素标签，诱导其内吞至溶酶体降解。
*   **癌症**：RTK 突变或过表达（如 EGFR 在非小细胞肺癌中高表达）导致持续激活。靶向药物：单抗（如曲妥珠单抗，后缀 `-mab`）和小分子抑制剂（如吉非替尼，后缀 `-nib`）。

**RTK 的两大下游经典通路：**
1.  **PI3K-Akt-mTOR 通路（促进生存与生长）**：
    RTK p-Tyr → 招募并激活 **PI3K** → 催化 PIP2 变为 **PIP3** → 招募 PDK1 和 **Akt** → Akt 激活 → 抑制凋亡（磷酸化 Bad）并促进生长（激活 mTORC1，受氨基酸信号整合）。
2.  **Ras-MAPK 通路（促进增殖）**：
    RTK p-Tyr → 接头蛋白 **Grb2** (含 SH2/ SH3) → 招募 **SOS** (Ras-GEF) → 激活 **Ras** (小 G 蛋白，非激酶) → 激活 **Raf** (MAP3K) → MEK (MAP2K) → **Erk** (MAPK) → 进入细胞核调控基因表达。

#### B. 受体丝氨酸/苏氨酸激酶 (TGFβ 受体)
*   配体结合 → 受体二聚化 → II 型受体磷酸化并激活 I 型受体 → 磷酸化 **Smad (R-Smad)** → R-Smad 结合 Co-Smad (Smad4) → 入核调控基因。

#### C. 细胞因子受体 (JAK-STAT 通路)
*   **特点**：受体本身**没有酶活性**，与胞内的 **JAK** (Janus 激酶) 结合。
*   **机制**：配体结合 → 受体二聚化 → JAK 互相磷酸化 → JAK 磷酸化受体 → 招募并磷酸化 **STAT** → STAT 二聚化入核调控基因。

---

### 4. 核受体 (Nuclear Receptors)
*   **配体**：脂溶性分子（类固醇激素、甲状腺素、维甲酸、维生素 D）。
*   **机制**：穿过质膜进入细胞。未结合配体时，受体结合抑制蛋白；配体结合后，构象改变（“盖子”关闭），释放抑制蛋白，招募辅激活蛋白 (Coactivator)，直接结合 DNA 上的响应元件调控转录。

## 三、细胞骨架与细胞黏附的信号：整合素 (Integrins)
*   **结构**：αβ 异二聚体跨膜受体。胞外结合 ECM（如纤连蛋白），胞内连接肌动蛋白骨架。
*   **FAK (黏着斑激酶)**：在黏着斑 (Focal adhesion) 处，整合素聚集引发 FAK 自磷酸化，介导力学信号传导（Mechano-signaling）。
*   **Talin 作为张力感受器**：细胞内 Rap1 激活并招募 Talin。外源机械力拉扯 Talin，使其去折叠，暴露出 Vinculin 结合位点，从而加固细胞骨架连接。
*   **Inside-out / Outside-in 信号**：胞内信号（如 Rap1）改变整合素胞外亲和力（内向外）；外力或配体结合改变胞内信号（外向内）。

---

## 四、经典发育信号通路（Alternative receptor signaling）
*   **Notch 通路**：接触依赖。Notch 结合 Delta 后，被蛋白酶切割，释放胞内段 (NICD) 入核。
*   **Wnt/β-catenin 通路**：
    *   *无 Wnt 时*：Axin 复合物 (含 APC, GSK3, CK1) 磷酸化 β-catenin，导致其泛素化降解。
    *   *有 Wnt 时*：Wnt 结合 Frizzled 和 LRP → 激活 Dishevelled → 破坏 Axin 复合物 → β-catenin 稳定积累并入核 → 激活靶基因。
*   **Hedgehog 通路**：在初级纤毛中。无 Hh 时，Patched 抑制 Smoothened；有 Hh 时，解除抑制，激活 Gli 转录因子。

## 五、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **信号 5 特征** | 特异性、放大、模块化、脱敏、整合。 |
| **GPCR** | 7次跨膜；作为 GEF 激活 G 蛋白；**6 步骤必背**；Gαs/Gαi 调节 AC；Gβγ 激活 PLCβ。 |
| **第二信使** | cAMP→PKA；IP3→Ca²⁺；DAG→PKC；NO→cGMP。钙振荡源于 IP3R 的正负反馈。 |
| **RTK** | 二聚化与交叉自磷酸化。SH2/PTB 识别 p-Tyr。 |
| **RTK 下游** | PI3K-Akt-mTOR（生存/生长）；Ras-MAPK（增殖）。 |
| **JAK-STAT** | 细胞因子受体无酶活，依赖 JAK 磷酸化 STAT 入核。 |
| **整合素** | αβ 异二聚体；连接 ECM 与骨架；Talin 是张力感受器。 |
| **Wnt 通路** | 核心是 Axin 复合物对 β-catenin 的降解控制。 |
