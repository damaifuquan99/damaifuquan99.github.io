# **物理化学学习笔记 4 | 第四章 相平衡：从相律到各类相图**

---

> **本章核心内容：** 相、相数、独立组分数与自由度的概念；Gibbs 相律的推导、形式与适用条件；单组分系统相图（点、线、面）与水的相图；Clapeyron 方程与 Clausius-Clapeyron 方程的推导及应用；二组分理想/非理想系统的气液平衡相图、杠杆规则与精馏原理；部分互溶双液系的液液相图；二组分固液平衡相图（简单低共熔、稳定与不稳定化合物、固溶体）；三组分系统的分配平衡与萃取

## 一、概述：相平衡研究什么

### 1. 知识定位

热力学第一定律解决**能量的转化与守恒**，第二、三定律解决**过程的方向与限度**，这两者是知识基础；在应用层面则依次是：

```
溶液热力学（第三章）——多组分均相系统
相平衡（第四章）        ——多组分多相系统   ← 本章
化学平衡（第五章）      ——多组分、有化学反应的系统
```

**相平衡的热力学基础：** 热力学基本定律与判据、多组分多相系统的热力学、化学势判据。

### 2. 两大研究内容

| 内容 | 含义 | 回答的问题 |
| :--- | :--- | :--- |
| **相律** | 多相平衡系统所遵守的普遍规律 | 一个系统最多几个相？需要几个独立变量？ |
| **相图** | 表示多相系统的状态随温度、压力和组成等变量的改变而改变的图形 | 给定条件下系统是什么相态？改变条件如何相变？ |

一句话：**相律管"数"，相图管"形"。** 相律给出拓扑约束（相数、自由度数），相图给出具体几何形状。

### 3. 实际意义

| 领域 | 典型问题 |
| :--- | :--- |
| 冶金 | 合金的组成—温度—相态关系 |
| 化工分离 | 蒸馏、精馏、萃取、重结晶、提纯 |

| 生命科学 | 血液中气体与金属离子的溶解与析出、渗透压与相变 |

### 4. 课件列出的若干实例

1. 血液中微量气体或金属离子溶解或析出——渗透压与相变；
2. 冰雪道路治理——添加盐或盐水（凝固点降低）；

4. 泰坦尼克号沉没——其中铆钉金属材料方面的原因分析（材料相变与低温脆性）。

## 二、相与相数

### 1. 定义

**相：** 系统内部**物理性质和化学性质完全均匀**的部分称为一个相。

**相数：** 系统达到平衡时相的总数称为相数，用 **P** 表示。

### 2. 均相系统与多相系统

- **均相系统：** 一个多组分平衡系统中，只有各种物质以**分子层次**相互混合才是均相系统。
- **多相系统：** 在指定条件下，相与相之间有**明显的界面**，越过相界面某些性质发生突变。

### 3. 三类聚集状态的相数规则

| 状态 | 规则 | 说明 |
| :--- | :--- | :--- |
| 气体 | 不论有多少种气体混合，**只有一个气相** | 气体分子间距大，任何气体都能以任意比例互溶 |
| 液体 | 按**互溶程度**可组成一相、两相或三相共存 | 完全互溶为一相，部分互溶分层为两相 |
| 固体 | 一般**一种固体便有一个相**；两种固体粉末无论混合得多均匀仍是两个相（**固溶体除外**，它是单相） | 只看晶型与组成，不看颗粒大小 |

### 4. 典型判断

| 系统 | 相数 | 理由 |
| :--- | :--- | :--- |
| 一杯牛奶 | 多相 | 乳浊液体系，不是分子层次混合 |
| 大块 CaCO3(s) 与粉末 CaCO3(s) | 1 | 同一化学物质、同一晶型，仅颗粒大小不同，物理化学性质仍均匀 |
| 水与乙醇的溶液 | 1 | 完全互溶，分子层次混合 |
| 水与苯的溶液 | 2 | 部分互溶，分层 |
| 一杯豆浆 | 多相 | 胶体/悬浊体系 |
| 一堆小冰块 | 1 | 同为冰，同一固相 |
| CaCO3(s) 与 CaO(s) 混合粉末 | 2 | 两种不同化学物质，各自一相 |
| Fe(δ)、Fe(γ)、Fe(α) | 3 | 同一物质的不同晶型，每种晶型各为一相 |

> **易错点：** 对于一个指定的系统，**决不可凭直观感觉**确定其相数。
> （1）气体，无论存在多少种，均为一相；
> （2）对于液体和固体，需要具体分析——液体看互溶程度，固体看晶型与化学组成，不看颗粒大小与堆积方式。

## 三、多相系统的平衡条件

### 1. 四个平衡

在一个封闭的多相系统中，相与相之间可以有热的交换、功的传递和物质的交流。多相系统的**热力学平衡状态**包含如下四个平衡：

| 平衡 | 条件 |
| :--- | :--- |
| (1) 热平衡 | 各相**温度相等** |
| (2) 力平衡 | 各相**压力相等** |
| (3) 相平衡 | 各相的**质量及组成不随时间而变化** |
| (4) 化学平衡 | 各相中化学反应达到平衡（第五章） |

### 2. 相平衡的必要条件

由化学势判据（第三章）可知：在等温、等压、W' = 0 的条件下，物质总是从化学势高的相流向化学势低的相，平衡时两相化学势相等。推广到 P 个相：

```
任意组分 B 在它所存在的各相中的化学势相等
μB(α) = μB(β) = … = μB(P)
```

> **注意：** 对于一个多相系统，相平衡**并不要求**每一种物质在所有相中都存在，**只要求每一种物质在它所在的所有相中化学势等值**。
> 例：水(A) + 蔗糖(B) 系统气液平衡，B 不挥发，只在液相中存在，则只需 μA(l) = μA(g)，不涉及 μB。

### 3. 一个重要推论

```
相平衡与物质的量无关。
一个多相系统的相平衡状态（平衡性质）由系统的强度性质决定。
```

于是在给定 S 个物种、P 个相的条件下，问题转化为：**需要多少个强度变量才能确定系统的状态？** 这正是相律要回答的。

## 四、独立组分数

### 1. 为什么需要"独立组分数"

平衡系统中**可独立改变其数量的化学物种数**称为**独立组分数**，用 C 表示。

- **物种数 S：** 系统中的物种数，即系统中所含物质的种类数；
- 物种数往往随人们主观考虑问题的方法、角度不同而不同（例如水可以算 1 种，也可以把 H+、OH− 都算进去而得到 3 种）；
- 但**独立组分数却与人为因素无关**——这正是引入它的原因。

### 2. 定义式

```
C = S − R − R'
```

| 符号 | 含义 |
| :--- | :--- |
| S | 物种数 |
| R | 独立的化学反应数（不能由其它化学反应式通过加减得到） |
| R' | 独立的浓度限制条件数 |

**关于 R' 的严格说明：** 浓度限制条件是指**固定不变的浓度关系**，且**必须是同一相中**几种物质浓度之间的关系，**不包括** ΣxB = 1 这种归一化条件（因为后者每相都有，属于定义性的约束，不构成额外的独立限制）。

> **更本质的说法：** R' 对应的是"能有一个方程把它们的化学势联系起来"的关系（Gibbs–Duhem 方程，本课程不要求）。

### 3. 示例：水

| 考虑方式 | S | R | R' | C |
| :--- | :--- | :--- | :--- | :--- |
| 只把水看作一种物质 | 1 | 0 | 0 | 1 |
| 考虑电离 H2O ⇌ H+ + OH− | 3 | 1 | 1（电中性：x(H+) = x(OH−)） | 3 − 1 − 1 = 1 |

两种算法结果一致，说明 C 与人为选择无关。

### 4. 确定 C 的四个例题

**例 1：2HI(g) ⇌ H2(g) + I2(g)**

```
S = 3，R = 1
```

- 若反应物**起始浓度相同**（例如只有 HI），则平衡时 H2 与 I2 浓度必相等，构成同一相内的浓度限制，**R' = 1**，故 C = 3 − 1 − 1 = 1；
- 若起始只有 HI 而无 H2、I2，也可等价理解为上述情况。

**例 2：碳在氧气中燃烧**

```
(1) C(s) + O2(g) = CO2(g)
(2) C(s) + ½O2(g) = CO(g)
(3) CO(g) + ½O2(g) = CO2(g)
```

因为 **(3) = (1) − (2)**，三个方程中只有 **2 个独立**，故 R = 2；无浓度限制，R' = 0：

```
S = 4，R = 2，R' = 0   →   C = 4 − 2 − 0 = 2
```

> **关键：** R 是"独立"反应数，写出的反应式个数不等于 R——必须剔除可由其它反应线性组合得到的方程。

**例 3：NH4Cl(s) 在真空容器中分解**

```
NH4Cl(s) = NH3(g) + HCl(g)
```

- 真空容器中分解：NH3 与 HCl 同由 NH4Cl 分解产生，且**都在气相**（同一相），物质的量必相等，故 **R' = 1**：
```
S = 3，R = 1，R' = 1   →   C = 3 − 1 − 1 = 1
```
- 若在**含有 NH3 的容器**中分解，则 NH3 与 HCl 的量不再相等，**R' = 0**：
```
C = 3 − 1 = 2
```

**例 4：HCN（氢氰酸）的水溶液**

```
物种：H2O, HCN, H+, CN−, OH−     →  S = 5

两个独立反应：
  H2O ⇌ H+ + OH−
  HCN ⇌ H+ + CN−                  →  R = 2

一个浓度限制条件（电中性）：
  [H+] = [OH−] + [CN−]             →  R' = 1
```

```
C = 5 − 2 − 1 = 2
```

**另一方法：** 直接把 H2O 与 HCN 看作两种组分，S = 2，R = 0，R' = 0，得 C = 2。两种算法一致。

**例 5：CaCO3(s) 在真空容器中分解**

```
CaCO3(s) = CaO(s) + CO2(g)
```

CaO(s) 与 CO2(g) **不在同一相中**，不构成浓度限制条件：

```
S = 3，R = 1，R' = 0   →   C = 3 − 1 = 2
```

> **易错点：** 判断 R' 时，必须检查浓度关系是否发生在**同一相内**。跨相的关系（如固相与气相的计量比）不能算作 R'。

### 5. 判断 C 的一般步骤

1. 列出系统中所有物种，得 S；
2. 写出所有可能发生的独立化学反应，剔除线性相关的，得 R；
3. 找出同一相中的浓度限制条件（如起始浓度相同导致的计量比、电中性条件），得 R'；
4. 代入 C = S − R − R'。

## 五、自由度

### 1. 定义（两种等价表述）

1. 确定平衡系统的状态所必须的**独立强度变量**的数目，用字母 **f** 表示；
2. 在保证系统**相态不变**的情况下（不引起旧相消失、新相生成），在一定范围内可自由变动的强度性质的数目，称为系统在指定相态下的自由度。

这些强度变量通常是**压力、温度和浓度**等。

> **注意：** 自由度数强调的是"在指定相态下"——一旦跨越相边界，相态改变，自由度的含义就变了。

## 六、相律及其推导

### 1. 总体思路

```
自由度数 = 系统总变量数 − 关联方程数
```

### 2. 系统总强度变量数

设系统有 S 个物种、P 相共存，并假设每一种组分都存在于各相中，则需要描述的量是：

```
温度 T、压力 p                            2 个
每一相中 S 个物种的摩尔分数：
  x1(1), x1(2), …, x1(P)
  …
  xS(1), xS(2), …, xS(P)                S·P 个

总数 = SP + 2
```

### 3. 关联方程数

| 来源 | 方程数 |
| :--- | :--- |
| a. 每相中物质的摩尔分数之和等于 1：ΣB xB(α) = 1 | P |
| b. 平衡时每种物质在各相中的化学势相等：μB(α) = μB(β) = … | S(P − 1) |
| c. 独立化学反应方程数 R 及浓度限制条件数 R' | R + R' |

其中 (b) 的数目：S 种物质，每种在 P 个相之间给出 P − 1 个等式，共 S(P − 1) 个。

### 4. 相律的导出

```
f = (SP + 2) − [P + S(P − 1) + R + R']
  = SP + 2 − P − SP + S − R − R'
  = S − R − R' + 2 − P
  = C − P + 2
```

**Gibbs 相律：**

```
f = C − P + 2
```

### 5. 相律的五点说明（高频考点）

| 说明 | 内容 |
| :--- | :--- |
| (1) 条件 | 相律适用于**相平衡**系统，不论 S 种物质是否同时存在于各平衡相中，都不影响相律的正确性 |
| (2) 意义 | **f ≥ 0**，不能为负（f 为负说明假定的相数不可能共存） |
| (3) 广义相律 | **f = C − P + n**。"2"代表温度和压力；若指定了温度或压力，则 **f = C − P + 1**；若除 T、p 外还需考虑电场、磁场、重力场等其它外界因素，n 要相应增加，具体分析 |
| (4) 条件自由度 | 在指定某些变量的情况下，系统的自由度称为**条件自由度**，用 **f\*** 表示 |
| (5) 局限 | 相律只能确定平衡系统**独立变量的数目**，**不能具体指出**独立变量是什么 |

> **记忆点：** "2" 不是永远不变的常数，而是"外界强度变量个数"。指定了 T 或 p 就少一个，这就是条件自由度 f* 的来源。

### 6. 相律的应用举例

**例 1：单组分均相封闭系统是双变量系统。**

```
f = 1 − 1 + 2 = 2
```

**例 2：纯液体的正常沸点 Tb\* 有定值，而溶液的 Tb 无定值。**

| 系统 | 条件自由度计算 | 结论 |
| :--- | :--- | :--- |
| 纯 A，外压一定 | f\* = 1 − 2 + 1 = 0 | Tb\* 不可变，有确定值 |
| A + B 溶液，外压一定 | f\* = 2 − 2 + 1 = 1 | Tb 可变，无确定值 |

**例 3：105 Pa 下，NaCl 饱和水溶液与 NaCl(s) 平衡共存时，溶解度与温度互为单值函数。**

```
f* = 2 − 2 + 1 = 1
```

只有一个条件自由度——指定温度则溶解度确定，指定溶解度则温度确定。

**例 4：Na2CO3(s) 与水可形成三种固体水合物，求与溶液及冰共存的含水盐可能有几种？**

设与溶液及冰共存的含水盐有 n 种，则总相数 P = n + 2（n 种水合物 + 溶液 + 冰），C = 2（Na2CO3 与 H2O）：

```
f = C − P + 2 = 2 − (n + 2) + 2 = 2 − n ≥ 0     →     n ≤ 2
```

即任意条件下，最多 **2 种**含水盐能与溶液及冰同时共存。

若在指定压力 pθ 下，改用条件自由度：

```
f* = C − P + 1 = 2 − (n + 2) + 1 = 1 − n ≥ 0     →     n ≤ 1
```

即定压下最多 **1 种**含水盐与溶液及冰共存。

> **易错点：** 这类题的关键是**先把相数用"n + 常数"表示出来**，再用 f ≥ 0（或 f\* ≥ 0）解出 n 的上限。注意区分 f 与 f*。

### 7. 课堂练习：H2(g) + I2(g) = 2HI(g) 的自由度

| 初始条件 | C | f |
| :--- | :--- | :--- |
| (1) 反应初始只有 HI(g) | 3 − 1 − 1 = 1 | 1 − 1 + 2 = 2 |
| (2) 初始 H2 与 I2 物质的量相等 | 3 − 1 − 1 = 1 | 1 − 1 + 2 = 2 |
| (3) 初始有任意量的 H2 与 I2 | 3 − 1 − 0 = 2 | 2 − 1 + 2 = 3 |

三者的差别只在 R'：起始条件是否额外提供了浓度限制。

## 七、相图的基本概念与单组分系统

### 1. 相图

**相图（平衡状态图）：** 表示相平衡体系的状态与影响相平衡的强度因素的关系的几何图形。另一种表述：用来表示多相系统的状态随温度、压力和组成等变量的改变而改变的图形。

分析相图要明确相图中**点、线、面**的关系。

### 2. 单组分系统的相律分析

```
C = 1   →   f = C − P + 2 = 3 − P
```

| 平衡类型 | P | f | 几何对应 |
| :--- | :--- | :--- | :--- |
| 单相平衡 | 1 | 2 | 面（双变量） |
| 两相平衡 | 2 | 1 | 线（单变量） |
| 三相平衡 | 3 | 0 | 点（无变量） |

```
单组分系统的自由度最多为 2，最多可能的相数为 3。
```

### 3. 水的相图（p-T 图）

拓扑示意（纵轴为压力 p，横轴为温度 T）：

```
        p ↑
          │   冰(s)
          │     ╲
          │  OA  ╲       水(l)
          │       ╲     ╱
          │        ╲   ╱  OC
          │         ╲ ╱
          │          ● O    ← 三相点
          │         ╱ ╲
          │    OD  ╱   ╲
          │       ╱     ╲
          │   气(g)      ● C    ← 临界点
          └─────────────────────→ T
```

**四条曲线的含义：**

| 曲线 | 含义 | 要点 |
| :--- | :--- | :--- |
| OA | 冰的饱和蒸气压曲线（升华线） | 冰—气两相平衡；f = 1 |
| OB | 冰和水的平衡曲线（熔化线） | **斜率为负**（冰的密度小于水）；OB **不可无限延长**，超高压下冰有多种晶形 |
| OC | 水的饱和蒸气压曲线（蒸发线） | 止于临界点 C（Tc = 647.2 K，pc = 2.206×10⁷ Pa）；临界点以上为**超临界状态** |
| OD | 过冷水的饱和蒸气压曲线 | **亚稳态**，f = 1 |

**三个面（单相区）：** 冰、水、水蒸气，各 f = 2。

**两相平衡曲线：** f = 1 − 2 + 2 = 1，单变量，所以 p 与 T 之间存在一一对应关系。

**三相点 O：** 气-液-固三相共存，P = 3，f = 0。H2O 的三相点温度为 **273.16 K**，压力为 **610.62 Pa**（≈611 Pa）。

```
三相点是物质自身的特性（与外界条件无关，只由物质本性决定）。
1967 年国际计量大会决定，将热力学温度 1 K 定义为水的三相点温度的 1/273.16。
```

> **科学史注记：** 清华大学化学系黄子卿教授（1929—1952 年在校任教）于 1938 年精确测定水的三相点为 0.00981 ± 0.00005 ℃，该结果被美国华盛顿哲学会主席 Stimson 推崇为水的三相点可靠数据之一，并成为 1948 年国际实用温标（IPTS-1948）选择基准点——水的三相点——的参照数据之一。

### 4. 三相点与冰点的区别（重点辨析）

| 项目 | 三相点 | 冰点 |
| :--- | :--- | :--- |
| 系统类型 | **单组分**体系（纯水） | **多组分**体系（含空气的稀溶液） |
| 共存相 | 气 + 液 + 固（都是纯水） | 空气 + 冰 + 水（稀溶液） |
| C | 1 | 2 |
| P | 3 | 3 |
| f | 1 − 3 + 2 = 0 | 2 − 3 + 2 = 1 |
| 温度 | 273.16 K | 273.15 K |
| 压力 | 610.62 Pa（水自身蒸气压） | 101325 Pa（外压） |

**冰点的定义：** 在 101.325 kPa 下，被空气所饱和的水的凝固点。

**为什么冰点比三相点低 0.01 K？** 由两个因素叠加造成：

| 因素 | 温度降低 |
| :--- | :--- |
| (1) 外压由 610.62 Pa 增加到 101325 Pa，使凝固点下降 | 0.00749 K |
| (2) 水中溶有空气，使凝固点下降 | 0.00242 K |

> **记忆点：** 三相点是"纯水自己的事"（f = 0，只由物质本性决定）；冰点是"水在空气中、一个大气压下的凝固点"（f = 1，受外压与溶气影响）。二者在组分数、自由度数、温度、压力上全都不同。

### 5. 相图上的过程分析

**等压加热过程（沿水平线 abcd 从左到右）：**

| 位置 | 相态 | 条件自由度 f\* = 1 − P + 1 | 加热时的现象 |
| :--- | :--- | :--- | :--- |
| ab 之间 | 固态冰单相 | f\* = 1 | 升温，相态不变 |
| b 点 | 液固两相平衡 | f\* = 0 | 温度不变（冰全部熔化后才继续升温） |
| bc 之间 | 液态水单相 | f\* = 1 | 升温，相态不变 |
| c 点 | 液气两相平衡 | f\* = 0 | 温度不变（水全部汽化后才继续升温） |
| cd 之间 | 气态水单相 | f\* = 1 | 升温，相态不变 |

> **思考：** 等温加压过程如何分析？——固定 T，沿竖直线由低压到高压，依次经历气 → 气液共存（f\* = 0，压力不变，气体液化）→ 液 → 液固共存（f\* = 0，压力不变，液体凝固）→ 固。

## 八、Clapeyron 方程

### 1. 问题的提出

纯物质呈两相平衡时：

```
C = 1，P = 2   →   f = 1 − 2 + 2 = 1
```

即 T、p 中只有一个独立变量，两相平衡时 p 与 T 之间存在确定的函数关系 p = f(T)。这个函数关系是什么？对纯物质的任意两相平衡（g-l、g-s、l-s）都要求解。

### 2. 推导

设纯物质 B 在 T、p 下呈 α、β 两相平衡：

```
B(α相, T, p)  ⇌  B(β相, T, p)
```

由相平衡条件：

```
μB(α, T, p) = μB(β, T, p)
```

沿两相平衡线（T、p 同时变化但仍保持平衡）取全微分，等式仍成立：

```
dμB(α) = dμB(β)
```

对纯物质，由基本关系式 dμ = −Sm dT + Vm dp：

```
−Sm(α)dT + Vm(α)dp = −Sm(β)dT + Vm(β)dp
```

移项整理：

```
[Vm(β) − Vm(α)] dp = [Sm(β) − Sm(α)] dT

dp/dT = [Sm(β) − Sm(α)] / [Vm(β) − Vm(α)] = ΔSm / ΔVm
```

对**可逆相变**（等温等压、W' = 0），有 ΔSm = ΔHm/T，代入得：

```
dp/dT = ΔHm / (T ΔVm)
```

**Clapeyron（克拉贝龙）方程：**

```
dp/dT = ΔHm / (T ΔVm)
```

### 3. 三点说明

| 说明 | 内容 |
| :--- | :--- |
| (1) 适用范围 | 适用于**单组分**的**任意两相平衡** |
| (2) 一致性 | ΔHm 和 ΔVm 必须对应于**同一个相变过程**（不能一个用汽化、一个用熔化） |
| (3) 不适用情形 | **不适用于无相变热和无体积变化的相变（二级相变）**。因为此时 ΔHm = 0、ΔVm = 0，方程右端为 0/0，失去意义 |

### 4. 液-气、固-气平衡：Clausius-Clapeyron 方程

对液-气或固-气平衡，凝聚相（液或固）的体积远小于气相的体积：

```
ΔVm = Vm(g) − Vm(l 或 s) ≈ Vm(g)
```

若气体为**理想气体**：

```
Vm(g) = RT/p
```

代入 Clapeyron 方程：

```
dp/dT = ΔHm / (T · RT/p) = p ΔHm / (RT²)
```

两边除以 p：

```
d ln p / dT = ΔHm / (RT²)
```

这就是**克劳修斯-克拉贝龙方程（克-克方程）的微分形式**：

```
d ln p / dT = ΔHm / (RT²)
```

若 ΔHm 视为常数，作不定积分：

```
ln p = −ΔHm / (RT) + C
```

其中 p 取相对压力（即 p/pθ，注意 p 必须是无量纲的相对值，否则对数无意义，故严格写作 ln(p/pθ)）。

若取两个温度 T1、T2：

```
ln(p2/p1) = −(ΔHm/R)(1/T2 − 1/T1) = (ΔHm/R)(1/T1 − 1/T2)
```

**克-克方程的定积分形式（最常用）：**

```
ln(p2/p1) = (ΔHm/R)·(1/T1 − 1/T2)
```

- 描述纯物质液-气或固-气两相平衡且蒸气为理想气体时，饱和蒸气压随温度的变化关系；
- **非常实用**：已知一个温度下的蒸气压和相变焓，可求另一温度下的蒸气压；反之亦可求 ΔHm；
- 由 ln p 对 1/T 作图为直线，斜率为 −ΔHm/R，这是实验测定相变焓的常用方法。

### 5. 固-液平衡

对固-液平衡**不能**作"气相体积占优"的近似（两相体积同量级），必须直接用 Clapeyron 方程：

```
dp/dT = ΔHm / (T ΔVm)
```

其中 ΔHm 为摩尔熔化焓（ΔfusHm > 0），ΔVm 为摩尔熔化体积变化。斜率的正负取决于 ΔVm：

| 情形 | ΔVm | dp/dT | 物理意义 | 实例 |
| :--- | :--- | :--- | :--- | :--- |
| 多数物质 | > 0 | > 0 | **压力增大，熔点升高** | 大多数金属、有机物 |
| 少数物质 | < 0 | < 0 | **压力增大，熔点降低** | 冰 → 水、铋、锑、镓 |

**水的特殊性：** 冰的密度小于水的密度，冰熔化为水时体积**减小**，ΔfusVm < 0，因此 p↑ 时 Tf\*↓，相图上 OB 线**斜率为负**。

> **思考：为什么滑冰鞋冰刀下冰的熔点更低？** 冰刀对冰面施加很大压力，p↑ → Tf\*↓，刀刃下的冰在低于 0 ℃ 时即可熔化形成水膜，起润滑作用。这正是 OB 线斜率为负的直接后果。

### 6. Trouton 规则（仅供了解）

对**正常液体**（非极性的、分子不缔合的），其**正常沸点**（外压为 101.325 kPa 时的沸点）与摩尔汽化焓之间近似满足：

```
ΔvapHm / Tb ≈ 88 J·K⁻¹·mol⁻¹
```

这是关于摩尔蒸发热的近似规则，可用于估算未知液体的汽化焓或沸点。对缔合液体（如水、醇）偏差较大。

## 九、二组分系统的气-液平衡相图

### 1. 相律分析与"降维"处理

```
C = 2   →   f = C − P + 2 = 4 − P
```

- 最大自由度 fmax = 3（P = 1 时），需要 T、p、组成三个变量——**三维坐标**；
- 最大相数 Pmax = 4（f = 0 时）。

三维相图不便使用，通常**固定一个变量**做成平面相图：

| 固定变量 | 相图类型 | 坐标轴 | 使用频率 |
| :--- | :--- | :--- | :--- |
| T 固定 | p-x 图 | 压力—组成 | 较常用 |
| p 固定 | T-x 图 | 温度—组成 | **最常用** |
| x 固定 | p-T 图 | 压力—温度 | 用得最少 |

### 2. 理想的两组分液态混合物（p-x 图）

液相中两组分均服从 Raoult 定律（第三章）：

```
pA = pA* xA
pB = pB* xB
```

总压：

```
p = pA + pB = pA* xA + pB* xB = pA* + (pB* − pA*)xB
```

可见 **p 与 xB 成线性关系**——液相线是一条直线。

**气相组成分析：** 设气相中 B 的摩尔分数为 yB，由分压定律 pB = p yB：

```
yB = pB / p = pB* xB / p
```

**结论：理想溶液中易挥发组分在气相中的含量大于它在液相中的含量，反之亦然。**

证明：若 pB\* > pA\*（B 为易挥发组分），则

```
p = pA* xA + pB* xB < pB*(xA + xB) = pB*
yB = pB* xB / p > xB
```

因此 **yB > xB**。

**相图结构（p-x 图，等温）：**

| 元素 | 内容 |
| :--- | :--- |
| 液相线 | **直线**（p 与 xB 的关系） |
| 气相线 | **曲线**（p 与 yB 的关系），位于液相线**下方** |
| 单相区 | 液相 l（f\* = 2）、气相 g（f\* = 2） |
| 两相区 | l + g（f\* = 1） |

> **注意：** p-x 图上"气相线位于液相线下方"是**等温**条件下的结论。到 T-x 图（等压）中，气相在上、液相在下，方向相反。

### 3. 相图中点、线、面的含义

| 术语 | 定义 |
| :--- | :--- |
| **物系点** | 表示系统**总组成**的点 |
| **相点** | 表示某个相中组分组成的点 |
| **露点** | 在一定压力下，混合气体**开始冷凝**（开始出现第一个液滴）时的温度 |
| **泡点** | 在一定压力下，混合液体**开始沸腾**（开始有气泡产生）时的温度 |

**两条基本规则：**

1. 在**单相区**中，物系点和相点**重合**；
2. 在**两相区**中，物系点与两个相点时，二者之间满足杠杆规则。

### 4. T-x 图（等压气液平衡相图，最常用）

在 p 固定时，以 T 为纵轴、组成 xB（或 yB）为横轴：

- **露点线（气相线）**：上方的曲线，其上各点给出气相组成，对应气体开始冷凝的温度；
- **泡点线（液相线）**：下方的曲线，其上各点给出液相组成，对应液体开始沸腾的温度；
- 两线之间为 **g + l 两相区**（f\* = 1）；
- 两线在纯 A（xB = 0）和纯 B（xB = 1）处交于 Tb,A\*、Tb,B\* 两个纯组分沸点。

| 相区 | 相态 | 条件自由度 f\* = 2 − P + 1 |
| :--- | :--- | :--- |
| 上方 | 气相 g | 2 − 1 + 1 = 2 |
| 中间 | 气液两相 g + l | 2 − 2 + 1 = 1 |
| 下方 | 液相 l | 2 − 1 + 1 = 2 |

**物系点与相点的关系：**

- (a) 在单相区中，物系点与相点**重合**；
- (b) 在两相平衡时，物系点与两个相点位于**同一条水平线**上；
- (c) 封闭体系中发生相变时（总组成不变），物系点**沿垂线**变化。

### 5. 杠杆规则

设物系点 O 的总组成为 Xo，两相平衡时液相点 a（组成 xB(l)）、气相点 b（组成 yB(g)），液相物质的量 n(l)、气相物质的量 n(g)。

由**质量守恒**（对 B 组分）：

```
n(l)·xB(l) + n(g)·yB(g) = n总·Xo
n(l) + n(g) = n总
```

将第二式代入第一式，整理得：

```
n(l)·[Xo − xB(l)] = n(g)·[yB(g) − Xo]
```

在 T-x 图上，a、O、b 依次排列，线段长度 Oa = Xo − xB(l)，Ob = yB(g) − Xo，于是：

```
n(l)·Oa = n(g)·Ob
n(l) / n(g) = Ob / Oa
```

**杠杆规则：** 在多组分体系的相图中，任意两个平衡相的物质数量**反比于**它们的相点到物系点的距离。

| 要点 | 内容 |
| :--- | :--- |
| ① 适用条件 | 适用于**任意两相区** |
| ② 实质 | **质量守恒** |
| ③ 质量分数形式 | 当组成为质量分数时同样适用：m(l)/m(g) = Ob/Oa；且 m(l)/m总 = Ob/ab |
| ④ 直观记忆 | 物系点越靠近某个相点，该相的量越大（"近多重少"） |

> **注意：** 杠杆规则两端是两个相点，支点是物系点。写比值时注意是**反比**——距离长的那一段对应量少的相。

### 6. 蒸馏与精馏的原理

| 操作 | 原理 | 结果 |
| :--- | :--- | :--- |
| 简单蒸馏（一次部分汽化） | 加热使液体部分汽化，气相中富集易挥发组分 | 只能达到有限的分离程度 |
| 精馏（多次蒸馏） | 将气相和液相分别进行**反复多次的部分液化**和**反复多次的部分汽化** | 可在塔顶得到纯的易挥发组分，塔釜得到难挥发组分 |

**精馏塔的构造与流程：** 塔釜加热，塔顶冷凝；进料口以上为精馏段（气相向上、液相回流），进料口以下为提馏段；塔顶得到低沸点组分 A(l)，塔釜得到高沸点组分 B(l)。

> **关键理解：** 精馏的本质是把"一次部分汽化 + 一次部分液化"的操作**串联多次**，等价于在相图上反复使用露点线与泡点线，逐步把组成推向两端。

## 十、非理想的二组分液态混合物

### 1. 偏差产生的原因

| 原因 | 微观解释 | 偏差方向 |
| :--- | :--- | :--- |
| (1) 缔合解离 | 某一组分 A 本身有缔合现象，与 B 混合时缔合分子解离，**分子数增加** | **正偏差**（蒸气压增加） |
| (2) 形成化合物 | A、B 混合时部分形成化合物，**分子数减少** | **负偏差**（蒸气压下降） |
| (3) 分子间引力不同 | A、B 分子间引力与同种分子间不同，使体积改变或作用力改变 | **可正可负** |

### 2. 三类相图

**类型一：与理想溶液偏差不大**

| 项目 | 正偏差不大 | 负偏差不大 |
| :--- | :--- | :--- |
| p-x 图 | 液相线、气相线仍近似直线，但偏离 | 同左，方向相反 |
| 蒸气压范围 | **仍介于 pA\* 与 pB\* 之间** | 同左 |
| T-x 图 | 与理想溶液的相似（透镜形） | 同左 |

**类型二：正偏差很大（如 水-乙醇 系统）**

```
p-x 图上有最高点  →  T-x 图上有最低点，称为最低恒沸点（azeotropic point）
溶液蒸气压不再介于 pA* 与 pB* 之间
具有最低恒沸点组成的混合物称为最低恒沸混合物
```

**类型三：负偏差很大（如 H2O-HNO3、H2O-HCl 系统）**

```
p-x 图上有最低点  →  T-x 图上有最高点，称为最高恒沸点
T-x 图上有最高恒沸点
```

> **记忆点：** **p-x 图的最高点 ↔ T-x 图的最低点；p-x 图的最低点 ↔ T-x 图的最高点。** 因为蒸气压越大，沸点越低，两图互为"上下镜像"。

### 3. 恒沸物及其特点

**恒沸物：** 具有恒沸点组成的溶液。

| 特点 | 内容 |
| :--- | :--- |
| (1) 气液同组成 | **xB = yB**，气、液相组成相同 |
| (2) 是混合物而非化合物 | 恒沸物的组成**随外压变化而变化**，甚至可能消失；化合物的组成则有定值，不随外压改变 |
| (3) 不能用普通精馏分离 | 具有恒沸物的系统，**不能用一般的精馏方法同时得到两种纯组分** |
| (4) 定压下组成有定值 | 其组成在定压下有定值；**在特定压力下，恒沸点处的自由度数为 0**（因为多了浓度限制条件） |

**为什么恒沸点处 f\* = 0？** 定压下本来是 f\* = C − P + 1 = 2 − 2 + 1 = 1；但恒沸时气液两相组成相同（xB = yB）构成一个额外的浓度限制条件（R' = 1），相当于有效 C 降为 1，于是 f\* = 1 − 2 + 1 = 0。也就是说，在给定压力下，恒沸温度和恒沸组成都被"锁死"，不能独立改变。

### 4. 恒沸物组成随外压变化（示例数据）

以 H2O(A)-C2H5OH(B) 系统为例：

| p / kPa | 恒沸温度 / ℃ | 恒沸物 wB / % |
| :--- | :--- | :--- |
| 17.29 | 39.20 | 98.7 |
| 53.54 | 63.04 | 96.25 |
| 101.33 | 78.15 | 95.6 |
| 193.49 | 95.35 | 95.25 |

**结论：** 恒沸组成随外压**明显改变**——这是"恒沸物是混合物而不是化合物"的直接实验证据。

> **思考：若将 50% 的乙醇水溶液精馏，会得到什么？** —— 塔釜得到**纯水**（难挥发组分），塔顶得到**恒沸物**（约 95.6% 乙醇）。这正是普通精馏无法由稀乙醇制得无水乙醇的原因。

## 十一、部分互溶液体系统的液-液相图

### 1. 部分互溶与共轭溶液

在常温常压下，两种液体常**部分互溶**。以水(A)-异丁醇(B) 在 20 ℃、pθ 下逐渐往水中滴加异丁醇为例：

| 组成范围 | 相态 |
| :--- | :--- |
| 0 < wB < 8.5% | 单一液相：异丁醇的水溶液 |
| 8.5% < wB < 83.6% | **两液相共存**（共轭溶液）：上层为水的异丁醇溶液，下层为异丁醇的水溶液 |
| 83.6% < wB < 100% | 单一液相：水的异丁醇溶液 |

**共轭溶液：** 两个平衡共存的液层。

**温度的影响：** 升高温度，彼此的溶解度一般都增加；升温到达某一温度，界面消失，成为单一液相——该温度称为**临界溶解温度**。

### 2. 液-液相图的形状（"帽形"）

以水-异丁醇系统为例，其 T-wB 图呈**帽形**：

| 元素 | 内容 |
| :--- | :--- |
| 左支曲线 | B 在 A 中的溶解度曲线（异丁醇在水中的溶解度随温度升高而增大） |
| 右支曲线 | A 在 B 中的溶解度曲线（水在异丁醇中的溶解度随温度升高而增大） |
| 帽顶 C | **最高临界溶解点 C**（最高临界溶解温度 Tc，又称最高会溶温度） |
| 帽内区域 | l1 + l2 两液相共存区（共轭溶液） |
| 帽外区域 | 单一液相区 l |
| 等温水平线与两支曲线的交点 | 该温度下两平衡液层的组成（共轭配对点） |

对水-异丁醇，Tc ≈ 406 K；温度高于 Tc 时，两液体完全互溶为单一液相。

**相图特点：**

```
① 形状似"帽子"：帽形区以外为单相区，以内为共轭溶液共存
② 温度升高，互溶程度增加（帽形区变窄），直到最高会溶温度 C 处合拢
③ 等温线上两支曲线的交点称为共轭配对点，连线中点近似为该温度下两液层的平均组成
```

### 3. 其它形式的部分互溶相图

| 类型 | 特征 | 实例 |
| :--- | :--- | :--- |
| 具有**最高**临界溶解温度 | 温度升高互溶度增大，"帽口朝上" | 水-异丁醇、水-苯胺 |
| 具有**最低**临界溶解温度 | 温度降低互溶度增大，"帽口朝下" | 水-三乙胺 |
| 兼具最低和最高临界溶解温度 | 曲线围成一个**封闭环**，环内为两液相共存区 | 水-烟碱 |
| 无临界溶解温度 | 在液相存在的整个温度区间内一直部分互溶 | 某些系统 |

### 4. 相图的应用

**用途：预测相变。** 已知相图，给定温度与组成即可判断系统处于单相还是两相；反之，指定相态变化可反推温度或组成条件。

> **思考（课件）：**
> (1) 373 K、pθ 下，向 H2O 中逐渐加入 C6H5NH2（苯胺），相态如何变化？——由单相（水相）进入两相区，出现共轭溶液，继续加至帽形区另一侧则又变为单相（苯胺相）。
> (2) pθ 下，wB = 70% 的溶液逐渐升温，相态如何变化？——若初始在两相区，升温使两液层溶解度增大，最终在临界溶解温度之上变为单一液相。

## 十二、二组分系统的固-液平衡相图

### 1. 总述

由于**压力对固-液平衡影响很小**，所以一般固-液平衡相图只作 **T-x 图**。液体降低到一定温度，将有固体析出。

以下只讨论**液相完全互溶**的情况，共包括四种典型相图：

```
1. 具有简单低共熔混合物的相图
2. 具有稳定化合物的相图
3. 具有不稳定化合物的相图
4. 形成固溶体的相图
```

### 2. 测定固-液相图的两种方法

| 方法 | 原理 | 常用对象 |
| :--- | :--- | :--- |
| **热分析法** | 先将组成恒定的系统加热使其完全熔化，然后令其**缓慢冷却**，记录冷却过程中系统在不同时刻的温度，以温度为纵坐标、时间为横坐标绘出 **T-t 曲线**（称为**步冷曲线**），以此为基础绘制相图 | 合金系统 |
| **溶解度法** | 在确定的温度下，直接测定固液两相平衡时液相和固相的组成（溶解度），以此为基础绘制相图 | 水盐系统 |

**步冷曲线的读法（核心技能）：**

| 曲线特征 | 含义 |
| :--- | :--- |
| 平滑下降 | 单相冷却，无相变（或仅有固相析出但潜热小） |
| 出现**折点**（斜率变小） | 开始有新相析出（如开始析出固体），放出凝固潜热，冷却变慢 |
| 出现**水平段** | 三相共存，f\* = 0，温度不变（如低共熔、化合物分解、固溶体共晶转变） |

### 3. 简单低共熔混合物系统的相图

以 Bi-Cd（铋-镉）系统为例：相图由两条液相线汇聚于一点 E（低共熔点），下方为 A(s) + B(s) 两固相区。

| 相区 | 相态 | 条件自由度 f\* = 2 − P + 1 |
| :--- | :--- | :--- |
| 上方 | 液相 l | 2 − 1 + 1 = 2 |
| 左下方 | l + A(s) | 2 − 2 + 1 = 1 |
| 右下方 | l + B(s) | 2 − 2 + 1 = 1 |
| 底部 | A(s) + B(s) | 2 − 2 + 1 = 1 |
| 水平线（三相线） | l + A(s) + B(s) | 2 − 3 + 1 = 0 |

**低共熔混合物与低共熔点：**

- **低共熔混合物（共晶物）：** 由两种或两种以上的纯固体所组成的、具有最低共熔温度的多相混合物；
- **低共熔点（共晶点，Eutectic Point）：** 低共熔混合物的熔点。

**两个要点：**

1. 低共熔点代表一个**特定的温度**，低共熔混合物具有一个**特定的组成**；
2. 低共熔点处是一个**三相平衡点**，f\* = C − P + 1 = 2 − 3 + 1 = 0。

**水-盐相图（溶解度法）：** 以 (NH4)2SO4-H2O 为例，ME 曲线是硫酸铵水溶液的凝固点曲线（冰析出线），NE 曲线是硫酸铵的溶解度曲线，E 点为低共熔点，下方为 (NH4)2SO4(s) + H2O(s) 两固相区。

### 4. 生成稳定化合物的相图

**稳定化合物：** 化合物升温至熔化前**一直不分解**，在熔化时**液相和固相的组成相同**，即**有自己的熔点**（称为**相合熔点**，congruent melting point）。

**特点：**

1. 该化合物在熔点以下是稳定的；
2. 相合熔点处化合物熔化时液相与固相有相同的组成（相图上表现为化合物组成对应的**尖峰**）。

**相图特征：** 相当于**两个简单低共熔相图"拼接"**而成，中间以化合物的组成竖线为界。

### 5. 生成不稳定化合物的相图

**不稳定化合物：** 化合物在达到熔点**之前就发生分解**，表现出不稳定性。其"熔点"实际上是**不相合熔点**（incongruent melting point，又称转熔温度）。

**实例：** CaF2·CaCl2(s) 在 737 ℃ 分解。

**相图特征：** 化合物组成对应的竖线**不能延伸到液相区**（因为它在熔化前已分解），而是终止在一条水平线上，该水平线代表"化合物 → 固相 + 液相"的转熔反应。

> **易错点：** 稳定化合物与不稳定化合物的区别，就看化合物组成对应的竖线**能否一直延伸到液相区**。能，则熔化时液相与固相组成相同（相合熔点，稳定）；不能，则熔化前已分解（不相合熔点，不稳定）。

### 6. 生成固溶体的两组分系统

**固溶体：** 两种或两种以上的组分在**固态**条件下相互溶解形成的**单相固态溶液**。

| 类型 | 形成条件 | 实例 |
| :--- | :--- | :--- |
| **取代型（代换式）** | 两种组分粒子（分子、原子、离子）**大小接近**，在晶格中互相取代 | Au-Ag、Ni-Cu |
| **镶嵌型（填隙式）** | 两种组分粒子**尺度相差较大**，由小粒子镶嵌在大粒子晶格空隙中 | Fe-C、Ni-C |

**（1）形成完全互溶固溶体的相图**

相图形状与**双液系的气液平衡相图相似**（透镜形），上方为液相 l，下方为固相 s，中间为 l + s 两相区。

**实际问题：**

- 由于**扩散**的限制，冷却过快会使析出的固体成分不均匀，形成"**枝晶偏析**"；
- **退火：** 将固体的温度升高到接近熔化温度，保持一定时间加热，使合金内部组成均匀，可消除枝晶偏析。

也可形成具有**最低熔点**或**最高熔点**的固溶体。

**（2）部分互溶的固溶体**

系统具有一个**低共熔点（共晶转变温度）** E：

```
S(I)：B(s) 在 A(s) 中形成的固溶体
S(II)：A(s) 在 B(s) 中形成的固溶体
共晶反应：l ⇌ S(I) + S(II)
```

这类系统液相完全互溶、固相部分互溶。实例：Cu(s)-Ag(s)。

### 7. 二组分相图小结

**（1）点、线、面的含义与 f\***

等压条件下：

```
f* = C − P + 1 = 2 − P + 1 = 3 − P
```

## 十三、三组分系统与分配定律

### 1. 相律分析

```
f = C − P + 2 = 3 − P + 2 = 5 − P
```

- 最大相数 Pmax = 5；
- P = 1 时 fmax = 4（需要四维坐标，无法直接图示）；
- 若 T、p 均指定，则 **f\* = 3 − P**，f\*max = 2，可用**平面图**表示。

三组分系统的平面相图通常用**等边三角形坐标**表示组成（本课程大部分内容以自学为主）。

**应用广泛的三组分相平衡系统：** 分配平衡、三液系统、二盐-水系统。

### 2. 分配定律

**内容：** 设物质 B 能溶于 α 和 β 两种液体中，且 α 和 β **完全不相互溶**（例如水和四氯化碳）。实验表明，在等温等压下若将 B 溶解在共存的 α 和 β 两种液体里，在**低浓度范围内**，B 在两相中的浓度比等于常数：

```
cB(α) / cB(β) = K
```

其中 **K 为分配系数**，与 T、p、溶质和两个溶剂的本性相关。

> **重要限制：** 分配定律**仅适用于分子形态相同**的条件。若溶质在某一相中发生缔合或解离，则不能直接使用浓度的简单比值。

### 3. 分配定律的热力学证明

相平衡时，B 在两相中的化学势相等：

```
μB(α) = μB(β)
```

由化学势通式（第三章）：

```
μBθ(α) + RT ln aB(α) = μBθ(β) + RT ln aB(β)
```

移项：

```
RT ln[aB(α)/aB(β)] = −[μBθ(α) − μBθ(β)]
aB(α)/aB(β) = exp{−[μBθ(α) − μBθ(β)]/RT} = K
```

对稀溶液，活度可用浓度代替，即得 cB(α)/cB(β) = K。

**结论：** K 只与 T、p 以及溶质、两溶剂的本性有关，与溶质总浓度无关（在低浓度范围内）。

### 4. 自由度分析

对上述三组分分配平衡系统（T、p 已固定，P = 2）：

```
f* = C − P + 0 = 3 − 2 + 0 = 1
```

表明两个浓度之间只有一个独立变量——给定一相中的浓度，另一相中的浓度即由分配定律确定。

### 5. 萃取

**萃取：** 将溶在 α 相中的溶质抽提到**不与 α 相互溶**的 β 相中的过程。例如用四氯化碳萃取水中的碘。

> **思考：分配定律的浓度关系是否可以作为计算独立组分数时的固定浓度限制条件 R'？**
> **不能。** 因为 R' 要求是**同一相中**几种物质浓度之间的关系，而分配定律描述的是**两个不同相**之间的浓度关系；且它本身就是相平衡条件的推论，已隐含在"化学势相等"这一条件中，不能重复计入。

## 十四、易错点清单

1. **相数判断不能凭直觉**：气体无论多少种都只有一相；固体要看**晶型与化学组成**，不看颗粒大小（大块与粉末的 CaCO3 是同一相）。
2. **固溶体是单相**，不是两相。
3. 相平衡只要求每种物质**在它所存在的各相中**化学势相等，不要求每种物质存在于所有相。
4. **R 是独立化学反应数**，不是写出的反应式个数；线性相关的反应要剔除。
5. **R' 必须是同一相内**的浓度关系。CaO(s) 与 CO2(g) 不在同一相，不能构成 R'。
6. **ΣxB = 1 不算 R'**，它是每相都有的定义性约束，已在相律推导的第 a 类方程中计入。
7. **f ≥ 0** 是判断相数是否合理的依据；算出 f < 0 说明该相数组合不可能存在。
8. **f 与 f\* 要分清**：f 用 "2"（T、p 都未固定），f\* 用 "1"（指定了 T 或 p）。
9. **广义相律 f = C − P + n** 中的 n 不一定是 2，要按实际外界变量数取值。
10. **相律只给出自由度数目**，不指出具体是哪几个变量。
11. **三相点 ≠ 冰点**：三相点是单组分系统（f = 0，273.16 K，610.62 Pa）；冰点是多组分系统（f = 1，273.15 K，101325 Pa）。
12. **Clapeyron 方程中 ΔHm 与 ΔVm 必须对应同一相变**；且不适用于二级相变（ΔHm = 0、ΔVm = 0）。
13. **水的 OB 线斜率为负**（ΔfusVm < 0），不要机械套用"加压熔点升高"。
14. **Clausius-Clapeyron 方程只适用于液-气、固-气平衡**，且假设蒸气为理想气体、凝聚相体积可忽略、ΔHm 近似为常数。**不能**用于固-液平衡。
15. 克-克方程中 ln p 的 p 必须**无量纲**（严格写 ln(p/pθ)），温度必须用**热力学温度**。
16. **p-x 图与 T-x 图的上下关系相反**：p-x 图气相线在下方，T-x 图气相线在上方。
17. **恒沸物不是化合物**：其组成随外压变化，这是判断依据。
18. **恒沸点处 f\* = 0**（定压下），原因是 xB = yB 构成额外浓度限制。
19. **有恒沸物的系统不能用普通精馏同时得到两种纯组分**。
20. 杠杆规则中两相物质的量**反比于**相点到物系点的距离（"近多重少"），不要写反。
21. **低共熔点处 f\* = 0**（等压下三相共存），且低共熔混合物有确定组成。
22. **稳定化合物与不稳定化合物**看化合物竖线能否延伸到液相区：能（相合熔点），不能（不相合熔点）。
23. **分配定律不能作为 R'**，因为它是跨相关系且已隐含在化学势相等条件中。
24. 步冷曲线的**水平段**对应三相共存（f\* = 0），**折点**对应开始析出新相。

## 十五、公式速查

| 名称 | 表达式 | 条件/说明 |
| :--- | :--- | :--- |
| 相律 | f = C − P + 2 | 相平衡系统 |
| 广义相律 | f = C − P + n | n 为外界强度变量数 |
| 条件自由度 | f\* = C − P + 1 | 指定 T 或 p |
| 独立组分数 | C = S − R − R' | R' 必须同相 |
| 单组分相律 | f = 3 − P | C = 1 |
| 二组分相律 | f = 4 − P | C = 2，fmax = 3 |
| 三组分相律 | f = 5 − P | C = 3，fmax = 4 |
| 相平衡条件 | μB(α) = μB(β) = … | 各相化学势相等 |
| Clapeyron 方程 | dp/dT = ΔHm/(T ΔVm) | 单组分任意两相平衡 |
| 液-气/固-气近似 | ΔVm ≈ Vm(g) = RT/p | 凝聚相体积可忽略 |
| 克-克方程（微分） | d ln p/dT = ΔHm/(RT²) | 蒸气为理想气体 |
| 克-克方程（不定积分） | ln p = −ΔHm/(RT) + C | ΔHm 视为常数 |
| 克-克方程（定积分） | ln(p2/p1) = (ΔHm/R)(1/T1 − 1/T2) | 最常用形式 |
| 固-液平衡 | dp/dT = ΔfusHm/(T ΔfusVm) | ΔVm < 0 时斜率为负 |
| Trouton 规则 | ΔvapHm/Tb ≈ 88 J·K⁻¹·mol⁻¹ | 正常液体，了解 |
| Raoult 定律 | pA = pA\* xA，pB = pB\* xB | 理想液态混合物 |
| 二组分总压 | p = pA\* + (pB\* − pA\*)xB | 液相线为直线 |
| 气相组成 | yB = pB\* xB/p | 气相线为曲线 |
| 易挥发判据 | pB\* > pA\* → yB > xB | 气相富集易挥发组分 |
| 杠杆规则 | n(l)·Oa = n(g)·Ob | 两相区；n(l)/n(g) = Ob/Oa |
| 杠杆规则（质量分数） | m(l)/m总 = Ob/ab | 组成用质量分数时 |
| 恒沸点自由度 | f\* = 0（定压） | 因 xB = yB 构成额外限制 |
| 低共熔点自由度 | f\* = 0（定压） | 三相共存：l + A(s) + B(s) |
| 分配定律 | cB(α)/cB(β) = K | 稀溶液、分子形态相同 |
| 分配系数 | K = exp{−[μBθ(α) − μBθ(β)]/RT} | 由 μB(α) = μB(β) 导出 |

## 十六、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **相与相数** | 物理化学性质完全均匀的部分；气体恒为一相，固体按晶型与组成计相，固溶体为单相 |
| **多相平衡条件** | 热平衡（T 相等）+ 力平衡（p 相等）+ 相平衡（组成不变）+ 化学平衡；化学势判据 μB 各相相等 |
| **独立组分数** | C = S − R − R'；S 可随视角变，C 与人为因素无关；R' 必须同相 |
| **自由度** | 确定状态所需的独立强度变量数；f ≥ 0 |
| **相律** | f = C − P + 2；由"总变量数 − 关联方程数"导出；指定 T 或 p 时 f = C − P + 1 |
| **相律的意义与局限** | 给出自由度数，不指出具体变量；可判断相数组合是否可能 |
| **单组分相图** | f = 3 − P；单相面（f = 2）、两相线（f = 1）、三相点（f = 0）；单组分最多三相共存 |
| **水的相图** | OA 升华线、OB 熔化线（斜率为负）、OC 蒸发线（止于临界点）、OD 过冷水（亚稳态）、O 三相点（273.16 K，610.62 Pa） |
| **三相点与冰点** | 单组分 f = 0 / 多组分 f = 1；冰点低 0.01 K = 外压贡献 0.00749 K + 溶气贡献 0.00242 K |
| **Clapeyron 方程** | dp/dT = ΔHm/(TΔVm)；ΔHm 与 ΔVm 对应同一相变；不适用于二级相变 |
| **克-克方程** | 液-气/固-气平衡，蒸气理想；ln(p2/p1) = (ΔHm/R)(1/T1 − 1/T2) |
| **二组分气液平衡** | f = 4 − P；固定一个变量降维；T-x 图最常用 |
| **理想溶液 p-x 图** | 液相线直线，气相线曲线且在下方；yB = pB\*xB/p；易挥发组分气相富集 |
| **物系点与相点** | 单相区重合；两相区在同一水平线上；封闭体系相变时物系点沿垂线移动 |
| **杠杆规则** | 两相物质的量反比于相点到物系点的距离；实质是质量守恒 |
| **精馏** | 多次部分汽化 + 多次部分液化；塔顶得低沸点组分，塔釜得高沸点组分 |
| **非理想系统** | 三种偏差原因；偏差不大 / 正偏差很大（最低恒沸点）/ 负偏差很大（最高恒沸点） |
| **恒沸物** | xB = yB；是混合物不是化合物（组成随外压变）；不能用普通精馏分离；定压下 f\* = 0 |
| **部分互溶液液** | 共轭溶液；帽形相图；最高/最低/封闭环/无临界溶解温度四类 |
| **固液平衡相图** | 压力影响小，只作 T-x 图；热分析法（步冷曲线）与溶解度法 |
| **四类固液相图** | 简单低共熔（f\* = 0 三相点）；稳定化合物（相合熔点）；不稳定化合物（不相合熔点）；固溶体（取代型/镶嵌型，完全/部分互溶） |
| **七张基本相图** | 理想溶液、恒沸混合物、部分互溶、简单低共熔、稳定化合物、不稳定化合物、固溶体 |
| **读图规律** | 竖线为纯物质；水平线为三相线；曲线为两相平衡线；两相区由相邻相区确定；上下相邻相区相数不同 |
| **三组分系统** | f = 5 − P；指定 T、p 后 f\* = 3 − P，可用平面图表示 |
| **分配定律** | cB(α)/cB(β) = K；仅适用分子形态相同；由化学势相等导出；用于萃取 |

## 十七、复习自测题

1. 什么是相？判断相数有哪几条基本规则？为什么气体无论多少种都只有一相，而两种固体粉末混合得再均匀仍是两相？
2. 判断下列系统的相数并说明理由：(1) 一杯牛奶；(2) 大块 CaCO3(s) 与粉末 CaCO3(s) 的混合物；(3) 水与乙醇的溶液；(4) 水与苯的溶液；(5) 一堆小冰块；(6) CaCO3(s) 与 CaO(s) 的混合粉末；(7) Fe(δ)、Fe(γ)、Fe(α) 共存。
3. 多相系统的热力学平衡包含哪四个平衡？相平衡的必要条件是什么？为什么不要求每一种物质存在于所有相中？
4. 为什么要引入独立组分数？它与物种数有何本质区别？试以水为例说明。
5. 写出 C = S − R − R' 中各符号的含义，并说明 R' 必须满足哪些条件。
6. 判断并计算下列系统的独立组分数：(1) 2HI(g) = H2(g) + I2(g)，起始只有 HI；(2) 碳在氧气中燃烧生成 CO 和 CO2；(3) NH4Cl(s) 在真空容器中分解；(4) NH4Cl(s) 在含 NH3 的容器中分解；(5) HCN 水溶液；(6) CaCO3(s) 在真空容器中分解。并说明每一题中 R' 取值的理由。
7. 什么是自由度？两种定义（"独立强度变量数"与"相态不变下可变动范围"）是否等价？
8. 从"总变量数 − 关联方程数"出发，完整推导 Gibbs 相律 f = C − P + 2，并说明每一类关联方程的来源与数目。
9. 相律有哪五点说明？什么是广义相律与条件自由度？为什么"2"有时要换成"1"？
10. 用相律解释：为什么纯液体的正常沸点有定值，而溶液的沸点没有定值？
11. NaCl 饱和水溶液与 NaCl(s) 在 105 Pa 下平衡共存时，为什么溶解度与温度互为单值函数？
12. Na2CO3 与水可形成三种固体水合物。证明：任意条件下最多 2 种含水盐能与溶液及冰共存；在 pθ 下最多 1 种。
13. 判断 H2(g) + I2(g) = 2HI(g) 在不同起始条件下的自由度数：(1) 初始只有 HI；(2) 初始 H2 与 I2 等量；(3) 初始 H2 与 I2 为任意量。并解释三者差异的来源。
14. 单组分系统的 f 与 P 有何对应关系？为什么单组分系统最多只能三相共存？
15. 画出水的相图，标出 OA、OB、OC、OD 四条曲线及三相点 O、临界点 C，说明每条曲线代表的相平衡与自由度，并指出 OB 线斜率为负的原因。
16. 比较三相点与冰点：系统组分数、相数、自由度、温度、压力各有什么不同？冰点比三相点低 0.01 K 由哪两个因素造成？
17. 说明水相图上等压加热过程（固态 → 液态 → 气态）中温度随加热的变化规律，并用条件自由度解释为什么在两相共存时温度不变。
18. 推导 Clapeyron 方程 dp/dT = ΔHm/(TΔVm)，并说明其适用条件与三条注意事项。
19. 由 Clapeyron 方程出发，推导 Clausius-Clapeyron 方程的微分形式与定积分形式，指出其中作了哪些近似。
20. 为什么 Clausius-Clapeyron 方程不能用于固-液平衡？固-液平衡的 dp/dT 正负由什么决定？举例说明。
21. 什么是 Trouton 规则？它对哪些液体适用、对哪些液体偏差大？为什么？
22. 二组分系统为什么通常要固定一个变量才能画出平面相图？p-x 图、T-x 图、p-T 图分别固定什么变量、各有什么用途？
23. 推导理想二组分液态混合物的总压表达式，说明为什么液相线是直线而气相线是曲线。证明易挥发组分在气相中的含量大于其在液相中的含量。
24. 什么是物系点、相点、露点、泡点？单相区与两相区中物系点与相点的关系有何不同？
25. 推导杠杆规则，说明它的实质、适用条件与使用要点。
26. 精馏为什么能实现分离？为什么有恒沸物的系统不能用普通精馏同时得到两种纯组分？
27. 非理想二组分液态混合物产生偏差的原因有哪三类？试分别说明其微观机制与偏差方向。
28. 正偏差很大与负偏差很大时，p-x 图与 T-x 图的极值点分别出现在何处？两者之间是什么对应关系？
29. 恒沸物有哪四个特点？如何判断恒沸物不是化合物？为什么恒沸点处 f\* = 0？
30. 画出部分互溶双液系的 T-w 相图，说明帽形区内外分别是什么相态、最高临界溶解温度的含义，并列举具有最低临界溶解温度、封闭环、无临界溶解温度的各一例。
31. 测定固-液相图的两种方法是什么？步冷曲线上的折点与水平段各代表什么？
32. 简单低共熔相图有几个相区？低共熔点处 P 与 f\* 各为多少？低共熔混合物是化合物吗？

34. 什么是固溶体？取代型与镶嵌型固溶体的形成条件与实例各是什么？什么是枝晶偏析与退火？
35. 二组分相图的七张基本类型分别是什么？复杂相图与它们是什么关系？
36. 读图时有哪些基本规律（竖线、水平线、曲线的意义）？为什么"垂直方向上相邻两相区的相数不同"？
37. 写出分配定律并说明其适用条件。如何由 μB(α) = μB(β) 导出分配系数的表达式？
38. 分配定律的浓度关系能否作为 R'？为什么？
