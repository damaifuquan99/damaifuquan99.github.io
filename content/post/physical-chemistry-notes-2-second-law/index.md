## 一、第一定律的局限：为什么还需要第二定律

第一定律 ΔU = Q − W 只说明能量守恒，**不能指出变化的方向和限度**。以下变化都不违反能量守恒，却不会自动发生：

| 例子 | 现象 |
| :--- | :--- |
| 氦气、氖气 | 高温、低温两种气体混合后不会自动分离 |
| 纯气体 | 两种气体混合后不会自动分开 |
| C(石墨) → C(金刚石) | 常温常压下不会自发转变 |
| H2(g) + 1/2O2(g) → H2O(l) | 放热 286 kJ/mol，加热也不能使之反向进行 |
| H+ + OH− → H2O | 极易进行，但最终 [H+][OH−] = 10⁻¹⁴，反应不进行到底 |

**第二定律的任务：判断过程的方向与限度。**

## 二、自发过程及其共同特征

### 1. 自发过程

在一定环境条件下，**无需外力推动、任其自然就能自动进行**的过程。

- 水：高水位 → 低水位
- 热：高温 → 低温
- 扩散：高浓度 → 低浓度

通常所说的"过程方向"就是指自发过程的方向。

### 2. 三条共同特征

1. 自发过程**单向地从不平衡走向平衡**，限度就是达到平衡；
2. 自发过程都**有做功本领**（水轮机、热机、浓差电池）；
3. 自发过程**都是不可逆过程**——让其返回时，环境无一例外要付出代价，**环境不可能复原**。

> **经典算例（课件）：** N2(4 kPa, 1 m³) → N2(1 kPa, 4 m³)，T = 273 K。
> 向真空膨胀（p外 = 0）：W = 0、Q = 0，自发；
> 反向压缩（p外 = 4 kPa）：W = −12 kJ、Q = −12 kJ，环境"得热失功"，无法复原。
> 除非能把环境中这 12 kJ 的热全部变成功——而这正是第二定律所禁止的。

### 3. 热功转换的不等价性

```
功 → 热：可以无代价、全部转化
热 → 功：不可能无代价、全部转化
```

- 并不是说热不能全部变成功，而是**必须付出代价**（系统或环境发生变化）；不付代价只能部分变功；
- 任何自发过程都与热功转换的不等价性相联系，这是第二定律的物理内核。

> **易错点：** "自发过程都是不可逆过程"——对；"不可逆过程都是自发过程"——错（如电解水、等温压缩，都是非自发的不可逆过程）。

## 三、第二定律的两种经典表述

| 表述 | 内容 |
| :--- | :--- |
| **Clausius 说法** | 热不可能从低温物体传到高温物体，而不引起其他变化 |
| **Kelvin 说法** | 不可能从单一热源取出热使之完全变为功，而不发生其他变化 |

- 两种说法**等价**，揭示的都是自然界过程的方向性；
- 等价表述：**第二类永动机不可能造成**（效率 100% 的热机不存在）；
- 第二定律是人类长期经验的总结，不需数学证明；
- **直接应用不方便**：任何不可逆过程都能转化为热功转换的不可逆性，但操作技巧高、难度大，因此需要更方便的判据（熵、A、G）。

## 四、卡诺循环与卡诺定理

### 1. 热机与效率

热机：通过工作介质把热转换为功的装置。工作于 T1（高温热源）与 T2（低温热源）之间：

```
η = W/Q1 = (Q1 + Q2)/Q1 = 1 + Q2/Q1        （Q2 < 0，故 η < 1）
```

### 2. 理想气体卡诺循环

以 n mol 理想气体为工作介质，由**两个等温可逆 + 两个绝热可逆**过程组成：

| 步骤 | 过程 | ΔU | Q | W |
| :--- | :--- | :--- | :--- | :--- |
| A→B | 等温可逆膨胀（T1） | 0 | Q1 = nRT1 ln(V2/V1) | 同 Q1 |
| B→C | 绝热可逆膨胀（T1 → T2） | nCv,m(T2 − T1) | 0 | = −ΔU |
| C→D | 等温可逆压缩（T2） | 0 | Q2 = nRT2 ln(V4/V3) < 0 | 同 Q2 |
| D→A | 绝热可逆压缩（T2 → T1） | nCv,m(T1 − T2) | 0 | = −ΔU |

两个绝热步的功相互抵消（W2 + W4 = 0），故：

```
W = Q1 + Q2
```

由绝热可逆过程方程可得 V2/V1 = V3/V4，于是：

```
ηr = 1 − T2/T1
```

> **结论：** 卡诺热机效率只取决于两个热源的温度，**与工作介质无关**。提高效率的根本途径是**增大冷热源温差**（降低 T2 比升高 T1 更有效）。

### 3. 卡诺定理（1824）

**所有工作于同温热源与同温冷源之间的热机，以可逆热机的效率最高。**

推论：

1. 所有可逆热机效率相同，且与工作介质无关；
2. 不可逆热机的效率必小于卡诺机。

```
η(不可逆) < ηr = 1 − T2/T1
η(可逆)   = 1 − T2/T1
```

### 4. 两个意义

- **实际意义**：给出了热机效率的上限，指明提高效率的方向；
- **理论意义**：Clausius 由此发现熵函数、导出 Clausius 不等式——这是整个第二定律定量化的起点。

## 五、熵与 Clausius 不等式

### 1. 熵函数的发现

对两个热源间的卡诺循环：

```
可逆：Q1/T1 + Q2/T2 = 0
不可逆：Q1/T1 + Q2/T2 < 0
```

对任意可逆循环，可用无限多个小卡诺循环逼近，得到**热温商之和为零**：

```
∮ δQr/T = 0
```

于是对任意可逆过程，从 A 到 B 的热温商积分只与始末态有关、与可逆途径无关——说明它对应一个**状态函数**。

### 2. 熵的定义

Clausius（1865）定义：

```
dS = δQr/T          ΔS = ∫(1→2) δQr/T
```

- 单位 J·K⁻¹；
- **容量性质**，是第二定律的基本状态函数；
- 意义：系统熵变在数值上等于**初末态之间任一可逆过程**的热温商之和。

### 3. Clausius 不等式

```
ΔS ≥ Σ δQ/T环
```

- ">" 对应不可逆过程，"=" 对应可逆过程；
- **T环 是环境温度**；取等号时可认为 T 就是系统温度；
- 意义：封闭系统中不可能发生熵变小于热温商的过程，这是**一切封闭系统的普遍规律**；
- 它就是第二定律的数学表达式，与"第二类永动机不可能"等价。

### 4. 用它判断过程性质

| 比较 | 结论 |
| :--- | :--- |
| ΔS > ΣδQ/T环 | 不可逆过程 |
| ΔS = ΣδQ/T环 | 可逆过程 |
| ΔS < ΣδQ/T环 | 不可能发生 |

> **利与弊：** 定量化、比定律本身方便；但要同时算 ΔS 和热温商，热温商的计算很麻烦。

## 六、熵增原理与熵判据

### 1. 绝热系统

绝热时 δQ = 0：

```
ΔS ≥ 0      （> 不可逆，= 可逆）
```

**绝热系统的熵不可能减少**——熵增原理。

### 2. 孤立系统（熵判据）

```
ΔS ≥ 0      （> 自发，= 可逆/平衡）
```

孤立系统中过程永远朝 **S 增大**的方向进行，限度是 **S 最大**。这解决了孤立系统中方向与限度的判别。

### 3. 大孤立系统

实际系统往往不是孤立的，可把"系统 + 环境"重新划成一个大孤立系统：

```
ΔS孤 = ΔS系 + ΔS环 ≥ 0      （> 自发，= 可逆）
```

> **注意：** 熵增原理只适用于**孤立系统**（或大孤立系统）。"系统的熵变在自发过程中一定大于零"——错，系统不是孤立系统时 ΔS 可正可负（如水结冰 ΔS < 0，但 ΔS环 > 0，总的仍大于零）。

### 4. 两个常考思考

- **从同一始态能否分别设计绝热可逆与绝热不可逆过程达到同一末态？** 不能。熵是状态函数，末态相同则 ΔS 相同；但绝热可逆 ΔS = 0，绝热不可逆 ΔS > 0，矛盾。
- **封闭系统的绝热过程是否一定是等熵过程？** 不一定，只有绝热**可逆**才是等熵。

## 七、熵变的计算

### 1. 基本方法

```
基本公式： ΔS = ∫(1→2) δQr/T
```

- **可逆过程**：直接套公式，用真实过程的热温商；
- **不可逆过程**：**设计**一条始末态相同的可逆途径，沿该途径积分；
- 熵是状态函数，设计途径合法；但 W、Q 不能设计途径。

### 2. 理想气体的简单 pVT 变化

| 过程 | ΔS |
| :--- | :--- |
| 任意等温过程 | nR ln(V2/V1) = nR ln(p1/p2) |
| 等容简单变温 | nCv,m ln(T2/T1) |
| 等压简单变温 | nCp,m ln(T2/T1) |
| pVT 都变化 | nCv,m ln(T2/T1) + nR ln(V2/V1) |
| 同上（另一写法） | nCp,m ln(T2/T1) − nR ln(p2/p1) |
| 绝热可逆 | 0 |

> **不必死记"pVT 都变化"的那两条**，掌握"先等温后等容""先等压后等容"两种拆法即可，三种拆法结果必然相同。

### 3. 相变过程

**(1) 可逆相变**（等温、等压、W' = 0，Qr = ΔH）：

```
ΔS = ΔH/T
```

**(2) 不可逆相变**：设计途径。以 298.15 K、pθ 下 1 mol 水气化为例：

```
H2O(l, 298.15 K, pθ) → H2O(g, 298.15 K, pθ)      （不可逆）
设计：升温到 373.15 K → 可逆气化 → 降温到 298.15 K
ΔS = ∫(298→373) nCp,m(l)dT/T + ΔvapHm/373.15 + ∫(373→298) nCp,m(g)dT/T
   = 75 ln(373.15/298.15) + 40.60×10³/373.15 + 33 ln(298.15/373.15)
   ≈ 118 J·K⁻¹
```

> **能否用 ΔS > 0 判断该过程自发？不能！** 系统不是孤立系统。需算环境熵：
> ΔS环 = −Q系/T环 = −ΔH/T = −43.75×10³/298.15 ≈ −146.7 J·K⁻¹
> ΔS孤 = 118 − 146.7 = −28.7 J·K⁻¹ < 0 → **该过程不能自发进行**。

### 4. 混合过程

不同理想气体在等温等压下混合：

```
ΔmixS = − R Σ nB ln xB  > 0
ΔmixG = RT Σ nB ln xB   < 0
```

理想气体混合物的容量性质可按组分加和：U = ΣU*、H = ΣH*、S = ΣS*。

- 等温等压混合时每个组分相当于从 p 膨胀到分压 pB = xB·p，故 ΔSB = nB R ln(p/pB) = −nB R ln xB；
- **非等温等压**的混合：分别考虑每个组分的状态变化（pVT 都变），再求和。

> **例（课件）：** 绝热容器中用铝板隔开 1 mol He(200 K) 与 1 mol H2(300 K)，抽去销钉后台导热。
> Q = 0、W = 0 → ΔU = 0 → T2 = 262.5 K；
> ΔH = nCp,m(He)(T2 − 200) + nCp,m(H2)(T2 − 300) ≈ 207.9 J；
> ΔS = 1×(3R/2)ln(262.5/200) + 1×(5R/2)ln(262.5/300) ≈ 1.61 J·K⁻¹ > 0。

### 5. 环境熵变

环境极大，对环境的实际热即等于可逆热：

```
ΔS环 = Q环/T环 = −Q系/T环       （以环境吸热为正）
```

### 6. 计算小结

1. 先判断过程可逆与否：可逆套公式，不可逆设计途径；
2. 多组分系统总熵变 = 各纯组分熵变之和（容量性质加和）；
3. 判断方向：要么用 Clausius 不等式（系统 ΔS + 实际热温商），要么用大孤立系统（ΔS系 + ΔS环）。

## 八、热力学第三定律与规定熵

### 1. 第三定律的建立

| 时间 | 人物 | 内容 |
| :--- | :--- | :--- |
| 1902 | Richard（美国） | 低温电池实验：T → 0 时 ΔS → 0 |
| 1906 | Nernst | 热定理：T → 0 K 时，等温过程中凝聚态反应系统的熵值不变 |
| 1912 | Planck | 假设 0 K 时纯凝聚态的熵为零 |
| 1920 | Lewis & Gibbs | 指出 Planck 假设只适用于**完美晶体** |

**表述：** 在 0 K 时，一切**纯态完美晶体**的熵均等于零。

```
lim(T→0) S = 0      （完美晶体）
```

- 完美晶体：晶体中原子或分子只有**一种有序排列方式**；
- 另一表述：**绝对零度不能达到**（不可能用有限手续使物体冷却到 0 K）；
- 反例：甘油以玻璃态冷到 0 K，与晶体相比仍有约 19.2 J·K⁻¹·mol⁻¹ 的残余熵；
- 统计意义：S = k ln Ω，0 K 完美晶体 Ω = 1，故 S = 0。熵是混乱度（多样性）的量度。

### 2. 规定熵与标准摩尔熵

由第三定律，从 0 K 到 T 的熵变就是该状态的**规定熵**（用量热数据算出的也叫量热熵）：

```
S(T) = ∫(0→T) (Cp/T)dT + Σ(相变) Δ相变H/T
```

1 mol 物质在温度 T、标准态下的规定熵，称为该温度的**标准摩尔熵** Smθ(T)，可查手册。

> **注意：** Smθ 是由第三定律定出零点的**规定熵**（也常直接称为绝对熵）；查表得到的 298.15 K 数据可直接用于反应熵变计算。

### 3. 化学反应的熵变

```
ΔrSmθ = Σ νB Smθ(B)
```

对任意温度 T2（标准压力下）：

```
ΔrS(T2) = ΔrSmθ(298.15 K) + ∫(298.15→T2) (ΔrCp,m/T) dT
```

- 若 ΔrCp,m = 0，则不同温度的 ΔrS 不变；
- 高温下 ΔrS 的变化通常不大，但 ΔrH 变化更明显，因此温度对 ΔrG 的影响主要来自 ΔrH 与 TΔS 的竞争。

## 九、Helmholtz 函数与 Gibbs 函数

熵判据的两个弊端：要同时算 ΔS 和热温商；且只适用于孤立系统。实际过程多在**等温等容**或**等温等压**下进行，需要新判据。

### 1. Helmholtz 函数（功函数）

由 Clausius 不等式出发，对**等温**过程（T1 = T2 = T环）：

```
TΔS ≥ Q = ΔU + W      →      Δ(U − TS) ≤ −W
```

定义：

```
A ≡ U − TS
```

于是：

```
ΔA ≤ −W        （< 不可逆，= 可逆）
```

- **条件：** 封闭系统、等温；
- 意义：等温过程中系统 Helmholtz 函数值的减少等于系统所能做的**最大功**（所以 A 也叫功函数）；
- 等温可逆：ΔA = −Wr；等温不可逆：ΔA < −Wir，故 Wr > Wir——"等温可逆过程系统做功最大"的理论依据。

**Helmholtz 函数减少原理**（等温、等容、W' = 0）：

```
ΔA ≤ 0        （< 自发，= 平衡）
```

### 2. Gibbs 函数（Gibbs 自由能）

对等温且**等压**过程，把体积功分离出来：

```
ΔA ≤ −(pΔV + W')   →   Δ(A + pV) ≤ −W'
```

定义：

```
G ≡ H − TS = A + pV
```

于是：

```
ΔG ≤ −W'       （< 不可逆，= 可逆）
```

- **条件：** 封闭系统、等温等压；
- 意义：等温等压过程中 Gibbs 函数值的减少等于系统对环境所能做的**最大非体积功**；
- **Gibbs 函数减少原理**（等温、等压、W' = 0）：

```
ΔG ≤ 0        （< 自发，= 平衡）
```

系统自发地朝 G 减小的方向进行，到达平衡时 G 最小。

> **注意：** A、G 都是状态函数、容量性质、**组合函数**，没有明确的物理意义。"G 是系统能做有用功的那部分能量"——这种说法不严格，只在特定条件下才有"最大非体积功"的意义。

### 3. 三个判据的比较

| 函数 | 系统 | 应用条件 | 判据 |
| :--- | :--- | :--- | :--- |
| **S** | 孤立系统 | 任意过程 | ΔS ≥ 0（> 自发，= 可逆） |
| **S** | 大孤立系统 | 任意过程 | ΔS系 + ΔS环 ≥ 0 |
| **A** | 封闭系统 | 等温、等容、W' = 0 | ΔA ≤ 0 |
| **G** | 封闭系统 | 等温、等压、W' = 0 | ΔG ≤ 0 |

补充的"功判据"：

```
等温：        ΔA ≤ −W
等温等压：    ΔG ≤ −W'
```

> **最常用的是 Gibbs 函数判据**：大多数化学反应和相变都在等温等压下进行。

## 十、热力学基本关系式

### 1. 八个基本状态函数

强度性质：T、p；容量性质：V、U、S、H、A、G。基本函数 U、S；导出函数 H、A、G：

```
H = U + pV
A = U − TS
G = H − TS = A + pV
```

### 2. Gibbs 公式

对封闭系统、W' = 0 的可逆过程，联合第一、第二定律：

```
dU = TdS − pdV
dH = TdS + Vdp
dA = −SdT − pdV
dG = −SdT + Vdp
```

### 3. 适用条件（重点）

1. 条件：封闭系统、**可逆**、W' = 0；
2. **特殊情形**：只发生简单物理变化的封闭系统（双变量系统），**不可逆也适用**——因为 U、S 等是状态函数，可用两条可逆路径拼出同样结果；
3. 对**复杂物理变化和化学变化**（相变、混合、化学反应，即组成变化的过程）：**必须可逆**。

> **例（说明为什么简单物理变化可用）：** 状态 1(T, p) 经不可逆过程到状态 2(T+dT, p+dp)，可拆成"等压可逆 + 等温可逆"两步，dG = dG1 + dG2 = −SdT + Vdp，与可逆与否无关。

### 4. 对应系数关系

由 dU = TdS − pdV 等全微分直接读出：

```
(∂U/∂S)V = T        (∂U/∂V)S = −p
(∂H/∂S)p = T        (∂H/∂p)S = V
(∂A/∂T)V = −S       (∂A/∂V)T = −p
(∂G/∂T)p = −S       (∂G/∂p)T = V
```

用途：证明题、把难测的偏导数换成可测量。

> **常用结论：** 恒压下纯物质升温，G 下降（因为 (∂G/∂T)p = −S < 0）；恒温下增大压力，G 增大（(∂G/∂p)T = V > 0）。

### 5. Maxwell 关系

若 dZ = Mdx + Ndy 是全微分，则 (∂M/∂y)x = (∂N/∂x)y。用于四个基本式，得：

```
(∂T/∂V)S = −(∂p/∂S)V
(∂T/∂p)S = (∂V/∂S)p
(∂S/∂V)T = (∂p/∂T)V
(∂S/∂p)T = −(∂V/∂T)p
```

**记忆规律：** S 与 T、p 与 V 为斜对角；偏导条件互换；**负号出现在含 S 与 p 的关系式中**。

用途：用易测量代替难测量；导出其他普遍关系。

### 6. 应用举例：证明理想气体 (∂U/∂V)T = 0

```
dU = TdS − pdV
(∂U/∂V)T = T(∂S/∂V)T − p
         = T(∂p/∂T)V − p       （用 Maxwell 关系）
对理想气体 p = nRT/V，(∂p/∂T)V = nR/V
         = T·nR/V − p = p − p = 0
```

这正是 Joule 实验的结论，说明"理想气体内能只是温度的函数"不是假设，而是可以由基本关系式推出。

### 7. 温度、压力对五个函数的影响

| 对象 | 温度的影响 | 压力的影响 |
| :--- | :--- | :--- |
| 气体 | 不可忽略 | 对 U、H 影响小；对 S、A、G 影响大，不可忽略 |
| 液体、固体 | 不可忽略 | 影响都很小，Δp 不大时 ΔU、ΔH、ΔS、ΔA、ΔG 可近似为零 |

## 十一、ΔG 与 ΔA 的计算

### 1. 基本公式

任意等温过程：

```
ΔA = ΔU − TΔS
ΔG = ΔH − TΔS
```

一般式（沿任意可逆路径积分）：

```
ΔG = −∫S dT + ∫V dp
ΔA = −∫S dT − ∫p dV
```

### 2. 理想气体等温过程

```
ΔG = ΔA = nRT ln(p2/p1) = −nRT ln(V2/V1)
```

> **例（课件）：** 300.2 K、1 mol 理想气体从 10pθ 等温膨胀到 pθ。
> (1) 等温可逆：ΔU = ΔH = 0；ΔS = nR ln(p1/p2) = 19.15 J·K⁻¹；ΔA = ΔG = −TΔS = −5748 J；Qr = Wr = 5748 J。
> (2) 等温向真空膨胀：Q = W = 0，但 ΔU、ΔH、ΔS、ΔA、ΔG 与 (1) **完全相同**（状态函数）。
> 这组对比是"过程量 vs 状态函数"最好的例子。

### 3. 相变过程

- **可逆相变**（等温等压、W' = 0）：ΔG = 0；ΔA = −W = −pΔV；
- **不可逆相变**：设计途径。

> **例：** 298.2 K、pθ 下 1 mol 水气化，求 ΔG。
> 解法 1：升温到 373.2 K → 可逆气化 → 降温回 298.2 K，得 ΔH = 43.75 kJ、ΔS ≈ 118 J·K⁻¹，故 ΔG = ΔH − TΔS = 43.75 − 298.2×0.118 ≈ **8.6 kJ > 0**，过程不能自发。
> 解法 2：改走"298.2 K 下变压到饱和蒸气压 3160 Pa → 可逆气化（ΔG = 0）→ 变压到 pθ"，凝聚相 ΔG 随压力变化可忽略，得 ΔG = nRT ln(pθ/3160) ≈ 8.6 kJ。
> 解法 3：直接用 Gibbs–Helmholtz 方程，以 373.2 K 的可逆气化为起点积分。

### 4. 混合过程

不同理想气体等温等压混合：

```
ΔmixH = 0（等温）
ΔmixS = − R Σ nB ln xB
ΔmixG = RT Σ nB ln xB  < 0
```

其他混合过程：分别求每个组分的 ΔGB，再求和。

### 5. 化学反应

```
ΔrGmθ(T) = ΔrHmθ(T) − T ΔrSmθ(T)
```

- ΔrHmθ、ΔrSmθ 由手册数据（生成焓、标准摩尔熵）算出；
- 298.15 K 的 ΔrGmθ 容易得到，其他温度需用 Gibbs–Helmholtz 方程或设计途径。

## 十二、ΔG 与温度、压力的关系

### 1. Gibbs–Helmholtz 方程

```
[∂(ΔG/T)/∂T]p = −ΔH/T²
```

积分形式：

```
ΔG(T2)/T2 = ΔG(T1)/T1 − ∫(T1→T2) (ΔH/T²) dT
```

- 描述等温等压过程中 ΔG 随温度的变化，多用于相变与化学反应；
- 若 ΔH 在区间内近似为常数：ΔG(T2)/T2 = ΔG(T1)/T1 + ΔH(1/T2 − 1/T1)。

### 2. ΔG 随压力的变化

```
(∂G/∂p)T = V        ΔG = ∫V dp
```

- 理想气体：ΔG = nRT ln(p2/p1)；
- 凝聚相：ΔG ≈ VΔp，通常很小（压力变化不大时可忽略）。

### 3. 典型应用：石墨 → 金刚石

298 K、pθ 下 ΔtrGmθ = 2.862 kJ/mol > 0，常温常压下石墨不能自发变金刚石。加压使 ΔG 变为 0：

```
ΔG = ΔtrGmθ + ΔtrV·(p − pθ) = 0
ΔtrV = M(1/ρ金刚石 − 1/ρ石墨) = 12×10⁻³ × (1/3513 − 1/2260) = −1.895×10⁻⁶ m³/mol
p = pθ + 2862/1.895×10⁻⁶ ≈ 1.5×10⁹ Pa
```

即需要约 1.5 GPa 以上的压力，石墨才可能转变为金刚石——这正是人造金刚石的原理。

## 十三、易错点与解题套路

### 1. 解题套路

| 要求 | 方法 |
| :--- | :--- |
| 判断方向/限度 | 选判据：孤立→ΔS；等温等容→ΔA；等温等压→ΔG |
| 求 ΔS | 可逆套公式；不可逆**设计可逆途径** |
| 求 ΔG | 等温用 ΔH − TΔS；理气用 nRT ln(p2/p1)；相变/反应设计途径 |
| 判断是否自发 | 系统非孤立时必须加 ΔS环（或直接用 ΔG） |
| 证明题 | Gibbs 公式 + 对应系数关系 + Maxwell 关系 |

### 2. 易错点清单

1. **熵增原理只适用于孤立系统**（或大孤立系统），不能直接对任意封闭系统下结论。
2. ΔS > 0 不一定是自发；ΔS < 0 也不一定不自发——要看环境。
3. Clausius 不等式中的 T 是**环境温度**；取等号时才可当作系统温度。
4. 不可逆过程算 ΔS 必须设计可逆途径，**不能**用实际热温商。
5. 可逆相变 ΔS = ΔH/T 只对**可逆**相变成立。
6. 可逆相变 ΔG = 0，但 ΔA ≠ 0（= −pΔV）。
7. 绝热不可逆过程 ΔS > 0，不能用绝热可逆过程来算它的熵变（末态不同）。
8. 熵是容量性质，混合熵、反应熵都要乘物质的量。
9. Gibbs 公式对简单物理变化不可逆也成立，但对相变、化学反应**必须可逆**。
10. ΔG ≤ 0 判据要求 W' = 0；有非体积功时要用 ΔG ≤ −W'。
11. "G 是能做有用功的那部分能量"——说法不严格。
12. 平衡时"熵最大、G 最小"要加条件：孤立系统熵最大，等温等压系统 G 最小。
