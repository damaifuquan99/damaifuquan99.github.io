# **细胞生物学学习笔记 1 | 细胞概论：从细胞学说 to 原核与真核**

---

> **对应课件：** Lecture 1 - Intro 2026  
> **本章核心内容：** 细胞生物学研究范围、细胞学说、细胞作为生命基本单位的依据、细胞的基本属性、细胞大小的限制因素、原核与真核细胞的区别、原核生物、病毒、真核细胞的进化  
> **复习目标：** 掌握细胞学说三条基本原则；理解细胞为什么是生命的基本单位；能对比原核细胞与真核细胞的主要差异；了解病毒的基本特征及内共生学说。

## 一、细胞生物学研究什么？

细胞生物学（Cell Biology）研究细胞的结构（structures）、功能（functions）及其调控（regulation）。细胞是生命的最小单位，连接分子（molecules）与复杂组织器官（tissues and organs）。

课件中列出的热点研究领域包括：

| 研究方向 | 具体内容举例 |
| :--- | :--- |
| 细胞周期与 DNA 损伤 | cell cycle checkpoint, DNA damage and repair |
| 信号转导 | signal transduction |
| 膜运输与细胞器 | membrane trafficking, organelle biology, degradation |
| 细胞运动与分化 | cell motility, cell differentiation, cell death |
| 干细胞与单细胞生物学 | stem cell, single cell biology, cell atlas |
| 表观遗传与 RNA 生物学 | epigenetics, miRNA, ncRNA |
| 组学与系统生物学 | genomics, proteomics, bioinformatics, systems biology |
| 合成生物学与成像 | synthetic biology, single molecule imaging |

与细胞生物学密切相关的主要疾病包括癌症（cancer）、心血管疾病（cardiovascular diseases）、糖尿病等代谢性疾病（diabetes and metabolic diseases），以及 AIDS、肝炎、流感、埃博拉、Zika、SARS-CoV-2 等传染病。

## 二、细胞学说（Cell Theory）

### 1. 发现历程

| 时间 | 人物 | 贡献 |
| :--- | :--- | :--- |
| 1665 | Robert Hooke | 首次报告“细胞”——观察的是死软木组织的空细胞壁，命名 *cellulae*（小房间） |
| 1674 | Anton van Leeuwenhoek | 描述细胞核和细菌（活细胞观察） |
| 1838 | Mathias Schleiden | 植物由细胞构成，植物从单个细胞发育而来 |
| 1839 | Theodor Schwann | 提出细胞学说两条原则 |
| 1855 | Rudolf Virchow | 提出第三条原则：细胞只能来自已有细胞的分裂 |

### 2. 细胞学说三条基本原则

1. **所有生物体由一个或多个细胞组成。**  
   All organisms are composed of one or more cells.
2. **细胞是所有生物体结构和功能的基本单位。**  
   Cells are the basic units of structure and function for all organisms.
3. **所有细胞只能来自先前存在的细胞分裂。**  
   All cells arise only from preexisting cells by division.

> **易错点：** Schwann 曾提出“blastema”（无结构物质）概念，认为细胞可以从这种物质中形成。Virchow 的“omnis cellula e cellula”（每个细胞来自另一个细胞）终结了这一错误观点。值得注意的是，这句格言最早由 François Vincent Raspail 在 1825 年提出，Virchow 将其发展为细胞病理学体系。

### 3. 细胞学说建立后的重要发现

- Flemming 和 Strasburger 分别发现动物和植物细胞的有丝分裂（mitosis）
- Van Beneden（1883）和 Strasburger（1886）分别发现动物和植物细胞的减数分裂（meiosis）
- Van Beneden 和 Boveri（1883）发现着丝粒（centromere）
- Altmann（1894）发现线粒体（mitochondria）
- Camillo Golgi（1898）发现高尔基体（Golgi apparatus）
- Claude、de Duve、Palade 因细胞器发现获 1974 年诺贝尔生理学或医学奖

## 三、为什么细胞是生命的基本单位？

课件从五个方面论证：

| 角度 | 说明 |
| :--- | :--- |
| **结构单位** | 所有生物体都由细胞组成（神经细胞、红细胞、骨细胞、肌细胞、上皮细胞等） |
| **功能单位** | 所有代谢活动都基于细胞 |
| **繁殖与遗传** | 细胞是繁殖的基础，也是遗传的桥梁 |
| **生长发育** | 一个受精卵可发育为约 \(3\times10^{13}\) 个细胞、210 种细胞类型的人体 |
| **全能性** | 细胞具有全能性（totipotent），可产生同类型的新个体 |

### 全能性与克隆实验

- **胚胎干细胞（embryonic stem cells, ES cells）**：来自囊胚内细胞团（inner cell mass），具有多能性（pluripotent），可分化为中胚层、内胚层、外胚层，并具备自我更新（self-renewal）能力。
- **核移植实验**：John B. Gurdon（1968, Oxford；2012 诺贝尔奖）将蝌蚪肠细胞核移植到去核卵母细胞中，部分可发育为游泳蝌蚪，证明高度分化的细胞仍保留完整基因组。
- **Dolly 羊**：1997 年 Ian Wilmut 等从成年细胞克隆出第一只动物，证明动物体细胞核具有全能性。
- **iPS 细胞**：Yamanaka 发现 Oct4、Sox2、Klf4、Myc 四个因子可将小鼠和成人成纤维细胞诱导为多能干细胞（induced pluripotent stem cells, iPS cells），获 2012 诺贝尔奖。

> **思考：** “多能性（pluripotent）”与“全能性（totipotent）”不同。受精卵和早期卵裂球是 totipotent，可形成完整个体及胚外组织；ES 细胞是 pluripotent，可形成三个胚层但不能单独形成完整个体。

## 四、细胞的基本属性

课件列出细胞的基本属性：

1. **高度复杂且有序**，能合成和降解大量分子与结构；
2. **拥有遗传程序**（genetic program）并具备使用该程序的能力；
3. **能自我繁殖**；
4. **能获取和利用能量**；
5. **能进行多种化学反应和机械活动**（如形状改变、运动）；
6. **能响应刺激**，感知和传递信息；
7. **能自我调节**，根据需求调节基因表达；
8. **会死亡**——或因外部损伤，或因内部程序性死亡（programmed cell death）。

### 所有细胞的共同结构基础

尽管原核与真核细胞差异巨大，所有细胞共享：

- **质膜（plasma membrane）**
- **DNA/RNA**
- **核糖体（ribosome）**

> **记忆点：** 膜、核酸、核糖体是细胞最基本的“通用装备”。

## 五、细胞的大小

### 1. 单位

- 微米：\(1\ \mu\text{m} = 10^{-6}\ \text{m}\)
- 纳米：\(1\ \text{nm} = 10^{-9}\ \text{m}\)

### 2. 细胞大小受限的原因

| 限制因素 | 解释 |
| :--- | :--- |
| **核质比（nucleus/cytoplasm ratio）** | 细胞核能控制的细胞质体积有限 |
| **表面积/体积比（surface area/volume ratio）** | 细胞越大，表面积相对越小，物质交换效率下降 |
| **扩散效率** | 物质通过细胞质扩散的速度有限，细胞过大则内部运输困难 |

### 3. 尺度感

课件中的尺度图可作为复习参考：

| 结构 | 大致尺寸 |
| :--- | :--- |
| 原子 | 0.1 nm |
| 小分子 | ~1 nm |
| 蛋白质 | 1–100 nm |
| 核糖体 | 25–30 nm |
| 病毒 | 20–300 nm |
| 细菌 | 1–2 μm |
| 线粒体 | 1–2 μm |
| 真核细胞 | 10–100 μm |
| 细胞核 | 5–10 μm |

> **注意：** 光学显微镜分辨率约 0.2 μm，因此大多数细胞器需要电子显微镜才能看清。荧光显微镜和共聚焦显微镜可提高对比度和三维重建能力。

## 六、原核细胞与真核细胞

### 1. 基本区分

| 特征 | 原核细胞（prokaryotes） | 真核细胞（eukaryotes） |
| :--- | :--- | :--- |
| **出现时间** | 约 35 亿年前 | 约 15 亿年前 |
| **核膜** | 无真正的核膜，仅有拟核（nucleoid） | 有真正的细胞核（nucleus） |
| **DNA 包装** | 单个“裸露”DNA 染色体，不与组蛋白形成核小体 | 多条染色体，DNA 与蛋白质结合 |
| **膜性细胞器** | 无 | 有（ER、Golgi、溶酶体、线粒体等） |
| **细胞骨架** | 无（或仅有类似结构） | 有（微丝、微管、中间丝） |
| **核糖体大小** | 70S | 80S（线粒体和叶绿体为 70S） |
| **细胞分裂** | 简单二分裂（binary fission） | 有丝分裂（mitosis） |
| **鞭毛结构** | 鞭毛蛋白（flagellin），质子驱动，旋转式 | 微管蛋白（tubulin），ATP 驱动，摆动式，有膜包裹 |
| **典型代表** | 细菌、古菌 | 原生生物、真菌、植物、动物 |

### 2. 原核细胞与真核细胞鞭毛的区别（易考）

| 特征 | 细菌鞭毛 | 真核鞭毛 |
| :--- | :--- | :--- |
| 主要蛋白 | flagellin | tubulin |
| 能量来源 | 质子动力势（proton motive force） | ATP |
| 运动方式 | 旋转（rotor） | 摆动（bending） |
| 是否被质膜包裹 | 否（outside） | 是（covered with PM） |
| 结构 | 钩状体+基体 | 9+2 微管轴丝 |

### 3. 植物细胞与动物细胞的区别

植物细胞特有：

- **细胞壁（cell wall）**
- **叶绿体（chloroplast）**
- **大液泡（large vacuole）**

动物细胞特有：

- **中心体（centrosome）**（多数植物细胞无）
- **溶酶体（lysosome）**（植物细胞中类似功能由液泡承担）

> 两者都有：质膜、细胞核、ER、Golgi、线粒体、核糖体、细胞骨架。

## 七、原核生物（Prokaryotes）

### 1. 三域系统

生命之树有三个主要分支：

1. **古菌（Archaea）**
2. **细菌（Bacteria）**
3. **真核生物（Eukarya）**

大多数细菌和古菌有 1000–4000 个基因。

### 2. 最小的细胞

- **支原体（Mycoplasma）**：0.1–0.3 μm
- 最小基因组：约 482 个基因
- 最小必需基因（minimal essential genes）：约 256 个

> **思考：** “最小必需基因”是通过转座子突变和基因组比较推算出的维持生命所需的最少基因集，对合成生物学（synthetic biology）有重要意义。

## 八、病毒（Viruses）

### 1. 基本特征

| 特征 | 说明 |
| :--- | :--- |
| **定义** | 严格胞内寄生（obligatory intracellular parasites） |
| **遗传物质** | 单链或双链 DNA 或 RNA |
| **结构** | 核酸 + 蛋白质衣壳（capsid），部分有脂质包膜（envelope） |
| **大小** | 约 20–300 nm |
| **感染类型** | 裂解性感染（lytic infection）、整合性感染（integrated infection） |

### 2. 病毒与细胞的区别

| 特征 | 病毒 | 细胞 |
| :--- | :--- | :--- |
| 能否独立代谢 | 不能 | 能 |
| 能否独立繁殖 | 不能（需宿主） | 能 |
| 是否有核糖体 | 无 | 有 |
| 是否有细胞膜 | 部分有包膜，但非细胞膜 | 有质膜 |
| 遗传物质 | DNA 或 RNA | DNA（少数例外） |

### 3. 病毒起源假说

- 病毒起源于宿主进化之后；
- 病毒可能起源于宿主染色体片段。

### 4. 类病毒与朊病毒

- **类病毒（viroids）**：感染性 RNA，无蛋白质外壳。
- **朊病毒（prions）**：感染性蛋白质，可引起克雅氏病（CJD）、牛海绵状脑病（BSE）等。

> **易错点：** 病毒不是细胞，不属于原核或真核生物。分类上独立于三域系统之外。

## 九、真核细胞的进化

### 1. 内共生学说（Endosymbiotic Theory）

真核细胞可能起源于一个古菌宿主细胞吞噬了好氧细菌，后者演化为线粒体；随后某些细胞又吞噬了光合细菌，演化为叶绿体。

| 事件 | 证据 |
| :--- | :--- |
| 线粒体起源 | 线粒体有双层膜、环状 DNA、70S 核糖体，大小和形态类似细菌 |
| 叶绿体起源 | 叶绿体有双层膜、环状 DNA、70S 核糖体，类似蓝细菌 |
| 古菌宿主 | Asgard 古菌（2020 年 Nature 论文）具有类似真核细胞的膜突起结构 |

### 2. 演化顺序

1. 厌氧古菌（anaerobic archaeon）
2. 获得好氧细菌共生体 → 线粒体（mitochondria）
3. 形成早期真核细胞
4. 部分谱系获得光合细菌 → 叶绿体（chloroplasts）
5. 分化出植物、动物、真菌等谱系

### 3. 关键证据

- 线粒体和叶绿体有独立的环状 DNA；
- 有 70S 核糖体，对细菌抗生素敏感；
- 双层膜结构；
- 分裂方式类似细菌二分裂；
- 系统发育分析显示线粒体与 α-变形菌相关，叶绿体与蓝细菌相关。

> **注意：** 内共生学说解释的是线粒体和叶绿体的起源，而非细胞核的起源。细胞核的起源仍有多种假说（如 invagination 假说、viral eukaryogenesis 假说等）。

## 十、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **细胞学说** | 三条原则：生物体由细胞组成；细胞是结构和功能单位；细胞来自已有细胞 |
| **细胞是基本单位** | 结构、功能、繁殖、遗传、发育、全能性六个维度 |
| **细胞基本属性** | 复杂有序、遗传程序、自我繁殖、能量利用、代谢活动、响应刺激、自我调节、死亡 |
| **细胞大小** | 受核质比、表面积/体积比、扩散效率限制 |
| **原核 vs 真核** | 核膜、膜性细胞器、DNA 包装、核糖体大小、分裂方式、鞭毛结构 |
| **原核生物** | 古菌和细菌两个亚界；支原体是最小细胞 |
| **病毒** | 严格胞内寄生；DNA 或 RNA；裂解性/整合性感染；不属于细胞 |
| **真核细胞进化** | 内共生学说：线粒体来自好氧细菌，叶绿体来自光合细菌 |
