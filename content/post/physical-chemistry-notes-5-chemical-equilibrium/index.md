# **物理化学学习笔记 5 | 第五章 化学平衡：从 ΔrGmθ 到平衡移动**

## 一、化学平衡的热力学本质

### 1. 什么是化学平衡

化学平衡是指在一定条件下，化学反应的**正向速率等于逆向速率**、反应体系的**宏观性质不随时间变化**的状态。也就是说，**化学平衡是一种动态平衡**。

### 2. 热力学本质

```
化学平衡的热力学本质：化学反应体系 Gibbs 函数最小的状态。
```

这一结论的历史源头是 Gibbs 在 1875—1878 年发表的长文 *On the Equilibrium of Heterogeneous Substances*——正是这篇文章奠定了用 Gibbs 函数（化学势）统一处理相平衡与化学平衡的基础，也是第四章、第五章共同的理论源头。

### 3. 为什么化学反应通常不能进行到底

这是本章的**核心问题**，答案是：**混合效应**。

**先看"没有混合"的理想情形。** 设反应 A → C，反应物与产物各自处于纯态、互不混合，则在等 T、p、W' = 0 时：

```
ΔG = G(产物) − G(反应物) = G*(C,T,p) − G*(A,T,p)
```

若此值小于 0，则 G 随反应进度 ξ **线性下降**，直到 ξ = 1（反应物全部耗尽）：

```
 G
 ↑
 │╲
 │ ╲
 │  ╲            ← 无混合时 G 随 ξ 线性变化
 │   ╲              反应进行到底
 │    ╲
 └──────────→ ξ
   0        1
```

只有**少数反应**如此，例如 CaCO3(s) = CaO(s) + CO2(g) 这类凝聚相分解反应。

**再看真实情形。** 绝大多数化学反应系统中反应物与产物是**混合**在一起的，而混合本身使 Gibbs 函数降低。回顾第三章的结论：

| 混合类型 | ΔmixG |
| :--- | :--- |
| 理想气体等温等压混合 | ΔmixG = RT Σ nB ln xB < 0 |
| 理想液体混合物等 T、p 混合 | ΔmixG = RT Σ nB ln xB < 0 |

即 **ΔmixG < 0，混合使 Gibbs 函数减少**。

于是实际的 G–ξ 曲线不是直线，而是**先降后升的曲线**（直线减去一个负的混合项，形成下凹的极小值）：

```
 G
 ↑
 │  ·╲                      ╱·      ← 曲线：实际反应过程
 │    ╲                    ╱
 │     ╲                  ╱
 │      ╲__            __╱
 │         ╲__      __╱
 │            ╲____╱  ← Geq = G 最小值，对应 ξeq
 │   ┈┈┈┈┈（直线：无混合时）
 └──────────────────────────→ ξ
   0                      1
```

**结论：** 由于 ΔmixG < 0，反应**不进行完全**，而是**留下部分反应物参与混合过程**，最终得到**平衡混合物**。这正是"化学反应通常不能进行到底"的热力学原因。（可参见傅献彩等《物理化学》第 5 版（上）P345–346。）

### 4. 本章三个核心问题

| 问题 | 对应的热力学工具 |
| :--- | :--- |
| (1) 在一定条件下，反应**正向还是逆向**进行？ | ΔrGm 的符号；J 与 Kθ 的比较 |
| (2) **平衡位置**在哪里？平衡混合物的组成如何？ | 标准平衡常数 Kθ |
| (3) 如何根据需要**改变**化学反应的平衡位置？ | 温度、压力、惰性组分、浓度的影响 |

## 二、化学反应的平衡条件与方向判据

### 1. 反应进度与 dG 的基本表达式

对任意化学反应，写成统一形式：

```
∑B νB B = 0
```

其中 νB 为**化学计量数**，**对反应物取负值、对产物取正值**。

当反应系统发生微量反应 dξ 时，各物质的量的变化为：

```
dnB = νB dξ
```

在 W' = 0 时，多组分系统的 Gibbs 函数全微分（式 3-11）为：

```
dG = −S dT + V dp + ∑B μB dnB
```

等 T、p 下（dT = 0、dp = 0）：

```
dG = ∑B μB dnB = ∑B μB νB dξ = (∑B νB μB) dξ
```

于是：

```
(∂G/∂ξ)T,p = ∑B νB μB
```

### 2. 反应的摩尔 Gibbs 函数变

**定义：**

```
ΔrGm ≡ (∂G/∂ξ)T,p = ∑B νB μB
```

称为**反应的摩尔 Gibbs 函数变**（Change of molar Gibbs function of a reaction）。

**两种物理意义：**

| 角度 | 表述 |
| :--- | :--- |
| (1) 变化率 | 在等 T、p、W' = 0 的反应系统中，Gibbs 函数随反应进度的**变化率**，即 **ΔrGm = f(ξ)** |
| (2) 单位进度 | 在等 T、p、W' = 0 的条件下，在**一个无限大的反应系统**中进行**单位反应进度**所引起的 Gibbs 函数变化 |

> **注意：** 第 (2) 条中"无限大"三个字不能省。只有系统足够大，单位反应进度才不会显著改变系统组成，ΔrGm 才是该组成下的"瞬时"变化率。

### 3. 方向判据与平衡条件

**等 T、p、W' = 0 条件下，化学反应方向判据：**

| ΔrGm 的符号 | 结论 |
| :--- | :--- |
| (∂G/∂ξ)T,p **<** 0 | 反应**正向**进行 |
| (∂G/∂ξ)T,p **=** 0 | 反应**达到平衡** |
| (∂G/∂ξ)T,p **>** 0 | 反应**逆向**进行 |

**化学反应平衡条件：**

```
ΔrGm(eq) = ∑B νB μB(eq) = 0
```

**G 最小值原理：** 在等 T、p、W' = 0 时，当化学反应达平衡时，反应体系的 **G 达最小值**。

> **记忆点：** 判据的几何含义就是"看 G–ξ 曲线在该点的斜率"——斜率为负则往右走（正向），斜率为零则停（平衡），斜率为正则往左走（逆向）。平衡点正是曲线的最低点。

## 三、化学反应的平衡常数

### 1. 理想气体反应系统：Kθ 的导出

对理想气体，化学势（式 3-20）：

```
μB = μBθ(T) + RT ln(pB/pθ)
```

代入平衡条件 ΔrGm(eq) = ∑νBμB(eq) = 0，得：

```
∑B νB μBθ + RT ∑B νB ln(pB(eq)/pθ) = 0
```

**定义反应的标准摩尔 Gibbs 函数变：**

```
ΔrGmθ = ∑B νB μBθ
```

于是：

```
ΔrGmθ + RT ln ∏B (pB(eq)/pθ)^νB = 0
```

**定义标准平衡常数（标准平衡常数或热力学平衡常数）：**

```
Kθ = ∏B (pB(eq)/pθ)^νB          （平衡分压积，又称平衡分压商）
```

其中 pB(eq) 为**平衡分压**，νB 为化学计量数。代入上式得：

```
ΔrGmθ = −RT ln Kθ
Kθ = exp(−ΔrGmθ / RT)
```

```
这个关系适用于任何类型的化学反应。
```

### 2. 任意化学反应：用活度表示的 Kθ

对任意反应（含气体、液体、固体、溶液），化学势通式为：

```
μB = μBθ + RT ln aB + ∫(pθ 到 p) VB dp
```

课件指出：对 B(g)，压力积分项为 0；对 B(l) 和 B(s)，压力积分项**近似为 0**。代入平衡条件：

```
∑B νB μBθ + RT ∑B νB ln aB(eq) + ∑B νB ∫VB dp = 0
```

于是：

```
ΔrGmθ = −RT ln ∏B aB(eq)^νB
Kθ = ∏B aB(eq)^νB = exp(−ΔrGmθ / RT)
```

```
此为任意化学反应达到平衡时所服从的热力学关系式。
```

> **要点：** Kθ 的**普适定义**是"平衡时的活度积"，一切具体表达式（分压积、逸度积、摩尔分数积、浓度积）都是它在特定系统下的**展开形式**。

### 3. Kθ 的性质（四条，高频考点）

| 性质 | 内容 |
| :--- | :--- |
| (1) **无量纲** | Kθ 是纯数，因为每个 aB（或 pB/pθ）都是相对值 |
| (2) **与温度 T 有关** | 由 ΔrGmθ = −RT ln Kθ，ΔrGmθ 是 T 的函数，故 Kθ = f(T) |
| (3) **与所选标准态有关** | 标准态不同，μBθ 不同，Kθ 的数值也不同 |
| (4) **与反应方程式的写法（νB）有关** | 同一反应写成不同计量系数，Kθ 不同 |

### 4. Kθ 与方程式写法的关系（重要）

**例：700 K 时**

```
(1) 3CO + 3Cl2 = 3COCl2          K1θ
(2) CO + Cl2 = COCl2             K2θ
```

显然：

```
K1θ = (K2θ)³
```

**思考：** 若写成

```
3COCl2 = 3CO + 3Cl2
```

则

```
K3θ = 1/K1θ = (K2θ)⁻³
```

**一般规律（同一反应的方程式变形）：**

| 方程式变形 | Kθ 的变化 |
| :--- | :--- |
| 方程式乘以系数 n | Kθ → (Kθ)ⁿ |
| 方程式反写（左右互换） | Kθ → 1/Kθ |
| 两反应相加 | Kθ → K1θ·K2θ |
| 两反应相减 | Kθ → K1θ/K2θ |

> **记忆点：** Kθ 是"乘幂式"的对象，方程式的一切线性运算都对应 Kθ 的乘除与乘方。做题时**先看方程式写法再动笔**，这是最常见的失分点。

## 四、化学反应等温式与方向判断

### 1. 反应商 J

对理想气体反应系统的**任意状态**（不一定是平衡态），定义：

```
J = ∏B (pB/pθ)^νB          （压力商）
```

对任意反应系统，用活度表示：

```
J = ∏B aB^νB              （活度商）
```

J 与 Kθ 的**形式完全相同**，区别只在于：**Kθ 用的是平衡时的分压（活度），J 用的是任意时刻的分压（活度）**。

### 2. 等温式（van't Hoff 等温方程式）

对理想气体反应系统的任意状态：

```
ΔrGm = ∑B νB μB
     = ∑B νB [μBθ + RT ln(pB/pθ)]
     = ΔrGmθ + RT ln ∏B (pB/pθ)^νB
     = −RT ln Kθ + RT ln J
```

即：

```
ΔrGm = RT ln(J/Kθ)
```

### 3. 方向判据

| 比较 | ΔrGm | 结论 |
| :--- | :--- | :--- |
| **J < Kθ** | < 0 | 反应**正向**进行 |
| **J > Kθ** | > 0 | 反应**逆向**进行 |
| **J = Kθ** | = 0 | 反应**达到化学平衡** |

```
通过 J 和 Kθ 数值的比较，可以判断任一指定状态下反应进行的方向和限度——简便实用的方法！
```

（课件示例：教材 P126 例 5-1。）

> **注意：** 这里是"**任意状态**"的判据，比"ΔrGm < 0 则正向"更细致。ΔrGm 本身已含 J，但直接用 J 与 Kθ 比较可以**避免重复计算 ΔrGm**，工程上最常用。

## 五、标准平衡常数的具体表达式

### 1. Kθ 的意义

```
Kθ 值是反应限度的标志：Kθ 值越大，表明平衡混合物中产物的浓度越大，反应进行的程度越大。
```

### 2. 四类系统的 Kθ 表达式

**（a）理想气体反应**

```
Kθ = ∏B (pB(eq)/pθ)^νB          （平衡分压积）
```

**（b）实际气体反应**

```
Kθ = ∏B (fB(eq)/pθ)^νB          （平衡逸度积）
```

其中 fB 为逸度，pθ 为标准压力。高压下必须用逸度代替分压。

**（c）溶液中的反应**

| 系统 | 标准态 | Kθ 表达式 |
| :--- | :--- | :--- |
| 理想液体混合物 | 各物质均以**纯态 (T, p)** 为标准态 | Kθ = ∏B xB(eq)^νB（平衡摩尔分数积） |
| 理想稀薄溶液（反应物、产物均为溶质） | aB = xB，或 aB = bB/bθ，或 aB = cB/cθ | Kθ = ∏B xB(eq)^νB；Kθ = ∏B (bB(eq)/bθ)^νB；Kθ = ∏B (cB(eq)/cθ)^νB |
| 实际溶液 | 活度 | Kθ = ∏B aB(eq)^νB（平衡活度积） |

**（d）多相反应**（只讨论气相是理想气体、液相和固相均是纯物质的系统）

纯固态物质的标准状态为 **T、pθ 下的纯固态物质**。由

```
μB(s,T,p) = μB*(s,T,p) + RT ln aB
μB*(s,T,p) = μBθ(s,T) + ∫(pθ 到 p) Vm,B(s) dp
```

代入后可见，当 p = pθ 时 aB = 1；且因凝聚相摩尔体积很小，压力改变对 aB 的影响可忽略：

```
aB = 1
```

同理，**纯液态物质的活度 aB = 1**。因此：

```
Kθ = ∏B aB(eq)^νB
   = ∏B(l) aB(l,eq)^νB · ∏B(s) aB(s,eq)^νB · ∏B(g) (pB(eq)/pθ)^νB
   = ∏B(g) (pB(eq)/pθ)^νB
```

即**多相反应的 Kθ 表达式中只出现气相组分，纯固、纯液的活度取 1，不写入表达式**。

> **易错点：** 多相反应写 Kθ 时，千万不要把纯固体、纯液体的"浓度"或"分压"写进去。它们的活度恒为 1，写进去就错了。

### 3. 三个例子

**例 1：NH4Cl(s) = NH3(g) + HCl(g)**

```
Kθ = (pNH3(eq)/pθ) · (pHCl(eq)/pθ)
```

NH4Cl(s) 是纯固体，a = 1，不出现。

**例 2（习题 9）：C2H4(g) + H2O(l) = C2H5OH(aq)**

```
Kθ = a(C2H5OH, eq) / (pC2H4(eq)/pθ)          （H2O(l) 为纯液体，a = 1）
```

若乙醇水溶液很稀，可近似 a(C2H5OH) ≈ cB/cθ 或 bB/bθ。

**例 3（课堂练习）：氨厂用氨水回收铜**

```
CuS(s) + 2O2(g) + 4NH3·H2O(aq) = Cu(NH3)4SO4(aq) + 4H2O(l)
```

```
Kθ = a(Cu(NH3)4SO4, eq) / [ (pO2(eq)/pθ)² · a(NH3·H2O, eq)⁴ ]
```

CuS(s) 与 H2O(l) 都是纯物质，活度为 1，均不出现。

## 六、平衡组成的计算

### 1. 两个基本概念

**平衡转化率：**

```
转化率 = (平衡时转化为产品的原料量 / 投入原料的量) × 100%
```

**平衡产率：**

```
平衡产率 = (平衡时某产品的量 / 理论上原料全部变为产品时该产品的量) × 100%
```

### 2. 相关概念

分解压、电离常数等概念都与平衡有关——它们本质上都是**特定反应体系下 Kθ 的另一种表达**（例如分解压就是固体分解达平衡时的气相总压，可由 Kθ 反解）。

### 3. 计算的通用步骤

```
① 写出配平的方程式，明确 νB 的正负；
② 设转化量为未知数（常用 ξ 或 n），列"起始—变化—平衡"三行表；
③ 求平衡时各物质的摩尔分数（对气相用分压 = xB·p）；
④ 代入 Kθ 的表达式，解方程；
⑤ 由解出的 n 计算转化率、产率或体积分数。
```

（课件示例：教材 P130 例 5-2、5-3、例 5-4，请自学。）

## 七、反应的标准摩尔 Gibbs 函数变 ΔrGmθ

### 1. 意义

```
ΔrGmθ = ∑B νB μBθ = −RT ln Kθ
```

**含义：** 指反应系统中所有参与反应的物质都处在**各自的标准态**时，发生 **1 mol 反应**（即反应进度变化 1 mol）后系统 G 值的改变。

**影响因素：**

```
ΔrGmθ = f (T, 反应系统, 方程式的写法)
```

即只与温度（客观因素）、系统的本性以及方程式怎么写有关，**与压力、浓度无关**。

### 2. ΔrGm 与 ΔrGmθ 的区别与联系（重点辨析）

| 项目 | ΔrGm（反应的摩尔 Gibbs 函数变） | ΔrGmθ（标准摩尔 Gibbs 函数变） |
| :--- | :--- | :--- |
| 定义 | (∂G/∂ξ)T,p = ∑νBμB | ∑νB μBθ |
| 所处状态 | 反应进度为**任意 ξ** 时的值 | 所有物质均处于**各自标准态**时的值 |
| 影响因素 | 与**温度、压力、活度**均有关 | **只与温度 T 有关**（对给定反应与写法） |
| 平衡时 | **等于 0** | **一般不等于 0**（= −RT ln Kθ） |
| 用途 | 判断任意状态下的反应方向 | 求 Kθ |

**思考题（教材 P147 思考题 1）：当一个气相反应在 101.325 kPa 的条件下进行时，反应的 ΔrGm 就是 ΔrGmθ，对吗？**

```
不对。
```

理由：总压等于 pθ（101.325 kPa）**并不意味着**每个组分都处于标准态。标准态要求每个物质都是**纯态**、且其分压（或逸度）等于 pθ。只有当所有参与反应的物质都处于各自标准态时，ΔrGm 才等于 ΔrGmθ。若总压为 pθ 而各组分分压不等于 pθ，则 J ≠ 1，ΔrGm = ΔrGmθ + RT ln J ≠ ΔrGmθ。

### 3. 求 ΔrGmθ 的三种方法

**（1）由 ΔrHmθ 和 ΔrSmθ 计算**

```
ΔrGmθ = ΔrHmθ − T ΔrSmθ
```

其中：

```
ΔrHmθ = ∑B νB ΔfHmθ(B)          （式 1-38，标准摩尔生成焓）
ΔrSmθ = ∑B νB Smθ(B)            （式 2-18，标准摩尔规定熵）
```

**由 298.15 K 的数据求 T 下的值**（Kirchhoff 定律，式 1-46）：

```
ΔrHmθ(T) = ΔrHmθ(298.15 K) + ∫(298.15 到 T) ΔrCp,m dT
ΔrSmθ(T) = ΔrSmθ(298.15 K) + ∫(298.15 到 T) (ΔrCp,m / T) dT
```

其中：

```
ΔrCp,m = ∑B νB Cp,m(B)
```

> **注意：** ΔrHmθ 对 T 的修正是 **∫ΔrCp,m dT**，而 ΔrSmθ 的修正是 **∫(ΔrCp,m/T) dT**——一个除以 T、一个不除，这是最常见的抄错点。

**（2）由标准摩尔生成 Gibbs 函数 ΔfGmθ 求算**

```
ΔrGmθ = ∑B νB ΔfGmθ(B)
```

**ΔfGmθ 的定义：** 在指定温度下，由标准状态的**稳定单质**生成 **1 mol 标准状态下指定相态的某物质**时，反应的 Gibbs 函数变。单位 J·mol⁻¹。

要点：

| 要点 | 内容 |
| :--- | :--- |
| 稳定单质 | ΔfGmθ = 0 |
| 温度 | 298.15 K 查手册，最常用 |
| 溶液中的溶质 | 通常用溶质浓度为 **b = 1 mol/kg** 的 ΔfGmθ |

**（3）电化学方法**（第六章）：由可逆电池电动势求 ΔrGmθ = −zFEθ。

### 4. 溶质标准态的处理：途径设计法（难点）

以教材 P135 例 5-6 求**丁二酸第一电离常数**为例：

```
C4H6O4(aq) = C4H5O4⁻(aq) + H⁺(aq)
```

关键在于求出 **C4H6O4(aq, b = 1 mol/kg)** 的 ΔfGmθ——因为手册上给的是**固体**丁二酸的 ΔfGmθ，而溶液中溶质的标准态是 b = 1 mol/kg 的假想态。

已知丁二酸的溶解度 b(饱和) = 0.715 mol/kg，可查得：

```
ΔfGmθ(C4H6O4, s)   与   ΔfGmθ(C4H5O4⁻, aq)、ΔfGmθ(H⁺, aq)
```

**设计如下途径：**

```
C4H6O4(s)  ──ΔG1 = 0──→  C4H6O4(饱和溶液, b = 0.715 mol/kg)
                                    │
                                    │ ΔG2 = RT ln(bθ/b)
                                    ↓
                          C4H6O4(aq, b = 1 mol/kg)
```

- 第一步：固液溶解达平衡，ΔG1 = 0（饱和溶液与纯固体平衡）；
- 第二步：由 μ(aq, b) = μθ(aq) + RT ln(b/bθ)，从 b = 0.715 mol/kg 变到标准态 b = 1 mol/kg：

```
ΔG2 = RT ln(bθ/b) = RT ln(1/0.715) > 0
```

于是：

```
ΔfGmθ(aq) = ΔfGmθ(s) + ΔG1 + ΔG2 = ΔfGmθ(s) + RT ln(bθ/b)
```

**物理解释：** 由饱和溶液"浓缩"到标准态 b = 1 mol/kg，Gibbs 函数必然升高（因为 b < bθ 时 ln(bθ/b) > 0）。

> **记忆点：** 遇到"手册有固体数据、题目要溶液数据"的情形，一律走 **固体 → 饱和溶液（ΔG = 0）→ 标准态溶液（ΔG = RT ln(bθ/b)）** 这条两步途径。

## 八、各种因素对化学平衡的影响

### 1. 平衡移动的实质

**平衡移动：** 在一定的条件下，一个化学平衡的位置是确定的；若改变平衡系统的某些条件，往往平衡将被打破，结果平衡位置发生变化，这一现象叫**平衡移动**。

```
平衡状态 1  ──改变条件──→  新状态  ──→  平衡状态 2
                            ↓
                   判断新状态下 J 与 Kθ 的关系
```

```
所有平衡移动的问题，实质上是"新状态"下化学反应方向的判断。
```

设 J 和 Kθ 分别代表"新状态"下的活度积和平衡常数，T 为此时的温度：

| 比较 | 结论 |
| :--- | :--- |
| J < Kθ | 平衡**右移**（正向） |
| J > Kθ | 平衡**左移**（逆向） |
| J = Kθ | 平衡**不移** |

以下依次讨论**温度、压力、浓度及惰性气体**等因素的影响。注意区分：**温度改变 Kθ，压力、浓度、惰性气体改变 J**——这是本章的总纲。

### 2. 温度对化学平衡的影响

**温度主要影响 Kθ。**

**（1）定性讨论**

由 ΔrGmθ = −RT ln Kθ 与 ΔrGmθ = ΔrHmθ − TΔrSmθ，可得 Gibbs-Helmholtz 方程（式 2-47）：

```
[∂(ΔrGmθ/T)/∂T]p = −ΔrHmθ/T²
```

将 ΔrGmθ/T = −R ln Kθ 代入：

```
∂(−R ln Kθ)/∂T = −ΔrHmθ/T²
```

即得 **van't Hoff 方程**（微分形式）：

```
d ln Kθ / dT = ΔrHmθ / (RT²)
```

由此：

| ΔrHmθ 的符号 | 吸放热 | T↑ 时 Kθ 的变化 | 平衡移动方向 |
| :--- | :--- | :--- | :--- |
| > 0 | 吸热 | Kθ ↑ | 右移（向吸热方向） |
| < 0 | 放热 | Kθ ↓ | 左移（向放热方向） |

```
结论：T↑ 平衡向吸热方向移动；T↓ 平衡向放热方向移动。
```

**（2）定量计算**

**情形 a：当 ΔrCp,m = 0（ΔrHmθ 与温度无关），或温度变化不大时**

把 ΔrHmθ 视为常数，两边从 T1 到 T2 积分：

```
ln(K2θ/K1θ) = −(ΔrHmθ/R)(1/T2 − 1/T1) = (ΔrHmθ/R)(1/T1 − 1/T2)
```

**情形 b：当 ΔrCp,m ≠ 0（ΔrHmθ 与温度有关），且温度变化较大时**

必须考虑 ΔrHmθ 与温度的关系，先由 Kirchhoff 定律写出：

```
ΔrHmθ(T) = ΔrHmθ(298.15 K) + ∫(298.15 到 T) ΔrCp,m dT
其中 ΔrCp,m = ∑B νB Cp,m(B)
```

再代入 van't Hoff 方程积分：

```
∫(K1θ 到 K2θ) d ln Kθ = ∫(T1 到 T2) [ΔrHmθ(T) / (RT²)] dT
```

**（3）van't Hoff 方程的两个用途**

| 用途 | 说明 |
| :--- | :--- |
| 求不同温度下的 Kθ | 由某一温度的 Kθ 与 ΔrHmθ，求另一温度的 Kθ |
| 由 Kθ 求 ΔrHmθ、ΔrSmθ | 将 ΔrGmθ = −RT ln Kθ 代入 ΔrGmθ = ΔrHmθ − TΔrSmθ，得 **ln Kθ = −ΔrHmθ/(RT) + ΔrSmθ/R**；以 ln Kθ 对 1/T 作图，**斜率 = −ΔrHmθ/R，截距 = ΔrSmθ/R** |

> **注意：** 第二种用法里 ΔrHmθ、ΔrSmθ 被当作常数处理，因此只在小温度区间内严格成立。

### 3. 压力对化学平衡的影响

**压力主要影响 J。** 讨论理想气体反应系统。

将分压写成 xB·p，则

```
J = ∏B (pB/pθ)^νB = ∏B (xB·p/pθ)^νB = (p/pθ)^(∑νB) · ∏B xB^νB
```

可见压力对 J 的影响完全集中在 **(p/pθ)^(∑νB)** 这一项上（∏xB^νB 只与组成有关，在瞬间改变压力时不变）：

| 反应类型 | ∑νB | p↑ 时 | 结果 |
| :--- | :--- | :--- | :--- |
| 增分子反应 | > 0 | J ↑ → J > Kθ | 平衡**左移**（向减分子方向） |
| 减分子反应 | < 0 | J ↓ → J < Kθ | 平衡**右移**（向减分子方向） |
| 等分子反应 | = 0 | J 与 p 无关 | 平衡**不移** |

```
小结：
p↑ → 平衡向减分子方向移动
p↓ → 平衡向增分子方向移动
p 不影响等分子反应的平衡
```

**两类特殊情况：**

| 情形 | 结论 |
| :--- | :--- |
| 无气体参与的反应 | 平衡基本**不受 p 影响**（因凝聚相的摩尔体积很小，压力项可忽略） |
| 高压气体反应 | 必须比较**新状态时的 Kθ 和 J**（逸度问题），不能简单套用上述规则 |

> **易错点：** 压力的影响看的是 **∑νB（气态物质计量数之和）**，不是所有物质的总和。纯固、纯液的 νB 不计入——因为它们不出现在 Kθ 的表达式中。

### 4. 惰性组分对化学平衡的影响

此处"惰性组分"**特指不参与反应的气体物质**（如合成氨中的 CH4、乙苯脱氢中的水蒸气）。

**（a）等温等压下加入惰性组分气体**

总压不变，但反应组分的**分压降低**（被惰性气体稀释）：

```
相当于 p↓ 对平衡的影响
→ 平衡向增分子方向移动
```

**（b）等温等容（刚性容器）下加入惰性组分气体**

| 气体类型 | 影响 |
| :--- | :--- |
| 理想气体（或低压气体）反应 | **无影响**——各组分分压不变，J 不变 |
| 高压气体反应 | 有影响（逸度问题） |

**（c）工业实例：乙苯脱氢制苯乙烯**

```
C6H5C2H5(g) = C6H5C2H3(g) + H2(g)
```

这是一个 **∑νB = +1 的增分子反应**。设起始只有 1 mol 乙苯，平衡时转化了 n mol：

| 物质 | 起始 nB / mol | 平衡 nB(eq) / mol | 平衡 xB |
| :--- | :--- | :--- | :--- |
| C6H5C2H5 | 1 | 1 − n | (1 − n)/(1 + n) |
| C6H5C2H3 | 0 | n | n/(1 + n) |
| H2 | 0 | n | n/(1 + n) |
| 合计 | 1 | 1 + n | 1 |

于是

```
Kθ = [n/(1+n)]² / [(1−n)/(1+n)] · (p/pθ) = n² p / [(1 − n²) pθ]
```

由此式可直接读出规律：

| 条件 | 对 n（转化量）的影响 |
| :--- | :--- |
| (a) p = pθ | 基准情形 |
| (b) p = 0.1pθ（减压） | n **增大**——减压有利于增分子反应 |
| (c) p = pθ 且加入 10 mol 水蒸气（惰性组分） | n 也**增大**——等压加惰性气体等效于减压 |

若加入惰性组分，设其物质的量为 n0，则总量为 1 + n + n0，Kθ 的表达式中分母出现 (1 + n + n0)：

```
Kθ = n² p / [(1 − n)(1 + n + n0) pθ]
```

n0 越大，为维持 Kθ 不变所需的 n 越大——这正是**工业上向乙苯脱氢体系通入大量过热蒸汽**的热力学依据（同时水蒸气还能抑制结焦、提供热量）。

> **记忆点：** "等压加惰性 = 减压"，"等容加惰性 = 没影响（对理想气体）"。前者稀释使分压下降，后者分压根本不变。

### 5. 浓度对化学平衡的影响

浓度影响的是 **J**：

```
J = ∏B aB^νB
```

```
添加反应物、取走产物，均会使 J < Kθ，反应向生成产物的方向移动（→）。
```

**应用（很广）：** 化工生产中**不按计量比投料**。例如

```
A(廉价) + B(昂贵) → C
```

令 **A 过量**，可提高昂贵原料 B 的转化率——因为增大 A 的浓度使 J 减小，平衡右移，从而"榨干"B。这与勒夏特列原理的定性说法一致，但严格依据是 J < Kθ。

### 6. Le Chatelier 原理及其限度

**Le Chatelier 原理（平衡移动规律）：**

```
一个化学反应如果已达到平衡，当改变影响此平衡的某一因素时，
则平衡向着削弱这种改变的方向移动。
```

**但课件特别提示：这个"规律"的正确性是存疑的**（思考题 5，并推荐阅读《Le Chatelier's Principle 的历史终结》）。

**为什么不能盲信它？**

| 问题 | 说明 |
| :--- | :--- |
| 它只是**定性经验规律** | 严格判据永远是 **J 与 Kθ 的比较**（ΔrGm = RT ln(J/Kθ)） |
| 对"加惰性气体"容易误判 | 等压加惰性气体时"总压没变"，按"削弱改变"的说法会得出"不移动"的错误结论，实际却因分压下降而移动 |
| 对"同时改变多个因素"失效 | 多个因素方向相反时，无法判断净效果 |
| 它不能给出**移动程度** | 只有 Kθ 与 J 的定量计算才能给出平衡组成 |

**正确做法：** 先判断该因素改变的是 **Kθ**（温度）还是 **J**（压力、浓度、惰性气体），再算新状态下的 J/Kθ 比值。

### 7. 合成氨工艺条件的综合分析

```
3H2(g) + N2(g) = 2NH3(g)
```

| 因素 | 分析 | 工艺选择 |
| :--- | :--- | :--- |
| ∑νB | = 2 − (3 + 1) = **−2 < 0**，减分子反应 | **高压有利**（30 MPa） |
| ΔrHmθ | **< 0**，放热反应 | 低温有利，但低温速率太慢 |
| 综合 | 平衡与速率矛盾 | 取 **520 ℃** 的中温折中 |
| 惰性气体 | 循环气中 CH4 积累会降低有效分压 | **经常排放循环气**以排除 CH4 |

工业生产中的工艺条件一般是 **520 ℃、30 MPa**，且要经常排放循环使用的原料气（主要是 H2、N2、NH3、CH4）以排除 CH4 气体。

> **思考：** 对于已经达到平衡的反应，可否改变其平衡位置？——可以。改变温度改变 Kθ；改变压力、浓度、惰性气体含量改变 J。二者都能使平衡移动，但**只有温度能改变 Kθ 本身**。

## 九、易错点清单

1. **ΔrGm 与 ΔrGmθ 不是一回事**：前者是任意状态（含 J），后者只与 T 有关；平衡时 ΔrGm = 0，而 ΔrGmθ = −RT ln Kθ ≠ 0。
2. **总压等于 pθ ≠ 各组分处于标准态**。这是"101.325 kPa 下 ΔrGm 就是 ΔrGmθ 吗"的标准答案依据。
3. **νB 的正负号**：反应物取负、产物取正。写错符号会导致 ΔrGmθ 与 Kθ 全部出错。
4. **Kθ 与方程式写法绑定**：方程式乘 n，Kθ 变 (Kθ)ⁿ；反写，Kθ 变 1/Kθ；相加，Kθ 相乘。做题前先确认方程式。
5. **Kθ 无量纲**，因为用的是相对分压 pB/pθ 或活度 aB，不是分压本身。
6. **多相反应中纯固、纯液的活度为 1**，不写入 Kθ 的表达式。写进去即错。
7. **纯液体的"浓度"不是 1 mol/L**，而是活度 1（标准态为纯液体）。
8. **压力影响看 ∑νB（仅气态）**，不是所有物质的计量数之和。无气体参与时压力基本无影响。
9. **等压加惰性气体 ≠ 等容加惰性气体**：前者等效减压（移动），后者对理想气体无影响。
10. **温度改变 Kθ，压力/浓度/惰性气体改变 J**——这是本章最重要的分界线。
11. **van't Hoff 方程积分式的符号**：ln(K2θ/K1θ) = (ΔrHmθ/R)(1/T1 − 1/T2)。注意是 (1/T1 − 1/T2)，不是 (1/T2 − 1/T1)；T↑ 时若 ΔrHmθ > 0，则 1/T1 − 1/T2 > 0，K2θ > K1θ，与"升温向吸热方向移动"一致——可用这个一致性来验算符号。
12. **ΔrSmθ 的温度修正要除以 T**：∫(ΔrCp,m/T)dT，而 ΔrHmθ 的修正不除 T。
13. **ΔfGmθ 只对稳定单质为零**，不是对所有单质为零（如 O3 不是稳定单质）。
14. **溶质标准态是 b = 1 mol/kg 的假想态**，不是饱和溶液，也不是"1 mol/L 的真实溶液"。求溶质的 ΔfGmθ 必须走"固体 → 饱和溶液（ΔG = 0）→ 标准态（RT ln(bθ/b)）"。
15. **催化剂不改变 Kθ，也不改变 ΔrGmθ**，只改变活化能与速率。所以"ΔrGm > 0 时找催化剂使反应正向进行"是错的。
16. **ΔrGmθ < 0（即 Kθ > 1）不代表实际一定正向进行**——实际方向由 J 与 Kθ 的相对大小决定。
17. **Kθ 改变不一定导致平衡移动**（若 J 同步变化到恰好等于新 Kθ）；**平衡移动也不一定伴随 Kθ 改变**（浓度、压力只改 J）。
18. **Le Chatelier 原理只是定性经验规律**，遇到"加惰性气体""多因素同时变化"时必须回到 J 与 Kθ 的比较。
19. **平衡产率 ≠ 平衡转化率**：转化率以"投入的原料"为基准，产率以"理论上原料全部转化时该产品的量"为基准。多产物反应中二者数值不同。
20. **ΔmixG < 0 是"反应不进行到底"的原因**，不是"反应不能进行"的原因。前者是平衡位置问题，后者是方向问题。

| 由生成焓、规定熵 | ΔrHmθ = ∑νB ΔfHmθ(B)；ΔrSmθ = ∑νB Smθ(B) | 式 1-38、2-18 |
| Kirchhoff（焓） | ΔrHmθ(T) = ΔrHmθ(298.15) + ∫ΔrCp,m dT | 式 1-46 |
| Kirchhoff（熵） | ΔrSmθ(T) = ΔrSmθ(298.15) + ∫(ΔrCp,m/T) dT | 注意除以 T |
| 由生成 Gibbs 函数 | ΔrGmθ = ∑B νB ΔfGmθ(B) | 稳定单质为零 |
| 溶质标准态换算 | ΔfGmθ(aq) = ΔfGmθ(s) + RT ln(bθ/b) | 经饱和溶液途径 |
| 电化学法 | ΔrGmθ = −zFEθ | 第六章 |
| van't Hoff 方程（微分） | d ln Kθ/dT = ΔrHmθ/(RT²) | ΔrHmθ 视为常数时积分 |
| van't Hoff 方程（积分） | ln(K2θ/K1θ) = (ΔrHmθ/R)(1/T1 − 1/T2) | 温差不大 |
| 压力对 J 的影响 | J = (p/pθ)^(∑νB) · ∏B xB^νB | 只影响第一项 |
| 惰性气体（等压） | 等效于 p↓ | 向增分子方向移动 |
| ln Kθ 与 T 的线性关系 | ln Kθ = −ΔrHmθ/(RT) + ΔrSmθ/R | 斜率 −ΔrHmθ/R，截距 ΔrSmθ/R |

## 十一、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **化学平衡本质** | 正逆速率相等的动态平衡；热力学上是 **G 最小的状态**（Gibbs 1875–1878） |
| **反应为何不进行到底** | **混合效应**：ΔmixG < 0 使 G–ξ 曲线出现极小值，留下部分反应物参与混合 |
| **ΔrGm 的定义** | (∂G/∂ξ)T,p = ∑νBμB；两种意义（变化率、单位进度的 G 变化） |
| **方向判据** | ΔrGm < 0 正向、= 0 平衡、> 0 逆向；几何上即 G–ξ 曲线的斜率 |
| **平衡条件** | ∑νBμB(eq) = 0，即 G 最小值 |
| **Kθ 的导出** | 由 ΣνBμB = 0 与 μB = μBθ + RT ln(pB/pθ) 得 ΔrGmθ = −RT ln Kθ |
| **Kθ 的普适定义** | Kθ = ∏aB(eq)^νB；一切具体形式都是它的展开 |
| **Kθ 的四条性质** | 无量纲；与 T 有关；与标准态有关；与方程式写法有关 |
| **Kθ 与方程写法** | 乘 n → (Kθ)ⁿ；反写 → 1/Kθ；相加 → K1θK2θ；相减 → K1θ/K2θ |
| **等温式** | ΔrGm = RT ln(J/Kθ)；J < Kθ 正向，J > Kθ 逆向，J = Kθ 平衡 |
| **Kθ 的四类表达式** | 理想气体（分压积）、实际气体（逸度积）、溶液（摩尔分数/浓度/活度积）、多相（只含气相） |
| **多相反应** | 纯固、纯液 aB = 1，不写入 Kθ 表达式 |
| **转化率与产率** | 转化率以投入原料为基准；产率以理论产量为基准 |
| **ΔrGmθ 的意义** | 各物质处于标准态时，1 mol 反应的 G 变化；只与 T、系统、写法有关 |
| **ΔrGm 与 ΔrGmθ** | 前者含 J、与 p 和活度有关、平衡时为零；后者只与 T 有关、平衡时 = −RT ln Kθ |
| **ΔrGmθ 三种求法** | ①ΔrHmθ − TΔrSmθ（含 Kirchhoff 温度修正）②∑νBΔfGmθ ③电化学 −zFEθ |
| **溶质标准态** | b = 1 mol/kg 的假想态；途径：固体 → 饱和溶液（ΔG = 0）→ 标准态（RT ln(bθ/b)） |
| **平衡移动的实质** | 新状态下 J 与 Kθ 的比较，本质仍是方向判断 |
| **温度的影响** | 改变 **Kθ**；van't Hoff 方程 dlnKθ/dT = ΔrHmθ/(RT²)；升温向吸热方向移动 |
| **压力影响** | 改变 **J**；J = (p/pθ)^(∑νB)·∏xB^νB；升压向减分子方向移动；等分子不受影响 |
| **惰性气体** | 等压加入 → 等效减压 → 向增分子方向移动；等容加入 → 对理想气体无影响 |
| **浓度影响** | 改变 J；加反应物、取产物使 J < Kθ → 正向；工业上廉价原料过量 |
| **Le Chatelier 原理** | 只是定性经验规律，遇惰性气体或多因素时必须回到 J–Kθ 比较 |
| **合成氨条件** | 减分子 + 放热 → 高压低温有利；实际 520 ℃、30 MPa，并排放循环气除 CH4 |
