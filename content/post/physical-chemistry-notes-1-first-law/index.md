# **物理化学学习笔记 1 | 第一章 热力学第一定律：从能量守恒到反应热**

---

> **对应课件：** 第 1 讲（第一章 上，§1-1～§1-5）、第 2 讲（第一章 下，§1-6～§1-9）
> **本章核心内容：** 系统与环境、热力学平衡态、状态函数、过程与途径、热与功、内能；第一定律及其数学表达；体积功的计算与可逆过程；等容热、等压热与焓；理想气体的 U、H、热容与绝热过程；相变过程；反应进度、反应热与热化学计算
> **复习目标：** 能准确判断状态函数与过程量；熟练计算各过程（等温、等压、等容、绝热、相变、反应）的 W、Q、ΔU、ΔH；会设计途径处理不可逆过程；掌握 Hess 定律、生成焓、燃烧焓与 Kirchhoff 定律

## 一、绪论：物理化学在研究什么？

物理化学是从物质的**物理现象与化学现象的联系**入手，探求化学变化及相关物理变化基本规律的科学。它更侧重研究具有普遍性、本质性的化学基本规律，因此常被称为"理论化学"。

### 1. 三大研究内容

| 研究内容 | 所属分支 | 典型问题 |
| :--- | :--- | :--- |
| 化学反应的方向、限度与能量转换 | 化学热力学 | N2 + 3H2 = 2NH3 能否进行、进行到什么程度 |
| 化学反应的速率与机理 | 化学动力学 | 橡胶为什么老化、反应有多快 |
| 微观结构与性质的关系 | 结构化学、量子化学 | 金刚石与石墨为何性质不同 |

其他分支：电化学、表面与胶体化学、光化学等。

### 2. 平衡热力学的四个特点

1. 研究对象是**大量粒子组成的宏观体系**，结论不适用于单个或少量粒子；
2. 研究方法是在**经验定律**基础上演绎，具有高度普适性与可靠性；
3. 只考虑**初、末态**，不考虑过程细节；
4. **不考虑时间因素**（常温常压下 2H2 + O2 → 2H2O 的转化率只有 0.18%，但热力学不管它要等多久）。

> **一句话：** 热力学"知其然，不知其所以然"；热力学说不行的，绝对不行；热力学说行的，未必行（还要看动力学）。

### 3. 化学热力学的任务

判断**方向**、确定**限度**、计算**能量转换**、求算**宏观性质**。课程的主线是热力学三大定律（第一、二章）→ 溶液热力学（第三章）→ 相平衡（第四章）→ 化学平衡（第五章）。

## 二、热力学基本概念

### 1. 系统与环境

- **系统（体系）**：被研究的对象，人为划定；
- **环境**：与系统有相互作用的外界。

| 系统类型 | 物质交换 | 能量交换 | 例子 |
| :--- | :--- | :--- | :--- |
| 开放（敞开）系统 | 有 | 有 | 敞口烧杯中的反应 |
| 封闭系统 | 无 | 有 | 密封钢瓶（物化研究的主体） |
| 孤立系统 | 无 | 无 | 杜瓦瓶（严格意义不存在，只能近似） |

> **注意：** 系统是人为划分的，**确定系统是解决热力学问题的第一步**，原则只有一个——方便解题。同一过程选不同系统，Q、W、ΔH 都会变。

### 2. 热力学平衡态

**定义**（两个条件同时满足）：

1. 系统所有性质都**不随时间变化**；
2. 把系统与环境**隔离后**，也不会引起任何性质变化。

平衡态必须同时满足**四个平衡**：

- **热平衡**：无绝热壁时，各部分之间及系统与环境之间没有温度差（热力学第零定律 → 温度的定义）；
- **力平衡**：无刚性壁时，没有不平衡的力（不计外场时内部处处压力相等）；
- **相平衡**：多相系统中各相的组成与数量不随时间变；
- **化学平衡**：组成不随时间变。

> **易错点：** 性质不随时间变化 ≠ 平衡态。两端分别接高、低温热源的金属棒，内部温度分布稳定，但撤去热源后会继续变化，这叫**稳态（stable state）**，不是热力学平衡态。

### 3. 状态函数

描述系统状态的宏观性质（n、T、p、V、U、H、S…）称为热力学性质，习惯叫**状态函数**。

| 分类 | 特点 | 例子 |
| :--- | :--- | :--- |
| 容量性质（广度） | 与 n 成正比，有加和性，是 n 的一次齐函数 | m、V、U、H、S |
| 强度性质 | 与 n 无关，无加和性，是 n 的零次齐函数 | T、p、Vm |

**三个特点：**

1. **相互关联**：组成不变的封闭系统（单组分均相）只有两个独立变量，两个强度性质即可确定全部强度性质；
2. **只取决于状态**：与历史无关，变化量只由始、末态决定；
3. **增量为全微分**：∮dY = 0，循环一圈状态函数复原。

> **常见判断：** "循环过程后状态函数不一定复原"——错；"状态函数的变化值与过程有关"——错；"系统的状态不随时间改变就一定是平衡态"——错。

### 4. 过程与途径

状态发生变化叫经历了一个**过程**，变化的具体方式叫**途径**。

| 过程 | 条件 | 说明 |
| :--- | :--- | :--- |
| 等温 | T1 = T2 = T环 = 常数 | 三个等号必须同时成立 |
| 等压 | p1 = p2 = p环 = 常数 | 同上 |
| 等容 | V = 常数 | — |
| 绝热 | Q = 0 | 不等于温度不变 |
| 循环 | 始末态相同 | ΔU = ΔH = 0 |
| 恒外压 | p环 = 常数 | 系统压力可变 |

> **易错点：** "恒外压"只要求 p环 恒定，不等于"等压"；"等温"不仅要求 T1 = T2，还要求 T环 也等于这个温度。

### 5. 热和功

- **热 Q**：因温度不同而在系统与环境之间传递的能量；
- **功 W**：除热以外传递的一切能量（体积功 + 非体积功 W'：电功、表面功、轴功等）。

**本课程的符号规定（与不少教材相反，务必记牢）：**

```
系统吸热 Q > 0，系统放热 Q < 0
系统对环境做功 W > 0，环境对系统做功 W < 0
```

Q、W 都是**过程量**，不是状态函数：同一对始末态，走不同途径 Q 不同、W 不同，但 Q − W 相同。

> **注意：** 一般 QⅠ ≠ QⅡ、WⅠ ≠ WⅡ，Q ≠ −Q逆、W ≠ −W逆，但 ΔY = −ΔY逆。只有状态函数才"倒着走就反号"。

### 6. 内能 U（热力学能）

系统内部所有粒子的各种运动与相互作用能量之和：分子平动、转动、振动能，电子与核的能量，分子间相互作用位能等。

- 状态函数、容量性质，单位 J；
- 绝对值不可测，只能测 ΔU = U2 − U1；
- 组成不变的封闭系统：U = U(T, V)，dU = (∂U/∂T)V dT + (∂U/∂V)T dV。

## 三、热力学第一定律

### 1. 文字表述

能量守恒与转化：能量有各种形式，可以相互转化，但总量不变；**第一类永动机不可能造成**。

### 2. 数学表达式

封闭系统：

```
ΔU = Q − W            dU = δQ − δW
```

**适用条件：** 宏观、静止、无外场作用的封闭系统。

### 3. 三个直接推论

1. 同一始末态的两条途径：Q1 − W1 = Q2 − W2（内能变化与途径无关）；
2. 循环过程：ΔU = 0，故 **Q = W**（净热 = 净功）；
3. 绝热过程 Q = 0：**ΔU = −W**，系统对外做功必然以降低内能为代价。

> **提醒：** 有的教材写成 ΔU = Q + W，其中 W 定义为"环境对系统做功"。本课程（朱文涛《简明物理化学》）采用"**系统对外做功为正**"，所以是 ΔU = Q − W，两套体系不要混用。

## 四、体积功的计算

### 1. 基本公式

系统体积变化时反抗外压所做的功：

```
δW = p外 dV          W = ∫(V1→V2) p外 dV
```

两个要点：

1. 被积函数是**外压 p外**，不是系统压力 p；
2. 膨胀时 dV > 0，W > 0（系统做功）。

### 2. 五种常见情形

| 过程 | 体积功 W |
| :--- | :--- |
| 等容 | 0 |
| 自由膨胀（p外 = 0） | 0 |
| 恒外压 | p外(V2 − V1) |
| 等压 | p(V2 − V1) = pΔV |
| 理想气体等温可逆 | nRT ln(V2/V1) = nRT ln(p1/p2) |

### 3. 经典算例：一次膨胀 vs 可逆膨胀

理想气体从 p1 = 4 kPa、V1 = 6 m³ 等温膨胀到 p2 = 1 kPa、V2 = 24 m³：

| 途径 | 分步方式 | W / kJ |
| :--- | :--- | :--- |
| 一次膨胀 | 4 kPa → 1 kPa | 18 |
| 二次膨胀 | 4 → 2 → 1 kPa | 24 |
| 三次膨胀 | 4 → 3 → 2 → 1 kPa | 26 |
| 等温可逆膨胀 | 无限多步 | 33.3 |

反向压缩：

| 途径 | W / kJ | 膨胀 + 压缩的循环净功 ΣW / kJ |
| :--- | :--- | :--- |
| 一次压缩 | −72 | −54 |
| 二次压缩 | −48 | −24 |
| 三次压缩 | −44 | −18 |
| 可逆压缩 | −33.3 | 0 |

**三条结论：**

1. 同样的状态变化，**过程不同，W 和 Q 都不同**（ΔU 相同）——算 W、Q 一定要先明确过程；
2. 膨胀时**可逆膨胀做功最大**；压缩时**可逆压缩环境做功最小**；
3. 只有可逆循环的净功为零，不可逆循环必然在环境中留下"多做的功"。

## 五、可逆过程

### 1. 定义

热力学的一类过程：**每一步都可以反向进行，而不在环境中引起其他变化**（系统与环境"双复原"）。

### 2. 三个特点

1. **双复原**：逆向走完后系统回到原态，环境也恢复原样；
2. **无限接近平衡**：T ≈ T环、p ≈ p环，推动力无限小、速度无限慢，是科学抽象；
3. **功和热取极限值**：等温可逆膨胀系统做功最大，等温可逆压缩环境做功最小。

### 3. 四个典型可逆过程

| 可逆过程 | 平衡条件 |
| :--- | :--- |
| 可逆膨胀/压缩 | 力平衡：p环 = p ∓ dp |
| 可逆传热 | 热平衡：T环 = T ± dT |
| 可逆相变 | 相平衡（两相共存） |
| 可逆化学反应 | 化学平衡 |

### 4. 为什么重要

1. 实际过程能量利用的**极限**（热机效率的理论上限）；
2. 计算状态函数变化（尤其熵）时必须借助可逆途径。

> **易错点：** "能使系统复原的过程就是可逆过程"——错，还要环境复原；"可逆过程真实存在"——错，客观世界不存在，只是极限；"自然界实际进行的一切过程都是不可逆过程"——对。"可逆" ≠ "回来"。

## 六、热的计算：等容热、等压热与焓

### 1. 等容热

条件：dV = 0（W = 0）且 W' = 0：

```
Qv = ΔU
```

物理意义：等容、无其他功时，系统吸收的热全部用来增加内能。

### 2. 等压热与焓

等压（p1 = p2 = p环）：

```
Qp = ΔU + pΔV = Δ(U + pV) = ΔH
```

**焓的定义：**

```
H ≡ U + pV
```

焓的四条性质：

1. 状态函数、容量性质，单位 J；
2. **导出函数，没有明确物理意义**，绝对值不可测；
3. 式中 p 是系统压力，**pV 不是功**；
4. 等压热等于焓变，但**不是只有等压过程才有焓变**。

对组成不变的封闭系统：H = H(T, p)，任意过程 ΔH = ΔU + Δ(pV)。

> **易错点：** "焓是等压过程中的热"——错，H 是状态函数；"Qp 和 Qv 是状态函数"——错，它们只是特定条件下数值上等于状态函数的变化量。

### 3. 热容

```
C = δQ/dT
Cv = (∂U/∂T)V         （等容，W' = 0）
Cp = (∂H/∂T)p         （等压，W' = 0）
```

摩尔热容：Cv,m = Cv/n，Cp,m = Cp/n，单位 J·mol⁻¹·K⁻¹。

简单变温过程（W' = 0）：

```
Qv = ∫(T1→T2) nCv,m dT ≈ nCv,m ΔT
Qp = ∫(T1→T2) nCp,m dT ≈ nCp,m ΔT
```

- Cp = f(T, p)：**压力影响很小**通常忽略；温度影响由经验式描述，如 Cp,m = a + bT + cT² 或 a + bT + c'T⁻²；
- 温度变化不大时，可把 Cp,m 当常数；
- 这类 Q 只由始末态和热容决定，**与过程是否可逆无关**（前提 W' = 0）。

## 七、第一定律对理想气体的应用

### 1. 理想气体

- 状态方程：pV = nRT，pVm = RT；
- 微观模型：分子是质点、分子间无相互作用力；
- 低压实际气体可近似看作理想气体。

### 2. Joule 实验：U、H 只是温度的函数

盖·吕萨克–焦耳实验：气体向真空膨胀，W = 0、Q = 0，故 ΔU = 0，温度不变。

结论（Joule 定律）：

```
(∂U/∂V)T = 0， (∂U/∂p)T = 0   →   U = f(T)
H = U + pV = U + nRT            →   H = f(T)
```

| 情形 | 结果 |
| :--- | :--- |
| 理想气体任意**等温**过程 | ΔU = 0，ΔH = 0 |
| 理想气体任意**变温**过程 | ΔU = ∫nCv,m dT，ΔH = ∫nCp,m dT |

> **注意：** 上表对理想气体的**任意物理过程**都成立——不论可逆与否、不论 pVT 怎么变。这是"状态函数 + 只与 T 有关"的直接结果，也是设计途径法的理论基础。

### 3. 理想气体的热容

```
Cp − Cv = nR          Cp,m − Cv,m = R
```

常温下：

| 气体类型 | Cv,m | Cp,m | γ = Cp,m/Cv,m |
| :--- | :--- | :--- | :--- |
| 单原子（He 等） | 3R/2 | 5R/2 | 5/3 |
| 双原子（H2 等） | 5R/2 | 7R/2 | 7/5 |

且 Cv、Cp **只是 T 的函数**（与 V、p 无关）。

### 4. 理想气体的绝热过程

一般特点：Q = 0，**ΔU = −W**；p、V、T 同时变化。

**绝热可逆过程方程**（三条等价）：

```
pV^γ = K
TV^(γ−1) = K'
T^γ p^(1−γ) = K''
```

**适用条件（四条必须同时满足）：** 理想气体、绝热、可逆、W' = 0。用途：由始态求末态。

绝热可逆功：

```
W = −ΔU = nCv,m(T1 − T2) = (p1V1 − p2V2)/(γ − 1)
```

> **重点：** **绝热不可逆过程不能用过程方程！** 只能联立
> ΔU = nCv,m(T2 − T1) = −W = −p外(V2 − V1)
> p2V2 = nRT2
> 解出 T2、V2，再算其余量。

**p–V 图：** 同一点出发，**绝热线比等温线更陡**（绝热线斜率 −γp/V，等温线 −p/V）。

### 5. 四过程对比（课件原例，务必会算）

n = 4.46 mol He(g)，T1 = 273.15 K，p1 = 1013.25 kPa，V1 = 10 dm³，膨胀到 p2 = 101.325 kPa，Cv,m = 3R/2：

| 过程 | 末态 | W / kJ | Q / kJ | ΔU / kJ | ΔH / kJ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ① 等温可逆 | V2 = 0.1 m³，T2 = 273.15 K | 23.3 | 23.3 | 0 | 0 |
| ② 恒外压等温 | V2 = 0.1 m³，T2 = 273.15 K | 9.12 | 9.12 | 0 | 0 |
| ③ 绝热可逆 | T2 ≈ 109 K | 9.15 | 0 | −9.15 | −15.0 |
| ④ 绝热恒外压 | T2 ≈ 175 K | 5.47 | 0 | −5.47 | −9.12 |

**四条结论：**

1. 同始态经**等温**可逆与等温不可逆，可以到达**同一末态**；
2. 同始态经**绝热**可逆与绝热不可逆，**到不了同一末态**；
3. 等温可逆膨胀做功（23.3 kJ）> 绝热可逆膨胀做功（9.15 kJ）；
4. 绝热可逆膨胀降温最多（109 K < 175 K）——绝热过程是"内能换功"，可逆时做功最大，温度降得最狠。

### 6. 理想气体各过程小结（W' = 0）

| 过程 | W | Q | ΔU | ΔH |
| :--- | :--- | :--- | :--- | :--- |
| 等温可逆 | nRT ln(V2/V1) | = W | 0 | 0 |
| 等温恒外压 | p外(V2 − V1) | = W | 0 | 0 |
| 等压变温 | pΔV = nRΔT | nCp,mΔT | nCv,mΔT | nCp,mΔT |
| 等容变温 | 0 | nCv,mΔT | = Qv | nCp,mΔT |
| 绝热可逆 | nCv,m(T1 − T2) | 0 | nCv,mΔT | nCp,mΔT |
| 绝热不可逆 | p外(V2 − V1) | 0 | = −W | nCp,mΔT |
| 等温自由膨胀 | 0 | 0 | 0 | 0 |

## 八、第一定律对相变过程的应用

### 1. 两类相变

- **可逆相变**：在相平衡温度与压力下进行。如 100 ℃、101.325 kPa 下水气化；任意温度下与其饱和蒸气压平衡的气化。
- **不可逆相变**：如向真空蒸发。

### 2. 相变热就是焓变

通常相变在等温、等压、W' = 0 下进行，所以相变热 = 等压热 = 相变焓：

```
Qp = ΔH = nΔ相变Hm
```

| 符号 | 含义 |
| :--- | :--- |
| ΔvapHm | 摩尔汽化焓（l → g） |
| ΔfusHm | 摩尔熔化焓（s → l） |
| ΔsubHm | 摩尔升华焓（s → g） |

逆过程焓变反号：Δg→lHm = −Δl→gHm。

### 3. 相变体积功

```
W = p外ΔV
```

- **有气相参加**：Vg ≫ Vl（Vs），W ≈ p外Vg ≈ nRT（汽化常用）；
- **无气相参加**（如熔化）：不能忽略凝聚相体积，必须用密度数据算 ΔV。

### 4. 相变焓的温度、压力依赖

1. 相变焓与 T、p 有关，但压力影响小，可忽略；
2. **正常相变点**（外压 101.325 kPa 时的沸点、熔点、晶型转化点）的相变焓可查手册；
3. **非正常相变温度**的相变焓必须**设计途径**求：如 25 ℃ 水 → 100 ℃ 水蒸气，拆成"升温 + 可逆相变 + 升温"三步。

> **例（课件例 1-3）：** 2 mol 水，25 ℃、101.325 kPa → 100 ℃ 水蒸气，求 Q、W、ΔU、ΔH。
> 思路：Q = Qp = ΔH（三步相加，气化步用 40.60 kJ/mol）；W = pΔV ≈ nRT（末态为水蒸气）；ΔU = Q − W。

## 九、热化学：第一定律对化学反应的应用

### 1. 反应进度 ξ

任意反应写成：

```
0 = Σ νB B
```

νB 为化学计量数，**反应物取负、产物取正**，无量纲，随方程式写法改变。

```
ξ = (nB − nB,0)/νB          dξ = dnB/νB
```

- 单位 mol；Δξ = 1 mol 表示"按该方程式进行了一个单位"；
- **Δξ 与选哪个物质无关，但与方程式写法有关**：3H2 + N2 = 2NH3 与 6H2 + 2N2 = 4NH3，同一变化对应的 Δξ 相差一倍。

### 2. 反应热与摩尔反应热

反应热：等温、W' = 0 时系统吸收或放出的热。

```
等温等容：Qv = ΔrU
等温等压：Qp = ΔrH
ΔrHm = ΔrH/ξ        ΔrUm = ΔrU/ξ
```

写热化学方程式必须：① 配平；② **注明各物质状态**。

### 3. ΔrHm 与 ΔrUm 的关系（Qp 与 Qv）

```
ΔrHm = ΔrUm + Σ νB(g) RT
```

- **只对气体**的化学计量数求和，凝聚相忽略；
- 低压下液、固相反应：ΔrHm ≈ ΔrUm；
- 有气体参加的低压非均相反应：只用 νB(g)。

> **例：** Ca(OH)2(s) + 2HCl(g) → CaCl2(s) + 2H2O(l)，ΣνB(g) = −2，故 ΔrHm = ΔrUm − 2RT。

### 4. Hess 定律（1840）

"一个化学反应，不论一步完成还是分几步完成，热效应相同。"

- 本质：H 是状态函数，反应热只与始末态有关；
- 用法：热化学方程式可以像代数式一样加减（**同一物质必须同一状态**）；
- **严格说只对 Qv、Qp 成立**，因为只有它们才等于状态函数的变化。

> **经典例：** C(s) + O2(g) → CO2(g)，ΔH1；CO(g) + 1/2O2(g) → CO2(g)，ΔH2；
> 则 C(s) + 1/2O2(g) → CO(g) 的 ΔH3 = ΔH1 − ΔH2。

### 5. 标准摩尔生成焓法

**定义：** 标准压力 pθ、指定温度下，由**最稳定单质**生成 1 mol 物质 B 的焓变，记 ΔfHmθ(B)。

- 标准态：g（pθ 下纯理想气体，假想态）、l（pθ 下纯液体）、s（pθ 下纯固体）；
- pθ = 101.325 kPa（课件取值）；
- **稳定单质的 ΔfHmθ = 0**：C 取石墨不取金刚石，Br2 取液态不取气态；
- 298.15 K 数据可查手册。

```
ΔrHmθ = Σ νB ΔfHmθ(B)      （产物之和 − 反应物之和）
```

### 6. 标准摩尔燃烧焓法

**定义：** 指定 T、pθ 下，1 mol 物质**完全燃烧**的焓变，记 ΔcHmθ。

完全燃烧的规定产物：

```
C → CO2(g)    H → H2O(l)    S → SO2(g)    N → N2(g)    Cl → HCl(aq)
```

```
ΔrHmθ = − Σ νB ΔcHmθ(B)
```

> **关系示例：** ΔcHmθ(C, 石墨) = ΔfHmθ(CO2, g)。

### 7. Kirchhoff 定律：反应热与温度的关系

```
微分式： (∂ΔrHm/∂T)p = ΔrCp,m
积分式： ΔrHm(T2) = ΔrHm(T1) + ∫(T1→T2) ΔrCp,m dT
其中     ΔrCp,m = Σ νB Cp,m(B)
```

- 描述等温等压化学反应的热效应对温度的依赖；
- **适用条件：** T1～T2 区间内所有物质**无相变**；
- 若 ΔrCp,m = 0，反应热与温度无关；
- 若 ΔrCp,m < 0，升温使 ΔrHm 变小：放热反应放出的热减少，吸热反应吸的热也减少。

> **思考（课件思考题 12）：** 放热反应、ΔrCp,m < 0，升温后放出的热减少——对吗？
> **不对。** ΔrHm(T2) = ΔrHm(T1) + ∫ΔrCp,m dT，T2 > T1 且 ΔrCp,m < 0，积分项为负，所以 ΔrHm 变得**更负**；放热反应 ΔrHm < 0，"更负"意味着**放热更多**。
> 若换成吸热反应（ΔrHm > 0），升温后 ΔrHm 变小，即**吸热减少**。
> 关键在于：先看 ΔrCp,m 的符号定增减方向，再结合 ΔrHm 本身的符号翻译成"吸热/放热"。

## 十、解题方法与易错点

### 1. 解题"三步曲"

1. **选系统**（气体？气体 + 容器？量热计？）
2. **定始末态**（T、p、V、n，尤其末态温度 T2）
3. **明过程**（等温/等压/等容/绝热，可逆/不可逆，恒外压）

然后：

- 算 ΔU、ΔH：利用状态函数性质，**可以设计途径**（找一条好算的可逆路径）；
- 算 W、Q：**不能设计途径**，必须按真实过程算（W 用真实 p外，Q 由 ΔU = Q − W 反推）；
- 最后用 ΔU = Q − W 交叉验算。

### 2. 常见组合

| 场景 | 处理要点 |
| :--- | :--- |
| 绝热 + 恒外压 | 联立 ΔU = −p外ΔV 与 p2V2 = nRT2 解 T2 |
| 绝热 + 自由膨胀 | Q = 0、W = 0 → ΔU = 0 → T 不变（理想气体） |
| 相变在非正常温度 | 分段设计：升温 → 可逆相变 → 降温 |
| 多组分系统 | 容量性质可加和：ΔU = ΣΔUi，ΔH = ΣΔHi |
| 反应热求另一温度 | Kirchhoff 积分式 |

### 3. 易错点清单

1. **符号**：本课程 W 以系统对外做功为正，ΔU = Q − W。
2. 体积功的被积函数是 **p外**，不是 p；只有可逆过程才能用 p 代替 p外。
3. "等温"要 T1 = T2 = T环；"等压"要 p1 = p2 = p环；"恒外压"≠ 等压。
4. 理想气体等温过程 ΔU = ΔH = 0，但 **Q、W 不一定为 0**。
5. 绝热过程 Q = 0，但 **ΔU ≠ 0**（自由膨胀除外）。
6. 绝热可逆过程方程只对"理想气体 + 绝热 + 可逆 + W' = 0"成立；**绝热不可逆禁用**。
7. 焓是状态函数，任何过程都有 ΔH；"等压热 = ΔH"只是特定条件下的数值相等。
8. 相变焓、反应焓都带符号，**吸热为正**。
9. 算 ΔrHm 前先看方程式配平系数和状态，ξ 与写法绑定。
10. Qv = ΔrU、Qp = ΔrH 只在**等温、W' = 0** 下成立。
11. 设计途径只适用于 ΔU、ΔH、ΔS 等状态函数，**不能用来算 W、Q**。
12. 标准生成焓的"最稳定单质"是石墨、液态 Br2、O2(g)，不是任意单质。

## 十二、本章关键点总结

| 主题 | 核心要点 |
| :--- | :--- |
| **系统与环境** | 开放/封闭/孤立；物化主要研究封闭系统；系统人为划定 |
| **平衡态** | 性质不随时间变 + 隔离后不再变；四平衡（热、力、相、化学）；稳态 ≠ 平衡态 |
| **状态函数** | 容量 vs 强度；只由状态决定；全微分 ∮dY = 0 |
| **热与功** | 过程量；本课程 Q吸 > 0、W系统做功 > 0 |
| **第一定律** | ΔU = Q − W；封闭、宏观静止、无外场；循环 Q = W |
| **体积功** | W = ∫p外dV；可逆时 p外 ≈ p；可逆膨胀做功最大 |
| **可逆过程** | 双复原 + 无限接近平衡 + 功热取极限；客观不存在 |
| **热** | Qv = ΔU；Qp = ΔH；H = U + pV；Cp − Cv = nR |
| **理想气体** | U、H 只看 T；绝热可逆 pV^γ = K；绝热不可逆禁用过程方程 |
| **相变** | Qp = ΔH；W ≈ nRT（有气相）；非正常温度要设计途径 |
| **热化学** | ξ、ΔrHm = ΔrUm + Σν(g)RT、Hess、生成焓、燃烧焓、Kirchhoff |

## 十三、复习自测题

1. 为什么"状态不随时间变化"不足以判定系统处于热力学平衡态？请举一个反例。
2. 同一始末态的两条不同途径，下列哪些量一定相同：Q、W、ΔU、ΔH、ΔT？为什么？
3. 体积功 W = ∫p外dV 中的 p外 能否换成系统压力 p？在什么条件下可以？为什么？
4. 为什么等温可逆膨胀系统做功最大？请从"可逆过程无限接近力平衡"的角度解释。
5. 焓 H = U + pV 有物理意义吗？"等压热等于焓变"是否意味着只有等压过程才有焓变？
6. 常温下 1 mol 单原子理想气体从 273 K、1 MPa 绝热可逆膨胀到 100 kPa，求 T2、W、ΔU、ΔH（Cv,m = 3R/2）。
7. 为什么绝热不可逆膨胀不能使用 pV^γ = 常数？应该用什么方程求解末态？
8. 2 mol 水在 25 ℃、101.325 kPa 下变为 100 ℃、101.325 kPa 的水蒸气，如何设计途径求 ΔH？W 又如何估算？
9. 已知 298.15 K 时 ΔfHmθ(CO2, g) = −393.5 kJ/mol、ΔfHmθ(CO, g) = −110.5 kJ/mol，求反应 C(s) + 1/2O2(g) → CO(g) 的 ΔrHmθ；若在等容条件下进行，Qv 与 Qp 相差多少？
10. 某反应 ΔrCp,m < 0 且为放热反应，升高温度后放出的热量如何变化？用 Kirchhoff 定律说明。

> **参考要点：** 第 2 题答 ΔU、ΔH、ΔT；第 6 题 T2 = 273 × 0.1^0.4 ≈ 109 K，W = nCv,m(T1 − T2) ≈ 2.05 kJ，ΔU = −2.05 kJ，ΔH = −3.41 kJ；第 9 题 ΔrHmθ = −110.5 kJ/mol，ΣνB(g) = 1 − 0.5 = +0.5，ΔrHm − ΔrUm = 0.5RT ≈ 1.24 kJ/mol，故 Qv = Qp − 1.24 kJ/mol；第 10 题 ΔrHm 变得更负，放热增多（"放出的热减少"是常见错误说法）。
