## Delta–Notch

| 作用 | 章节 |
|---|---|
| **体节的周期性生成**（分节钟，与 hairy 振荡偶联） | [06 §2.2](/p/dev-bio-notes-6-mesoendoderm/) |
| 果蝇卵室（egg chamber）间互作，**决定卵的前后轴** | 04、09 |
| **斑马鱼动/静脉命运**：外周感觉神经元与胶质细胞分泌 VEGF → 激活侧板中胚层 Notch → **动脉命运** | [06 §6.1](/p/dev-bio-notes-6-mesoendoderm/) |
| **神经元命运决定**：侧向抑制，使一群等价前体只产生部分神经元 | [05 §6.4](/p/dev-bio-notes-5-neural-development/) |

## BMP

| 作用 | 章节 |
|---|---|
| **爪蛙腹部化信号**，与背部化信号互作决定中胚层背腹分化 | [03 §6.7](/p/dev-bio-notes-3-gastrulation/) |
| **诱导外胚层向表皮分化**（抑制神经命运）→ 神经诱导"默认模型" | [05 §3.2](/p/dev-bio-notes-5-neural-development/) |
| **促进骨生成**（膜内成骨：头部表皮产生 BMP2/4/7 → 神经嵴间质 → CBFA1/Runx2 → osteocalcin/osteopontin） | [06 §3.2](/p/dev-bio-notes-6-mesoendoderm/) |
| **促进趾间细胞凋亡**（趾分离）；后期促进间质→软骨 | [07 §七](/p/dev-bio-notes-7-limb-development/) |
| **哺乳动物 PGC 由 BMP4 诱导**（诱导型生殖细胞） | [09 §7.2](/p/dev-bio-notes-9-sex-determination-germline/) |
| 背侧神经管高 BMP → 感觉神经元、背侧中间神经元 | [05 §6.2](/p/dev-bio-notes-5-neural-development/) |

**拮抗者**：Chordin、Noggin、Follistatin（组织者分泌）、**Gremlin**（鸭趾间）、ADMP（反向调节）

## FGF

| 作用 | 章节 |
|---|---|
| **抑制骺生长板软骨细胞增生、促进分化** → FGFR 组成型激活 → **侏儒症** | [06 §3.2](/p/dev-bio-notes-6-mesoendoderm/)、[10 §3.4](/p/dev-bio-notes-10-postembryonic-ageing/) |
| 生骨区在生肌区释放的 **Fgf8** 诱导下形成**生腱区** | [06 §2.3](/p/dev-bio-notes-6-mesoendoderm/) |
| **FGF10** 诱导肢芽；**FGF8** 在 AER 表达是肢芽形成所必需 | [07 §3.4](/p/dev-bio-notes-7-limb-development/) |
| 内胚层前部 **Fgf8** 诱导心脏发育 | [06 §5.2](/p/dev-bio-notes-6-mesoendoderm/) |
| 海胆原肠作用中调控 **PMC 迁移、骨与小肠形成** | [03 §四](/p/dev-bio-notes-3-gastrulation/) |
| **后部化信号**（与 Wnt、RA 一起）使神经板后部化 | [05 §4.2](/p/dev-bio-notes-5-neural-development/) |
| 肢体再生：芽基的促增殖与**远端化** | [08 §5.1](/p/dev-bio-notes-8-regeneration/) |

## Ephrin / Eph

| 作用 | 章节 |
|---|---|
| 不同类型**毛细血管丛内皮细胞分类聚集**（动脉 EphrinB2 / 静脉 EphB4） | [06 §6.1](/p/dev-bio-notes-6-mesoendoderm/) |
| **体节边界**确立（EphA4 / ephrinB2） | [06 §2.2](/p/dev-bio-notes-6-mesoendoderm/) |
| **体节生骨区后部的 Ephrin 排斥运动神经元轴突** → 只从体节前半部穿过 | [05 §7.2](/p/dev-bio-notes-5-neural-development/)、[09 §8.3](/p/dev-bio-notes-9-sex-determination-germline/) |
| 神经嵴细胞也只从体节**前半部**迁移 | [05 §8.3](/p/dev-bio-notes-5-neural-development/) |
| 视网膜 **EphA3** 梯度 × 顶盖 Ephrin 梯度 → 拓扑投射（化学亲和性） | [05 §7.2](/p/dev-bio-notes-5-neural-development/) |

## Shh

| 作用 | 章节 |
|---|---|
| **ZPA 的关键信号**，决定肢体 **A–P 轴极性**；表达异常 → **多指（趾）症** | [07 §5.2](/p/dev-bio-notes-7-limb-development/) |
| 由**脊索与底板**分泌，沿脊髓 **D–V 轴由低到高**梯度；**高浓度诱导运动神经元** | [05 §6.2](/p/dev-bio-notes-5-neural-development/) |
| **诱导体节生骨区形成** | [06 §2.3](/p/dev-bio-notes-6-mesoendoderm/) |
| 锚定神经板中线细胞，启动**神经褶**形成；Shh 是神经管闭合所必需 | [05 §5.2](/p/dev-bio-notes-5-neural-development/) |
| 蛇/蟒肢体退化：**Shh 弱表达** → AER 过早退化 | [07 §八](/p/dev-bio-notes-7-limb-development/) |

**拮抗者**：Hhip；**下游**：Gli（激活/抑制双功能）

## RA（视黄酸）

| 作用 | 章节 |
|---|---|
| **诱导肢体形成**；决定 Tbx5/Tbx4 表达域（前低后高） | [07 §3.3](/p/dev-bio-notes-7-limb-development/) |
| **使再生芽基近端化** → 长出重复的近端结构 | [08 §5.1](/p/dev-bio-notes-8-regeneration/) |

| **后部化信号**之一（与 FGF、Wnt 一起） | [05 §4.2](/p/dev-bio-notes-5-neural-development/) |

## β-catenin / Wnt

| 作用 | 章节 |
|---|---|
| **海胆、爪蟾、斑马鱼的胚胎组织者均依赖母源 β-catenin 入核** | [03 §4.3、§6.5](/p/dev-bio-notes-3-gastrulation/) |
| 经典 Wnt：**背部组织者形成、神经诱导、神经外胚层分化、促增殖** | [01 §九](/p/dev-bio-notes-1-introduction/) |
| 非经典 Wnt：**促进细胞运动**（原肠运动） | [01 §九](/p/dev-bio-notes-1-introduction/) |
| **Wnt3a + Nodal 诱导小鼠原条**；AVE 分泌 Dkk1/Cerberus 抑制近端 Wnt → 定前极 | [03 §9.2–9.3](/p/dev-bio-notes-3-gastrulation/) |
| **Wnt7a → Lmx1b** 决定肢体**背腹轴**；敲除 → 双腹侧 | [07 §六](/p/dev-bio-notes-7-limb-development/) |
| 血管发生、造血干细胞维持 | [06 §六](/p/dev-bio-notes-6-mesoendoderm/) |
| **水螅头部诱导因子**；涡虫后部化；尾鳍再生 | [08 §4.2、§5.2](/p/dev-bio-notes-8-regeneration/) |
| 器官大小（与 Hippo/YAP 交互） | [10 §3.3](/p/dev-bio-notes-10-postembryonic-ageing/) |

## 一句话总结每个信号的"身份"

| 信号 | 一句话 |
|---|---|
| **Wnt/β-catenin** | 背部、增殖、运动、再生 |
| **Nodal** | 中内胚层、左侧 |
| **BMP** | 表皮化、腹侧化、成骨、凋亡 |
| **FGF** | 生长、远端化、肢芽、侏儒 |
| **Shh** | 腹侧化、生骨、ZPA、运动神经元 |
| **Notch/Delta** | 侧向抑制、分节、动静脉 |
| **Ephrin/Eph** | 排斥、边界、拓扑投射 |
| **RA** | 后部化、近端化、减数分裂启动 |
